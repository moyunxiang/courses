Formula Sheet

1 · Simple RNN (6-rnn)

  • Feedforward: output depends only on the current input. Sequences (video, translation, speech) need feedback: the state keeps the important aspects of the past.
  • Unfolding = copies of the same network, each passing its state on. The same weights are used at every time step.
ht=fW(ht−1,xt)ht=tanh⁡(Whhht−1+Wxhxt),yt=Whyht
  • BPTT: backprop on the unrolled computation graph (loss at every step, L=∑tLt). Shared weights, so the gradient of Whh is the sum of its contributions over all time steps.
  • Backward signal is multiplied by the same Whh at every step:
∂ht∂ht−1=diag⁡(1−ht2) Whh⇒∂hT∂h0=∏t=1Tdiag⁡(1−ht2) Whh
Problem Telephone game Effect Fix (slides)
vanishing gradients everyone mumbles a little learning very slow or stops LSTM (cell state)
exploding gradients everyone exaggerates a little numerical instability (NaN loss) gradient clipping
  • Simple RNN does not work well for long sequences.

2 · LSTM (6-rnn)

C~t=tanh⁡(WC[ht−1,xt]+bC)(candidate)it=σ(Wi[ht−1,xt]+bi)(input gate: write to cell?)ft=σ(Wf[ht−1,xt]+bf)(forget gate: erase cell?)ot=σ(Wo[ht−1,xt]+bo)(output gate: let the cell affect others?)Ct=ft⊙Ct−1+it⊙C~t,ht=ot⊙tanh⁡(Ct)
  • ⊙ = elementwise product. Gates use σ∈(0,1); candidate and output use tanh⁡.
  • Cell state lets gradients flow straight back without being repeatedly squashed by nonlinearities or multiplied by the weight matrices. Information stays while the forget gate is on.
  • Gradient clipping (for exploding gradients): 𝐠←c 𝐠∥𝐠∥ if ∥𝐠∥>c (keeps the direction, caps the norm).
  • Stacked RNN: depth in space (RNN is already "deep" through time). Lower layers = local dynamics, higher = abstractions. Rarely more than 2–4 layers (cost, gradient instability).
  • Applications: image captioning (CNN features → LSTM → words); activity recognition (images → activity); machine translation (words → words).

3 · Transformer (7-xformer)

  • Encoder: input embedding + positional encoding → multi-head self-attention → add & norm → MLP (feed-forward) → add & norm. Decoder: masked self-attention, cross-attention, feed-forward.
  • Motivation: "The chicken didn't cross the road because it was too tired / wide." A word's meaning depends on context → contextual embedding, computed by attention (a word attends to some words more than others).
  • Self-attention relates positions of a single sequence. In the slides it is left-to-right: ai uses x1,…,xi only.
simplified:score(xi,xj)=xi⋅xj,αij=softmax⁡j(score), j≤i,ai=∑j≤iαijxjactual head:qi=xiWQ, kj=xjWK, vj=xjWVscore(xi,xj)=qi⋅kjdk,ai=∑j≤iαijvj
Role Meaning
query qi current element, compared with the preceding inputs
key kj preceding input, compared with the current element to get a similarity
value vj value of a preceding element, weighted and summed

Why divide by dk (components i.i.d., mean 0, variance 1):

S=q⋅k=∑i=1dqiki,E[S]=∑iE[qi]E[ki]=0Var⁡(qiki)=E[qi2]E[ki2]−0=1 ⇒ Var⁡(S)=dVar⁡ ⁣(S/d)=1d⋅d=1
  • Unscaled: large variance → the largest logit dominates the softmax (pk≈1, others ≈0) → ∂pk∂zj=pk(δkj−pj)≈0 in every case → vanishing gradients. Scaling keeps the logits at variance 1, so gradients stay non-zero.

Multi-head attention (h heads in parallel; each can capture different relations):

qic=xiWQ,c, kjc=xjWK,c, vjc=xjWV,c,WQ,c,WK,c∈ℝd×dk, WV,c∈ℝd×dvheadic=∑j≤iαijcvjc,ai=(headi1⊕⋯⊕headih)WO,WO∈ℝhdv×d
  • Residual connection: output x+F(x); makes very deep networks easier to train.
  • Cross-attention: uses the encoder output as input (decoder gives the query; encoder gives key and value).
  • Positional encoding: an RNN processes tokens one by one; a transformer processes all tokens simultaneously, so position must be added to the embedding.
PE(pos,2i)=sin⁡ ⁣(pos100002i/dmodel),PE(pos,2i+1)=cos⁡ ⁣(pos100002i/dmodel),i=0,…,dmodel2−1

(even indices sine, odd indices cosine; i indexes the sine/cosine pair)

4 · Clustering & k-means (8-kmeans)

  • Clustering: high similarity within a cluster, dissimilar across clusters; no class attribute → unsupervised (labels are costly). Uses: customer groups, taxonomies, houses by type/location, outlier (fraud) detection.
Measure Formula Note
Euclidean ∑i(x1i−x2i)2 dissimilarity, min 0
Manhattan ∑i∣x1i−x2i∣ dissimilarity
cosine 𝐱1⋅𝐱2∥𝐱1∥∥𝐱2∥ similarity; slide example 0.31
SMC (binary) f11+f00f00+f01+f10+f11=f11+f00d slide example 0.7
  • Standardize attributes if their scales differ a lot.
  • k-means: (1) pick k random points as initial means; (2) assign each point to the closest mean; (3) recompute each mean ci=1Ni∑x∈Cix; (4) repeat until the means stop changing.
SSE=∑i=1k∑x∈Ci∥x−ci∥2
  • Boundaries = Voronoi diagram: piecewise linear (perpendicular bisectors).
  • Random init → local minimum; different starts give different answers. Fix: multiple restarts + keep the smallest SSE (wasteful), or k-means++: first center uniform; each next center with probability ∝D(x)2 (squared distance to the nearest chosen center); then run k-means. E[SSE(T)]≤O(log⁡k) SSE(T∗). Default in scikit-learn.
  • Choose k: elbow method (plot SSE for k=1..kmax⁡, look where the drop flattens).
  • Implicit assumption on cluster shape (compact, roughly spherical); other shapes give wrong results.

5 · PCA & autoencoders (8-pca)

  • Why preprocess: irrelevant features; correlated features repeat information. Feature extraction maps to a (usually lower-dim) space; unsupervised = uses inputs only, no targets.
𝐦=1n∑k𝐱k,S=∑k=1n(𝐱k−𝐦)(𝐱k−𝐦)t (scatter matrix)max⁡𝐰 𝐰tS𝐰  s.t. ∥𝐰∥=1 ⇒ S𝐰=λ𝐰,𝐰tS𝐰=λ
  • Best 0-D representation = sample mean 𝐦. Best 1-D: line 𝐱=𝐦+a𝐰 with ak=𝐰t(𝐱k−𝐦) (projection), and J1(𝐰)=−𝐰tS𝐰+∑k∥𝐱k−𝐦∥2, so minimizing error = maximizing 𝐰tS𝐰.
  • Best direction = eigenvector of the largest eigenvalue; n-th best = eigenvector of the n-th largest eigenvalue (orthogonal to the earlier ones).
  • Not scale-invariant (mph vs number of seats → PC ≈ speed axis). Normalize each feature first: x~kj=(xkj−mj)/σj.
  • Choose k: proportion of variance explained λ1+⋯+λkλ1+⋯+λd, e.g. stop when >0.9.
  • Limitations: (1) PCA is linear (curve with intrinsic dimension 1 in 2-D); (2) max variance may be within classes, so projecting can destroy class separation.
  • Autoencoder: 𝐳=f(W𝐱), 𝐱^=g(V𝐳), bottleneck M<D, minimize ∑n∥𝐱(n)−𝐱^(n)∥2.
    • Linear f,g → same subspace as PCA (axes need not be orthogonal).
    • Deep (nonlinear) → nonlinear manifold, can beat PCA.
    • Denoising: input 𝐱~=𝐱+ϵ (or masked pixels), reconstruct the clean 𝐱 → more robust features.

6 · GAN (8-gan)

  • Generative model: learn the data distribution and generate new samples.
  • Generator G(z): noise z∼p(z) (normal / uniform) → deep net; tune θ so the output distribution matches the data. Discriminator D(x): 1 = real, 0 = fake. Cat-and-mouse game.
min⁡Gmax⁡DV(D,G)=Ex∼pdatalog⁡D(x)+Ezlog⁡(1−D(G(z)))J(D)=V (D maximizes=minimizes CE),J(G)=−J(D)DG∗(x)=pdata(x)pdata(x)+pg(x)
  • Solved by alternating optimization. When pg=pdata, D∗=12 everywhere (random guessing). After training, keep only G to generate samples (new faces, image editing).

N · Short concept answers.

  • Why LSTM over RNN: additive cell update + gates → gradient flows through Ct → handles long sequences.
  • Why positional encoding: attention is order-free; tokens processed in parallel.
  • Why multi-head: different heads attend to different relations (syntax, semantics).
  • Why k-means++: spread-out seeds, outliers less dominant, O(log⁡k) guarantee.
  • When PCA hurts classification: largest variance is within-class, not between-class.

Common Mistakes

  • RNN: the same Whh,Wxh at every step; BPTT adds the gradient contributions over time.
  • LSTM: ht=ot⊙tanh⁡(Ct), not ot⊙Ct; gates are sigmoid, candidate is tanh; Ct update is additive.
  • Clipping fixes exploding gradients only, and rescales the whole vector (direction kept); only when ∥𝐠∥>c.
  • Attention: divide by dk, not dk; softmax over j≤i only (left-to-right); weighted sum of values, not keys.
  • WO is hdv×d; concatenation comes before WO.
  • PE: sine for even, cosine for odd indices; the exponent uses 2i, so dims 2i and 2i+1 share a frequency.
  • k-means: assign all points first, then recompute means; converges to a local minimum; SMC counts 0–0 matches too (f00 is in the numerator).
  • k-means++ uses D(x)2, not D(x).
  • PCA: center (and usually standardize) first; pick the largest eigenvalue; scores are 𝐰t(𝐱−𝐦), not 𝐰t𝐱.
  • GAN: D maximizes V, G minimizes; D∗=pdatapdata+pg (not pg on top).
