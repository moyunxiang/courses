2. Short Answer

(1) Average access time; locality

Compute Tavg with h=0.9, Thit=2 ns, Tmiss=50 ns (Ch. 1, slide 1.32).

Tavg=h⋅Thit+(1−h)⋅Tmiss=0.9×2+0.1×50=1.8+5.0
Tavg=6.8 ns
Locality Definition Example: for (i = 0; i < n; i++) sum += a[i];
Temporal address x accessed at t ⇒ x likely accessed again at t+Δ i, sum, loop-body instructions reused every iteration
Spatial address x accessed ⇒ x±δ likely accessed soon a[0], a[1], a[2], … consecutive; one cache line serves several accesses

(2) Multiprogramming vs. time sharing

  • Multiprogramming (Ch. 1, slide 1.42): ≥2 jobs in memory; running job waits for I/O ⇒ CPU switches to another ready job.
    CPU idle  ⟺  no job ready ⇒ utilization↑
  • Time sharing adds:
Feature Multiprogramming Time sharing
Switch trigger job blocks (I/O) also timer interrupt every time slice q (preemption)
Switch frequency low high (q small)
Goal CPU utilization response time <∼1 s ⇒ interactive
OS support needed job scheduling CPU scheduling + swapping / virtual memory

(4) read(): user → kernel → user

Step Action Mode bit
1. Trap wrapper puts syscall no. + (fd, buf, count) in registers/stack; executes syscall; HW jumps via trap vector 1→0
2. Service syscall table[no.] → sys_read; validate args; do I/O (may block); copy data → buf 0
3. Return return value (bytes read, or −1) → register; return-from-trap; resume after the call 0→1

(5) Parent → child through an ordinary pipe

pipe(fd) ≺ fork()(fd[0]=read end, fd[1]=write end)
Step Parent (writer) Child (reader)
1 pipe(fd) —
2 fork() inherits fd[0], fd[1] (same pipe)
3 close(fd[0]) close(fd[1])
4 write(fd[1], …) read(fd[0], …)
5 close(fd[1]) close(fd[0])
  • pipe() after fork() ⇒ two unrelated pipes (not shared).
  • read() returns 0 (EOF)   ⟺   all write ends closed ⇒ child must close fd[1] or it may block forever.
  • Ordinary pipe is unidirectional ⇒ data flows parent → child only.

3. Simple C Programs on fork

(1) Two children

(a) Values of x

fork() copies the address space at the moment of the fork; later writes are private.

P: x=1C1 (copy of x=1): x=1+2=3P: x=1×2=2C2 (copy of x=2): x=2+3=5P: x=2 (unchanged)
C1: 3,C2: 5,P: 2
  • Values differ: separate copies; C1 forked at x=1, C2 forked at x=2.

(b) All possible output sequences

C1≺P,  C2≺P(P prints after two waits),C1∥C2  (no sync)
#sequences=2!×1=2
# Output
1 C1: 3 → C2: 5 → P: 2
2 C2: 5 → C1: 3 → P: 2

(c) First wait(NULL) moved before x *= 2

C1 prints≺C1 exits≺wait returns≺x *= 2≺fork()C2≺C2 prints≺wait≺P prints
C1: 3 → C2: 5 → P: 2 (only order)
  • Values unchanged: C1 still copies x=1, C2 still copies x=2, P still ends at x=2.

(2) execlp with two levels of fork

(a) Processes and tree

#processes=1 (P)+1 (P’s fork)+1 (C’s fork)=3,execlp adds 0
3 processes
P            prints A, P; wait(C); prints D
└── C        (p == 0) fork G; wait(G); prints C
    └── G    (q == 0) execlp("./worker") -> runs worker, prints W

(b) Is X printed?

  • No. execlp succeeds ⇒ G's code/data/stack replaced by worker ⇒ never returns ⇒ printf("X\n") unreachable.

(c) All possible output sequences

A≺fork()(printed once; buffer flushed before fork)W≺G exits≺C’s wait≺C⇒W≺CC≺C exits≺P’s wait≺D⇒C≺DP≺wait≺D⇒P≺DP∥{W,C}(no constraint)
A {P} interleaved into (W,C)⏟3 slots D ⇒ 3 sequences
# Output
1 A P W C D
2 A W P C D

(3) Sending an integer through a pipe

(a) Ends closed / used

Process Closes Uses Action
Parent fd[0] (read) fd[1] (write) write n=6
Child fd[1] (write) fd[0] (read) read n=6
direction: parent→ fd[1] → fd[0] child(pipe≺fork⇒shared pipe)

(b) Exact output and order

n⋅2=6×2=12
Child: 12
Parent: done
read blocks until 4 bytes arrive⇒n=6;Child prints≺child exits≺wait(NULL)≺Parent prints

(c) pipe(fd) called separately after fork()

  • No. Each pipe() creates a new kernel pipe; descriptors shared only if created before fork() ⇒ pipeP≠pipeC, not connected.
Process What happens
Child closes write end of pipeC ⇒ no writer ⇒ read returns 0 (EOF); n uninitialized ⇒ garbage printed
Parent closes read end of pipeP ⇒ write with no reader ⇒ SIGPIPE ⇒ killed; Parent: done never printed (if ignored: write =−1, EPIPE)

from itertools import permutations
print(0.9*2 + 0.1*50)          # 6.8
def seqs(items, before):
    return [p for p in permutations(items)
            if all(p.index(a) < p.index(b) for a, b in before)]
print(seqs(["C1","C2","P"], [("C1","P"),("C2","P")]))   # 2 sequences
