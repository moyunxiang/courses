1 · Markov Processes

1.1 Markov property

Definition. A state st is Markov iff p(st+1∣st)=p(st+1∣s1,s2,…,st)

  • state 包含 history 中所有相关信息；知道 state 后，history 可以丢掉
  • state 是未来的 sufficient statistic

1.2 Markov process 与转移矩阵

Markov process 是 memoryless 的随机过程：一串满足 Markov property 的随机 state s1,s2,…

Definition. A Markov Process（Markov Chain） is a tuple ⟨𝒮,𝒫⟩：

  • 𝒮：（有限）state 集合
  • 𝒫：state transition probability matrix，𝒫ss′=p(s′∣s)=p(st+1=s′∣st=s)
𝒫=(p(s1∣s1)p(s2∣s1)⋯p(sN∣s1)⋮⋮p(s1∣sN)⋯⋯p(sN∣sN))

第 i 行 = 从 si 出发的分布，所以每一行加起来是 1。

1.3 例：Student Markov Chain

from \ to C1 C2 C3 Pass Pub FB Sleep
C1 0.5 0.5
C2 0.8 0.2
C3 0.6 0.4
Pass 1.0
Pub 0.2 0.4 0.4
FB 0.1 0.9
Sleep 1.0
  • 每行和为 1；Sleep 是 terminal（absorbing）state（进去就出不来）

从 s1=C1 开始的 sample episodes：

  • C1 C2 C3 Pass Sleep
  • C1 FB FB C1 C2 Sleep
  • C1 C2 C3 Pub C2 C3 Pass Sleep
  • C1 FB FB C1 C2 C3 Pub C1 FB FB FB C1 C2 C3 Pub C2 Sleep

1.4 Episodic vs Continuing tasks

Episodic Continuing
含义 交互自然地分成一段段 episode（结束时评判 reward） 没有自然的 episode，一直进行下去（就像现实生活）
例子 一局游戏、走一趟迷宫
Return 一般用简单总和 Gt=rt+rt+1+⋯+rT（T = 到达 terminal 的时刻） 一般用 discounted 总和 Gt=∑k=0∞γkrt+k

2 · Markov Reward Processes

2.1 定义

MRP = Markov chain + values（rewards）

Definition. A Markov Reward Process is a tuple ⟨𝒮,𝒫,r,γ⟩：

  • 𝒮：（有限）state 集合
  • 𝒫：转移矩阵，𝒫ss′=p(st+1=s′∣st=s)
  • r：reward function，rt=r(st=s)=𝔼[ri∣st=s]
  • γ：discount factor，γ∈[0,1]

Student MRP 的 reward：C1 = C2 = C3 = −2，Pass = +10，Pub = +1，FB = −1，Sleep = 0。

2.2 Horizon 与 Return

  • Horizon：每个 episode 最多多少步；可以无穷，否则叫 finite Markov (reward) process

Definition. The return Gt is the total discounted reward from time step t：

Gt=rt+γrt+1+⋯=∑k=0∞γkrt+k

  • γ∈[0,1] 是未来 reward 的「现值」：k 步之后收到的 reward r 只值 γkr
  • γ→0：myopic（短视）评价；γ→1：far-sighted（远见）评价

2.3 为什么要 discount

  • 避免有环的 Markov process 中 return 无穷大
  • 如果所有序列都会终止，也可以用 undiscounted（γ=1）
  • 数学上方便
  • 对未来的不确定性可能没有被完全表示出来（打折是一种保守）

2.4 Value function

Definition. The state value function V(s) of an MRP is the expected return starting from state s：

V(s)=𝔼[Gt∣st=s]

  • Gt 是一条具体路径的回报（随机变量）；V(s) 是它的期望（一个数）

2.5 Sample returns（计算题）

2.7 Bellman equation for MRP（核心推导）

value function 可以分成两部分：immediate reward rt + 后继 state 的 discounted value γV(st+1)：

V(s)=𝔼[Gt∣st=s]=𝔼[rt+γrt+1+γ2rt+2+⋯∣st=s]=𝔼[rt+γ(rt+1+γrt+2+⋯ )∣st=s]=𝔼[rt+γGt+1∣st=s]=𝔼[rt+γV(st+1)∣st=s]

（最后一步：𝔼[Gt+1∣st+1]=V(st+1)，再用全期望公式。）

Backup diagram 形式（从 s 往下看一步）：

V(s)=r(s)⏟immediate reward+γ∑s′p(s′∣s)V(s′)⏟discounted sum of future reward

例（γ=1）：C3 的 value

4.3=−2⏟r(C3)+0.6⋅10⏟V(Pass)+0.4⋅0.8⏟V(Pub)

2.8 矩阵形式与闭式解

Q：能不能一次把所有 value 都算出来？ 把每个 state 的 Bellman equation 摞起来：

(V(s1)⋮V(sN))=(r(s1)⋮r(sN))+γ(p(s1∣s1)⋯p(sN∣s1)⋮⋮p(s1∣sN)⋯p(sN∣sN))(V(s1)⋮V(sN))
V=r+γ𝒫V

线性方程，直接解：

V=r+γ𝒫V(I−γ𝒫)V=rV=(I−γ𝒫)−1r
  • 计算复杂度 O(N3)（N 个 state，矩阵求逆）
  • 只适用于小的 MRP
  • 大 MRP 用迭代方法：dynamic programming、Monte-Carlo evaluation、temporal-difference learning（1.4、2.1）

3 · Markov Decision Processes

3.1 定义

MDP = MRP + decisions（actions）；所有 state 都是 Markov 的环境。

Definition. A Markov Decision Process is a tuple ⟨𝒮,𝒜,𝒫,r,γ⟩：

  • 𝒮：（有限）state 集合
  • 𝒜：（有限）action 集合
  • 𝒫：转移概率，𝒫ss′a=p(s′∣s,a)=p(st+1=s′∣st=s,at=a)
  • r：reward function，rt=r(st=s,at=a)=𝔼[ri∣st=s,at=a]
  • γ∈[0,1]

和 MRP 的区别：转移和 reward 都多了一个 a。

Alternative definition：⟨𝒮,𝒜,𝒫,γ⟩，其中 𝒫 是 reward 和下一 state 的联合概率：

𝒫(r,s′∣s,a)=p(st+1=s′,rt=r∣st=s,at=a)
  • 𝒫 定义了问题的 dynamics
  • 两种定义等价（没有额外假设）：
p(s′∣s,a)=∑rp(s′,r∣s,a)r(s,a)=∑rr∑s′p(s′,r∣s,a)

3.2 例：Student MDP

state action reward 去哪
C1 Facebook −1 FB
C1 Study −2 C2
FB Facebook −1 FB
FB Quit 0 C1
C2 Sleep 0 Sleep（terminal）
C2 Study −2 C3
C3 Study +10 Sleep
C3 Pub +1 0.2 → C1，0.4 → C2，0.4 → C3（随机）

（只有 Pub 是随机转移，其余确定。）

3.3 Policy

Definition. A policy π is a distribution over actions given states：

π(a∣s)=p(at=a∣st=s)

  • policy 完全定义了 agent 的行为（每个 state 采取什么 action）
  • MDP 的 policy 只依赖当前 state（不依赖 history）——因为 state 是 Markov 的
  • policy 是 stationary（与时间无关）：at∼π(a∣s) 对任意 t>0
  • 特例：deterministic policy π(s) = 在 s 以概率 1 采取的 action

3.4 给定 policy：MDP → MP → MRP

给定 MDP ⟨𝒮,𝒜,𝒫,r,γ⟩ 和 policy π：

  • MDP → MP：state 序列 s1,s2,… 是 Markov process ⟨𝒮,𝒫π⟩
  • MDP → MRP：s1,r1,s2,r2,… 是 MRP ⟨𝒮,𝒫π,rπ,γ⟩，其中
pπ(s′∣s)=∑a∈𝒜π(a∣s) p(s′∣s,a)rπ(s)=∑a∈𝒜π(a∣s) r(s,a)

直觉：policy 固定后，「选 action」这一步被平均掉了，剩下的就是一个 MRP——所以 MRP 的所有工具（Bellman equation、闭式解）都能用来评估 policy。

3.5 两个 value function

State-value function：从 s 出发、按 π 行动的期望 return

Vπ(s)=𝔼π[Gt∣st=s]

Action-value function：从 s 出发、先做 a、之后按 π 行动的期望 return

Qπ(s,a)=𝔼π[Gt∣st=s,at=a]

  • value function 体现了 agent 关于「每个 state 对目标有多好」的知识（Horde, AAMAS 2011：knowledge 可表示为并行学习的大量近似 value function）

V 与 Q 的关系（必背）：

Vπ(s)=∑a∈𝒜π(a∣s) Qπ(s,a)

（站在 state 上：按 policy 对各 action 的 Q 加权平均）

Qπ(s,a)=r(s,a)+γ∑s′∈𝒮p(s′∣s,a) Vπ(s′)

（做了 a 之后：拿到即时 reward，再按转移概率对下一 state 的 V 加权平均、打折）

3.6 Bellman Expectation Equation

期望形式：

Vπ(s)=𝔼π[rt+γVπ(st+1)∣st=s]Qπ(s,a)=𝔼π[rt+γQπ(st+1,at+1)∣st=s,at=a]

展开形式（把 3.5 的两式互相代入）：

Vπ(s)=∑a∈𝒜π(a∣s)(r(s,a)+γ∑s′∈𝒮p(s′∣s,a)Vπ(s′))
Qπ(s,a)=r(s,a)+γ∑s′∈𝒮p(s′∣s,a)∑a′∈𝒜π(a′∣s′)Qπ(s′,a′)

Backup diagram：

  • Vπ：s（空心圆）→ 按 π 分到各个 a（实心点）→ 每个 a 按 p 分到各个 s′
  • Qπ：(s,a) → 按 p 到 s′ → 按 π 到 a′

Theorem. 对任意 MDP 和任意 policy π，value functions 满足上面的 expectation equations。

3.7 例：Student MDP，uniform random policy（γ=1）

每个 state 两个 action 各 0.5。结果：Vπ：C1 = −1.3，C2 = 2.7，C3 = 7.4，FB = −2.3，Sleep = 0。

验证 C3：

Vπ(C3)=0.5⋅(1+0.2⋅(−1.3)+0.4⋅2.7+0.4⋅7.4)⏟Pub+0.5⋅10⏟Study=0.5⋅4.78+5≈7.4

⚠️ 课件这一行印成「0.4∗2.7∗7.4」，中间应为 +0.4∗7.4（第三个分支是以 0.4 留在 C3）。

3.8 矩阵形式

用 induced MRP：

Vπ=rπ+γ𝒫πVπ⇒Vπ=(I−γ𝒫π)−1rπ

4 · Optimal Policies 与 Optimal Value Functions

4.1 定义

  • Optimal state-value function：V∗(s)=max⁡πVπ(s)
  • Optimal action-value function：Q∗(s,a)=max⁡πQπ(s,a)
  • optimal value function 给出 MDP 中可能达到的最好表现
  • 知道了 optimal value function，MDP 就「solved」了

Student MDP（γ=1）：

C1 C2 C3 FB Sleep
V∗ 6 8 10 6 0
Q∗ 值
C1, Facebook 5
C1, Study 6
FB, Facebook 5
FB, Quit 6
C2, Sleep 0
C2, Study 8
C3, Study 10
C3, Pub 9.4

Q：Q∗ 和 V∗ 的关系？ —— V∗(s)=max⁡aQ∗(s,a)（每个 state 的 V∗ 就是该 state 最大的 Q∗）。

验算 C3, Pub：1+0.2⋅6+0.4⋅8+0.4⋅10=1+1.2+3.2+4=9.4 ✓

4.2 Optimal policy

Policy 的偏序：

π≥π′if Vπ(s)≥Vπ′(s), ∀s

Corollaries. 对任意 MDP：

  • 存在至少一个 optimal policy π∗，比所有其他 policy 好或一样好：π∗≥π，∀π
  • 也就是说，optimal policy 可能有多个
  • 所有 optimal policy 都达到 optimal value function：Vπ∗(s)=V∗(s)
  • 所有 optimal policy 都达到 optimal action-value function：Qπ∗(s,a)=Q∗(s,a)

注意：偏序要求每个 state 都不差，所以一般两个 policy 可能比不出大小；但上面的结论保证存在一个对所有 state 同时最好的 policy。

4.3 怎样找 optimal policy

已知 Q∗：

π∗(a∣s)={1,if a=arg⁡max⁡a∈𝒜Q∗(s,a)0,otherwise
  • 任何 MDP 都存在 deterministic optimal policy
  • 知道 Q∗ 就直接有 optimal policy，不需要 dynamics！
  • 若多个 action 都使 Q∗(s,⋅) 最大，任选（也可以随机选）

已知 V∗：要用 model dynamics 做 one step look ahead：

π∗(a∣s)={1,if a=arg⁡max⁡a∈𝒜∑s′,rp(s′,r∣s,a)(r+γV∗(s′))0,otherwise
  • 只知道 V∗ 时，需要 dynamics 才能选出最优 action

为什么有这个区别？ Q∗(s,a) 已经把「做 a 之后会怎样」算进去了；V∗ 只告诉你每个 state 有多好，要知道每个 action 会把你带到哪些 state（p），才能比较 action。→ 这也是为什么 model-free control 学的是 Q 而不是 V（2.2）。

Student MDP 的 optimal policy：C1 → Study，FB → Quit，C2 → Study，C3 → Study。

4.4 Policy search

  • 一种办法是枚举所有 policy
  • Deterministic policy 的个数是 ∣𝒜∣∣𝒮∣（每个 state 独立选一个 action）
  • policy iteration、value iteration 更高效（1.4）

4.5 Prediction vs Control

State values Action values
Prediction（policy evaluation） Vπ Qπ
Control（policy optimization） V∗ Q∗
  • Problem 1：Prediction —— 给定 policy，期望 return 是多少？
  • Problem 2：Control —— 最好的行为方式是什么？optimal value function 是什么？

4.6 Bellman Optimality Equations

回顾 expectation equation（对任意 π）：见 3.6。

Theorem. 对 MDP ⟨𝒮,𝒜,𝒫,r,γ⟩，optimal value functions 满足：

V∗(s)=max⁡a[r(s,a)+γ∑s′∈𝒮p(s′∣s,a)V∗(s′)]
Q∗(s,a)=r(s,a)+γ∑s′∈𝒮p(s′∣s,a)max⁡a′∈𝒜Q∗(s′,a′)

直觉理解：optimal policy 是对 Q∗ 取 argmax 的 deterministic policy。把它代入 Bellman expectation equation，「按 π∗ 对 a′ 加权平均」就变成「取 max」：

Q∗(s,a)=r(s,a)+γ∑s′p(s′∣s,a)∑a′π∗(a′∣s′)Q∗(s′,a′)=r(s,a)+γ∑s′p(s′∣s,a)max⁡a′∈𝒜Q∗(s′,a′)

两个关系式（和 3.5 对应，平均换成 max）：

V∗(s)=max⁡aQ∗(s,a)Q∗(s,a)=r(s,a)+γ∑s′p(s′∣s,a)V∗(s′)

Expectation vs Optimality 对比：

Expectation（给定 π） Optimality
V 由 Q ∑aπ(a∣s)Qπ(s,a) max⁡aQ∗(s,a)
Q 由 V r+γ∑s′pVπ(s′) r+γ∑s′pV∗(s′)
方程类型 线性（可直接解） 非线性（有 max，一般没有闭式解，要迭代）

例（Student MDP，γ=1，C1）：V∗(C1)=6=max⁡{−2+8, −1+6}（Study 到 C2，Facebook 到 FB）。

4.7 例：Gridworld（Sutton & Barto Ch 3，p.60）

  • 5×5 网格，actions：north、south、east、west
  • 走出网格：不动，reward −1
  • 其他 action reward 0；除了从特殊 state A 和 B 出去的：A 的任何 action → 到 A′，reward +10；B → B′，reward +5

Equiprobable random policy（γ=0.9），某个格子（上、下、左、右邻居的 value 为 5.3、2.3、8.8，以及往边外走）：

4.43=0.25⋅(0+0.9⋅5.3+0+0.9⋅2.3+0+0.9⋅8.8+(−1)+0.9⋅4.4)

（最后一项：走出网格，reward −1，留在原地，value 4.4。）

Optimal policy（γ=0.9）：

  • A 格：24.4=10+0.9⋅16.0（任何 action 都跳到 A′，V∗(A′)=16.0）
  • 另一格：
22.0=max⁡(0+0.9⋅19.4, 0+0.9⋅19.8,0+0.9⋅24.4, (−1)+0.9⋅22)

四项分别是 17.46、17.82、21.96、18.8，最大的 ≈ 22.0（走向 A 那个方向）。

手算套路：每个 action 的值 = 即时 reward + γ× 到达 state 的 value；expectation 按 policy 概率平均，optimality 取 max。

6 · 易错点

  • MRP 的 reward 是 r(s)，MDP 的是 r(s,a)。
  • Vπ=∑aπQπ（加权平均）；V∗=max⁡aQ∗（取最大）——不要混。
  • Bellman expectation equation 是线性的，可以矩阵求逆；optimality equation 有 max，不是线性的。
  • 只知道 V∗ 不能直接得到 policy（要 dynamics）；知道 Q∗ 可以。
  • Deterministic policy 个数是 ∣𝒜∣∣𝒮∣，不是 ∣𝒮∣∣𝒜∣。
  • Sample return 里第一个 reward 不打折（γ0=1）。
  • Gridworld 走出边界：reward −1 且留在原地，所以那一项用的是自己的 value。
