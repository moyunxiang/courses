algorithm update based on

5 · Model-free prediction (2.1)

method update target bias / variance
MC V(st)←V(st)+α(Gt−V(st)) actual return Gt unbiased, high variance
TD(0) V(st)←V(st)+α(rt+γV(st+1)−V(st)) rt+γV(st+1) biased, low variance
n-step TD V(st)←V(st)+α(Gt(n)−V(st)) Gt(n)=∑k=0n−1γkrt+k+γnV(st+n) in between
TD(λ), forward view V(st)←V(st)+α(Gtλ−V(st)) Gtλ=(1−λ)∑n≥1λn−1Gt(n) λ=0: TD(0); λ=1: MC
DP V(st)←𝔼π[rt+γV(st+1)] expectation needs the model
  • TD error: δt=rt+γV(st+1)−V(st).
  • Incremental mean: N(s)←N(s)+1, V(s)←V(s)+1N(s)(Gt−V(s)); non-stationary: 1N(s)→α const.
  • First-visit: first occurrence of s / episode; every-visit: all occurrences; both →Vπ (LLN).
  • Bootstrap: DP ✓ · TD ✓ · MC ✗ — Sample: MC ✓ · TD ✓ · DP ✗.
  • Batch: MC →arg⁡min⁡∑(G−V)2; TD(0) → certainty equivalence (ML Markov model p^,r^).
  • TD: online, incomplete episodes, continuing tasks. MC: episodic only, robust to non-Markov, insensitive to V0.

H · Proofs / concept questions

  • Fπ γ-contraction: ∥γPπ(U−V)∥∞≤γmax⁡s∑s′Pss′π∣U(s′)−V(s′)∣≤γ∥U−V∥∞ (Pss′π≥0, ∑s′Pss′π=1). ∎
  • Policy improvement thm: §4, unroll to Vπ′.
  • PI: (full eval + improve) until πk+1=πk; VI: iterate F∗, extract π once.
  • Bandit "stateless": at does not change s; once it does ⇒ MDP.

Common mistakes

  1. Index: slides rt = S&B Rt+1; TD target rt+γV(st+1), not rt+1+⋯.
  2. Pr⁡(greedy)=1−ϵ+ϵ/∣𝒜∣, not 1−ϵ.
  3. UCB: numerator t (total), denominator Nt(a) (arm); Nt(a)=0⇒ bonus ∞ (pull each arm once).
  4. V∗→π∗ needs model; Q∗→π∗ does not.
  5. VI: Vk need not be any Vπ; PI: every V=Vπk.
  6. TD target rt+γV(st+1) biased; "true" rt+γVπ(st+1) unbiased.
  7. MC: episodic only; first-visit ⇒ check first occurrence in the episode.
  8. Batch: MC = min MSE, TD = certainty equivalence (ML model).
  9. ⚠️ Cliff walking: SARSA (on-policy) → safe path; Q-learning (off-policy) → cliff edge.
