0 · 这一讲在讲什么

Roadmap：Introduction to RL → Model-based RL → Model-free RL（Direct Evaluation、TD Value Learning）

上两讲的 MDP 假设 T(s,a,s′) 和 R(s,a,s′) 都已知，可以离线算出 V∗。这一讲去掉这个假设：转移和奖励未知，只能靠和环境交互得到的样本来学。

必考：offline planning vs online（RL）；model-based 的计数估计 T^、R^；direct evaluation 的平均（课件的 A–E 例子，B=+8、C=+4、E=−2）；direct evaluation 的优缺点（为什么 B、E 都去 C 却值不同）；TD 更新式的两种写法和手算（例子 −1、3）；为什么 TD 学了 V 还不能改进 policy ⇒ 引出 Q-learning。

1 · Introduction to RL

1.1 Review：MDP

Definition: MDP：States；sstart；Actions(s)；T(s,a,s′)：在 s 做 a 到 s′ 的概率；Reward(s,a,s′)；IsEnd(s)；0≤γ≤1（默认 1）

现在的设定：T 和 Reward 未知（racing car 例子里每条转移的概率和奖励都是「?」）⇒ Reinforcement learning!

1.2 RL 的基本思路

Agent 在 state s 做 action a，environment 返回 reward r 和新的 state。

  • 通过 action 和环境交互
  • 以 reward 的形式收到反馈
  • 必须（学会）行动以最大化期望 reward
  • 所有学习都基于观察到的结果样本

1.3 Offline（MDP）vs Online（RL）

Offline Planning Online Planning
知道 MDP 的全部细节 一种特殊的 MDP：光靠计算解不出来
所有量都靠计算得到 必须真的去行动才能弄清楚
不用真的玩这个游戏

课件的图：offline 时机器人在脑子里推演哪里有火坑；online 时要真走过去（可能掉进火坑）才知道。

2 · Model-based RL

2.1 思路

  • Model-based idea：根据经验学一个近似模型，再在这个模型上解出 state values
  • Step 1：学经验 MDP（empirical MDP）
    • 对每个 (s,a)，数各个 s′ 出现的次数
    • 归一化得到 T(s,a,s′) 的估计
    • 每次经历 (s,a,s′) 时记下它的 reward
  • Step 2：解学到的 MDP，例如用 value iteration（和之前一样）

数据：s0;a1,r1,s1;a2,r2,s2;a3,r3,s3;… ;an,rn,sn

T^(s,a,s′)=# times (s,a,s′)# times (s,a)Reward^(s,a,s′)=r in (s,a,r,s′)

2.2 例：A–E gridworld（γ=1）

地图：中间一行 B–C–D，C 上方 A、下方 E。Input policy π：B → east，C → east，E → north；A、D 是出口（exit）。

Observed episodes（每行是 s, a, s′, r）：

Episode 1 Episode 2 Episode 3 Episode 4
B, east, C, −1 B, east, C, −1 E, north, C, −1 E, north, C, −1
C, east, D, −1 C, east, D, −1 C, east, D, −1 C, east, A, −1
D, exit, x, +10 D, exit, x, +10 D, exit, x, +10 A, exit, x, −10

Learned model：

T^(B,east,C)=22=1.00T^(C,east,D)=34=0.75T^(C,east,A)=14=0.25
  • (B,east) 出现 2 次（Ep 1、2），两次都到 C
  • (C,east) 出现 4 次（每个 episode 一次），3 次到 D、1 次到 A（Ep 4：C 处 east 却到了 A，说明转移是随机的）
R^(B,east,C)=−1,R^(C,east,D)=−1R^(D,exit,x)=+10, …

补充：Step 2 解出来是多少（课件没算，按 policy evaluation 自己算，γ=1）：

V(D)=10,V(A)=−10V(C)=0.75(−1+10)+0.25(−1−10)=6.75−2.75=4V(B)=−1+V(C)=3,V(E)=−1+V(C)=3

注意 V(B)=V(E)——模型把「B 和 E 都确定地走到 C」这个结构用上了。和 3.2 的 direct evaluation 对比。

2.3 优缺点

  • 优点：非常简单直观，效果却出奇地好；只靠计数和归一化就得到 T 和 R
  • 缺点：要为每个见过的 (s,a,s′) 维护计数，代价高

3 · Model-free RL：Direct Evaluation

3.1 思路

  • 目标：在 policy π 下算出每个 state 的 value
  • Idea：对所有观察到的样本值取平均
    • 按 π 行动（生成 episodes）
    • 每次访问某个 state，记下从那以后的折扣 reward 总和：
      samplei(s)=R(s)+γR(s′)+γ2R(s′′)+⋯
    • 用这些样本的平均来估计 state value：
      Vπ(s)=∑isamplei(s)N(N=访问次数)

课件配图是老虎机：拉很多次、记下每次赢多少（$0、$2…），平均值就是期望。

3.2 例：同一组 episodes（γ=1）

Vπ(s)=Total sample values# of times visited
state 样本（从该 state 到结束的 reward 和） 平均
A Ep 4：−10 −10
B Ep 1：−1−1+10=8；Ep 2：8 +8
C Ep 1、2、3：−1+10=9；Ep 4：−1−10=−11 9+9+9−114=+4
D Ep 1、2、3：+10 +10
E Ep 3：−1−1+10=8；Ep 4：−1−1−10=−12 8−122=−2

课件写出 E 的算式：((−1−1+10)+(−1−1−10))/2=−2。

问：B 和 E 在这个 policy 下都走到 C，它们的 value 能不一样吗？

真实意义上不应该不一样：两者都是「−1 后到 C」，所以真值都是 −1+V(C)。这里 B=8、E=−2，只是因为样本太少——B 碰巧只跟了 C 的好结局，E 跟了一好一坏。样本足够多时两者都会收敛到同一个值（2.2 的模型给的是 3）。

3.3 Direct evaluation 的优缺点

好处：

  • 容易理解
  • 不需要任何关于 T、R 的知识
  • 只用样本转移，探索足够时最终会算出正确的 value

坏处：

  • 浪费了 state 之间连接的信息（没用上 Bellman 方程 V(B)=−1+V(C)）
  • 每个 state 都要单独学
  • 所以要很久才能学好（不高效）

4 · Model-free RL：Temporal Difference Value Learning

4.1 思路

  • Learn from every experience! 每经历一次转移 (s,π(s),s′,r) 就更新一次 Vπ(s)
  • Temporal difference learning of values：
    • policy 仍然固定，做的仍然是 policy evaluation
    • 用 running average 把 value 往真值挪

4.2 更新式（关键）

Vπ(s) 的一个样本：

sample=R(s,π(s),s′)⏟immediate reward+γVπ(s′)⏟discounted future rewards

更新（running average）：

Vπ(s)←(1−α)Vπ(s)⏟old value+α⋅sample⏟new sample value

0≤α≤1 是 learning rate：越大，越看重当前样本。

同一个更新的另一种写法：

Vπ(s)←Vπ(s)+α(sample−Vπ(s)⏟temporal difference)

（展开 (1−α)V+α⋅sample=V+α(sample−V)，两式相同。）括号里的差就是 temporal difference——「新估计」和「旧估计」在时间上的差。

这个形式像什么？ Stochastic gradient update：把 sample 当作目标 y，对 12(y−V)2 关于 V 做一步梯度下降，就是 V←V+α(y−V)。

和 direct evaluation 比：

  • 收敛快得多
  • 需要的 episode 更少

原因：TD 的 sample 里用的是 Vπ(s′)——利用了 state 之间的连接（Bellman 方程），而不是等到 episode 结束才算总 reward。

和 Bellman 的关系：policy evaluation 是 Vπ(s)=∑s′T(s,π(s),s′)[R+γVπ(s′)]，要知道 T；TD 用真实采到的 s′ 代替对 T 的求和，再靠 running average 把多个样本平均起来——「mimicking Bellman updates with running sample averages」。

4.3 例：TD 手算（γ=1，α=12）

初始：V(D)=8，其余全为 0。

转移 1：(B, east, C, −2)

Vπ(B)←0+0.5×[−2+1×V(C)−0]=0+0.5×[−2+0−0]=−1

转移 2：(C, east, D, −2)

Vπ(C)←0+0.5×[−2+1×V(D)−0]=0+0.5×[−2+8−0]=3

结果：V(B)=−1，V(C)=3，V(D)=8，A、E 仍为 0。

做题套路：① 只更新转移的起点 s；② sample = 这一步的 reward + γ×当前表里 V(s′)；③ 新值 = 旧值 + α(sample − 旧值)；④ 按转移的顺序依次更新，后面的转移用前面更新过的值。

注意 B 的更新用的是更新前的 V(C)=0；C 是后来才变成 3 的，B 不会自动跟着变——要等下次再经过 B。

5 · TD Value Learning 的问题 → Q-learning

  • TD value learning 是做 policy evaluation 的 model-free 方法：用 running sample average 模仿 Bellman 更新
  • 但想把 value 变成（新的）policy 时卡住了：
π(s)=arg⁡max⁡aQ(s,a),Q(s,a)=∑s′T(s,a,s′)[R(s,a,s′)+γV(s′)]

要算 Q 就要 transition probability T——而它是未知的（model-free）！

  • Idea：直接学 Q-values，而不是 values
  • 这样 action selection 也是 model-free 的（off-policy）！——下一讲的 Q-learning

6 · Summary

  • Reinforcement learning（从经验学）：online planning 设定，学着在真实世界里采取行动
  • Model-based RL：从经验学 MDP 模型（转移和奖励），再解这个 MDP
  • Model-free RL：不学模型，直接学 state 的 value
    • Value learning：在固定 policy 下学 value；两种方法：Direct Evaluation 或 TD Learning
    • 预告 Q-learning：为最优 policy 学最优 Q-values

8 · 易错点

  • Direct evaluation 的 sample 是从该 state 起到 episode 结束的总 reward，不是整条 episode 的总和（B 从第 1 步算，C 从第 2 步算）。
  • 同一个 state 在多个 episode 里出现，每次都算一个样本，分母是访问次数，不是 episode 数。
  • T^ 的分母是 (s,a) 的次数，不是 s 的次数。
  • TD 只改转移起点的 value；sample 用的是表里当前的 V(s′)。
  • γ=1、α=12 时 TD 新值 = 旧值和 sample 的平均。
  • TD value learning 和 direct evaluation 都是固定 policy 下的 policy evaluation，不会改进 policy。
  • 「学了 V 也选不出动作」的原因是 Q(s,a) 要用未知的 T；学 Q 就绕开了。
