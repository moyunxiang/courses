6. Learning rate and batch size? · 学习率与批量？

  • η 太大 → overshoot 越过最小值、震荡；用 schedule 逐渐减小 η；先在小子集上调 η。

11. Cross-entropy & softmax? · 交叉熵与 softmax？

H(p,q)=−∑ipilog⁡qi,qi=eαi∑keαk,CE loss=−log⁡qc
  • 不对称 H(p,q)≠H(q,p)；H(p,p)=H(p)；p = target（one-hot），q = model。
  • 例：logits (0,0,ln⁡2) → softmax (14,14,12)；真类是 3 → loss 1 bit，真类是 1 → 2 bits。
  • Binary 二分类：−∑[tlog⁡f+(1−t)log⁡(1−f)]。

∂E∂wi=−(t−o) o(1−o) xi,wi←wi+η(t−o)o(1−o)xi

推导三步：E 对 o（−(t−o)）× o 对 net（o(1−o)）× net 对 wi（xi）。 例：net=0 → o=0.5 → ∂E/∂wi=−0.125xi（t=1）。

15. Practice details? · 实践细节？

  • Init 初始化：small random 小随机数。
  • Stop 停止：固定迭代数 / training error 低于阈值 / validation error 最小处（early stopping）。
  • Momentum 动量：Δw(t+1)=−η ∂E/∂w+αΔw(t)，α≈0.9。例：梯度 2、1，η=0.1 → −0.2、−0.28。
  • GD 只保证 local minimum 局部最小 → 多次随机初始化。

E · Convolution 卷积与滤波

16. Why CV? · 为什么做计算机视觉？

一图胜千言；海量图像 / 视频。典型任务 object recognition；应用：实时检测、自动驾驶卡车、人脸识别 / 刷脸支付、biometrics。

17. Flip or not? · 翻不翻转？

conv: S(i,j)=∑m∑nI(i−m,j−n)K(m,n)
NN（cross-correlation）: S(i,j)=∑m∑nI(i+m,j+n)K(m,n)

神经网络不翻转。题目说 flipped / true convolution 时先把核转 180°。Valid 输出大小 (H−K+1)×(W−K+1)。

例：I=(102310021)，K=(1−102) → 不翻转 (3−263)，翻转 (0−181)。

18. Filters? · 滤波器？

  • Smoothing 平滑：19𝟏3×3，blur；窗口越大越糊。加权平均：中心权重大，除以权重和。
  • Averaging ↔ integration 积分（模糊）；differencing ↔ differentiation 微分（锐化），f(x+1)−f(x)。
  • Edge 边缘：[−1 0 1] 每行（水平差分）→ 竖直边缘；[−1 0 1]⊤ 每列 → 水平边缘；平坦区输出 0。

20. Why CNN works? · CNN 的几个想法？

  • Sparse connectivity 稀疏连接：receptive field 感受野，越深越大；层级特征 边 → 部件 → 物体。
  • Parameter sharing 参数共享：一个核到处用 → 平移鲁棒、参数少。效率表：卷积 2 个数 vs dense >8×109 vs sparse 178,640（320×280，2×1 核）。
  • 1×1 conv：只混通道，用来降维。
  • Nonlinearity（ReLU）：卷积是线性的。Padding：防止每层缩小。Pooling：spatial invariance（「7」的例子）+ downsampling。
  • 一个 complex layer = conv → detector（ReLU）→ pooling。
  • 课件架构：2562×3→2562×64→ pool/4 →642×64→642×64→ pool/4 →162×64=16,384→1000→ softmax。

G · Last-minute traps 最后提醒

  • step(0) = 1；更新时带上 I0=1；预测对了不更新。
  • Convergence only if linearly separable. 收敛只在线性可分时保证。
  • σ′=σ(1−σ)；sigmoid 梯度带负号 −(t−o)⋯，更新变成 +η(t−o)⋯。
  • Add gate gives each input the full gradient (not split). add 门不平分。
  • A variable used twice → gradients add. 用了两次的变量梯度相加。
  • Momentum multiplies the previous update, not the gradient. 动量乘的是上一步的更新量。
  • CE is not symmetric; one-hot → −log⁡qc. 交叉熵不对称。
  • NN conv = no flip; [−1,0,1] rows → vertical edges. 不翻转；横向差分检测竖直边。
  • Size formula: 2·pad, floor, then +1. 尺寸公式：两倍 pad，向下取整，再加一。
  • Parameters ignore H,W; pooling has none. 参数与 H,W 无关；pooling 无参数。
