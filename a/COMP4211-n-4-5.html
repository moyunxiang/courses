0 · 这一讲在讲什么

  1. Back-propagation 的想法 = gradient descent：算 loss 对权重的梯度，往反方向走
  2. 链式法则；一个 sigmoid unit 的梯度推导 ∂E∂wi=−(t−o)o(1−o)xi
  3. In short：z=wx+b、y=σ(z)、ℒ=12(y−t)2 的逐级求导
  4. Computation graph 上的 backprop：forward pass（拓扑序）/ backward pass（vˉi=∑j∈Ch(i)vˉj∂vj∂vi）
  5. 实践细节：初始化、何时停止、加速（momentum）、局部最小

必会推导：sigmoid unit 的梯度（每一步用了什么）；「In short」四个导数。必会概念：backward pass 公式里为什么要对 children 求和；三种停止准则；momentum 公式与作用；GD 只保证收敛到局部最小。

1 · 回顾与动机

  • 单个 perceptron 能表示 ⟺ 线性可分；多层足够多 perceptrons 能表示任意 Boolean function
  • 非线性激活 + 多层 ⇒ 需要更复杂的学习算法 → Back-propagation

想法：gradient descent

  1. 给 𝐰 一个初值
  2. repeat until convergence：算当前 𝐰 下 error（loss）函数的梯度向量；往相反方向移动

（梯度例：hinge loss 的梯度，见第 2 讲：margin <1 时 −ϕ(x)y，否则 0。）

2 · MLP 中的梯度

  • 定义一个对网络输出可导的 error function
  • 网络用可导的激活函数 ⇒ 输出是输入和权重（及 bias）的可导函数 ⇒ error 是权重的可导函数

链式法则：x→u→y，dydx=dydududx。

3 · 一个 Sigmoid Unit 的梯度

net=∑i=0nwixi（x0=1），o=σ(net)=11+e−net，E=12(t−o)2。

∂E∂wi=∂∂wi12(t−o)2=12⋅2(t−o)∂∂wi(t−o)=(t−o)(−∂o∂wi)=−(t−o)∂o∂net∂net∂wi

其中

∂o∂net=∂σ(net)∂net=o(1−o),∂net∂wi=∂(𝐰′𝐱)∂wi=xi
∂E∂wi=−(t−o) o(1−o) xi

更新：wi←wi−η∂E∂wi=wi+η(t−o)o(1−o)xi。

补充算例：𝐱=(1,1)（含 x0），𝐰=(0,0)，t=1：net=0，o=0.5，∂E∂wi=−(0.5)(0.5)(0.5)(1)=−0.125；η=1 时 𝐰←(0.125,0.125)。

4 · In Short（课件）

计算 loss（forward）：

z=wx+b,y=σ(z),ℒ=12(y−t)2

计算导数（backward，从 ℒ 往回）：

dℒdy=y−tdℒdz=dℒdyσ′(z)∂ℒ∂w=dℒdzx,∂ℒ∂b=dℒdz

多变量链式法则：ddtf(x(t),y(t))=∂f∂xdxdt+∂f∂ydydt——一个变量通过多条路径影响输出时，各路径贡献相加。

5 · Backprop on a Computation Graph

  • Activity forward（输入 → 输出）；error backward（输出 → 输入）——「propagate error back」

记号：v1,…,vN 是计算图的拓扑序（父节点在子节点之前）；vN 是要求导的变量（如 loss）；vˉi = vN 对 vi 的梯度。

Forward pass：

For i=1,…,N:compute vi as a function of Pa(vi)

Backward pass：

vˉN=1;For i=N−1,…,1:vˉi=∑j∈Ch(vi)vˉj∂vj∂vi

（Pa = parents，Ch = children；求和 = 多变量链式法则。具体算例见 4.6。）

6 · 实践细节

怎么初始化？——小的随机值。

何时停止训练？

  1. 固定迭代次数之后
  2. training error 低于某个阈值
  3. 在 validation set 误差的最小值处停止（early stopping）

速度：测试很快；多 hidden layers 的网络训练可能很慢。加速方法：

  1. Momentum：给每个权重一点惯性
Δwji(t+1)=−η∂E∂wji+αΔwji(t),0<α<1 (如 0.9)
  1. 动态调整 η
  2. 利用误差面的高阶信息
  3. 更复杂的优化算法

局部最小：误差面可能有多个局部最小；GD 只保证收敛到某个局部最小，不一定是全局最小。怎么逃出局部最优？（课件图：多个降落伞从不同位置出发 → 多次随机初始化；momentum 也有助于冲过浅的局部最小。）

8 · 易错点

  • E=12(t−o)2 的 12 是为了约掉求导出来的 2。
  • 梯度有负号：−(t−o)⋯；更新时 w−η∇ 变成 +η(t−o)⋯。
  • Backward pass 对所有 children 求和（一个节点被多处使用时梯度相加）。
  • Momentum 里 α 乘的是上一步的更新量 Δw(t)，不是上一步的梯度。
