MDP = states, sstart, Actions(s), T(s,a,s′), Reward(s,a,s′), IsEnd(s), discount 0≤γ≤1. Vs. search: T replaces Succ, reward replaces cost. Policy π: state → action.

  • Logic = syntax (formulas) + semantics (models; n symbols ⇒2n models) + inference rules.
  • Model checking = SAT = a CSP (symbols = variables, domain {T, F}, formulas = constraints); no satisfying assignment of KB ∧¬f ⇒ entailed.

Common Mistakes

  1. γ multiplies only the future value V(s′); the reward sits inside the bracket and is weighted by T.
  2. Policy evaluation has no max (π(s) fixed); value iteration has max; terminal states stay 0.
  3. Every update uses the previous iteration's values (V(t−1)), not values updated in the same sweep.
  4. TD learns Vπ (policy fixed); Q-learning learns Qopt with max⁡a′ even though actions are chosen ε-greedily (off-policy).
  5. Alpha-beta: MAX prunes on v≥β, MIN on v≤α; pruning never changes the root value; chance nodes can't be bounded.
  6. P(Y∣X) table sums to ∣X∣, not 1; always normalize after selecting evidence.
  7. BN joint uses P(xi∣parents) only, not all predecessors; VE cost = largest factor, so order matters.
  8. Naive Bayes: compare P(y)∏iP(fi∣y); forgetting the prior P(y) is the usual slip.
  9. p→q is true when p is false; ∀ goes with →, ∃ with ∧ (∃x (Student(x)→… ) is almost always true).
