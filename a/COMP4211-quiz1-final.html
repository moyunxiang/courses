A · Learning paradigms 学习范式

1. Three paradigms and their training data? · 三种学习范式各用什么数据？

  • Supervised 监督学习：pairs (x,y); a teacher gives the desired output. 有老师给出正确输出。
  • Unsupervised 无监督学习：inputs x only, no teacher. 只有输入，没有标签。
  • Reinforcement 强化学习：(x,reward); only evaluative feedback, never the correct answer. 只有奖励，没有正确答案。

2. Examples from the slides? · 讲义里的例子？

  • Supervised：classification 分类、regression 回归、recommender system 推荐系统、control 控制（steering network：sharp left / straight / sharp right）
  • Unsupervised：clustering 聚类、PCA / eigenface 特征脸、outlier detection 异常检测、data generation 数据生成
  • Reinforcement：mountain car（reward −1 per step until the goal 到终点前每步 −1）、portfolio 投资组合（reward = return 收益）、robotics 机器人

3. Four supervised task types? · 四种监督任务？

Task 任务 y Examples 例子
Binary classification 二分类 {−1,+1} fraud 欺诈、toxic comments 恶意评论、Higgs boson
Multiclass 多分类 {1,…,K} extension of binary 二分类的推广
Regression 回归 R poverty mapping 贫困地图、house price 房价、arrival time 到达时间
Structured prediction 结构化预测 sentence / image 句子 / 图像 translation 翻译、dialogue 对话、captioning 图像描述、segmentation 分割

4. Pipeline and performance measure? · 流程和评价指标？

  • Pre-processing 预处理 → feature extraction 特征提取 → training 训练（learn decision boundary 学决策边界）→ classify new inputs 分类新样本
  • Classification error rate 错误率 = fraction misclassified 分错的比例。Central issue 核心问题：generalization 泛化。

B · Linear regression 线性回归

5. Predictor and features? · 预测器与特征？

fw(x)=w⋅ϕ(x),ϕ(x)=[1,x],fw(x)=w1+w2x

6. Three design decisions? · 三个设计决策？

  • Hypothesis class 假设空间 → linear functions 线性函数 F={fw}
  • Loss function 损失函数 → squared loss 平方损失
  • Optimization algorithm 优化算法 → gradient descent 梯度下降

7. Squared loss and TrainLoss? · 平方损失与训练损失？

Loss(x,y,w)=(fw(x)−y)2
TrainLoss(w)=1∣Dtrain∣∑(x,y)∈DtrainLoss(x,y,w)

Residual 残差 =w⋅ϕ(x)−y（prediction − target 预测 − 真值）。TrainLoss 是平均，要除以样本数。

8. What is the gradient? · 梯度是什么？

The direction that increases TrainLoss the most. 使训练损失增加最快的方向，所以梯度下降要走 −∇。

9. Gradient of squared loss? · 平方损失的梯度？

∇w(w⋅ϕ(x)−y)2=2(w⋅ϕ(x)−y) ∇w(w⋅ϕ(x))=2(w⋅ϕ(x)−y) ϕ(x)
∇wTrainLoss(w)=1∣Dtrain∣∑2(w⋅ϕ(x)−y) ϕ(x)

Chain rule 链式法则；别漏系数 2。

10. Update rule? · 更新式？

w←w−η ∇wTrainLoss(w)

η>0：step size 步长（learning rate 学习率）。减梯度。

11. Slide example? · 讲义例题？

D={(1,1),(2,3),(4,3)}, w=[1,0.57]：

fw(3)=[1,0.57]⋅[1,3]=2.71TrainLoss=13(0.572+0.862+0.282)≈0.38

C · Linear classification 线性分类

13. Classifier and hypothesis class? · 分类器与假设空间？

fw(x)=sign⁡(w⋅ϕ(x)),F={fw:w∈R2},ϕ(x)=[x1,x2]

14. Score vs. margin? · score 与 margin？

  • Score =w⋅ϕ(x)：how confident in predicting +1，预测 +1 有多自信
  • Margin m=(w⋅ϕ(x)) y：how correct，预测有多对。m>0 分对，m≤0 分错

15. Decision boundary? · 决策边界？

{x:w⋅ϕ(x)=0}，orthogonal to w 与 w 垂直；w points to the +1 side，w 指向 +1 一侧。

Example 例：w=[−0.6,0.6] gives x2=x1；f([0,2])=sign⁡(1.2)=+1，f([−2,0])=+1，f([1,−1])=sign⁡(−1.2)=−1。

16. Three losses and gradients? · 三种损失及梯度？

Loss 损失 Formula 公式 ∇w
zero-one 0-1 1[m≤0] 0 a.e. 几乎处处为 0
hinge max⁡{1−m,0} −ϕ(x)y if m<1, else 0
logistic log⁡(1+e−m) −ϕ(x) y e−m1+e−m
  • 0-1 loss：gradient is 0 almost everywhere, so GD cannot move. 梯度几乎处处为 0，梯度下降走不动。
  • Hinge：nonzero gradient whenever m<1 (not just m<0). m<1 就有梯度，不是只有分错时才有。
  • Logistic：>0 for all m, keeps pushing the margin up. 永远大于 0，会一直推大 margin。

17. Prove hinge ≥ zero-one · 证明 hinge ≥ 0-1

  • m≤0：0-1 =1, and 1−m≥1 gives hinge ≥1。
  • m>0：0-1 =0, and hinge ≥0。

So max⁡{1−m,0}≥1[m≤0] for every m. 所以 hinge 是 0-1 的上界。■

18. Values at m=0 and m=2? · m=0 和 m=2 时的取值？

  • m=0：0-1 =1，hinge =1，logistic =log⁡2≈0.69
  • m=2：0-1 =0，hinge =0，logistic =log⁡(1+e−2)>0

D · Model evaluation & selection 模型评估与选择

20. Training error vs. testing error? · 训练误差与测试误差？

errorS(h)=1n∑x∈Sδ(f(x)≠h(x))

Training error 训练误差：what we can measure，能算出来的。

errorD(h)=Pr⁡x∼D[f(x)≠h(x)]

Testing / true error 测试（真实）误差：what we want to be low，真正要小的。Estimated by the test set 用测试集估计：

errortest(h)=1∣testSet∣∑x∈testSetδ(f(x)≠h(x))

21. Test-set rules? · 测试集的规矩？

  • Test patterns are drawn independently from the training patterns. 与训练集独立抽样。
  • Never used in any way to learn the hypothesis, including choosing the model. 任何方式都不能用来学模型，包括选模型、调超参数。

22. Why not fit the training set? · 为什么不直接拟合训练集？

The training set is a finite sample; different training sets give different classifiers. 训练集只是有限样本，换一组数据就会得到不同的分类器。Lowest training error ≠ lowest testing error. 训练误差最低不等于测试误差最低。

23. Overfitting definition? · 过拟合的定义？

h∈H overfits if ∃ h′∈H such that

errorS(h)<errorS(h′)buterrorD(h)>errorD(h′)

在训练集上更好，在整个分布上更差。

24. Bias and variance? · 偏差与方差？

  • Bias 偏差：how far the prediction is from the true value. 预测偏离真值多少。
  • Variance 方差：how much the model changes when the training set changes. 换训练集时模型变多少。
Model 模型 Bias 偏差 Variance 方差
Too complex 太复杂（many hidden units） small 小 large 大
Too simple 太简单（few hidden units） large 大 small 小

25. Hold-out validation? · 留出法验证？

  • Split into a training set and a validation set; e.g. 23 / 13. 分成训练集和验证集，例如 23 / 13。
  • Larger training set → better hypothesis; larger validation set → more accurate error estimate. 训练集越大模型越好；验证集越大误差估计越准。
  • Optionally retrain on all the data afterwards. 最后可以用全部数据重训。
  • More reliable: repeat with different subsamples. 想更可靠就换不同子样本重复几次。

26. k-fold cross-validation? · k 折交叉验证？

  1. Partition the m examples into k disjoint subsets of size m/k. 把 m 个样本分成 k 份互不相交的子集，每份 m/k 个。
  2. Run k times, validating on one fold and training on the other k−1. 跑 k 次，每次 1 份验证、其余 k−1 份训练。
  3. Average the k validation errors. 取 k 次验证误差的平均。

Each example is validated once and trained on k−1 times; training fraction 1−1k; k training runs; typically k≈10. 每个样本恰好验证一次、训练 k−1 次；训练比例 1−1k；训练 k 次；通常 k≈10。

27. Leave-one-out CV? · 留一法？

k=m: m runs, each trains on m−1 examples and validates on 1. Useful for small data sets. 跑 m 次，每次用 m−1 个训练、1 个验证；适合小数据集。

28. Worked example: counting · 例题：计数

m=100, k=5 gives folds of 20, 80 training examples per run, and 5 runs. Comparing M models takes M⋅k runs (+1 optional final retrain). LOOCV with m=100 takes 100 runs of 99 examples each.

m=100，k=5：每份 20 个，每次训练 80 个，跑 5 次。比较 M 个模型要跑 M⋅k 次（最后可选再重训 1 次）。LOOCV：跑 100 次，每次 99 个。

E · Last-minute traps 最后提醒

  • Margin = score × y；m=0 counts as wrong 算分错。
  • Hinge gradient has a minus sign 有负号：−ϕ(x)y。
  • GD subtracts the gradient. 梯度下降是减梯度。
  • Squared-loss gradient has the factor 2. 平方损失梯度有系数 2。
  • TrainLoss is an average. TrainLoss 是平均。
  • Complex model → low bias, high variance. 复杂模型：低偏差、高方差。
  • Choose models with a validation set, never the test set. 用验证集选模型，绝不用测试集。
