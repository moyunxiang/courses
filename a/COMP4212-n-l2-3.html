0 · 这一讲在讲什么

前两讲的 MC / TD / SARSA / Q-learning 都是 tabular：每个 s 或 (s,a) 一格。状态一多就存不下、学不完。这一讲把表换成带参数 𝐰 的函数。

  1. Function approximation：为什么要近似；选什么函数；linear vs 可微（神经网络）；RL 数据的特殊性
  2. Gradient-based algorithms：SGD 目标；linear VFA 更新 = 步长 × 预测误差 × 特征；MC / TD(0) / TD(λ) 的 target；semi-gradient；control；action-in vs action-out
  3. Convergence and divergence：MC、TD 的不动点 𝐰MC、𝐰TD；VE‾ 定理；发散的例子；deadly triad；收敛表
  4. DQN：深度学习和 RL 的三点区别；Atari 上的 DQN；用 TD 训练 Q(s,a;𝐰)；两个缺点（浪费经验、更新相关）

期中范围到 2.3 为止（10/08 公告：Ch 1.1–2.3）。DQN 的 experience replay、target network 在 2.4，不考；这一讲只讲到「为什么需要它们」。

必考：linear VFA 的 MC / TD(0) 更新式（会代数算一步）；为什么叫 semi-gradient；MC target 无偏、TD target 有偏；𝐰MC 和 𝐰TD 的推导；发散例子里 wt+1=(1+α(2γ−1))wt；deadly triad 三个要素以及去掉任何一个为什么就不发散；收敛表；DQN 的 TD target 和 loss；两个缺点。

1 · Function Approximation

1.1 为什么要近似

  • 到目前为止，value function 是一张 lookup table：每个 s 有一格 V(s)，或每个 (s,a) 有一格 Q(s,a)
  • 真实问题状态极多：Backgammon 1020；Go 10170；直升机是连续状态空间；机器人在真实世界里
  • 大 MDP 的两个问题：
    • 状态 / 动作太多，内存存不下
    • 每个状态单独学太慢——没见过的状态完全没有估计
  • 所以要近似：policy、value function、model、agent state update 本质上都是函数，都可以近似

1.2 选哪种函数

可选：特征的线性组合、神经网络、决策树、最近邻、Fourier / wavelet 基……

类型 理论 实践
Tabular 理论好 不能 scale、不能泛化
Linear 理论较好 依赖好的特征（往往手工设计）
Non-linear（神经网络） 理解得少 scale 得好；不太依赖手工特征
  • 用（深度）神经网络表示这些函数，就叫 deep reinforcement learning

1.3 Linear function approximation

  • 先固定 agent state update（最简单是 st=ot）
  • 固定的特征映射 𝐱:s→ℝn
  • value 是特征的线性函数：V(s;𝐰)=𝐰⊤𝐱(s)

1.4 一般的可微近似

  • 用参数化函数估计：
V(s;𝐰)≈Vπ(s)或Q(s,a;𝐰)≈Qπ(s,a)
  • 从见过的状态泛化到没见过的状态
  • 用 MC 或 TD learning 更新 𝐰
  • V(s;𝐰) 是 𝐰 的可微函数，可以是非线性的，例如输入像素的 CNN
  • 另一种理解：特征不再固定，而是学出来的

1.5 RL 里做函数近似的特殊困难

原则上任何近似器都能用，但 RL 数据有自己的性质：

  • 经验不是 i.i.d.：相邻时间步强相关
  • agent 的 policy 影响它收到的数据
  • 回归目标不平稳（non-stationary），因为：
    • policy 在变（target 和数据都会变）
    • bootstrapping（target 里含有正在学的估计）
    • 环境动态不平稳（比如还有别的学习 agent）
    • 世界太大，几乎不会两次处在同一状态

和监督学习的对比：监督学习的 label 是固定的、样本独立同分布；RL 里这两条都不成立。这一讲后面的 semi-gradient、发散、DQN 的两个缺点，都是这几条的后果。

1.6 VFA 和 policy approximation 的样子

  • VFA：表换成参数化形式。输入 s，输出 V(s;𝐰)；或输入 (s,a)，输出 Q(s,a;𝐰)
  • 关键区别：更新 𝐰 时，很多状态的值同时改变（表格只改一格）
  • Policy approximation：输入 s，输出 π(a∣s;𝐰)（3.x 讲）

1.7 例子

  • 图像分类：图片 → 类别（cat / dog / …），在像素空间里用 f(x)=Wx 打分
  • CNN 处理图像输入；RNN 处理序列：ht=fW(ht−1,xt)，每步用同一组参数 W

1.8 Agent state update

  • 环境状态不完全可观测时（stenv≠ot），用带参数的 agent state：
st=U(st−1,at−1,ot;𝐰)
  • 以后 st 都指 agent state：可以是 agent 内部的一个向量（如 RNN 隐状态），最简单就是 st=ot

2 · Gradient-based Algorithms

2.1 Gradient descent 回顾

  • J(𝐰) 可微，梯度
∇𝐰J(𝐰)=(∂J(𝐰)∂w1⋮∂J(𝐰)∂wn)
  • 沿负梯度走找局部最小：Δ𝐰=−12α∇𝐰J(𝐰)（α 是步长；12 只是为了消掉平方求导出来的 2）
  • 从 𝐰0 出发得到 𝐰0,𝐰1,…，步长合适时 J(𝐰0)≥J(𝐰1)≥J(𝐰2)≥…

2.2 VFA 的目标函数

  • 目标：最小化真值 Vπ 与近似 V(s;𝐰) 之间的均方误差
J(𝐰)=𝔼s∼d[(Vπ(s)−V(s;𝐰))2]

d 是状态分布（由 policy 和环境动态决定）——误差按访问频率加权，常去的状态更重要

  • 梯度下降：
Δ𝐰=−12α∇𝐰J(𝐰)=α 𝔼d[(Vπ(s)−V(s;𝐰))∇𝐰V(s;𝐰)]

（对 (Vπ−V)2 求导得 −2(Vπ−V)∇V，乘 −12α 正好是上式）

  • 记号：∇V(st) 是 ∇𝐰V(st;𝐰)∣𝐰=𝐰t 的简写

2.3 Feature vector

𝐱(s)=(x1(s)x2(s)⋮xn(s))
  • 𝐱:s→ℝn 是从 state（如 observation）到特征的固定映射；简写 𝐱t=𝐱(st)

2.4 Linear VFA（关键）

V(s;𝐰)=𝐱(s)⊤𝐰=∑j=1nxj(s)wj
  • 目标函数对 𝐰 是二次的：J(𝐰)=𝔼s∼d[(Vπ(s)−𝐱(s)⊤𝐰)2]——凸的，只有一个全局最优
  • 梯度就是特征本身：∇𝐰V(st;𝐰)=𝐱(st)=𝐱t
  • SGD 更新：
Δ𝐰=α(Vπ(st)−V(st;𝐰))𝐱t

Update = step-size × prediction error × feature value

Tabular 是 linear 的特例（课件 Deadly Triad 一页用到）：特征取 one-hot，𝐱(s)=(0,…,1,…,0)⊤（第 s 位是 1）。那么 V(s;𝐰)=ws，更新只改 ws：ws←ws+α(target−ws)，正是表格更新。

2.5 用 target 代替真值

  • 上面假设监督者给出了真值 Vπ(s)——RL 里没有监督者，只有 reward
  • 实际做法：用一个 target 代替 Vπ(s)
  • SGD 每次只用一个样本估计梯度：
Δ𝐰=α(Gt−V(st;𝐰))∇𝐰V(st;𝐰)
  • MC return Gt 是 Vπ(st) 的样本，所以期望更新等于完整梯度更新

2.6 Incremental prediction：三种 target

方法 target 更新 Δ𝐰
MC Gt α(Gt−V(st;𝐰))∇𝐰V(st;𝐰)
TD(0) rt+γV(st+1;𝐰) α(rt+γV(st+1;𝐰)−V(st;𝐰))∇𝐰V(st;𝐰)
TD(λ) Gtλ α(Gtλ−V(st;𝐰))∇𝐰V(st;𝐰)

λ-return 的递归形式：

Gtλ=rt+γ((1−λ)V(st+1;𝐰)+λGt+1λ)

（λ=0 就是 TD(0) target；λ=1 展开后是 MC return Gt。）

2.7 MC with VFA

  • Gt 是 Vπ(st) 的无偏、有噪声的样本
  • 所以可以直接当监督学习，训练数据是 ⟨s1,G1⟩,⟨s2,G2⟩,…,⟨sT,GT⟩
  • Linear MC policy evaluation：
Δ𝐰=α(Gt−V(st;𝐰))𝐱t
  • Linear MC 收敛到（全局 = 局部）最优；非线性 VFA 也收敛，但可能是局部最优——因为它就是真正的 SGD

Gradient Monte Carlo Algorithm for Estimating v^≈vπ

输入：要评估的 policy π；可微函数 v^:𝒮×ℝd→ℝ；步长 α>0

任意初始化 𝐰∈ℝd（如 𝐰=𝟎）

Loop forever（for each episode）：

  • 按 π 生成 episode S0,A0,R1,S1,A1,…,RT,ST
  • Loop t=0,1,…,T−1：𝐰←𝐰+α[Gt−v^(St,𝐰)]∇v^(St,𝐰)

2.8 TD with VFA 与 semi-gradient（关键）

  • TD target rt+γV(st+1;𝐰) 是 Vπ(st) 的有偏样本（用的是估计 V(st+1;𝐰)，不是真值）
  • 仍然可以当监督学习，训练数据是 ⟨st,rt+γV(st+1;𝐰)⟩
  • Linear TD(0)：
Δ𝐰=α(rt+γV(st+1;𝐰)−V(st;𝐰))∇𝐰V(st;𝐰)=α δt 𝐱t

δt=rt+γV(st+1;𝐰)−V(st;𝐰) 是 TD error

  • 像一个不平稳的回归问题；但更特别：target 本身依赖于我们要学的参数 𝐰
  • 我们忽略 target 对 𝐰 的依赖，只对 V(st;𝐰) 求导——所以叫 semi-gradient method

为什么说只是「半个」梯度？ 若对 12(rt+γV(st+1;𝐰)−V(st;𝐰))2 求完整梯度，会多出一项 γ∇V(st+1;𝐰)：

∇𝐰=−δt(∇V(st;𝐰)−γ∇V(st+1;𝐰))

semi-gradient 把 target 当成固定的 label，只保留 ∇V(st;𝐰)。代价：它不是任何目标函数的真梯度，所以 SGD 的收敛保证不能直接套用（第 3 节的发散就来自这里）；好处：简单、快、能在线学。

Semi-gradient TD(0) for estimating v^≈vπ

输入：要评估的 policy π；可微函数 v^:𝒮+×ℝd→ℝ，且 v^(terminal,⋅)=0；步长 α>0

任意初始化 𝐰∈ℝd（如 𝐰=𝟎）

Loop for each episode：初始化 S；Loop for each step：

  • 选 A∼π(⋅∣S)；执行 A，观察 R、S′
  • 𝐰←𝐰+α[R+γv^(S′,𝐰)−v^(S,𝐰)]∇v^(S,𝐰)
  • S←S′；until S is terminal

2.9 Control with VFA

和 tabular 一样走 generalized policy iteration，只是 evaluation 是近似的：

  • Policy evaluation：近似 policy evaluation，Q(st,at;𝐰)≈Qπ
  • Policy improvement：ε-greedy policy improvement

课件的图：从初始 θ 出发，在「Qθ≈Qπ」和「π=ε-greedy(Qθ)」两条线之间来回折，逼近 Qθ≈Q∗。每次 evaluation 不必做完。

2.10 Action-value 的两种结构

形式 适合
Action-in Q(s,a;𝐰)=𝐰⊤𝐱(s,a)：特征里包含 action 连续 action 更容易（后面的讲）
Action-out Q(s;𝐰)=W𝐱(s)，Q(s,a;𝐰)=Q(s;𝐰)[a]：一次输出所有 action 的值 （小的）离散 action 空间常用，如 DQN
  • 一般情况下哪个更好没有定论
  • action-out 的好处：一次前向就得到 max⁡aQ(s,a)，Q-learning 的 target 很便宜

3 · Convergence and Divergence

3.1 要问的问题

  • incremental prediction 算法什么时候收敛？用 bootstrapping（TD）时？用（如线性）VFA 时？用 off-policy learning 时？
  • 理想：所有情况都收敛；退而求其次：搞清楚什么时候收敛、什么时候不收敛

3.2 MC 的不动点

用线性函数（步长适当衰减），MC 收敛到

𝐰MC=arg⁡min⁡𝐰𝔼π[(Gt−V𝐰(st))2]=𝔼π[𝐱t𝐱t⊤]−1𝔼π[Gt𝐱t]

（状态分布隐含依赖 π。）推导：令梯度为 0（这就是最小二乘的 normal equation）

∇𝐰𝔼[(Gt−V𝐰(st))2]=0  ⟺  𝔼[(Gt−𝐱t⊤𝐰MC)𝐱t]=0  ⟺  𝔼[Gt𝐱t−𝐱t𝐱t⊤𝐰MC]=0  ⟺  𝔼[𝐱t𝐱t⊤] 𝐰MC=𝔼[Gt𝐱t]
  • agent state 不必是 Markov：不动点只依赖观测到的数据（和特征）。这和 2.1 讲「MC 对非 Markov 稳健」是同一回事

3.3 TD 的不动点

用线性函数，TD 收敛到（continuing 问题，固定 γ<1，αt→0）：

𝐰TD=𝔼[𝐱t(𝐱t−γ𝐱t+1)⊤]−1𝔼[rt𝐱t]

推导：不动点就是期望更新为 0 的点（假设 αt 与 rt,𝐱t,𝐱t+1 不相关）

𝔼[Δ𝐰TD]=0=𝔼[αt(rt+γ𝐱t+1⊤𝐰TD−𝐱t⊤𝐰TD)𝐱t]0=𝔼[αtrt𝐱t]+𝔼[αt𝐱t(γ𝐱t+1⊤−𝐱t⊤)]𝐰TD𝔼[αt𝐱t(𝐱t⊤−γ𝐱t+1⊤)]𝐰TD=𝔼[αtrt𝐱t]𝐰TD=𝔼[𝐱t(𝐱t⊤−γ𝐱t+1⊤)]−1𝔼[rt𝐱t]

（最后一步 αt 和期望无关，两边约掉。）

对比 MC：MC 是「令一个目标函数的梯度为 0」；TD 是「令 semi-gradient 更新的期望为 0」——不是任何目标函数的最小点。

  • 这个解和 MC 的解不同
  • 渐近来看，通常 MC 的解更好（预测误差最小）
  • 但 TD 往往收敛更快（特别是中间的 λ∈[0,1] 或 n∈{1,…,∞}）

3.4 TD vs MC 的误差界（*）

  • value error：
VE‾(𝐰)=∥Vπ−V𝐰∥dπ=∑sdπ(s)(Vπ(s)−V𝐰(s))2
  • MC 的解最小化 value error

Theorem.

VE‾(𝐰TD)≤11−γVE‾(𝐰MC)=11−γmin⁡𝐰VE‾(𝐰)

怎么读：TD 的误差最多是最优误差的 11−γ 倍。γ 接近 1 时这个倍数很大（γ=0.9 时是 10 倍）——这就是「渐近 MC 更好」的量化版本。如果特征能精确表示 Vπ（最优误差为 0），TD 也是 0。

3.5 发散的例子（必会）

两个状态，一维特征：左边 x=1（V=w），右边 x=2（V=2w），左 → 右 reward r=0。

问：只在这一条转移上做 TD，会怎样？

wt+1=wt+αt(r+γV(s′)−V(s))∇V(s)=wt+αt(r+γV(s′)−V(s))x(s)=wt+αt(0+γ⋅2wt−wt)=wt+αt(2γ−1)wt

设 wt>0。若 γ>12，则 wt+1>wt，lim⁡t→∞wt=∞。

数字：γ=0.9，α=0.1，w0=1：每步乘 1+0.1×0.8=1.08，w=1.08, 1.1664, 1.2597,⋯→∞。

直觉：真值是 w=0（reward 全是 0）。但每次把 V(s)=w 往 target 2γw 拉，而 w 增大时 target 涨得更快（右边特征是 2）；右边状态自己从来不被更新，没人把它拉回来。

3.6 Deadly triad

同时具备以下三者的算法可能发散：

  1. Bootstrapping
  2. Off-policy learning
  3. Function approximation

这叫 deadly triad。上面的例子三者全占：TD（bootstrap）、只更新一条转移（相当于 off-policy 的状态分布）、两个状态共享一个参数（FA）。下面三页课件依次去掉一个，看到都不发散。

3.7 去掉 off-policy：按 on-policy 采样

在右边加一个终止状态（V=0，reward 0）：x=1→x=2→terminal。按 on-policy 走完一整个 episode，两条转移都更新：

Δw=α(0+γ⋅2w−w)+α(0+γ⋅0−2w)=α(2γ−3)w
  • 乘子对所有 γ∈[0,1] 都为负 ⇒ 收敛（w→0，这里正好最优）
  • 关键：右边状态也被更新了，它的误差 −2w 把 w 往回拉

课件第二项没乘特征 x(s′)=2。严格按 Δw=α δ x 算，第二项是 α(0−2w)⋅2，合计 α(2γ−5)w。结论一样：对所有 γ∈[0,1] 都为负。考试照课件写 (2γ−3)w，必要时注明。

3.8 去掉 function approximation：用 tabular 特征

特征换成 one-hot：左边 𝐱=(1,0)，右边 𝐱=(0,1)，即 V(s)=w[0]、V(s′)=w[1]：

  • 这就是普通的回归，答案可能不好，但不会发散
  • 若只更新左边状态：V(s)=w[0] 收敛到 γV(s′)；V(s′)=w[1] 停在初始值
  • 关键：两个状态不共享参数，更新左边不会改变右边的值

3.9 去掉（一部分）bootstrapping：multi-step return

仍然只更新左边状态，但 target 换成 λ-return：

Gtλ=r+γ((1−λ)V(s′)+λGt+1λ),Gt+1λ=r′+γV(s′′)Δw=α(Gtλ−V(s))=α(r+γ(1−λ)V(s′)+γλ(r′+γV(s′′))−V(s))=α(2γ(1−λ)−1)w(r=r′=V(s′′)=0)
  • 乘子为负 ⇔ 2γ(1−λ)<1 ⇔ λ>1−12γ
  • 例：γ=0.9 时要 λ>1−11.8=49≈0.45
  • 关键：λ 越大越接近 MC，bootstrap 的成分 (1−λ) 越小；λ=1（MC）时乘子是 −1，一定收敛

课件这一页前两行把 γ 写成了 λ、漏了几个 γ；上面是按 Gλ 定义补全的式子，最后一行和课件一致。

3.10 收敛表

On/Off-policy 算法 Table Lookup Linear Non-Linear
On-policy MC ✓ ✓ ✓
On-policy TD ✓ ✓ ×
Off-policy MC ✓ ✓ ✓
Off-policy TD ✓ × ×

怎么记：MC 一行全 ✓（真正的 SGD）；table 一列全 ✓（没有泛化）；TD 越往右越差，off-policy TD 只剩 table。

  • tabular control 算法（如 Q-learning）可以推广到 FA（如 DQN）
  • control + FA 的理论还不完善

3.11 收敛一定重要吗？Tracking

  • 实践中常常更想要 tracking（持续调整 policy），而不是收敛到一个固定 policy
  • 真实环境很少静止。只追求收敛的 agent 会找到一个固定的「最优」policy 然后停止学习；环境一变，这个 policy 就过时
  • Tracking：把学习当作持续过程，policy 一直调整，「追踪」环境当前的最优行为
  • 要做到这一点，算法必须保持 plasticity（持续学习和改变的能力），而不是固化

4 · Deep Q Network（DQN）

4.1 Deep RL：DL 和 RL 的三点区别

Deep Learning Reinforcement Learning
监督信号 大量人工标注的数据 标量 reward：稀疏、有噪声、有延迟
样本独立性 假设样本独立 状态序列高度相关
数据分布 假设固定分布 算法学到新行为后分布会变

（Playing Atari with Deep Reinforcement Learning，NIPS workshop 2013）

4.2 DQN in Atari

  • 从像素 s 端到端学 Q(s,a)
  • 输入 state s：最近 4 帧原始像素叠在一起（单帧看不出速度和方向，叠帧让状态更接近 Markov）
  • 输出：18 个摇杆 / 按钮位置各自的 Q(s,a)——action-out 结构
  • Reward：这一步分数的变化
  • 所有游戏用同一个网络结构和同一组超参数

4.3 网络

  • 用 Q(s,a;𝐰) 近似最优 action-value function（课件写 Qπ，指的是 Q∗）
  • 结构：卷积 → 卷积 → 全连接 → 全连接（输出层每个 action 一个值），中间用非线性激活
  • 例：输入游戏画面 s，输出 Q(s,"left";𝐰)、Q(s,"right";𝐰)、Q(s,"up";𝐰)

4.4 结果

  • 柱状图的纵轴是归一化分数
100×DQN score−random play scorehuman score−random play score

100% 表示达到人类水平；在很多游戏上超过人类，少数游戏（需要长期规划的）很差

4.5 用 TD learning 训练 DQN

  • 观察 st，执行 at；环境给出 st+1 和 rt
  • TD target：yt=rt+γmax⁡aQ(st+1,a;𝐰)
  • TD error：δt=Qt−yt，其中 Qt=Q(st,at;𝐰)
  • 目标：让 Qt 对所有 t 都接近 yt（等价地让 δt2 小）
  • 对照 tabular Q-learning：Q(st,at)←Q(st,at)+α[rt+γmax⁡aQ(st+1,a)−Q(st,at)]

训练过程：

  • TD learning：最小化 L(𝐰)=1T∑t=1Tδt22
  • Online gradient descent：
    • 观察 (st,at,rt,st+1)，算 δt
    • 梯度 𝐠t=∂(δt2/2)∂𝐰=δt⋅∂Q(st,at;𝐰)∂𝐰
    • 梯度下降 𝐰←𝐰−α 𝐠t
    • 用完就丢掉 (st,at,rt,st+1)

注意符号：这里 δt=Qt−yt，和第 2 节的 δt=target−V 反号，所以这里是 𝐰−α𝐠t。展开后 𝐰+α(yt−Qt)∇Q，和 2.8 一样。𝐠t 只对 Qt 求导、把 yt 当常数，同样是 semi-gradient。

这已经是 deadly triad：bootstrap（yt 用 Q）+ off-policy（Q-learning）+ 非线性 FA，所以原始版本不稳定。

4.6 两个缺点

Shortcoming 1：浪费经验

  • 一个 transition：(st,at,rt,st+1)；experience：所有 t=1,2,… 的 transition
  • 之前用一次就丢，是浪费

Shortcoming 2：更新相关

  • 之前按 t=1,2,… 顺序用 transition 更新 𝐰
  • 相邻状态 st、st+1 强相关（这不好）
  • 违反了随机梯度下降常用的独立样本假设（和 continual learning 的问题类似）

（怎么解决——experience replay、target network——是 2.4 的内容，不在期中范围。）

Extra reading：Playing Atari with Deep Reinforcement Learning（NIPS workshop 2013）；Human-level Control through Deep Reinforcement Learning（Nature 2015）。

5 · 算例：一步 linear VFA 更新

设 𝐱(s)=(1,0,1)⊤，𝐱(s′)=(0,1,1)⊤，𝐰=(1,2,0.5)⊤，α=0.1，γ=0.9，观察到 s→s′，r=1。

先算值：V(s)=1+0.5=1.5，V(s′)=2+0.5=2.5。

TD(0)：

target=r+γV(s′)=1+0.9×2.5=3.25δ=3.25−1.5=1.75Δ𝐰=α δ 𝐱(s)=0.175 (1,0,1)⊤𝐰′=(1.175, 2, 0.675)⊤

MC（假设这一步之后的 return 是 G=2）：

Δ𝐰=α(G−V(s)) 𝐱(s)=0.1×0.5×(1,0,1)⊤𝐰′=(1.05, 2, 0.55)⊤

观察（泛化）：TD 更新后 V(s)=1.85，同时 V(s′)=2+0.675=2.675 也变了——因为两个状态共享第 3 个特征。表格方法只会改 V(s)。这也是 3.5 发散例子的根源：改 s 时连带改了 target 里的 V(s′)。

做题套路：① 算 V(s)=𝐱(s)⊤𝐰 和 target 里要用的值；② target − 预测 = 误差；③ Δ𝐰=α×误差×𝐱(s)（乘的是 s 的特征，不是 s′ 的）；④ 题目问哪个值就用新 𝐰 重新算。

7 · 易错点

  • linear VFA 的更新乘的是 𝐱(st)（被更新的那个状态的特征），不是 𝐱(st+1)。
  • semi-gradient 的「半」：只对预测 V(st;𝐰) 求导，target 当常数；它不是 J(𝐰) 的真梯度。
  • MC with VFA 是真正的 SGD，非线性也收敛（可能到局部最优）；TD 只在 on-policy + linear 时有保证。
  • 𝐰TD≠𝐰MC；MC 的 value error 更小，但 TD 通常学得更快。
  • 发散例子的条件是 γ>12，和 α 大小无关（α 只影响发散速度）。
  • Deadly triad 要三个同时出现才「可能」发散；线性特征下任意两个都收敛（on-policy TD + linear ✓；off-policy MC + FA ✓；off-policy TD + table ✓）。但收敛表里 on-policy TD + 非线性 也是 ×（没有收敛保证），别说成「只要不凑齐三个就一定收敛」。
  • DQN 一节 δt=Qt−yt（反号），所以是 𝐰−α𝐠t；别把符号弄反。
  • DQN 近似的是 Q∗（Q-learning 的 target 有 max）；课件写成 Qπ 是笔误。
  • Experience replay、target network、Double DQN 是 2.4，期中不考；2.3 只要求说出两个缺点。
