1 · Policy Evaluation

1.1 想法

  • Problem：评估一个给定的 policy π（prediction）
  • 我们只知道 Bellman expectation equation：Vπ(s)=𝔼[rt+γVπ(st+1)]
  • Q：怎样高效算出 Vπ(s)？（矩阵求逆 O(n3) 太贵）
  • High-level idea：把这个等式变成更新，逐步减小和 Bellman equation 的不一致：
V1→V2→⋯→Vπ

1.2 算法

  • 初始化 V0（例如全 0）
  • 迭代：
∀s:Vk+1(s)←𝔼[rt+γVk(st+1)∣s,π]
  • Stopping：当所有 s 都有 Vk+1(s)=Vk(s)，就找到了 Vπ（它满足 Bellman equation）
  • Q：一定收敛吗？ A：是，在适当条件下（如 γ<1）。证明见第 4 节。

1.3 Synchronous backup

每次迭代 k+1，对所有 state s，用 Vk(s′)（s′ 是 s 的后继）更新 Vk+1(s)：

Vk+1(s)=∑a∈𝒜π(a∣s)(r(s,a)+γ∑s′∈𝒮p(s′∣s,a)Vk(s′))

Synchronous：右边全部用旧的 Vk（要存两份）。

1.4 In-place 版本（Sutton & Barto 的算法框）

Iterative Policy Evaluation, for estimating V≈vπ

Input π；参数：小阈值 θ>0 决定精度 初始化 V(s)（任意，V(terminal)=0）

Loop：

  • Δ←0
  • Loop for each s∈𝒮：
    • v←V(s)
    • V(s)←∑aπ(a∣s)∑s′,rp(s′,r∣s,a)[r+γV(s′)]
    • Δ←max⁡(Δ,∣v−V(s)∣)

until Δ<θ

（In-place：直接覆盖 V(s)，后面的 state 立刻用到新值，只存一份，通常收敛更快。）

2 · Policy Improvement

2.1 怎样改进 policy

  • 对参考 policy π，找 π′ 使 Vπ′(s)≥Vπ(s)，∀s
  • 方法：考虑 deterministic policy a=π(s)，acting greedily：
π′(s)=arg⁡max⁡a∈𝒜Qπ(s,a)=arg⁡max⁡a∈𝒜𝔼[r(s,a)+γVπ(st+1)∣st=s,at=a]

Small gridworld：对随机 policy 的 Vk 做贪心——k=3 时得到的 greedy policy 已经是 optimal policy（k=10、k=∞ 也一样）。k=1,2 时还不是。

2.2 Policy Improvement Theorem（证明是考点）

由 π′(s)=arg⁡max⁡aQπ(s,a)，有

Qπ(s,π′(s))=max⁡aQπ(s,a)≥Qπ(s,π(s))=Vπ(s)

Thm. Vπ′(s)≥Vπ(s)，∀s

Proof（反复用「一步按 π′ 走，比按 π 走不差」）：

Vπ(s)≤Qπ(s,π′(s))=𝔼[rt+γVπ(st+1)∣st=s,at=π′(st)]=𝔼π′[rt+γVπ(st+1)∣st=s]≤𝔼π′[rt+γQπ(st+1,π′(st+1))∣st=s]=𝔼π′[rt+γ 𝔼[rt+1+γVπ(st+2)∣st+1,at+1=π′(st+1)] ∣ st=s]=𝔼π′[rt+γrt+1+γ2Vπ(st+2)∣st=s]≤𝔼π′[rt+γrt+1+γ2rt+2+γ3Vπ(st+3)∣st=s]≤⋯≤𝔼π′[rt+γrt+1+⋯∣st=s]=Vπ′(s)∎

每个「≤」是同一个理由：在下一个 state 把 Vπ(st+k) 换成 Qπ(st+k,π′(st+k))（贪心那一步不差）；每个「=」是把 Qπ 按定义展开一步。一直展开下去，所有步都按 π′ 走，就是 Vπ′。

同理 Qπ′(s,a)≥Qπ(s,a)：从 Qπ(s,a)≤Qπ(s,π′(s)) 出发，同样逐步展开（课件第 16 页），得到 ≤Qπ′(s,π′(s))。

如果改进停止了呢？（补充，S&B 4.2）若 Vπ′=Vπ，则 Vπ(s)=max⁡aQπ(s,a)，这就是 Bellman optimality equation ⇒ π 已经是 optimal。

2.3 小结

给定 policy π：

  1. Evaluate：Vπ(s)=𝔼[rt+γrt+1+⋯∣st=s]
  2. Improve：acting greedily w.r.t. Vπ：π′=greedy(Vπ)

Demo：cs.stanford.edu/people/karpathy/reinforcejs/gridworld_dp.html

3 · Policy Iteration 与 Value Iteration

3.1 Policy Iteration

π0 用 Vπ0 改进得到更好的 π1，再算 Vπ1、改进得 π2……

π0→EVπ0→Iπ1→EVπ1→Iπ2→E⋯→Iπ∗

（→E：policy evaluation；→I：policy improvement）

  • Policy evaluation：估计 Vπ（iterative policy evaluation）
  • Policy improvement：产生 π′≥π（greedy policy improvement）

Policy Iteration（S&B 算法框）

  1. Initialization：V(s)∈ℝ、π(s)∈𝒜(s) 任意；V(terminal)=0
  2. Policy Evaluation：Loop：Δ←0；对每个 s：v←V(s)，V(s)←∑s′,rp(s′,r∣s,π(s))[r+γV(s′)]，Δ←max⁡(Δ,∣v−V(s)∣)；until Δ<θ
  3. Policy Improvement：policy-stable←true；对每个 s：old-action←π(s)，π(s)←arg⁡max⁡a∑s′,rp(s′,r∣s,a)[r+γV(s′)]；若 old-action≠π(s)，policy-stable←false 若 policy-stable，停止并返回 V≈v∗、π≈π∗；否则回到 2

为什么一定会停？ 每次改进都不变差（定理），而有限 MDP 的 deterministic policy 只有有限个（∣𝒜∣∣𝒮∣），所以有限步内 policy 不再变。

3.2 Modified Policy Iteration

  • Issue：policy evaluation 要很多次迭代才能得到 Vπ
  • Q：一定要收敛到 Vπ 吗？ 能不能加停止条件？比如 iterative policy evaluation 做 k 次就停？
  • 例如 small gridworld 里 k=3 就足以得到 optimal policy
  • 为什么不每次迭代都更新 policy？ 即 k=1 就停 → 这就是 value iteration

3.3 Value Iteration

Value iteration 直接把 Bellman optimality equation 变成更新：

Value Iteration, for estimating π≈π∗

参数 θ>0；初始化 V(s)，∀s∈𝒮+ 任意，V(terminal)=0

Loop：

  • Δ←0
  • Loop for each s∈𝒮：v←V(s)；V(s)←max⁡a∑s′,rp(s′,r∣s,a)[r+γV(s′)]；Δ←max⁡(Δ,∣v−V(s)∣)

until Δ<θ

输出 deterministic policy：π(s)=arg⁡max⁡a∑s′,rp(s′,r∣s,a)[r+γV(s′)]

和 policy evaluation 只差一处：∑aπ(a∣s) 换成 max⁡a。

3.4 例：Shortest Path

4×4 网格，左上角是 goal，每步 reward −1，deterministic。Value iteration（全部初始化为 0）：

迭代 第一行 最后一行
V1 0 0 0 0 0 0 0 0
V2 0 −1 −1 −1 −1 −1 −1 −1
V3 0 −1 −2 −2 −2 −2 −2 −2
V4 0 −1 −2 −3 −3 −3 −3 −3
V5 −3 −4 −4 −4
V6 −3 −4 −5 −5
V7 0 −1 −2 −3 −3 −4 −5 −6

最终 V∗(i,j)=−(i+j)（离 goal 的步数取负）。信息从 goal 每轮向外传播一格。After the optimal values are reached, run policy extraction to retrieve the optimal policy.

3.5 PI vs VI

Policy Iteration

  1. Evaluation Vπ(s)（内层循环，policy evaluation）
  2. π′(at∣st)=1 if at=arg⁡max⁡atQπ(st,at)，否则 0
  3. π←π′，回到第 1 步

Value Iteration

  1. Q(s,a)←r(s,a)+γ 𝔼s′∼p(s′∣s,a)[V(s′)]
  2. V(s)←max⁡aQ(s,a)，回到第 1 步

区别：

  • Policy iteration：policy evaluation + policy improvement，两者反复交替，直到 policy 收敛
  • Value iteration：先找到 optimal value function，最后做一次 policy extraction。不需要反复，因为 value 已经最优，从它取出的 policy 也一定最优（已收敛）

（课件 VI 第 1 步写 r(s,π(s))、p(s′∣s,π(s))，应该是对每个 a 计算 Q(s,a)，即 r(s,a)、p(s′∣s,a)。）

3.6 Generalized Policy Iteration（GPI）

  • Policy evaluation：估计 Vπ ——任何 policy evaluation 算法
  • Policy improvement：产生 π′≥π ——任何 policy improvement 算法

（PI、VI、以及后面 model-free 的方法都是 GPI 的特例：evaluation 和 improvement 互相推动，最终同时收敛。）

3.7 DP 的效率

  • 基于 state-value Vπ(s) 或 V∗(s)：每次迭代 O(mn2)（m 个 action，n 个 state）
  • 基于 action-value Qπ(s,a) 或 Q∗(s,a)：每次迭代 O(m2n2)
  • 找 optimal policy 是 state 数的多项式时间
  • 但 state 数常常是天文数字，随 state 变量个数指数增长（curse of dimensionality）
  • 实践中经典 DP 可用于几百万个 state 的问题

O(mn2) 怎么来？ 每个 state（n）、每个 action（m）、对所有后继 s′（n）求和。Q 版本：每个 (s,a) 对（mn），对所有 (s′,a′)（mn）。

3.8 Asynchronous DP

  • 前面的 DP 都要扫遍整个 state 集合
  • Asynchronous DP 不用 sweep：反复随机选一个 state，做相应的 backup，直到满足收敛条件
  • 仍需大量计算，但不会被困在漫长的 sweep 里
  • 只要所有 state 都持续被选到，保证收敛

三个简单想法：

方法 做法
In-place DP Synchronous VI 存两份 value（Vnew 由 Vold 算，算完 Vold←Vnew）；in-place 只存一份，直接 V(s)←max⁡a(r(s,a)+γ∑s′p(s′∣s,a)V(s′))
Prioritized sweeping 用 Bellman error 的大小 ∣max⁡a(r(s,a)+γ∑s′p(s′∣s,a)V(s′))−V(s)∣ 选 state；先 backup error 最大的；每次 backup 后更新受影响 state 的 error；需要 reverse dynamics（前驱 state）；用 priority queue 实现
Real-time DP 只关注与 agent 相关的 state：用 agent 的经验（st,at,rt+1）决定 backup 哪个 state；每步后 backup st

3.9 Full-width vs Sample backups

Full-width backups（标准 DP） Sample backups（后续几讲）
做法 每次 backup 考虑所有后继 state 和 action，用真实的转移和 reward 用采样的 ⟨s,a,r,s′⟩ 代替 reward function r 和 dynamics 𝒫
适用 中等规模（百万级 state） 大规模
问题 / 优点 curse of dimensionality：backup 成本随 state 变量数指数增长，连一次完整 backup 都可能太贵 Model-free（不需要事先知道 MDP）；通过采样打破 curse of dimensionality；backup 成本是常数，与 n=∣𝒮∣ 无关

4 · Value Function in Theory：为什么收敛

4.1 Contraction Mapping Theorem

Definition（γ-contraction）. 赋范向量空间 𝒳 上的算子 F 是 γ-contraction（0<γ<1），如果 ∀x1,x2∈𝒳：

∥F(x1)−F(x2)∥≤γ∥x1−x2∥

Theorem（Contraction Mapping）. 对在 F 下 complete（closed）的度量空间 𝒳，若 F 是 γ-contraction，则

  • 迭代 F 收敛到唯一的不动点
  • 收敛速度是线性的，速率 γ

直觉：每用一次 F，任意两点的距离至少缩小到原来的 γ 倍。迭代下去所有点都挤到同一个点——那就是不动点。

4.2 ∞-norm

用 ∞-norm（最大的 state value 差）衡量两个 value function u、v 的距离：

∥u−v∥∞=max⁡s∣u(s)−v(s)∣∥u∥∞=max⁡s∣u(s)∣

4.3 Value function space

  • value function 组成的向量空间 𝒱，有 ∣𝒮∣ 维
  • 空间中每个点完全确定一个 value function V(s)
  • Bellman backup 让 value function 在这个空间里彼此靠近 ⇒ backup 一定收敛到唯一解

4.4 Bellman expectation backup 是 contraction（证明）

定义 Bellman expectation backup 算子：Fπ(V)=rπ+γ𝒫πV

∥Fπ(U)−Fπ(V)∥∞=∥(rπ+γ𝒫πU)−(rπ+γ𝒫πV)∥∞=∥γ𝒫π(U−V)∥∞≤∥γ𝒫π𝟏 ∥U−V∥∞∥∞=∥γ𝟏 ∥U−V∥∞∥∞=γ∥U−V∥∞

每步的理由：

  • 第 2 行：rπ 抵消
  • 第 3 行：U−V 的每个分量都 ≤∥U−V∥∞，而 𝒫π 的元素非负，所以 𝒫π(U−V) 每个分量不超过 𝒫π 乘以全是 ∥U−V∥∞ 的向量（𝟏 是全 1 向量）
  • 第 4 行：𝒫π 每行和为 1，所以 𝒫π𝟏=𝟏

4.5 收敛结论

  • Bellman expectation 算子 Fπ 有唯一不动点
  • Vπ 是 Fπ 的不动点（由 Bellman expectation equation）
  • 由 contraction mapping theorem：
    • iterative policy evaluation 收敛到 Vπ
    • policy iteration 收敛到 V∗

Bellman optimality backup 也是 contraction：定义 F∗(V)=max⁡a∈𝒜(ra+γ𝒫aV)，它也是 γ-contraction（证明类似，多用一个 ∣max⁡af(a)−max⁡ag(a)∣≤max⁡a∣f(a)−g(a)∣）。

  • F∗ 有唯一不动点；V∗ 是它的不动点（Bellman optimality equation）
  • ⇒ value iteration 收敛到 V∗

（课件把算子写成 Pπ、P∗，这里统一写 Fπ、F∗ 以免和转移矩阵混淆。）

6 · 易错点

  • DP 是 planning，要已知 p 和 r；不知道时用 MC / TD（2.1）。
  • Policy evaluation 用 ∑aπ(a∣s)，value iteration 用 max⁡a。
  • Small gridworld 里撞墙的 action 也要算进平均（留在原地，用自己的旧值）。
  • PI 的「收敛」看 policy 不再变；VI 的「收敛」看 value 变化 < θ。
  • V 版本 DP 每轮 O(mn2)，Q 版本 O(m2n2)。
  • Contraction 证明的关键是 𝒫π 行和为 1（𝒫π𝟏=𝟏）和元素非负。
  • Contraction 需要 γ<1；γ=1 时要另外的条件（如所有 episode 都会终止）。
