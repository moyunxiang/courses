0 · 这一讲在讲什么

Roadmap：

  1. Image Classification Pipeline：问题是什么、难在哪
  2. K Nearest Neighbor Classifier：不用训练、直接「找最像的」
  3. Linear Classifier for Image Classification：把 L2 的线性分类推广到图像、多类，并推出 logistic loss 的 gradient
  4. Non-linear Features：只改 ϕ(x) 就能得到非线性 predictor

主线：K-NN 要存全部数据、测试慢 → 能不能把训练数据「压缩」成一组可学习的权重？→ linear classifier → 线性不够用 → non-linear features → 下一讲 neural network 自动学 features。

1 · Image Classification

1.1 问题

  • Input：一张图是一个 tensor，例如 300×500×3（高 × 宽 × RGB 三通道），每个像素值在 [0,255]。
  • Output：预测这张图的类别 label。

1.2 难点（Challenges）

  • Viewpoint variation：相机一动，所有像素值都变了，但还是同一个物体。
  • Illumination changes：光照不同，像素值差很多。
  • Intraclass variation：同一类物体长得很不一样（例：不同口味的巧克力包装，还有归类模糊的 ambiguous category）。

所以不能靠「手写规则」判断像素，必须从数据里学。

1.3 Pipeline（data-driven approach）

  1. 收集图片和 label 组成的数据集
  2. 用 machine learning 训练分类器：train(images, labels) → model
  3. 在新图片上评估：predict(model, test_images) → test_labels

2 · Nearest Neighbor

2.1 两个设计问题

  1. 图片用什么表示（representation）？
  2. 用什么 distance metric 比较两张图？

2.2 L1 distance（逐像素绝对差之和）

D1(I1,I2)=∑p∣I1p−I2p∣

课件例子（4×4 图）：test image 与 training image 逐像素相减取绝对值，得到

[461214182133933121003023222108] →全部相加 456

（逐行和 73+167+52+164=456。）

2.3 Supervised learning 的设置

y=f(x)

  • y：output label，f：classifier，x：input image

  • Training（learning）：给定带 label 的训练集 {(x1,y1),…,(xN,yN)}，训练出 predictor f

  • Testing（inference）：对新的 test example x，输出 y=f(x)

2.4 Nearest Neighbor classifier

  • f(x) = 离 x 最近的那个训练样本的 label（用 distance metric 算距离）
  • 「训练」= 把所有训练数据存起来；每次测试都要搜索全部数据。

2.5 K-Nearest Neighbor（K-NN）

  • 问题：只看 1 个最近邻，遇到 outlier（离群点）就会错。
  • K-NN：找最近的 K 个样本，按它们 label 的多数投票（majority voting）决定。

实际步骤：

  1. 提取每张训练图的 feature，记下 label
  2. 给定测试图，提取 feature，算它和整个训练集的距离
  3. 选出距离最小的 top-K 个邻居，拿到它们的 label
  4. 测试图分到 K 个邻居中最多的那一类

性质：

  • K-NN 能画出类别之间清晰的边界（课件 5-NN 的图）
  • K 越大，对 outlier 越 robust（单个离群点投票被淹没）

2.6 超参数：K 和 distance metric

  • 最好的 K 是多少？用哪种距离？
L1 (Manhattan):D1(I1,I2)=∑p∣I1p−I2p∣L2 (Euclidean):D2(I1,I2)=∑p(I1p−I2p)2
  • 很依赖具体问题 / 数据集，只能都试一试，看哪个效果好。
  • 怎么试：把数据分成 train / validation / test：
    • 在 train 上「训练」（K-NN 就是存起来）
    • 在 validation 上选超参数（K、距离）
    • 最后只在 test 上评估一次

为什么不能直接在 test 上调参？ 那样 test 就被「用过了」，报告出来的准确率会偏乐观，不代表在真正新数据上的表现。

2.7 K-NN 的优缺点

Pros

  • 不需要复杂训练：没有可学习参数，只有超参数
  • 简单，对 outlier 比较 robust

Cons

  • Storage：要存下整个数据集
  • Time：每次预测都要和每个训练样本比，推理时间随训练数据量线性增长

引出问题：能不能把训练样本「压缩」成一组可学习的权重？ → linear classifier。

3 · Linear Classifier for Image Classification

3.1 回顾 L2

  • f(x)=sign⁡(w⋅ϕ(x))；decision boundary w⋅ϕ(x)=0
  • 例：w=[−0.6,0.6] 时 f([0,2])=+1、f([−2,0])=+1、f([1,−1])=−1

3.2 加上 bias term

f(x)=w1x1+w2x2+⋯+wdxd+b=w⋅ϕ(x)+b
  • 没有 b 的话，boundary 必须过原点；加了 b 可以平移。
  • 二分类时 b∈ℝ，只是一个数。
  • （和 L2 里把 1 放进 ϕ(x) 是同一件事的两种写法。）

3.3 多类：每类一组权重

  • 一条 boundary 只能分两类 → 需要多个 boundary = 多个二分类器。
  • 每个类别学一个 weight vector：
car:f1(x)=w1⋅ϕ(x)+b1deer:f2(x)=w2⋅ϕ(x)+b2airplane:f3(x)=w3⋅ϕ(x)+b3
  • 预测：选 score 最大的那一类。

3.4 例：4 个像素、3 个类别（dog / cat / ship）

把 2×2 的图 flatten 成向量 ϕ(x)=[56,231,24,2]。写成矩阵：

f(x)=Wϕ(x)+b
  • W∈ℝ3×4，b∈ℝ3，Score ∈ℝ3
W=[0.2−0.50.12.01.51.32.10.000.250.2−0.3],b=[1.13.2−1.2]

逐行算：

dog: 0.2(56)−0.5(231)+0.1(24) +2(2)+1.1=−96.8cat: 1.5(56)+1.3(231)+2.1(24) +0+3.2=437.9ship: 0.25(231)+0.2(24)−0.3(2) −1.2=60.75
  • 最大是 cat（437.9） → 预测为 cat。
  • ⚠️ 课件写的 ship score 是 61.95，那是没加 bias −1.2 的值；加上 bias 应为 60.75。不影响结论，考试照课件思路算即可。
  • 真实图像：CIFAR 图 32×32×3 → x∈ℝ3072。

W 的每一行可以看成一个「模板」：把 10 个类别的 wi reshape 回图像大小显示，就像每一类的平均模样（课件 “Visualizing W in 10 different classes”）。Score = 图像和模板的 dot product = 匹配程度。

3.5 怎么学这些权重？Logistic loss 的 gradient（推导必会）

回顾 L2：hinge loss 在 margin ≥1 后 gradient 为 0；logistic loss 处处可导、gradient 非零：

Losslogistic(x,y,w)=log⁡(1+e−(w⋅ϕ(x))y)

目标：min⁡wLosslogistic(x,y,w)。要做 gradient descent，就要算 gradient。

关键：认出 sigmoid function

σ(z)=11+e−z(把实数压到 (0,1)，S 形曲线)

于是

log⁡(1+e−w⋅ϕ(x)y)=−log⁡11+e−w⋅ϕ(x)y=−log⁡σ(w⋅ϕ(x)y)

两条求导规则：

[log⁡σ(t)]′=σ′(t)σ(t)
σ′(t)=σ(t)(1−σ(t))=σ(t)σ(−t)

（1−σ(t)=σ(−t)：因为 1−11+e−t=e−t1+e−t=1et+1。）

Chain rule，令 t=w⋅ϕ(x)y，则 ∇wt=ϕ(x)y：

∇wLosslogistic=−∇wlog⁡σ(t)=−σ(t)σ(−t)σ(t) ∇wt=−σ(−w⋅ϕ(x)y) ϕ(x) y

直觉：σ(−m) 是一个 (0,1) 之间的权重：

  • margin m 很大（分得很对）→ σ(−m)≈0 → 几乎不更新
  • margin 很小或为负（分错）→ σ(−m)≈1 → 接近 hinge 的 −ϕ(x)y，大力更新
  • 永远不会正好为 0 → 这就是「margin 超过 1 也继续推大」的来源

更新（对所有训练样本的 gradient 取平均）：

w←w−η ∇wLosslogistic(x,y,w)⏟average gradient from all training samples

3.6 K-NN vs Linear Classifier（常考对比）

K-NN Linear classifier
训练 不需要训练 需要训练
测试时间 慢（要和所有数据比） 快（一次矩阵乘法）
模型类型 Non-parametric，显式搜索数据 Parametric，用参数「记住」数据集
Outlier K 大时更 robust 可能对 outlier 敏感

4 · Non-linear Features

4.1 Feature extraction + learning

ℱ={fw(x)=sign⁡(w⋅ϕ(x)): w∈ℝd}
  • Feature extraction：根据领域知识选 ϕ，也就决定了 ℱ（所有 predictor 里的一个子集）
  • Learning：根据数据在 ℱ 里选一个 fw

两步分工：ϕ 决定「能表达什么」，learning 决定「选哪个」。

4.2 线性不够用

  • 线性回归：ϕ(x)=[1,x]，f(x)=[1,0.57]⋅ϕ(x)、[2,0.2]⋅ϕ(x)……预测和 x 是线性关系。
  • 数据可能是非线性的（课件里的散点先升后降），直线拟合不了。

4.3 Quadratic predictors

ϕ(x)=[1,x,x2],例：ϕ(3)=[1,3,9]
  • 例：f(x)=[2,1,−0.2]⋅ϕ(x)、[4,−1,0.1]⋅ϕ(x)、[1,1,0]⋅ϕ(x)（最后一个其实是直线）
  • ℱ={w⋅ϕ(x):w∈ℝ3}
  • 只改 ϕ 就得到非线性 predictor

4.4 Periodicity structure

ϕ(x)=[1,x,x2,cos⁡(3x)]

  • 例：ϕ(2)=[1,2,4,cos⁡6]=[1,2,4,0.96]

  • 例：f(x)=[1,1,−0.1,1]⋅ϕ(x)、[3,−1,0.1,0.5]⋅ϕ(x)；ℱ⊂{w∈ℝ4}

  • “Just throw in any features you want”：

    • 某个 feature 没用 → 学习算法会给它一个接近 0 的权重
    • 但 feature 越多，学习越难

4.5 Linear in what?（核心概念）

fw(x)=w⋅ϕ(x)
问题 答案
Linear in w？ Yes
Linear in ϕ(x)？ Yes
Linear in x？ No!
  • ϕ(x) 本身对 x 是非线性的，所以 fw(x) 对 x 也是非线性的。

Key idea: non-linearity of features

  • Expressiveness：score w⋅ϕ(x) 可以是 x 的非线性函数 → 表达能力强
  • Efficiency：score 永远是 w 的线性函数 → 优化还是一样简单（gradient 好算）

4.6 Quadratic classifier：圆形 decision boundary

  • 线性 feature ϕ(x)=[x1,x2]、f=sign⁡([−0.6,0.6]⋅ϕ(x)) → boundary 是直线。
  • 非线性 feature：
ϕ(x)=[x1, x2, x12+x22]
f(x)=sign⁡([2,2,−1]⋅ϕ(x))

推导等价形式（配方）：

[2,2,−1]⋅ϕ(x)=2x1+2x2−x12−x22=2−[(x1−1)2+(x2−1)2]

所以

f(x)={+1,(x1−1)2+(x2−1)2<20,(x1−1)2+(x2−1)2=2−1,otherwise
  • Decision boundary 是圆心 (1,1)、半径 2 的圆：圆内 +1，圆外 −1。

4.7 在 feature space 里看

  • Input space x=[x1,x2]：boundary 是圆（非线性）
  • Feature space ϕ(x)=[x1,x2,x12+x22]：boundary 是一个超平面（hyperplane，线性）
  • 也就是：把数据「抬」到更高维的 feature space，原来要用曲线分的，现在一个平面就能分开。

4.8 小结

  • fw(x)=w⋅ϕ(x)：对 w、ϕ(x) 线性，对 x 非线性
  • Regression → 非线性 predictor；classification → 非线性 decision boundary
  • 常见非线性 feature：quadratic、periodic 等
  • 怎么得到更强的非线性 feature？→ Deep neural network 自动学习紧凑、分层的非线性 feature（下一讲）

5 · 总结 & 考点

5.1 Overall summary

  • K-NN：non-parametric（超参数 K 和距离），推理开销大
  • Linear classifier：parametric（可学习权重），loss 有 zero-one / hinge / logistic，推理高效
  • Non-linear features：对 w 线性、对 x 非线性，能建复杂模型

5.2 考点清单

考点 至少要会
图像分类难点 viewpoint、illumination、intraclass variation
L1 / L2 distance 公式；会手算 L1（例：456）
K-NN 步骤 4 步；K 大更抗 outlier
超参数怎么选 train / validation / test；在 validation 上选，test 只评估一次
K-NN 优缺点 不用训练；存储大、推理慢（线性增长）
Bias term w⋅ϕ(x)+b，让 boundary 不必过原点
多类线性分类 每类一个 wi；Wϕ(x)+b；选最大 score；会手算
Logistic gradient −σ(−w⋅ϕ(x)y)ϕ(x)y，会推导（sigmoid + chain rule）
K-NN vs linear 训练 / 测试时间、parametric 与否、outlier
Linear in what w 是，ϕ(x) 是，x 不是；expressiveness vs efficiency
Quadratic classifier 会配方推出圆形 boundary

5.3 易错点

  • K-NN 测试慢、训练快（几乎不用训练），别反过来。
  • 超参数在 validation 上选，不是 test。
  • 多类预测取 argmax score，不是 sign。
  • 「linear classifier」的 linear 指对 w 线性；加了非线性 feature 后对 x 就不是线性的。
  • σ′(t)=σ(t)(1−σ(t))，1−σ(t)=σ(−t)。
