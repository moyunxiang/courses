Part II · Answers

A · Learning paradigms and tasks

  1. Supervised: pairs (x,y); a teacher gives the desired output. Unsupervised: inputs x only, no teacher. Reinforcement: (x,reward); only evaluative feedback, never the correct answer.
  2. Supervised: classification, regression, recommender systems, control (steering network: sharp left / straight ahead / sharp right). Unsupervised: clustering, PCA / eigenfaces, outlier detection, data generation. Reinforcement: mountain car, portfolio trading, robotics.
  3. −1 for every time step until the car reaches the goal, so maximizing reward means reaching the goal fast.
  4. Binary classification y∈{−1,+1} · multiclass classification y∈{1,…,K} · regression y∈R · structured prediction: y is a structured object (sentence, image).
  5. Binary: fraud, toxic comments, Higgs boson. Regression: poverty mapping (asset wealth index), house price, arrival time. Structured: translation, dialogue, captioning, segmentation.
  6. Pre-processing → feature extraction (x=[x1,x2]⊤) → training (learn a decision boundary) → classify new inputs.
  7. Classification error rate = fraction of misclassified patterns. Central issue: generalization to unseen data.

B · Linear regression

  1. fw(x)=w⋅ϕ(x) with ϕ(x)=[1,x], w=[w1,w2], i.e. fw(x)=w1+w2x.

  2. Hypothesis class → linear functions F={fw(x)=w⋅ϕ(x)}. Loss function → squared loss. Optimization algorithm → gradient descent.

  3. Loss(x,y,w)=(fw(x)−y)2

  4. TrainLoss(w)=1∣Dtrain∣∑(x,y)∈DtrainLoss(x,y,w)

  5. Residual =fw(x)−y=w⋅ϕ(x)−y (prediction − target).

  6. The direction that increases the training loss the most.

  7. Chain rule, with ∇w(w⋅ϕ(x))=ϕ(x):

    ∇w(w⋅ϕ(x)−y)2=2(w⋅ϕ(x)−y) ∇w(w⋅ϕ(x))=2(w⋅ϕ(x)−y) ϕ(x)

  8. Average of the per-example gradients:

    ∇wTrainLoss(w)=1∣Dtrain∣∑(x,y)∈Dtrain2(w⋅ϕ(x)−y) ϕ(x)

  9. w←w−η ∇wTrainLoss(w); η>0 is the step size (learning rate).

  10. fw(3)=[1,0.57]⋅[1,3]=2.71; TrainLoss([1,0.57])≈0.38.

C · Linear classification

  1. fw(x)=sign⁡(w⋅ϕ(x)); F={fw:w∈R2}.
  2. Score =w⋅ϕ(x): how confident we are in predicting +1.
  3. Margin m=(w⋅ϕ(x)) y: how correct we are. m>0 means correct.
  4. {x:w⋅ϕ(x)=0}; it is orthogonal to w, and w points to the +1 side.
  5. Loss0-1=1[fw(x)≠y]=1[(w⋅ϕ(x))y≤0]. Note that m=0 counts as an error.
  6. ∇wLoss0-1=0 almost everywhere (piecewise constant), so the update never moves w.
  7. Losshinge=max⁡{1−m, 0}
  8. ∇wLosshinge=−ϕ(x) y if 1−m>0, and 0 otherwise.
  9. Losslogistic=log⁡(1+e−m)
  10. ∇wLosslogistic=−ϕ(x) y e−m1+e−m
  11. m=0: zero-one 1, hinge 1, logistic log⁡2≈0.69. m=2: zero-one 0, hinge 0, logistic log⁡(1+e−2)>0. The hinge loss is always ≥ the zero-one loss. Logistic is >0 for every m, so it keeps increasing the margin.
  12. sign⁡(1.2)=+1, sign⁡(1.2)=+1, sign⁡(−1.2)=−1. Boundary: −0.6x1+0.6x2=0  ⟺  x2=x1.

D · Model evaluation and selection

  1. errorS(h)=1n∑x∈Sδ(f(x)≠h(x)), with δ=1 if f(x)≠h(x) and 0 otherwise. This is what we can measure.
  2. errorD(h)=Pr⁡x∼D[f(x)≠h(x)], the error we want to be low. Estimate: errortest(h)=1∣testSet∣∑x∈testSetδ(f(x)≠h(x)).
  3. Test patterns are drawn independently from the training patterns, and test data is not used in any way to learn the hypothesis.
  4. The training set is only a finite sample from the distribution; different training sets lead to different classifiers (and different regression curves).
  5. h∈H overfits if ∃ h′∈H such that errorS(h)<errorS(h′) but errorD(h)>errorD(h′).
  6. Bias: the amount by which the prediction differs from the true value. Variance: the amount by which the model changes when the training set changes.
  7. Too complex (many hidden units): small bias, large variance. Too simple (few hidden units): large bias, small variance.
  8. Split the data into a training set (learn h) and a validation set (estimate its accuracy); optionally retrain on all the data afterwards. A larger training set gives a better hypothesis, while a larger validation set gives a more accurate error estimate. Typical split: 23 train, 13 validation. To make the estimate more reliable, repeat with different subsamples.
  9. (1) Partition the m examples into k disjoint subsets of size m/k. (2) Run learning k times, each time using one subset for validation and the other k−1 for training. (3) Average the validation performance over the k runs.
  10. Each example is validated on once and trained on in the other k−1 runs. Training fraction 1−1k. k training runs (per model). Typical k≈10.
  11. k=m; each run trains on m−1 examples and validates on 1, so m runs in total. Useful for small data sets.
