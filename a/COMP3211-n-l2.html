0 · 这一讲在讲什么

整讲围绕一个统一框架，后面所有模型（neural network、甚至 RL）都按它拆：

Hypothesis class→ Loss function→ Optimization algorithm
  1. Hypothesis class：哪些 predictor 允许选？
  2. Loss function：怎么评价一个 predictor 好不好？
  3. Optimization algorithm：怎么在允许的里面找到最好的？

Roadmap：Machine learning overview → Linear regression → Linear classification。

读法：regression 和 classification 不是两套东西，只是「输出类型」和「loss」不同，框架完全一样。

1 · Machine Learning Overview

1.1 Reflex-based model

x → f  y

给一个 input x，predictor f 一步直接输出 y（不搜索、不推理）。这一讲和下两讲都是这种模型。

1.2 三类任务（按输出 y 的类型分）

任务 y 是什么 课件里的例子
Binary classification y∈{+1,−1}（label） fraud detection、toxic comments、spam emails
Regression y∈ℝ（response） poverty mapping（卫星图 → 财富指数）、房价、到达时间
Structured prediction y 是复杂对象 machine translation、image captioning、image segmentation
  • 一句话：classification 输出类别，regression 输出连续数值，structured prediction 输出一整个结构（句子、整张分割图）。
  • 判断题型时看输出：「预测房价」是 regression，「判断是否垃圾邮件」是 binary classification。

2 · Linear Regression

2.1 引子：Ceres 的发现

  • 1801 年 Piazzi 观测 Ceres 19 次后，它被太阳挡住。问题：什么时候、在哪里能再看到它？
  • Gauss 用这些数据建立轨道模型做预测，12 月 7 日在离预测 0.5° 以内找到 Ceres，远比其他天文学家准。
  • 方法：least squares linear regression（最小二乘）。

2.2 Learning framework

  • 训练：training data 𝒟train → learning algorithm → predictor f
  • 预测：新输入 x=3 → f → 输出 2.71
  • 设计 learning algorithm = 回答三个问题（hypothesis class、loss、optimization）。

2.3 第一步：Hypothesis class

一维线性回归：

f(x)=w1+w2x(例：1+0.57x,  2+0.2x)
  • w1：intercept / bias，w2：slope。

改写成向量形式（整门课都这么写）：

  • weight vector：w=[w1,w2]
  • feature extractor：ϕ(x)=[1,x]，输出叫 feature vector
  • score：
fw(x)=w⋅ϕ(x)

为什么 ϕ(x) 里要放一个 1？ 为了把 bias w1 也塞进 dot product：[w1,w2]⋅[1,x]=w1⋅1+w2x。这样不管多少个 feature，predictor 永远只是一个 w⋅ϕ(x)。

例：w=[1,0.57]，x=3：

fw(3)=[1,0.57]⋅[1,3]=1+0.57×3=2.71

Hypothesis class = 所有可能 predictor 的集合（不是某一个 predictor）：

ℱ={fw(x)=w⋅ϕ(x): w∈ℝ2}

选定了 ϕ，hypothesis class 就定了；学习只是在 ℱ 里挑一个 w。

2.4 第二步：Loss function

  • 真实答案 y，模型预测 fw(x)，两者之差叫 residual：
residual=fw(x)−y
  • Linear regression 用 squared loss：
Loss(x,y,w)=(fw(x)−y)2

为什么要平方？

  1. 预测高了、低了都要罚：(+2)2=(−2)2=4，正负误差不会互相抵消。
  2. 误差越大，惩罚涨得越快（2 倍误差 → 4 倍 loss）。
  3. 处处可导，好算 gradient。

（课件总结里还提到另一种 regression loss：absolute deviation ∣fw(x)−y∣，对大误差罚得没那么狠。）

2.5 TrainLoss

单个样本的 loss 不够，对整个训练集取平均：

TrainLoss(w)=1∣𝒟train∣∑(x,y)∈𝒟trainLoss(x,y,w)

课件例子：𝒟train={(1,1),(2,3),(4,3)}，w=[1,0.57]

三个预测：1.57, 2.14, 3.28

Loss(1,1)=(1.57−1)2=0.32Loss(2,3)=(2.14−3)2=0.74Loss(4,3)=(3.28−3)2=0.08TrainLoss([1,0.57])=13(0.32+0.74+0.08)=𝟎.𝟑𝟖
  • 可视化：TrainLoss 是 (w1,w2) 平面上的一个碗形曲面（凸的），碗底就是最好的 w。

2.6 第三步：Optimization

问题变成纯数学问题：

min⁡w TrainLoss(w)

Gradient 是什么？

∇wTrainLoss(w) 指向让 training loss 增加最快的方向（steepest ascent）。

  • 1D 直觉：在碗形曲线的左侧，曲线往右在下降，gradient <0；在右侧，gradient >0。
  • 不管在哪边，往 gradient 的反方向走都是往谷底走。

于是 gradient descent：

w←w−η ∇wTrainLoss(w)
  • η：step size（learning rate），每步走多远。
  • 减号一定要记：gradient 指向上坡，所以要走 −∇。

Algorithm（gradient descent）

  1. 初始化 w=[0,…,0]
  2. For t=1,…,T（T = steps）：w←w−η ∇wTrainLoss(w)

2.7 Regression 的 gradient 怎么算（必会）

Objective：

TrainLoss(w)=1∣𝒟∣∑(x,y)∈𝒟(w⋅ϕ(x)−y)2

用 chain rule：外层 u2 求导是 2u，内层 u=w⋅ϕ(x)−y 对 w 求导是 ϕ(x)：

∇wTrainLoss(w)=1∣𝒟∣∑(x,y)∈𝒟2(w⋅ϕ(x)−y) ϕ(x)

记成：

2×(prediction−target)⏟error×ϕ(x)⏟feature
  • 预测偏大（error >0）→ gradient 沿 +ϕ(x) → 更新时 w 往 −ϕ(x) 走 → 下次预测变小。方向是对的。
  • 误差越大，这个样本对更新的贡献越大。

2.8 Gradient descent 例子（课件逐步表格）

同一训练集，w0=[0,0]，η=0.1，更新 w←w−0.1∇wTrainLoss(w)。

第 1 步：w=[0,0] 时三个预测都是 0：

∇=13[2(0−1)[1,1]+2(0−3)[1,2]+2(0−3)[1,4]]=13[−14, −38]=[−4.67, −12.67]w=[0,0]−0.1×[−4.67,−12.67]=[𝟎.𝟒𝟕, 𝟏.𝟐𝟕]

完整迭代：

t ∇wTrainLoss(w) 更新后 w
0 — [0,0]
1 [−4.67,−12.67] [0.47,1.27]
2 [2.18,7.24] [0.25,0.54]
… … …
200 [0,0] [1,0.57]
  • 第 2 步 gradient 变成正的：第 1 步走过头了（斜率 1.27 已超过最优值 0.57），所以往回调。step size 太大就会这样来回震荡。
  • 收敛到 [1,0.57] 时 gradient =0 → 碗底 → 这就是 least squares 的最优解。前面例子用的 f(x)=1+0.57x 就是它，所以 0.38 已经是这组数据能达到的最小 TrainLoss。

2.9 Linear regression 小结

设计决定 Linear regression 的选择
Hypothesis class ℱ={w⋅ϕ(x)}，ϕ(x)=[1,x]
Loss squared loss (fw(x)−y)2
Objective min⁡wTrainLoss(w)
Optimization gradient descent w←w−η∇TrainLoss(w)

3 · Linear Classification

3.1 从 regression 到 classification

  • Regression 输出实数；binary classification 要输出 y∈{+1,−1}。
  • 做法：先算同样的线性 score w⋅ϕ(x)，再取符号：
fw(x)=sign⁡(w⋅ϕ(x)),ϕ(x)=[x1,x2]
sign⁡(z)={+1,z>0−1,z<00,z=0
  • Hypothesis class：ℱ={fw:w∈ℝ2}（例：sign⁡([−0.6,0.6]⋅ϕ(x))、sign⁡([0.5,1]⋅ϕ(x))）

3.2 例子：w=[−0.6,0.6]

f([0,2])=sign⁡(1.2)=+1f([−2,0])=sign⁡(1.2)=+1f([1,−1])=sign⁡(−1.2)=−1

（例如第一个：[−0.6,0.6]⋅[0,2]=0+1.2=1.2。）

3.3 Decision boundary

{x: w⋅ϕ(x)=0}
  • 上例：−0.6x1+0.6x2=0  ⟺  x2=x1，一条过原点的直线。
  • 几何直觉：dot product 的符号由夹角决定。
    • ϕ(x) 与 w 夹锐角 → w⋅ϕ(x)>0 → 预测 +1
    • 夹钝角 → w⋅ϕ(x)<0 → 预测 −1
    • 所以 boundary 是一条与 w 垂直的线，w 指向 +1 那一侧。
  • 恰好落在线上的点（课件问 “What about the points on the red line?”）：score =0 → sign⁡(0)=0，不属于任何一类。

3.4 Score 与 Margin（很重要，别混）

Score：

score=w⋅ϕ(x)
  • 含义：预测 +1 有多 confident。≫0 很确定是 +1，≪0 很确定是 −1。
  • 注意：score 没有看真实 label。

Margin：

margin=(w⋅ϕ(x)) y
  • 含义：预测得有多正确（how correct we are）。
  • 为什么乘 y 就能判断对错？
    • y=+1：分对需要 score >0 → (+)(+)=+
    • y=−1：分对需要 score <0 → (−)(−)=+
    • 分错时符号相反 → 乘积为负
  • 所以：
margin>0  ⟺  分对,margin<0  ⟺  分错
  • margin 越大：不只分对了，而且是很有把握地分对（离 boundary 越远）。

对照：regression 看 residual = score − y；classification 看 margin = score × y。

3.5 Zero-one loss

最直觉的分类 loss：错了记 1，对了记 0。

Loss0-1(x,y,w)=𝟏[fw(x)≠y]=𝟏[(w⋅ϕ(x))y⏟margin≤0]
  • 用 margin 改写：margin ≤0 → loss =1；margin >0 → loss =0。
  • 图像：横轴 margin，在 0 处从 1 跳到 0 的阶梯函数。

例：训练集 {([0,2],+1),([−2,0],+1),([1,−1],−1)}，w=[0.5,1]

Loss([0,2],+1)=𝟏[sign⁡(2)≠1]=0Loss([−2,0],+1)=𝟏[sign⁡(−1)≠1]=1Loss([1,−1],−1)=𝟏[sign⁡(−0.5)≠−1]=0TrainLoss([0.5,1])=13

3.6 为什么不能直接用 zero-one loss 训练？（典型考点）

∇wLoss0-1(x,y,w)=∇ 𝟏[(w⋅ϕ(x))y≤0]
  • 阶梯函数除了跳变点，到处都是平的 → gradient is zero almost everywhere。
  • Gradient descent 拿到 0：w←w−η⋅0=w，原地不动，完全不知道往哪走。
  • 在跳变点上又不可导。
0-1 loss 适合「评价」分类器，但不适合用 gradient「优化」

→ 需要一个好优化的替代 loss（surrogate loss）：hinge 或 logistic。

3.7 Hinge loss

记 m=(w⋅ϕ(x))y：

Losshinge(x,y,w)=max⁡{1−m, 0}

即 max⁡{1−(w⋅ϕ(x))y, 0}。

  • margin ≥1 → loss =0；margin <1 → loss 线性上升（斜率 −1）。
  • 图像：在 m=1 处折一下的折线，始终在 zero-one loss 上方（是它的上界）。

分三种情况理解：

margin m 分类结果 hinge loss
m<0 分错 >1
0<m<1 分对，但不够有把握 0<loss<1
m≥1 分对，离 boundary 足够远 0
  • 第二行最容易错：比如 m=0.2 已经分对了，但 loss =1−0.2=0.8，还在罚。
  • 原因：hinge loss 要求 margin ≥1，不仅要对，还要离 decision boundary 足够远（这就是 SVM 的想法）。

3.8 Hinge loss 的 gradient（必会）

  • 若 m<1：loss =1−(w⋅ϕ(x))y，对 w 求导 → −ϕ(x) y
  • 若 m>1：loss 恒为 0 → gradient 0
∇wLosshinge={−ϕ(x) y,1−(w⋅ϕ(x))y>00,otherwise
  • 在 m=1 这一点不可导（严格说要用 subgradient），课件没展开，考试按上面的分段规则算。
  • 直觉：分得不够好的样本（m<1）推 w 往 ϕ(x)y 方向走，让它的 margin 变大；分得够好的样本不再管。

3.9 Logistic loss

Losslogistic(x,y,w)=log⁡(1+e−(w⋅ϕ(x))y)

即 log⁡(1+e−m)。

  • margin 越大，loss 越小，但永远不会正好等于 0。
  • Differentiable everywhere，gradient 处处非零。
  • Intuition：即使 margin 已经超过 1，也还会继续把 margin 推大（hinge 到 m≥1 就不管了）。

3.10 三种分类 loss 对比（建议直接记）

Loss 公式 图像 特点
Zero-one 𝟏[m≤0] 阶梯 最符合对 / 错，但 gradient 几乎处处为 0
Hinge max⁡{1−m,0} 折线，m=1 处折 m≥1 后 loss = 0、gradient = 0
Logistic log⁡(1+e−m) 平滑下降曲线 处处可导，margin 再大也继续改善

3.11 例：hinge loss 在训练集上（课件计算题）

训练集 {([0,2],+1),([−2,0],+1),([1,−1],−1)}，w=[0.5,1]，ϕ(x)=[x1,x2]。

先算 margin：

m1=([0.5,1]⋅[0,2])(+1)=2m2=([0.5,1]⋅[−2,0])(+1)=−1m3=([0.5,1]⋅[1,−1])(−1)=0.5

再算 loss：

Loss1=max⁡{1−2, 0}=0Loss2=max⁡{1−(−1), 0}=2Loss3=max⁡{1−0.5, 0}=0.5

再算 gradient（m<1 的才有 −ϕ(x)y）：

∇1=[0,0](m1=2≥1)∇2=−[−2,0]⋅(+1)=[2,0]∇3=−[1,−1]⋅(−1)=[1,−1]

取平均：

  • TrainLoss =13(0+2+0.5)=0.83
  • 平均 gradient =13([0,0]+[2,0]+[1,−1])=[1, −0.33]
  • 用平均 gradient 做 gradient descent 更新 w。

计算题套路：margin → loss → 看 m<1 决定 gradient → 平均。

4 · 总结 & 必背

4.1 一张总图

Data → Hypothesis class → Loss → Optimization → w

Regression Classification
Prediction score sign(score)
和 target 的关系 residual = score − y margin = score × y
Loss squared / absolute deviation zero-one / hinge / logistic
Algorithm gradient descent gradient descent

4.2 考点清单

考点 至少要会
三类任务 按输出类型区分
Hypothesis class 所有候选 predictor 的集合 ℱ
Feature extractor ϕ(x)=[1,x]，1 是为了 bias
Squared loss / TrainLoss 会手算（例：0.38）
Gradient steepest ascent；descent 要用减号
Regression gradient 2(w⋅ϕ(x)−y)ϕ(x) 取平均，会手算一步更新
GD 收敛 gradient =0 处就是最优解（[1,0.57]）
Linear classifier sign⁡(w⋅ϕ(x))，sign⁡(0)=0
Decision boundary w⋅ϕ(x)=0，与 w 垂直
Score vs margin score 不看 label；margin >0 ⇔ 分对
0-1 loss 为什么不能优化 gradient 几乎处处为 0
Hinge loss 及 gradient max⁡{1−m,0}；m<1 时 −ϕ(x)y，否则 0
Logistic loss log⁡(1+e−m)，处处可导，margin 超过 1 仍继续推大

4.3 易错点

  • Gradient 指向 loss 上升的方向，更新要减。
  • Hinge loss 在 margin =1 才变 0，不是 0：0<m<1 分对了也有 loss。
  • Hinge gradient 是 −ϕ(x)y，别漏负号，也别漏乘 y。
  • TrainLoss 和 gradient 都要除以样本数。
  • Margin 乘的是真实 label y，不是预测值。
