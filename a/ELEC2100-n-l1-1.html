0 · 这一讲在讲什么

Chapter 1 的大纲：1 Basic concepts → 2 Description and classification of signals → 3 Continuous-time signals → 4 Unit step & unit impulse → 5 Decomposition → 6 Discrete-time signals → 7 System。本讲（1.1）覆盖前三部分：

  1. 信号与系统的基本概念、学习方法
  2. 信号的描述与分类：确定 / 随机、连续 / 离散、周期 / 非周期、能量 / 功率、一维 / 多维
  3. 典型连续信号：指数、正弦（Euler 公式）、复指数、Sa / sinc、Gaussian
  4. 连续信号的运算：加、乘、微分、积分；平移、反转、尺度变换 f(t)→f(at+b)

必考计算：判断周期性并求基波周期（两个正弦之和）；判断能量信号 / 功率信号并算 E 或 P；画 f(at+b) 的波形（先平移再压缩，或换元找新坐标）。概念：连续 / 离散 / 数字信号的区别；复指数 est 中 σ 的符号决定增长 / 衰减。

1 · 基本概念

1.1 Signal 与 System

  • Message：通信系统中，语音、文字、图像、数据统称消息
  • Signal：消息的表示形式和传输载体（消息是信号要传递的实际内容）
  • System：由多个相互作用、相互依赖的部分组成、具有稳定功能的整体
e(t)  ⟶  System  ⟶  r(t)

e：excitation（激励，输入），r：response（响应，输出）。

  • 系统的基本功能：把输入信号处理、变换成需要的输出信号
  • Analog：模拟信号 → analog signal processor → 模拟信号
  • Digital：模拟信号 → ADC → digital signal processor → DAC → 模拟信号
  • 例：RC 电路把方波输入变成指数上升 / 下降的输出——输入经过系统会不会失真？系统怎样影响信号的传输？能否达到想要的处理效果？

1.2 信号与系统理论

研究什么
Signal analysis 信号的描述和性质
System analysis 给定系统，研究它对输入产生的输出
System synthesis 按给定要求设计系统

应用：signal transmission、signal processing。

通信系统：Information source → Transmitter → Channel（+ Noise）→ Receiver → Destination。发送端把消息变成信号，接收端把信号还原成消息。历史：1844 Morse 第一封电报；1876 Bell 发明电话；之后有线、微波、光纤、卫星、移动通信（1G 模拟 → 2G TDMA / GSM → 3G CDMA → 4G OFDMA、MIMO → 5G massive MIMO、NOMA → 6G）。

Signal processing 例：带噪声的音乐，经过滤波降噪——目的是把信号变成便于分析识别的形式，高效地估计和选择特征参数。

1.3 学习方法（课件建议）

  • 注意物理概念与数学分析的对应，不要盲目计算
  • 注意分析结果的物理解释、参数变化时的物理意义和后果
  • 同一问题可能有多种解法，找最简单合理的，比较各方法的优缺点
  • 课程结束很久以后仍要反复学习基本概念

2 · 信号的描述与分类

描述方法：信号可表示为一个或多个自变量的函数——函数式（如 f(t)=sin⁡(ωt)）、波形图、表格。

2.1 Deterministic vs Random

定义 例
Deterministic 任一时刻 t，信号值 f(t) 确定 sin⁡(ωt)
Random 有不可预知的不确定性，瞬时值事先不能确定 鼠脑电图信号

2.2 Continuous vs Discrete

  • Continuous-time signal：在信号存在的时间范围内，除有限个间断点外每一时刻都有定义；用连续变量 t，记 f(t)
  • Discrete-time signal：只在某些不连续的离散时刻有定义，其他时刻无定义；用离散变量 n，记 f[n]

连续 → 采样 → 量化：

时间 幅值
Continuous signal f(t) 连续 连续
Sampled signal f[n]（采样后） 离散 连续
Digital signal q[n]（再量化后） 离散 离散

例 1：三个波形——连续波形是 continuous signal；只在整数点有值、幅值任意的是 discrete signal；只在整数点有值且幅值只取 1、2、3 的是 discrete signal 且是 digital signal。

判断套路：先看时间是否离散（discrete vs continuous），再看幅值是否只取有限个值（digital）。

2.3 Periodic vs Aperiodic

周期信号：

f(t)=f(t+nT),n=0,±1,±2,…
  • 基波周期 T：满足上式的最小正值（单位 s）
  • 基波频率 f0=1T（Hz）
  • 基波角频率 ω0=2πf0=2πT（rad/s）
  • 正弦周期信号（harmonic signal）：单一频率；复杂周期信号（方波、三角波等）：可以用 Fourier series（一组谐波相关的正弦之和）表示

两个周期信号之和的周期性（必考）：

和是周期的   ⟺   两个周期之比 T1T2 是有理数。此时 T=k1T1=k2T2（k1,k2 正整数），取最小的那个。

例 2：f(t)=cos⁡10t+cos⁡30t 是否周期？

  • cos⁡10t：T1=2π10；cos⁡30t：T2=2π30
  • T1T2=k2k1=3，有理数 ⇒ 周期
  • 最小 k1=1（k2=3）：T=k1T1=2π10=π5
  • ω0=2πT=10 rad/s

快速法（补充）：ω0 是 10 和 30 的最大公约数 =10，T=2π/ω0。

非周期信号：

  • Transient signals：脉冲、衰减函数
  • Quasi-periodic signals：由周期信号组成但周期之比是无理数，整体不周期——如 sin⁡(πt)+sin⁡(t)（T1T2=22π=1π，无理）

2.4 Energy vs Power（必考）

把信号 f(t) 看成加在 1 Ω 电阻上的电压（或电流）：

  • Normalized instantaneous power：p(t)=∣f(t)∣2
  • Normalized energy（signal energy）：
E=∫−∞∞∣f(t)∣2 dt
  • Average power（整个时间轴上的平均）：
P=lim⁡T→∞1T∫−T/2T/2∣f(t)∣2 dt
能量 E 功率 P 典型例子
Energy signal 有限（0<E<∞） 0 大多数时限信号
Power signal 无穷 有限（0<P<∞） 周期信号、step function、signum function

为什么能量有限 ⇒ 功率为 0？ P=lim⁡ETT，分子有界、分母 →∞。反之功率有限且非零，能量一定无穷。

例 3：f1(t)=1（0≤t≤2），否则 0：

E1=∫0212 dt=2,0<E1<∞,P1=0  ⇒  energy signal

例 4：f2(t) 是周期为 2、每周期在 [0,1] 上为 1 的方波（无限延续）：

P2=12∫0112 dt=0.5,0<P2<∞,E2=∞  ⇒  power signal

周期信号的平均功率 = 一个周期内的平均：P=1T∫0T∣f(t)∣2dt。 有的信号既不是能量信号也不是功率信号（例如 et 在整个时间轴上，E 和 P 都无穷）。

2.5 One-dimensional vs Multidimensional

  • 一维：一个自变量（时间或空间），如音频（waveform、spectrum）
  • 多维：需要多个自变量，如图像（Lenna 图，双边滤波）、电磁场分布、Wi-Fi 信号强度的可视化

3 · 典型连续信号

3.1 指数信号

f(t)=Aeαt
α 波形
α=0 常数（DC）
α<0 指数衰减
α>0 指数增长
  • 关键性质：对时间求导、积分仍是指数形式

单边指数信号：f(t)=e−t/τ（t>0）

  • τ：time constant，有时间的量纲，表示衰减速度
  • t=τ 时 f(t)=1e≈0.368（衰减到初值的 36.8%）

3.2 正弦信号

f(t)=Asin⁡(ωt+θ)
  • Amplitude A；angular frequency ω；initial phase θ
  • f=ω2π，T=1f=2πω

Euler's formula（「数学的桥梁」）：

ejθ=cos⁡θ+jsin⁡θ,e−jθ=cos⁡θ−jsin⁡θ
  • 复平面上，从原点到单位圆上、与实轴夹角 θ 的点：polar form 1∠θ=ejθ；rectangular form cos⁡θ+jsin⁡θ
  • 特殊值：j=ejπ/2，−1=ejπ，−j=e−jπ/2；Euler's identity ejπ+1=0
  • 电子工程里虚数单位常写作 j

令 θ=ωt：

cos⁡(ωt)=12(ejωt+e−jωt),sin⁡(ωt)=12j(ejωt−e−jωt)

（复指数与三角函数的桥梁——Fourier 分析的基础。）

单边衰减正弦：

f(t)={Ke−αtsin⁡(ωt),t≥00,t<0(α>0)

3.3 复指数信号

f(t)=Kest,−∞<t<∞
  • s=σ+jω 是复数，叫 complex frequency；K、σ、ω 都是常数
  • σ 的量纲是 1/s，ω 的量纲是 rad/s
  • ω=0：f(t)=Keσt，就是实指数信号
  • ω≠0：
f(t)=Ke(σ+jω)t=Keσtcos⁡(ωt)+jKeσtsin⁡(ωt)

实部和虚部都是振荡：

σ 振荡
σ=0 等幅（constant-amplitude）
σ>0 增幅（amplifying）
σ<0 衰减（decaying）

（复指数一个式子就概括了 DC、指数、正弦、衰减 / 增长正弦——所以它是 Laplace 变换的基本信号。）

3.4 Sampling signal：Sa 与 sinc

Sa(t)=sin⁡tt
  • 偶函数：Sa(−t)=Sa(t)
  • t=0：lim⁡t→0Sa(t)=1
  • 零点：Sa(t)=0 于 t=±nπ，n=1,2,3,…
  • lim⁡t→±∞Sa(t)=0
  • 中间 [−π,π] 是 main lobe（主瓣），两边是 side lobes（旁瓣）
  • 积分：
∫0∞Sa(t) dt=π2,∫−∞∞Sa(t) dt=π

（正好等于主瓣的「内接三角形」面积：底 2π、高 1，面积 π）

sinc(t)=sin⁡(πt)πt=Sa(πt)

零点在 t=±1,±2,…

（Sa / sinc 在 Ch3 中是矩形脉冲的 Fourier transform，非常重要。）

3.5 Gaussian pulse

f(t)=Ee−(t/τ)2
  • 钟形，t=0 时最大值 E；t=τ 时降到 Ee

4 · 连续信号的运算

4.1 因变量的运算

  • 相加 / 相乘：同一时刻的值相加 / 相乘（例：sin⁡(πt)+sin⁡(8πt) 是慢变化上叠加快振荡；sin⁡(πt)⋅sin⁡(8πt) 是快振荡被慢包络调制）
  • 微分：f′(t)=df(t)dt
  • 积分（running integral）：∫−∞tf(τ) dτ

课件例（宽 τ 的脉冲，在 −τ2 到 τ2 之间）：

  • 梯形（从 −τ2 到 0 线性上升到 1，然后保持 1 到 τ2，再跳回 0）求导：上升段导数 =1τ/2=2τ，平段为 0，在 t=τ2 的跳变（下降 1）处产生一个强度 −1 的冲激
  • 矩形脉冲（高 1，从 −τ2 到 τ2）的 running integral：从 0 线性上升到 τ（在 t=τ2），之后保持 τ

信号有跳变时，导数在跳变处是一个冲激，强度 = 跳变量（向上跳 +，向下跳 −）——1.2 讲 δ(t) 时会严格讲。

4.2 自变量的变换：f(t)→f(at+b)

  • f：函数（映射）；at+b：argument；t：自变量
  • 变换后，波形的横坐标仍是 t
  • 所有变换都作用在 t（自变量）上！

4.3 平移（shifting）

f(t)→f(t−τ)
  • τ>0：右移（delay，延迟）
  • τ<0：左移（advance，超前）

例 1：f(t) 在 [−1,1] 上（从 −1 线性升到 1 于 t=0，再保持 1 到 t=1），画 f(t−1)：整体右移 1，变成 [0,2]。

  • 「幅值不变、函数值相同、移动时间坐标」：f(t) 在 t=0 时为 1 ⇒ f(t−1) 在 t−1=0 即 t=1 时为 1

例：多径传输（信号延迟）：

r(t)=a1e(t−τ1)+a2e(t−τ2)+a3e(t−τ3)+a4e(t−τ4)

接收到的是同一信号经不同路径延迟、衰减后的叠加。

4.4 反转（reversal）

f(t)→f(−t)
  • 沿纵轴翻折，过去和未来对调（例：f(t) 在 [−2,1] ⇒ f(−t) 在 [−1,2]）
  • 现实中没有物理器件能实现（要用到未来的值）；但在数字信号处理中可以实现，例如用后进先出（LIFO）栈

4.5 尺度变换（scaling）

f(t)→f(at),a 是实数
a 效果
a>1 压缩（compression）
0<a<1 扩展（expansion）

（时间变量乘系数 = 改变观察的时间尺度。）

例 2：f(t) 在 [0,T] 上从 1 线性升到 2。

f(2t)——「同样的 argument，同样的函数值，找新坐标」：

t f(t) → 2t f(2t) t f(2t)
0 1 0 1 0 1
T 2 T 2 T/2 2

⇒ f(2t) 在 [0,T2] 上：压缩一半。

f(t2)：t2=T ⇒ t=2T ⇒ 在 [0,2T] 上：扩展一倍。

4.6 一般形式 f(at+b)（必考）

例 3：已知 f(t)（在 [−1,1] 上），画 f(3t+5)。

方法 1（先平移后压缩）：

  1. t→t+5：左移 5，得 f(t+5)，在 [−6,−4]
  2. t→3t：压缩 3 倍（f(t+5)→f(3t+5)，每个点的横坐标除以 3），得在 [−2,−43]

方法 2（先压缩后平移）：

  1. t→3t：压缩，得 f(3t)，在 [−13,13]
  2. 注意：f(3t+5)=f(3(t+53))，所以要左移 53（不是 5！），得 [−13−53,13−53]=[−2,−43]

方法 3（找端点，最可靠）：令 argument 等于原来的端点：

3t+5=−1⇒t=−2,3t+5=1⇒t=−43

解题套路：f(at+b) 的点 t 对应原信号的 at+b。求新横坐标：t=told−ba。先压缩再平移时，平移量是 ba。a<0 时还要反转。

6 · 易错点

  • f(t−τ)，τ>0 是右移（延迟）。
  • f(2t) 是压缩，不是扩展。
  • f(3t+5) 先压缩时，平移量是 53 而不是 5。
  • 两正弦之和：周期比有理才周期；基波周期取最小公倍的那个。
  • 能量信号的功率为 0；功率信号的能量无穷；有的信号两者都不是。
  • 周期信号是功率信号。
  • Sa 的零点是 ±nπ（n≠0），sinc 的零点是 ±n。
  • 数字信号要求时间和幅值都离散。
