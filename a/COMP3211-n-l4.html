0 · 这一讲在讲什么

Roadmap 两部分：

  1. Neural networks：从「手选 non-linear feature」到「让网络自己学 feature」
  2. Backpropagation：在 computation graph 上用 chain rule 自动算 gradient

和前两讲的关系：L2 的框架（hypothesis class → loss → gradient descent）完全不变，只是 hypothesis class 换成神经网络；而神经网络的 gradient 手推太难，所以要 backpropagation。

1 · Neural Networks

1.1 从 linear 到 non-linear predictors

Predictor 公式 feature 从哪来
Linear fw(x)=w⋅ϕ(x)，ϕ(x)=[1,x] 手选
Quadratic（L3） fw(x)=w⋅ϕ(x)，ϕ(x)=[1,x,x2] 手选非线性 feature
Neural network fw(x)=w⋅σ(Vϕ(x))，ϕ(x)=[1,x] 从数据中学
  • Neural network：从输入 x 中学到高度紧凑（compact）且非线性的 feature。

1.2 结构：intermediate features

h(x)=σ(Vϕ(x))

各部分的含义：

  • ϕ(x)：input（原始数据或已提取的 input features）
  • V：用来学 feature 的参数 / 权重（一个矩阵）
  • σ：non-linear activation function，例如 sigmoid σ(z)=11+e−z，逐元素作用
  • h(x)：hidden feature representation（隐藏层）

Predictor（classification）：

fV,w(x)=sign⁡(w⋅h(x))

Interpret h(x) as a learned feature representation! 对比 L3：L3 里 ϕ(x) 是人手设计的；这里 h(x) 是网络通过学习 V 自动得到的 feature，后面再接一个 linear classifier w。

为什么一定要非线性的 σ？ 如果没有 σ：w⋅(Vϕ(x))=(V⊤w)⋅ϕ(x)，又退化成一个 linear predictor，叠多少层都一样。非线性激活才让网络比线性模型强。

1.3 Deep neural networks（多层）

1-layer:score=w⋅ϕ(x)2-layer:score=w⋅σ(Vϕ(x))3-layer:score=w⋅σ(V2 σ(V1ϕ(x)))
  • 规律：每多一层，就多一个「线性变换 + 非线性激活」。
  • 注意计数：1-layer 就是 linear classifier；「几层」数的是有几个权重矩阵（V1,V2,w）。

1.4 层代表不同层次的抽象

以人脸为例（figure from Honglak Lee），从下往上：

层 学到的东西
Pixels 原始像素
Earlier layers Edges（边缘）
Middle layers Object parts（眼睛、鼻子等部件）
Deep layers Object（整张脸）

1.5 Why depth?

ϕ(x)→h1(x)→h2(x)→h3(x)→h4(x)→score

Intuitions：

  • Multiple levels of abstraction（多层抽象）
  • 能建模输入和输出之间的复杂关系
  • Empirically works well（实践效果好）
  • Theory is still incomplete（理论还不完整）

1.6 例：3-layer feed-forward computation

结构：input layer（3 个）→ hidden layer 1（4 个）→ hidden layer 2（4 个）→ output layer（1 个），权重 W1,W2,W3。

# activation function (sigmoid)
f = lambda x: 1.0/(1.0 + np.exp(-x))
# random input vector of three numbers (3x1)
x = np.random.randn(3, 1)
# first hidden layer activations (4x1)
h1 = f(np.dot(W1, x) + b1)
# second hidden layer activations (4x1)
h2 = f(np.dot(W2, h1) + b2)
# output neuron (1x1)
out = np.dot(W3, h2) + b3
  • 维度：W1∈ℝ4×3，W2∈ℝ4×4，W3∈ℝ1×4。
  • 输出层不加激活，直接输出 score。

1.7 训练一个 2-layer 网络的完整实现（约 20 行）

import numpy as np
from numpy.random import randn

N, D_in, H, D_out = 64, 1000, 100, 10
# 1. define network input and output
x, y = randn(N, D_in), randn(N, D_out)
w1, w2 = randn(D_in, H), randn(H, D_out)

for t in range(2000):
    # 2. feed-forward computation
    h = 1 / (1 + np.exp(-x.dot(w1)))
    y_pred = h.dot(w2)
    loss = np.square(y_pred - y).sum()
    print(t, loss)

    # 3. analytical gradient calculation
    grad_y_pred = 2.0 * (y_pred - y)
    grad_w2 = h.T.dot(grad_y_pred)
    grad_h = grad_y_pred.dot(w2.T)
    grad_w1 = x.T.dot(grad_h * h * (1 - h))

    # 4. gradient descent to update parameters
    w1 -= 1e-4 * grad_w1
    w2 -= 1e-4 * grad_w2

四步对应：

  1. 定义 network 的输入 / 输出和参数
  2. Feed-forward：h=σ(xw1)，y^=hw2，loss = squared loss 之和
  3. 手推 gradient：
    • ∂L/∂y^=2(y^−y)
    • ∂L/∂w2=h⊤⋅∂L/∂y^
    • ∂L/∂h=∂L/∂y^⋅w2⊤
    • ∂L/∂w1=x⊤(∂L/∂h⊙h⊙(1−h))（h(1−h) 就是 sigmoid 的导数）
  4. Gradient descent：learning rate 10−4

2 · 为什么需要 Backpropagation

2.1 (Bad) idea：在纸上推 ∇WL

对一个很复杂的网络（从 input image 到 loss 上百层）：

  • Very tedious：大量 matrix calculus，要写很多页纸
  • 换个 loss 就要重来：比如把 logistic loss 换成 hinge loss，得从头推
  • 对每个复杂模型都这么推，不可行

2.2 (Good) idea：Computational graphs + Backpropagation

把计算拆成一个个简单节点组成的图，例如 linear classifier + hinge loss + 正则：

  • x,W→ ∗ s=Wx（scores）
  • s→hinge lossLi=∑max⁡(0, 1−(Wxi)yi)
  • Li→ + L

另一支：W→R(W)（weights regularization）也加进 L。

  • 每个节点只需要知道自己的 local gradient，整张图的 gradient 用 chain rule 自动串起来。

3 · Backpropagation

3.1 单个节点：local / upstream / downstream gradient

节点 f：输入 x,y，输出 z=f(x,y)，最终 loss 为 L。

  • Local gradient：∂z∂x, ∂z∂y（只和这个节点自己的运算有关）
  • Upstream gradient：∂L∂z（从后面传回来的）
  • Downstream gradient：要求的 ∂L∂x, ∂L∂y

Chain rule：

∂L∂x=∂L∂z⋅∂z∂x,∂L∂y=∂L∂z⋅∂z∂y
downstream=upstream×local
  • 每个节点都这样做，从输出往输入一路往回传 → 这就是 backpropagation。

3.2 简单例子：f(x,y,z)=(x+y)z（必会）

取 x=−2, y=5, z=−4。拆成两个节点：

q=x+y,f=qz

Forward pass（从左往右算值）：

q=−2+5=3,f=3×(−4)=−12

Local gradients：

q=x+y:∂q∂x=1,∂q∂y=1f=qz:∂f∂q=z,∂f∂z=q

Backward pass（从右往左，想要 ∂f∂x,∂f∂y,∂f∂z）：

∂f∂f=1(base case)∂f∂z=q=3∂f∂q=z=−4∂f∂y=∂f∂q⏟upstream⋅∂q∂y⏟local=(−4)(1)=−4∂f∂x=∂f∂q⋅∂q∂x=(−4)(1)=−4

检验：f=(x+y)z 直接求导，∂f/∂x=z=−4 ✓，∂f/∂z=x+y=3 ✓。

3.3 Patterns in gradient flow（四种门，必背）

门 名字 规则 课件例子
add gradient distributor 把 upstream 原样分给每个输入 输入 3、4，输出 7；upstream 2 → 两个输入都得 2
mul “swap multiplier” 每个输入的 gradient = upstream × 另一个输入的值 输入 2、3，输出 6；upstream 5 → 第一个得 5×3= 15，第二个得 2×5= 10
copy gradient adder 一个值被用到多处，各分支传回的 gradient 相加 7 复制成两份，回传 4 和 2 → 得 4+2= 6
max gradient router 只有较大的那个输入拿到 upstream，另一个得 0 输入 4、5，max = 5；upstream 9 → 5 得 9，4 得 0

为什么：

  • add：z=x+y，∂z/∂x=∂z/∂y=1，所以 downstream = upstream × 1。
  • mul：z=xy，∂z/∂x=y、∂z/∂y=x，所以是「交换」后相乘。
  • copy：多元 chain rule，一个变量影响 L 的所有路径要加起来。
  • max：z=max⁡(x,y)，对较大的那个导数是 1，另一个是 0。

3.4 完整例子：L=Sigmoid(w0x0+w1x1+w2)

取 w0=2，x0=−1，w1=−3，x1=−2，w2=−3。

Forward pass（代码 def L(x0, x1, w0, w1, w2)）：

s0=w0x0=−2s1=w1x1=6s2=s0+s1=4s3=s2+w2=1L=σ(s3)=11+e−1=0.73

Backward pass：

base case:∂L∂L=1sigmoid:∂L∂s3=1⋅σ(s3)(1−σ(s3))=σ(1)(1−σ(1))=0.20

Add gate（原样分发）：

∂L∂w2=∂L∂s2=0.20,∂L∂s0=∂L∂s1=0.20

Multiply gate（乘另一个输入）：

∂L∂w0=0.20×x0=0.20×(−1)=−0.20∂L∂x0=0.20×w0=0.20×2=0.40∂L∂w1=0.20×x1=0.20×(−2)=−0.40∂L∂x1=0.20×w1=0.20×(−3)=−0.60

对应代码：

# forward pass: compute outputs
s0 = w0 * x0
s1 = w1 * x1
s2 = s0 + s1
s3 = s2 + w2
L = sigmoid(s3)
# backward pass: compute gradients
# base case
grad_L = 1.0
# sigmoid
grad_s3 = grad_L * (1 - L) * L
# add gate
grad_w2 = grad_s3
grad_s2 = grad_s3
# add gate
grad_s0 = grad_s2
grad_s1 = grad_s2
# multiply gate
grad_w0 = grad_s0 * x0
grad_x0 = grad_s0 * w0
grad_w1 = grad_s1 * x1
grad_x1 = grad_s1 * w1
  • 注意 sigmoid 的导数直接用了 forward 时算好的 L：σ′(s3)=L(1−L)，不用重新算 exp。这就是为什么要先 forward 存下中间值。

3.5 把 sigmoid 再拆开（课件问：Can we further decompose the Sigmoid?）

σ(s3)=11+exp⁡(−s3)

拆成四个节点：×(−1)→exp⁡→+1→1/x。

Forward：

s4=−s3=−1s5=es4=0.37s6=s5+1=1.37s7=1s6=0.73

Backward（从 ∂L/∂s7=1 开始）：

∂L∂s6=1⋅(1s6)′=−1s62=−11.372=−0.53∂L∂s5=(−0.53)⋅(s5+1)′=−0.53∂L∂s4=(−0.53)⋅es4=(−0.53) e−1=−0.20∂L∂s3=(−0.20)⋅(−1)=0.20
  • 结果和直接用 σ′=σ(1−σ) 得到的 0.20 一样 → 节点怎么拆都可以，只要每个节点的 local gradient 会算。
  • 之后的 add / multiply gate 和 3.4 完全相同。

各节点的 local gradient 速查：

节点 前向 local gradient
×(−1) −x −1
exp⁡ ex ex
+1 x+1 1
1/x 1/x −1/x2
sigmoid σ(x) σ(x)(1−σ(x))

4 · 总结 & 考点

4.1 Overall summary

  • Neural networks：学习分层的 feature representation
  • Backpropagation：基于 computation graph 计算 gradient 的通用算法（也帮助可视化、理解 gradient）
  • 下一讲：unsupervised learning、stochastic gradient descent、generalization、ML best practices

4.2 考点清单

考点 至少要会
NN 公式 h(x)=σ(Vϕ(x))，f=sign⁡(w⋅h(x))；各符号含义
为什么要非线性激活 否则多层退化成一个 linear predictor
Deep NN 1 / 2 / 3-layer 的 score 公式
层次抽象 pixels → edges → object parts → object
Why depth 多层抽象、复杂关系、经验有效、理论不完整
手推 gradient 的问题 繁琐、换 loss 要重来、复杂模型不可行
Chain rule downstream = upstream × local
(x+y)z 例题 forward q=3,f=−12；backward −4,−4,3
四种门 add 分发、mul 交换相乘、copy 相加、max 路由
Sigmoid 例题 会画图、forward、backward 每个数（0.73、0.20、−0.20、0.40、−0.40、−0.60）
拆 sigmoid ×(−1)、exp、+1、1/x 的 local gradient，结果仍是 0.20

4.3 易错点

  • Mul gate 乘的是另一个输入的值，不是自己的。
  • Copy（分支）处 gradient 是相加，add gate 处是复制，两者别搞反。
  • Max gate 只有大的那一支有 gradient。
  • Backward 前必须先 forward，因为 local gradient 要用 forward 的中间值（例：σ′=L(1−L)）。
  • Sigmoid 导数 σ(1−σ)，在 s3=1 时是 0.73×0.27≈0.20。
