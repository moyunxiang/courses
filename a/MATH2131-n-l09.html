1 · 为什么要 determinant

det 决定 A𝐱=𝐛 是否有唯一解：

A𝐱=𝐛 has a unique solution  ⟺  A is invertible  ⟺  det⁡(A)≠0

2 · 公理化定义

Def. The determinant is a function det⁡:Mn×n(K)→K satisfying：

  1. Multilinear w.r.t. columns：（其他列固定）
    det⁡(⋯ 𝐮+𝐯 ⋯ )=det⁡(⋯ 𝐮 ⋯ )+det⁡(⋯ 𝐯 ⋯ )
    det⁡(⋯ c𝐯 ⋯ )=cdet⁡(⋯ 𝐯 ⋯ ),c∈K
  2. Alternating：交换两列变号
    det⁡(⋯ 𝐮 ⋯ 𝐯 ⋯ )=−det⁡(⋯ 𝐯 ⋯ 𝐮 ⋯ )
  3. det⁡(I)=1

注意：multilinear 是对每一列分别线性，不是 det⁡(A+B)=det⁡A+det⁡B（这个一般不成立）。

3 · 由公理推出的性质

3.1 两列相同 ⇒ det = 0

Rem. ②   ⟺   ②′：If A has 2 same columns ⇒ det⁡A=0

Pf.

  • (⇒) 令 𝐯=𝐮：交换这两列，矩阵不变，但 det 变号 ⇒ det⁡A=−det⁡A ⇒ det⁡A=0（需要 2≠0）
  • (⇐) 把 𝐮+𝐯 同时放在两列，由 ②′ 和 ①：
0=det⁡(⋯ 𝐮+𝐯 ⋯ 𝐮+𝐯 ⋯ )=①det⁡(⋯𝐮⋯𝐮⋯ )⏟0+det⁡(⋯𝐮⋯𝐯⋯ )+det⁡(⋯𝐯⋯𝐮⋯ )+det⁡(⋯𝐯⋯𝐯⋯ )⏟0

⇒ det⁡(⋯𝐮⋯𝐯⋯ )=−det⁡(⋯𝐯⋯𝐮⋯ ) ∎

3.2 零列 ⇒ det = 0

① 中取 c=0：

det⁡(⋯ 𝟎 ⋯ )=det⁡(⋯ 0⋅𝟎 ⋯ )=0⋅det⁡(⋯ )=0

3.3 列变换

Can calculate det⁡A using column operations：

det⁡(⋯ 𝐮 ⋯ 𝐯 ⋯ )=①②′det⁡(⋯ 𝐮+c𝐯 ⋯ 𝐯 ⋯ )

为什么？ 由 ①，右边 =det⁡(⋯𝐮⋯𝐯⋯ )+cdet⁡(⋯𝐯⋯𝐯⋯ )，后一项两列相同为 0。

列变换 det 的变化
一列加另一列的倍数 𝐚i↦𝐚i+c𝐚j 不变
一列乘 c 乘 c
交换两列 变号

3.4 三角矩阵

Prop. Det of triangular matrix = product of diagonal.

det⁡(a110a22∗⋱ann)=a11a22⋯ann

Pf.

  • 若所有 aii≠0：先用 ① 把每列的 aii 提出来，变成对角线全是 1 的三角矩阵，=a11⋯anndet⁡(⋯ )；再用列变换把对角线下方的 ∗ 消掉（从最后一列往前，用 1 去消），得到 I ⇒ =a11⋯anndet⁡(I)=a11⋯ann
  • 若某个 aii=0：取最大的这种 i（i=n 时第 n 列直接是零列 ✓）；对 j>i 有 ajj≠0，用列变换把第 i 列消成零列 ⇒ det⁡=0 = 乘积 ✓

3.5 例：用列变换算

det⁡(123456788)→𝐜3↦𝐜3−3𝐜1𝐜2↦𝐜2−2𝐜1det⁡(1004−3−67−6−13)→𝐜3↦𝐜3−2𝐜2det⁡(1004−307−6−1)

下三角，=1⋅(−3)⋅(−1)=3。

（验算，余子式展开：1(40−48)−2(32−42)+3(32−35) =−8+20−9=3 ✓）

4 · 存在唯一性与 Leibniz 展开

Thm. ∃! function det⁡ satisfying ①–③.（要 write down a formula）

Leibniz Expansion.

det⁡A:=∑σ∈Snε(σ) aσ(1)1aσ(2)2⋯aσ(n)n

  • Sn：permutation of n elements（= bijection {1..n}→{1..n}），共 n! 个
  • 每一项：从每一列各取一个元素，且它们的行号互不相同（第 j 列取第 σ(j) 行）——每行每列恰好一个
  • ε(σ) = sign of permutation：
ε(σ)={+1even # of transpositions−1odd # of transpositions

（transposition = swap 2 numbers）

例：σ=(1234534215)。从 12345 开始一次交换两个数，变到 34215：

12345→21345→23145→23415→32415→34215

5 次 swap（奇数）⇒ ε(σ)=−1。

另一个例子：(001100010) 对应 σ:123→231，两次交换，ε(σ)=+1，det = +1。

4.1 小矩阵

n 公式 说明
1 det⁡(a)=a
2 det⁡(abcd)=ad−bc ad：σ=id（a11a22）；bc：σ=(12)（a21a12），带负号
3 det⁡(abcdefghi)=aei+bfg+cdh−ceg−bdi−afh 三条「主对角线方向」为正，三条反方向为负（Sarrus 法则，只对 3×3 有效）

5 · 证明思路

Idea of Proof：

  • !（唯一）：证明任何满足 ①–③ 的 D 都必须是 Leibniz 公式的形式（只满足 ①② 时是它的倍数）
  • ∃（存在）：验证 Leibniz 公式满足 ①–③

5.1 唯一性

设 D:Mn×n(K)→K 满足 ①②，证明 D=c⋅det⁡（c∈K）；再加 ③ ⇒ D=det⁡。

每列写成标准基的组合：𝐚j=a1j𝐞1+⋯+anj𝐞n=∑i=1naij𝐞i。

D(A)=D(∑i1ai11𝐞i1, ∑i2ai22𝐞i2, …, ∑inainn𝐞in)=①∑i1=1n⋯∑in=1nai11ai22⋯ainn D(𝐞i1,𝐞i2,…,𝐞in)
  • 大多数项是 0：如果 i1,…,in 有重复，D 里有两列相同（②′）
  • 只剩 i1,…,in 是 (1,…,n) 的一个排列的项，即 ik=σ(k)：
D(A)=∑σ∈Snaσ(1)1⋯aσ(n)n D(𝐞σ(1),…,𝐞σ(n))
  • 把 (𝐞σ(1),…,𝐞σ(n)) do swaps 换回 (𝐞1,…,𝐞n)=I，每次 swap 给一个 (−)：
D(𝐞σ(1),…,𝐞σ(n))=ε(σ)D(I)
⇒D(A)=∑σ∈Snε(σ)aσ(1)1⋯aσ(n)n⏟det⁡A⋅D(I)⏟=c

If ③ is satisfied：c=D(I)=1 ⇒ D=det⁡ ∎

5.2 存在性

Check Leibniz 的 det⁡ 满足 ①–③（看成 aij 的函数）：

  1. 若 𝐚k=𝐮+c𝐯，即 aσ(k)k=uσ(k)+cvσ(k)。每一项最多含一个 aσ(k)k（第 k 列只出一个）⇒ 每项对第 k 列线性 ⇒ linear ✓
  2. 用 ②′（⇐ same columns ⇒ det 0）：若 𝐚k=𝐚ℓ。对每个 σ，令 σ′=(k ℓ)∘σ（交换 σ(k)、σ(ℓ)），ε(σ′)=−ε(σ)；而 σ 和 σ′ 的项里乘的元素相同（因为两列相同），一正一负 cancels ⇒ det⁡=0 ✓
  3. det⁡(I)=1：只有 σ=id 那一项非零，=1 ✓

6 · 推论

6.1 det⁡(AB)=det⁡(A)det⁡(B)

Pf. Fix A，treat B as a variable!

D(B):=det⁡(AB)=det⁡(A𝐛1 ⋯ A𝐛n)
  • D 对 B 的列 multilinear（①）且 alternating（②）——因为 𝐛j↦A𝐛j 是线性的，交换 B 的两列就是交换 AB 的两列
  • By uniqueness：D(B)=c⋅det⁡(B)
  • 取 B=I：D(I)=det⁡(A)=c
  • ⇒ det⁡(AB)=D(B)=det⁡A⋅det⁡B ∎

6.2 可逆 ⟺ det ≠ 0

Cor. A is invertible   ⟺   det⁡A≠0，且 det⁡(A−1)=(det⁡A)−1

Pf.

  • A invertible：det⁡A⋅det⁡(A−1)=det⁡(AA−1)=det⁡I=1（by previous slide）⇒ det⁡A≠0
  • A not invertible：列 l.d. ⇒ column operations 得到 zero column ⇒ det⁡A=0

6.3 相似矩阵与 det⁡T

Cor. If A∼B then det⁡(A)=det⁡(B).

Pf. B=PAP−1：det⁡B=det⁡(P)det⁡(A)det⁡(P)−1=det⁡A（det⁡P 和 (det⁡P)−1 cancel——数可交换）。

Def. If dim⁡V<∞，determinant of T∈ℒ(V,V) is defined to be

det⁡T:=det⁡(A)
for any square matrix A representing T in some basis of V.

（well-defined：不同 basis 给出相似的矩阵，det 相同。）

6.4 分块三角矩阵

Cor. det⁡(Ak×kBk×ℓOℓ×kCℓ×ℓ)=det⁡kA⋅det⁡ℓC

例：(1234567800910001112) 的 det =det⁡(1256)det⁡(9101112)=(−4)(−2)=8。

Pf.

(ABOC)=(IBOC)⋅(AOOI)
  • det⁡(IBOC)：用前 k 列（单位向量）做列变换把 B 消掉 → (IOOC)，=det⁡C
  • D(A):=det⁡(AOOI) 作为 A 的函数满足 ①–③ ⇒ =det⁡A
  • 由 det⁡(XY)=det⁡Xdet⁡Y：det⁡=det⁡Adet⁡C ∎

8 · det⁡A=det⁡AT

Thm. det⁡A=det⁡AT

Pf.

  • If det⁡A=0：A not invertible（rank <n）⇒ AT not invertible（rank AT = rank A <n）⇒ det⁡AT=0 ✓
  • Note：det⁡E=det⁡ET for all 3 types（第一类的转置还是第一类，det 都是 1；后两类是对称的）
  • If det⁡A≠0：RCEF（列变换的约化形式）=In×n，即 A=IE1E2⋯Ek。
AT=EkTEk−1T⋯E1TI((AB)T=BTAT)
det⁡A=det⁡E1det⁡E2⋯det⁡Ek=det⁡EkT⋯det⁡E1T=det⁡AT∎

推论：前面所有关于列的结论，对行也成立（行变换算 det、两行相同为 0 等）。

9 · Worksheet 03

P1：det⁡(c⋅A)=cdim⁡Vdet⁡(A)（A∈ℒ(V,V)，dim⁡V=n）

方法 1（multilinear）：cA 的每一列都乘了 c，逐列提出来：

det⁡(cA)=det⁡(c𝐚1 ⋯ c𝐚n)=cdet⁡(𝐚1 c𝐚2⋯ )=⋯=cndet⁡A

方法 2（Leibniz）：∑σε(σ)(caσ(1)1)⋯(caσ(n)n)=cndet⁡(A)——every term has n of them。

（常见错误：写成 cdet⁡A。）

P2：Vandermonde 行列式

det⁡(1t0t02⋯t0n1t1t12⋯t1n⋮⋮1tntn2⋯tnn)=∏0≤i<j≤n(tj−ti)

Pf 思路（把 det 看成 t0,…,tn 的多项式）：

  1. Leibniz formula：det 是 t0,t1,…,tn 的多项式，每一项 degree =0+1+2+⋯+n=n(n+1)2=(n+12)
  2. If ti=tj for some i≠j ⇒ same row ⇒ det⁡=0 ⇒ (ti−tj) is a factor of det
  3. 这样的因子有 (n+12) 个，degree 已经满了 ⇒
det⁡=c (t0−t1)(t0−t2)⋯(t0−tn)⋅(t1−t2)⋯(tn−1−tn)

c 是常数

  1. 定 c：Leibniz 里 t1t22t33⋯tnn（对角线）的系数是 1。把乘积按「大下标在前」重写：
c (tn−tn−1)(tn−tn−2)⋯(tn−t0)⋅(tn−1−tn−2)⋯(tn−1−t0)⋯(t2−t1)(t2−t0)⋅(t1−t0)

每个括号取第一项正好得到 tnntn−1n−1⋯t1，系数为 c ⇒ c=1

（用 (tj−ti)、j>i 的写法，符号刚好是正的。）

联系 L08：Vandermonde 矩阵可逆 ⟺ ti 互不相同 ⟺ 这个乘积 ≠0。

11 · 易错点

  • det⁡(A+B)≠det⁡A+det⁡B；multilinear 是一次只动一列。
  • det⁡(cA)=cndet⁡A，不是 cdet⁡A。
  • 交换两列变号；一列加另一列的倍数不变；一列乘 c 时 det 乘 c（算的时候要记得除回来）。
  • Sarrus 法则只对 3×3 有效。
  • ε(σ) 数的是交换次数的奇偶；具体的交换序列不唯一，但奇偶性唯一。
  • Leibniz 公式里第 j 列取第 σ(j) 行：aσ(j)j（行下标是 σ(j)）。
