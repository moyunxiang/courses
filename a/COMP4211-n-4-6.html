0 · 这一讲在讲什么

用 CS231n 的两个例子手算 backprop：

  1. 简单例：f(x,y,z)=(x+y)z，x=−2、y=5、z=−4
  2. Local gradient × upstream gradient 的通用规则
  3. Sigmoid 神经元例：f(𝐰,𝐱)=11+e−(w0x0+w1x1+w2)；sigmoid gate 合并
  4. 反向流动的模式：add = distributor、max = router、mul = switcher；分支处梯度相加

必会计算：这两个例子每个节点的前向值和梯度（必考手算题型）。必会概念：add / max / mul gate 的反向规则；分支处梯度相加。

1 · 简单例：f=(x+y)z

x=−2，y=5，z=−4。

Forward：令 q=x+y=3，f=qz=−12。

想要：∂f∂x,∂f∂y,∂f∂z。

Local derivatives：

q=x+y: ∂q∂x=1, ∂q∂y=1;f=qz: ∂f∂q=z, ∂f∂z=q

Backward（从 f 开始）：

节点 梯度 值
f ∂f∂f 1
z ∂f∂z=q 3
q ∂f∂q=z −4
y ∂f∂q∂q∂y=−4⋅1 −4
x ∂f∂q∂q∂x=−4⋅1 −4

Chain rule：∂f∂y=∂f∂q∂q∂y。

2 · 通用规则：Local × Upstream

对计算图中的一个门 f，输入 x,y，输出 z：

  • Local gradient：∂z∂x、∂z∂y（只看这个门本身，前向时就能算）
  • Upstream gradient：∂L∂z（从后面传回来）
∂L∂x=∂z∂x⏟local⋅∂L∂z⏟upstream

（每个门只需要知道自己的 local gradient——这就是 backprop 可以模块化的原因。）

3 · Sigmoid 神经元例

f(𝐰,𝐱)=11+e−(w0x0+w1x1+w2)

值：w0=2，x0=−1，w1=−3，x1=−2，w2=−3。

需要的 local gradients：

f(x)=ex→ex,fa(x)=ax→af(x)=1x→−1x2,fc(x)=c+x→1

Forward（拓扑序）：

节点 运算 值
w0x0 2×(−1) −2
w1x1 (−3)×(−2) 6
和 −2+6 4
+w2 4+(−3) 1
×(−1) −1
exp⁡ e−1 0.37
+1 1.37
1/x 1/1.37 0.73

Backward（从输出往回，每步 = local × upstream）：

门 local upstream 梯度
输出 1.00
1/x（x=1.37） −11.372 1.00 −0.53
+1 1 −0.53 −0.53
exp⁡（x=−1） e−1 −0.53 −0.20
×(−1) −1 −0.20 (−1)(−0.20)= 0.20
+w2（add） 1, 1 0.20 和：0.20；w2：0.20（两个输入都是！）
+（add） 1, 1 0.20 w0x0：0.20；w1x1：0.20
w0x0（mul） x0=−1；w0=2 0.20 w0：[−1]×0.2= −0.20；x0：[2]×0.2= 0.40
w1x1（mul） x1=−2；w1=−3 0.20 w1：−0.40；x1：−0.60

3.1 Sigmoid gate

σ(x)=11+e−x,dσ(x)dx=e−x(1+e−x)2=(1−σ(x))σ(x)

把后四个门（×(−1)、exp、+1、1/x）合成一个 sigmoid gate：输入 1，输出 0.73，local gradient =(0.73)(1−0.73)=0.2——一步就得到上表中的 0.20。

计算图的粒度可以自己选：只要能写出 local gradient 的子表达式，都可以合成一个门。

（python 复算：σ(1)=0.7311，σ(1)(1−σ(1))=0.1966≈0.20 ✓。）

4 · 反向流动的模式

门 名字 反向规则
add gradient distributor 把 upstream 梯度原样分给每个输入
max gradient router 梯度全部给值较大的那个输入，另一个得 0
mul gradient switcher 每个输入得到 upstream × 另一个输入的值（「交换」）

（例：mul 门 w0x0：w0 的梯度用 x0 的值，x0 的梯度用 w0 的值。）

Gradients add at branches：一个变量被多个下游节点使用时，回传的梯度相加（多变量链式法则，就是 4.5 公式里对 children 求和）。

6 · 易错点

  • add 门两个输入都得到同样的梯度（不是平分）。
  • mul 门的 local gradient 是另一个输入的值。
  • 1/x 的导数是 −1x2（负号）。
  • ×(−1) 门会翻转梯度符号：−0.20→0.20。
  • 一个变量用了多次时，梯度要加起来，不是取其一。
