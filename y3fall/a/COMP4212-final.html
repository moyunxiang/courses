1 · Advanced DQN tricks (2.4)

TD with ER:  L(𝐰)=1T∑tδt22,δi=Q(si,ai;𝐰)−yi,𝐰←𝐰−α δi∇𝐰Q(si,ai;𝐰)PER:  P(i)=piα∑kpkα,pi=∣δi∣+ϵ  or  pi=1rank⁡(i)(α=0: uniform)PER lr scaling:  αi=α (nP(i))−β,β: small→1target network:  yt=rt+γmax⁡aQ(st+1,a;𝐰−)target update:  𝐰−←𝐰 (periodic)or𝐰−←τ𝐰+(1−τ)𝐰−Double DQN:  a∗=arg⁡max⁡aQ(st+1,a;𝐰),yt=rt+γ Q(st+1,a∗;𝐰−)advantage:  Aπ(s,a)=Qπ(s,a)−Vπ(s),max⁡aA∗(s,a)=0dueling:  Q(s,a;𝐰A,𝐰V)=V(s;𝐰V)+A(s,a;𝐰A)−max⁡aA(s,a;𝐰A)(or −mean⁡a)
  • ER: transition (st,at,rt,st+1); buffer of the last n (105–106); reuse each sample many times; random sampling breaks correlation ⇒ lower variance, smoother learning.
  • ER weakness: on-policy methods cannot use it (SARSA, REINFORCE, A2C).
  • PER: new transition gets max priority; δ updated whenever sampled. Big ∣δ∣ ⇒ high probability ⇒ small learning rate (corrects the sampling bias). Link to prioritized sweeping (1.4).
  • Overestimation: (1) maximization bias 𝔼[max⁡iXi]≥max⁡i𝔼[Xi]; (2) bootstrapping propagates it. Uniform overestimation is harmless; it is non-uniform (frequent (s,a) overestimated more).
  • Target network partly avoids bootstrapping (not completely: 𝐰− depends on 𝐰). Double DQN alleviates maximization; overestimation can still happen. Ordering: Double-Q ≤max⁡i𝔼[Xi]≤𝔼[max⁡iXi] (single Q).
  • Dueling: without the −max⁡aA term, V+c, A−c give the same Q (non-identifiable). Mean version empirically more stable.
  • Rainbow = multi-step + Double + PER + Dueling + Noisy + Distributional.

  • Value-based (implicit policy) · policy-based (no value function) · actor-critic (both).
  • PG pros: true objective, better convergence, high-dim / continuous actions, stochastic policies. Cons: local optimum, high variance, inefficient evaluation.
  • Why stochastic: aliased states / partial observability (aliased gridworld: π(E)=π(W)=0.5), games (rock-paper-scissors: uniform = Nash), smoother search space, exploration. Fully observable MDP ⇒ an optimal deterministic policy exists.
  • REINFORCE ≈ "weighted maximum likelihood": good trajectories made more likely, bad less likely.
  • Causality: action at t′ cannot affect reward at t<t′ ⇒ reward to go (lower variance).
  • PG is on-policy: must resample after every update ⇒ sample-inefficient. Off-policy PG ratio is a product, exponential in T; first-order approximation keeps only πθ′(at∣st)πθ(at∣st) (drops the state ratio).
  • Stationary distribution: d(s′)=∑s∑ap(s′∣s,a)π(a∣s)d(s); used to turn the unrolled sum into (1+γ+⋯+γn−1)→11−γ.

4 · Advanced policy gradient (3.3)

vanilla:  d∗=arg⁡max⁡∥d∥≤ϵJ(θ+d)natural:  d∗=arg⁡max⁡DKL(πθ∥πθ+d)≤ϵJ(θ+d)KL Taylor:  DKL(πθ∥πθ+d)≈12d⊤F(θ) d(0th, 1st order terms =0)Fisher:  F(θ)=𝔼x∼pθ[∇θlog⁡pθ(x)∇θlog⁡pθ(x)⊤]≈1N∑i∇log⁡pθ(xi)∇log⁡pθ(xi)⊤Lagrangian:  min⁡d −g⊤d+λ2d⊤Fd ⇒ d=1λF−1gnatural gradient:  gN=F−1g,α=2ϵg⊤F−1g,θnew=θold+αF−1gperf. difference:  J(θ′)−J(θ)=𝔼τ∼pθ′[∑tγtAπθ(st,at)]surrogate:  Aˉ(θ′)=∑t𝔼st∼pθ𝔼at∼πθ[πθ′(at∣st)πθ(at∣st)γtAπθ(st,at)]mismatch bound:  ∣pθ′(st)−pθ(st)∣≤2(1−(1−ϵ)t)≤2ϵtPPO-KL:  LKLPEN(θ)=𝔼^t[πθ(at∣st)πθold(at∣st)A^t−βDKL(πθold(⋅∣st)∥πθ(⋅∣st))] d<dtarg/1.5⇒β←β/2;d>1.5 dtarg⇒β←2βPPO-clip:  rt(θ)=πθ(at∣st)πθk(at∣st),LCLIP=𝔼^t[min⁡(rtA^t, clip⁡(rt,1−ϵ,1+ϵ)A^t)], ϵ≈0.2
  • Step-size problem is worse in RL than SL: a bad step ⇒ bad policy ⇒ bad data ⇒ hard to recover; too small ⇒ wastes experience.
  • Same parameter distance ≠ same policy change (Gaussians μ1=0,μ2=1 with σ=0.3 vs 3). KL constraint is easier to set.
  • Trust region / MM: maximize a surrogate that lower-bounds the true objective and matches it at the current policy.
  • PG = soft policy iteration: estimate A^π, then improve. Expectation under πθ′, advantage under πθ; replace pθ′(st) by pθ(st) only when policies are close.
  • TRPO = NPG + line search + monotonic improvement theorem (line search because the quadratic KL approximation may be violated).
  • PPO: first-order only (no Fisher matrix); several epochs of minibatch SGD; clipping removes the incentive to move far from θk; clip ≈ KL-penalty performance, simpler.

  • Discretization: k bins per dimension, d DoF ⇒ kd actions (curse of dimensionality).
  • Greedy improvement arg⁡max⁡aQ needs a global maximization per step in continuous 𝒜 ⇒ move the policy along ∇aQ instead.

J · Proofs to be able to write

  • Log-derivative trick: ∇θpθ=pθ∇θlog⁡pθ ⇒ ∇J=𝔼[∇log⁡pθ(τ)G(τ)]; log⁡p(s1), log⁡p(st+1∣st,at) independent of θ. ∎
  • Baseline unbiased: 𝔼a[b∇log⁡π]=b∑a∇π=b∇1=0 (b independent of a). ∎
  • Golden baseline: ddb𝔼[g2(G−b)2]=0⇒b=𝔼[g2G]𝔼[g2]. ∎
  • Complete PG: ∂Qπ∂θ=γ𝔼s′[∂Vπ(s′)∂θ] (since p,r independent of θ) → unroll → stationary d → 11−γ.
  • KL 1st-order term: −𝔼pθ[∇log⁡pθ]=−∫∇pθ dx=−∇∫pθ dx=0; 2nd order =F. ∎
  • NPG: set ∇d(−g⊤d+λ2d⊤Fd)=0⇒d=1λF−1g; 12(αgN)⊤F(αgN)=ϵ⇒α=2ϵ/(g⊤F−1g). ∎
  • Performance difference: J(θ)=𝔼s0[Vπθ(s0)], telescope ∑tγt(γV(st+1)−V(st))=−V(s0), add ∑tγtrt ⇒ 𝔼pθ′[∑tγtAπθ]. ∎
  • DPG: ∇θQ(s,μθ(s))=∇θμθ(s)∇aQ(s,a)∣a=μθ(s) (chain rule), unroll as in PG.

K · Pseudo-code reading checklist

  • DQN with ER + target net: where is 𝐰− used (target only) and updated (every C steps / soft).
  • PER: new transitions get max priority; priorities updated after sampling; IS weight (nP)−β.
  • QAC summary (9 steps): a~t+1 is sampled but not executed; critic descends, actor ascends.
  • AC with replay buffer: spot the two bugs (critic target, actor action) — §3.
  • TD3: twin critics + min, clipped target noise, if t mod d ⇒ delayed actor and target updates.

Common mistakes

  1. ER with on-policy methods (SARSA, REINFORCE, A2C) — not valid.
  2. PER: high priority ⇒ smaller learning rate, not larger.
  3. Double DQN: select with online 𝐰, evaluate with target 𝐰− (not the reverse).
  4. Target network removes bootstrapping only partly; Double DQN does not remove all overestimation.
  5. Dueling without the −max⁡aA / −mean⁡aA term is non-identifiable.
  6. ∇log⁡π for softmax is 𝟙a=b−π(b) for every b (non-chosen actions decrease).
  7. Baseline must not depend on at; V(st) is fine, Q(st,at) is not.
  8. PG is on-policy; reusing old trajectories needs importance ratios.
  9. Natural gradient uses F−1g; step size 2ϵ/(g⊤F−1g), not 2ϵ/(g⊤g).
  10. PPO clip: the gradient vanishes only on the side that would improve the objective further (r>1+ϵ with A^>0, r<1−ϵ with A^<0).
  11. TD3 takes the min of two target critics; DDPG uses one critic. Both need target actor π(s′;θ−) in the TD target.
  12. DPG is a deterministic actor: no log⁡π, gradient through ∇aQ.
