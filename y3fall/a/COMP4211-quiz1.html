4 · Model evaluation & selection

errorS(h)=1n∑x∈Sδ(f(x)≠h(x))(training error: what we can measure)error𝒟(h)=Pr⁡x∼𝒟[f(x)≠h(x)](true / testing error: what we want)errortest(h)=1∣testSet∣∑x∈testSetδ(f(x)≠h(x))
  • Overfitting. h∈ℋ overfits if there exists h′∈ℋ with errorS(h)<errorS(h′) but error𝒟(h)>error𝒟(h′).
  • Test patterns must be drawn independently and must not be used in any way to learn the hypothesis.
  • Why not just fit the training set: the training set is a finite sample from 𝒟; a different training set gives a different classifier.
Model Bias Variance
Too complex (many hidden units) small (can get close to the ground truth) large (sensitive to the finite training set)
Too simple (few hidden units) large small
  • Hold-out validation. Split the data into a training set (to learn h) and a validation set (to estimate its error), e.g. 23 / 13. A larger training set gives a better hypothesis; a larger validation set gives a more accurate error estimate. Optionally retrain on all the data afterwards.
  • k-fold cross-validation. Partition the m examples into k disjoint subsets of size m/k. Run training k times, each time validating on one subset and training on the other k−1. Average the k validation errors.
    • Each example is used for validation exactly once and for training k−1 times; the training fraction is 1−1k.
    • Typically k≈10. Leave-one-out CV: k=m, i.e. train m times on m−1 examples each; useful for small data sets.

E · Counting in cross-validation

  • m=100, k=5: each fold validates on 100/5=20 and trains on 80; training is run 5 times (plus one optional final retrain on all 100).
  • LOOCV with m=100: 100 training runs, each on 99 examples.
  • Selecting among M candidate models with k-fold CV: M⋅k training runs; pick the model with the lowest average validation error.

F · Conceptual questions

  • The lowest training error is not necessarily the best model: we want low testing / validation error.
  • As model complexity grows, training error decreases, while testing error first decreases and then increases (overfitting).
  • Identify the paradigm: labels given → supervised; only groupings / anomalies → unsupervised; only rewards → reinforcement.
  • Identify the task: binary (fraud, toxic comments), multiclass (y∈{1,…,K}), regression (house price, arrival time), structured prediction (translation, captioning, segmentation).

Common Mistakes

  • TrainLoss is an average: divide by ∣𝒟train∣. The squared-loss gradient has a factor 2.
  • Margin = score × y, not the score itself. At m=0 the 0-1 loss counts as an error (m≤0).
  • Hinge gradient is nonzero whenever m<1 (not only m<0), and it carries a minus sign: −ϕ(x)y.
  • Gradient descent subtracts the gradient.
  • Never use the test set to tune hyperparameters or choose a model; use a validation set.
  • In k-fold CV every example is validated on exactly once.
  • Direction of bias/variance: complex model → low bias, high variance.
