2 · Recap：MDP

Definition: MDP：States、sstart、Actions(s)、T(s,a,s′)、Reward(s,a,s′)、IsEnd(s)

和确定性搜索的显著区别：Succ(s,a)→T(s,a,s′)；Cost(s,a)→Reward(s,a,s′)。

2.1 四个重要的量

量 定义
Policy states → actions 的映射
Utility 一条 path 上 discounted rewards 的和
Value 从一个 state 出发的 expected（future）utility
Q-Value 从一个 Q-state (s,a) 出发的 expected（future）utility
  • Search problem 的解：a path；MDP 的解：a policy
  • State 是做决定的节点；Q-state (s,a) 是「已选好 action、等待随机结果」的节点

3 · 用 Value Iteration 解 MDP

3.1 Car Racing（同 L10）

  • 想跑得远、跑得快；三个 states：Cool、Warm、Overheated；两个 actions：Slow、Fast；fast 的 reward 翻倍
  • Cool：slow → Cool（1.0，+1）；fast → Cool / Warm（各 0.5，+2）
  • Warm：slow → Cool / Warm（各 0.5，+1）；fast → Overheated（1.0，−10）

3.2 Racing search tree

从一个 state 展开：state → 两个 action（slow、fast）→ Q-state（transition）→ 各种 s′ → ……

Many many paths, and could be infinite in depth. 计算 state 的 value 时有什么问题？

问题 对策
Problem 1：Tree goes on forever depth-limited computation + discounting factor；γ<1 时树的深处最终不重要（γk→0）
Problem 2：States are repeated（同一个 state 在树里出现无数次） 只计算需要的量（如 optimal values），每个 state 算一次就行，不用整棵树展开

Value iteration 就是这两个对策的结合：第 t 轮的 V(t) 相当于「深度为 t 的树」的值，而且每个 state 只存一个数。

3.3 Optimal quantities

  • Optimal value at state s Vopt(s)：从 s 出发、acting optimally 的最大 expected utility
  • Optimal value at q-state (s,a)（optimal q-value）Qopt(s,a)：在 s 做 a、此后 acting optimally 的最大 expected utility
  • Optimal policy：从 s 出发的最优 action（让 optimal q-value 最大的 action）

Updating：

Vopt(t)(s)←max⁡a∈Actions(s)∑s′T(s,a,s′)⋅[Reward(s,a,s′)+γVopt(t−1)(s′)]

3.4 Value iteration 算法（Bellman, 1957）

Initialize Vopt(0)(s)←0 for all states s. For iteration t=1,…,tVI: For each state s: 用上式更新。

Time：O(tVI SAS′)

  • 每个 state 都要遍历所有 actions 才能找到最好的 Q-value。
  • Do we need to loop over all the states in each iteration? → 看下面的 grid world。

3.5 Grid World 上的 value iteration

T=12 和 T=100 时的 value 几乎一样：
0.64 0.74 0.85 1.00
0.57 （墙） 0.57 −1.00
0.49 0.42 → 0.43 0.47 → 0.48 0.28

（箭头左边是 T=12，右边是 T=100；其余格子两者相同）

Most of the state values converge at early iterations!!! —— 很多 state 早就不变了，每轮还对它们重算是浪费。

4 · Policy Iteration

4.1 Value iteration 的问题

Value iteration 不断重复 Bellman update：

  • Problem 1：慢——每轮 O(SAS′)
  • Problem 2：每个 state 上的 「max」很少变化（选中的 action 早就定了）
  • Problem 3：policy 往往比 values 早很多就收敛了

Could we directly target solving the policy? —— Yes, by policy iteration!

为什么 problem 3 重要？ 我们最终要的是 policy，不是精确的 value。value 还在小数点后几位慢慢变的时候，argmax 早就不变了。

4.2 Key idea

  • Policy Evaluation：对固定的当前 policy π，用 policy evaluation 求 values（迭代直到 values 收敛）
  • Policy Improvement：对固定的 values，用 policy extraction 得到更好的 policy
  • Repeat：重复直到 policy 收敛

Step 1：Policy evaluation

Vπ(s)=Qπ(s,π(s))=∑s′T(s,π(s),s′)[Reward(s,π(s),s′)+γVπ(s′)]

（左边是 state s 在 π 下的 value，右边是 Q-state (s,π(s)) 的 value。）

两种算法求 values：

  • Linear equation system（直接解方程）
  • Iterative algorithm（见 Lecture 10）

Step 2：Policy improvement（policy extraction，one-step lookahead）

πi+1(s)=arg⁡max⁡a∑s′T(s,a,s′)⋅[Reward(s,a,s′)+γVπi(s′)]
  • 用当前 policy 的 values Vπi，对每个 action 往前看一步，选 Q 最大的。

Step 3：Repeat

π∗←πi+1=πi
  • 当 πi+1=πi（policy 不再变化），返回它作为 π∗。

4.3 Car Racing 手算（γ=0.5，考试重点）

初始 policy π0：Cool → slow，Warm → slow，Overheated → --（terminal）。

Step 1：Policy evaluation（求 Vπ0）——用 Qπ(s,a)=∑s′T[Reward+γVπ(s′)] 列方程：

Vπ0(cool)=1⋅[1+0.5 Vπ0(cool)]
Vπ0(warm)=0.5[1+0.5 Vπ0(cool)]+0.5[1+0.5 Vπ0(warm)]

解：

  • 第一式：V=1+0.5V⇒Vπ0(cool)=2
  • 第二式代入 cool = 2：V=0.5⋅2+0.5+0.25V=1.5+0.25V，所以 Vπ0(warm)=2
  • Overheated：0
Vπ0=[2,  2,  0]

Step 2：Policy improvement（求 π1）

  • Cool：
    • slow：1⋅[1+0.5⋅2]=2
    • fast：0.5⋅[2+0.5⋅2]+0.5⋅[2+0.5⋅2]=3
    • → π1(cool)=fast
  • Warm：
    • slow：0.5⋅[1+0.5⋅2]+0.5⋅[1+0.5⋅2]=2
    • fast：1⋅[−10+0.5⋅0]=−10
    • → π1(warm)=slow
π1=[fast,  slow,  –]

⚠️ 课件这一步写 argmax{slow:3, fast:−10}，但 0.5⋅[1+0.5⋅2]+0.5⋅[1+0.5⋅2]=1+1=2，不是 3。结论（选 slow）不受影响。

Step 3：Policy convergence

再做一轮：

  • 评估 π1：
V(cool)=0.5[2+0.5V(cool)]+0.5[2+0.5V(warm)]V(warm)=0.5[1+0.5V(cool)]+0.5[1+0.5V(warm)]

解得 Vπ1=[3.5,  2.5,  0]（课件没写这些数，这里补全）。

  • 提取：
    • Cool：slow =1+0.5⋅3.5=2.75，fast =0.5(2+1.75)+0.5(2+1.25)=3.5 → fast
    • Warm：slow =0.5(1+1.75)+0.5(1+1.25)=2.5，fast =−10 → slow

π2=[fast,slow]=π1，policy 不变 → 收敛：π1=π2=π∗。

4.4 Policy iteration 算法

Algorithm: policy iteration

Initialize π(s) arbitrarily, ∀s∈S

For iteration t=1,…,tPI:

  • Initialize any state value to be 0, Vπ(s)←0
  • Repeat（Policy evaluation）
    • For each state s：Vπ(s)←Qπ(s,π(s))（即 4.2 的式子）
  • Until Vπ(s)'s convergence
  • For each state s（Policy improvement）：
    • πi+1(s)=arg⁡max⁡aQπ(s,a)（即 4.2 step 2 的式子）

Time complexity（每次外层迭代）：

部分 时间 为什么
Policy evaluation O(tPE SS′) 只用 π(s) 一个 action
Policy improvement O(SAS′) 每个 state 遍历所有 action，一次

In practice, only a few iterations are needed to converge the policy (fast)!

5 · Value Iteration vs Policy Iteration

两者都能求出 MDP 的 optimal values。

Value iteration Policy iteration
每轮同时更新 values 和（隐式的）policy 先用固定 policy 做几遍 value 更新（每遍快，因为只看一个 action，不看全部）
不显式记录 policy，但对 actions（Q-values）取 max 等于每轮重新算了一次 policy policy 评估完后，再选新 policy（相当于做一次 value iteration 那样的 pass）
收敛快（实际中通常几次迭代就够了）

MDP Algorithms：So you want to…

想要 用
求 optimal values value iteration 或 policy iteration
求某个特定 policy 的 values policy evaluation
把 values 变成 policy policy extraction（one-step lookahead）

6 · A Preview of Reinforcement Learning

6.1 Double Bandit Game

  • Actions：Blue、Red；States：Win、Lose
  • Blue：概率 1.0 得 $1
  • Red：概率 0.75 得 $2，概率 0.25 得 $0
  • No discount，100 time steps，两个 state 的 value 一样
Value
Play Red 150（100×(0.75×2)=150）
Play Blue 100（100×1）

6.2 Offline planning

  • Solving MDPs is offline planning
    • 所有量都通过计算得到
    • 需要知道 MDP 的全部细节（T 和 Reward）
    • You do not actually play the game!

6.3 Online planning

  • Rules changed! Red's win chance is different——但没告诉你变成多少。How do we figure it out?
  • 只能真的去玩：课件 Let's Play 里拉 Red 得到一串 $0 $0 $0 $2 $0 / $2 $0 $0 $0 $0，从结果里估计 Red 现在的胜率。
  • Not offline planning any more. It is online planning (learning)
    • 具体说就是 reinforcement learning
    • 有一个 MDP，但光靠计算解不出来（不知道 T / Reward）
    • You need to actually act to figure it out

7 · Summary

  • MDPs：应对不确定性的模型
  • Solution：policies rather than paths
  • Policy evaluation：(MDP,π)→Vπ
  • Value iteration：MDP→(Vopt,Qopt,πopt)
  • Policy iteration：MDP→(πopt,Vopt,Qopt)
  • Next time：Reinforcement Learning

9 · 易错点

  • Policy iteration 的 evaluation 步没有 max（action 由 π 固定）；只有 improvement 步有 argmax。
  • Improvement 用的是 Vπi（当前 policy 的值），不是 Vopt。
  • 收敛条件是 policy 不再变化，不是 values 不再变化。
  • Car racing 的 policy iteration 例子用 γ=0.5；L10 的 value iteration 例子是无 discount。看清题目给的 γ。
  • Overheated 是 terminal，value 恒为 0，policy 写「--」。
  • 课件 warm 的 slow 那一步算成 3 是错的，正确值是 2（不影响结论）。
  • Offline planning 需要已知 T 和 Reward；不知道时就是 RL。
