1 · 回到 XOR

单个 perceptron 不能解 XOR，加一个 hidden unit 就可以：

  • Hidden unit：y3=step(x1+x2−1.5)——就是 AND
  • Output：y=step(x1+x2−2y3−0.5)
x1 x2 y3（AND） x1+x2−2y3−0.5 y（XOR）
0 0 0 −0.5 0
0 1 0 0.5 1
1 0 0 0.5 1
1 1 1 −0.5 0

（输入同时直连 output；本质上「OR 但排除 AND」。）

2 · Multi-layer Feedforward Networks

Simple perceptron 的推广：input units Ik →（Wk,j）→ hidden units aj →（Wj,i）→ output units Oi。

用于分类：

  • 多类：每类一个输出，分到 arg⁡max⁡i=1myi
  • 二类：当多类处理；或只用一个输出 y：y>0 归 yes 类，y≤0 归 no 类

3 · Hidden Unit 的激活函数

3.1 为什么必须非线性

若 hidden units 都是线性的：

y(p)=W2W1x(p)=(W2W1)x(p)

——等价于单层网络（权重 W2W1）。

MLP 的能力来自 hidden units 的非线性。

用 perceptron（step）当 hidden unit？——step 不可导，不适合梯度下降。

3.2 Sigmoid

σ(x)=11+e−x,dσ(x)dx=σ(x)(1−σ(x))

像 perceptron，但用光滑、可导的阈值函数。（对比：step 输出 0/1，sign 输出 ±1，sigmoid 输出 (0,1)。）tanh 有时代替 sigmoid。

导数推导（补充）：σ′=e−x(1+e−x)2=11+e−x⋅e−x1+e−x=σ(1−σ)。

3.3 RBF（Radial Basis Function）network

例：Gaussian exp⁡(−(𝐱−𝐰j)⊤(𝐱−𝐰j)2σj2)——径向对称。

  • 每个 hidden unit 产生局部响应：只在输入落在一个小区域时才有显著非零输出
  • 对比 sigmoid：在无限大区域上非零
  • 有的问题 sigmoid 更高效，有的更适合 RBF

3.4 ReLU

f(x)=max⁡(0,x)
  • 深度网络最流行的激活函数
  • 计算高效；梯度简单：>0 时 1，≤0 时 0
  • Sparse activation（只有部分 hidden units 输出非零）
  • ⚠️ 梯度可能为 0（输入 ≤0 时）

4 · Universal Approximation

只用一层 sigmoid hidden units 就足以把任何 well-behaved function 近似到任意精度。

超过 2 层的网络也有 universal approximation 性质。

5 · Loss Functions

回顾（第 2 讲）：zero-one loss 𝟏[(𝐰⋅ϕ(x))y≤0]；hinge loss max⁡{1−(𝐰⋅ϕ(x))y,0}。

Cross-entropy loss 在分类中最常用——先简单介绍信息论。

5.1 Entropy：直觉

衡量 impurity / uncertainty / irregularity / surprise。两类样本集 S，p⊕、p⊖ 是正 / 负样本比例：

  • 最纯（不确定性 0）：p⊕=1 或 p⊕=0
  • 最不纯（最大不确定性）：p⊕=p⊖=0.5

5.2 Entropy：定义

H(X)=−∑x∈𝒳p(x)log⁡bp(x),0⋅log⁡0=0

两类：H=−p⊕log⁡p⊕−p⊖log⁡p⊖。

例：14 个样本，9 正 5 负

Entropy([9+,5−])=−914log⁡2914−514log⁡2514=0.94
  • 全同类 ⇒ 0；正负相等 ⇒ 1；否则在 0 和 1 之间

单位：取决于底 b——b=e：nats；b=2：bits（本课采用）。换底：Hb(X)=(log⁡ba)Ha(X)。

不同分布可以有相同 entropy：p={.5,.25,.25}，q={.48,.32,.2}，H(p)=1.5，H(q)≈1.4987≈1.5（课件写作相等，实为近似）。

界：X 取 n 个值时 0≤H(X)≤log⁡n；均匀分布取上界；某个 p(xk)=1 时取 0。

5.3 与编码的关系

P(X)：a=12，b=14，c=18，d=18

  • 定长码 00 / 01 / 10 / 11：期望长度 2 bits
  • 变长码 0 / 10 / 110 / 111：12⋅1+14⋅2+18⋅3+18⋅3=1.75 bits（= H(X)）

最优码给概率 p 的消息分配 −log⁡2p bits。Entropy(S) = 用最优最短码编码一个随机成员的类别所需的期望 bits 数。最坏情况（p⊕=0.5）每个样本 1 bit；不确定性小（如 p⊕=0.8）可以少于 1 bit。

5.4 Cross-entropy

H(p,q)=−∑ipilog⁡qi
  • 用另一个模型 q 编码来自源分布 p 的消息所需的平均 bits
  • 不对称：H(p,q)≠H(q,p)
  • H(p,p)=H(p)

5.5 用于神经网络

  • Target p：one-hot（正确类位置为 1，其余 0）
  • Model 预测分布 q（属于各类的概率）
  • 分类网络最后一层通常是 linear（无非线性），输出不一定在 [0,1] ⇒ softmax：
(α1,…,αC)→(eα1∑ieαi,…,eαC∑ieαi)

Cross-entropy loss：

H(p,q)=−∑ipilog⁡qi=−log⁡qc,c=真实类
  • 模型给真实类高概率（qc≈1）⇒ loss 小
  • 给真实类低概率（qc≈0）⇒ loss 大

二分类：

−∑i=1N(tilog⁡f(xi;w)+(1−ti)log⁡(1−f(xi;w)))

补充算例：logits (2,1,0)，真实类 1：softmax =(e2,e1,e0)e2+e+1≈(0.665,0.245,0.090)；loss =−ln⁡0.665≈0.41 nats。

7 · 易错点

  • 线性 hidden units 叠多少层都等价于一层。
  • σ′(x)=σ(x)(1−σ(x))，不是 σ(x)(1+σ(x))。
  • Entropy 的 log 默认底 2（bits）；0log⁡0=0。
  • Cross-entropy 不对称：p 是 target，q 是 model。
  • One-hot target 下 cross-entropy 只剩 −log⁡qc。
  • Softmax 是对 logits 做指数归一化，不是直接除以和。
