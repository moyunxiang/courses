0 · 这一讲在讲什么

rzs(t)=e(t)∗h(t)=∫−∞∞e(τ) h(t−τ) dτ
  1. 卷积的性质：交换律、分配律（并联）、结合律（串联）；时移；与 δ / u 的卷积；微分积分性质
  2. 卷积的计算：解析法（关键是积分上下限）；图解法（反转 → 平移 → 相乘 → 积分，分段讨论）

必考计算：图解法分段求卷积（课件例 3：分 5 段，得到梯形）；解析法定积分限（课件例 2：矩形脉冲 * 指数）；用 δ 和微分积分性质简化（课件例 1）。结论：卷积结果的起点 = 两起点之和、终点 = 两终点之和、宽度 = 两宽度之和。

1 · 代数性质

1.1 交换律

f1(t)∗f2(t)=f2(t)∗f1(t)

证明：令 λ=t−τ，dτ=−dλ；τ:−∞→∞ 时 λ:∞→−∞：

∫−∞∞f1(τ)f2(t−τ) dτ=∫∞−∞f2(λ)f1(t−λ)(−dλ)=∫−∞∞f2(λ)f1(t−λ) dλ

（用处：图解时可以选简单的那个去反转平移。）

1.2 分配律 ⇒ 并联系统

f1(t)∗[f2(t)+f3(t)]=f1(t)∗f2(t)+f1(t)∗f3(t)

并联：f(t) 同时进 h1 和 h2，输出相加：

g(t)=f∗h1+f∗h2=f∗(h1+h2)  ⇒  h(t)=h1(t)+h2(t)

子系统并联，总 impulse response = 各子系统 impulse response 之和。

1.3 结合律 ⇒ 串联系统

[f(t)∗h1(t)]∗h2(t)=f(t)∗[h1(t)∗h2(t)]

串联（cascade）：f→h1→h2→g：

h(t)=h1(t)∗h2(t)

子系统串联，总 impulse response = 各 impulse response 的卷积。由交换律，串联子系统的顺序可以交换。

2 · 时移性质

若 f(t)=f1(t)∗f2(t)，则

f1(t−t1)∗f2(t)=f(t−t1),f1(t−t1)∗f2(t−t2)=f(t−t1−t2)

（直观：一个延迟器放在系统前面或后面效果一样；两个延迟加起来。）

3 · 与冲激、阶跃的卷积（最常用）

卷积 结果 对应的系统
f(t)∗δ(t) f(t) 理想导线，h(t)=δ(t)
f(t)∗δ(t−t0) f(t−t0) 延迟器，h(t)=δ(t−t0)
f(t)∗δ′(t) f′(t) 微分器，h(t)=δ′(t)
f(t)∗δ(k)(t) f(k)(t) k 个微分器
f(t)∗δ(k)(t−t0) f(k)(t−t0) 微分 + 时移
f(t)∗u(t) ∫−∞tf(τ) dτ 积分器，h(t)=u(t)

证明 f∗δ=f：

f(t)∗δ(t)=∫−∞∞f(t−τ)δ(τ) dτ=f(t)∫−∞∞δ(τ) dτ=f(t)

（sifting：δ(τ) 只在 τ=0 处，把 f(t−τ) 在 τ=0 的值 f(t) 筛出来。）

和 δ 卷积 = 把原信号加权、平移一份。所以分段常数信号经常先求导变成冲激，卷积就只是平移相加。

4 · 微分积分性质

若 g(t)=f(t)∗h(t)，则

g′(t)=f′(t)∗h(t)=f(t)∗h′(t)
g(−1)(t)=f(−1)(t)∗h(t)=f(t)∗h(−1)(t)
g(t)=f(−1)(t)∗h′(t)=f′(t)∗h(−1)(t)

（f(−1) 表示积分 ∫−∞tf(τ)dτ。一个求导、一个积分，结果不变。）

直觉：LTI 系统的微积分特性——输入先求导，输出也求导；而卷积可以看成「把 f 送进 h 系统」。

使用条件（补充）：g=f′∗h(−1) 要求 f(−∞)=0（或 h(−1)(∞) 有限等），课件的例子都满足。

4.1 例 1（用微积分性质）

f(t)：[0,1] 上为 1，[1,2] 上为 −1，其余为 0；h(t)：[0,1] 上为 1（矩形）。求 g=f∗h。

思路：h 是矩形，求导后变成两个冲激：

h′(t)=δ(t)−δ(t−1)

f 积分一次：f(−1)(t) 是一个三角形（[0,1] 上升到 1，[1,2] 下降到 0）。

g(t)=f(−1)(t)∗h′(t)=f(−1)(t)∗[δ(t)−δ(t−1)]=f(−1)(t)−f(−1)(t−1)

一个三角形减去右移 1 的三角形：

  • [0,1]：从 0 线性升到 1
  • [1,2]：从 1 线性降到 −1
  • [2,3]：从 −1 线性升到 0

（我数值验算：g(0.5)=0.5，g(1)=1，g(2)=−1，g(2.5)=−0.5 ✓）

和 δ 卷积 = 加权、平移的原信号——这是这种方法省事的原因。

5 · 卷积计算：解析法

rzs(t)=∫−∞∞e(τ) h(t−τ) dτ

由于系统的因果性或激励的时限性，积分上下限会变——正确确定积分限是关键。

5.1 例 2（必会）

e(t)=u(t)−u(t−t0)（宽 t0 的矩形脉冲），h(t)=e−tu(t)，t0>0。求 r(t)=e(t)∗h(t)。

r(t)=∫−∞∞[u(τ)−u(τ−t0)]e−(t−τ)u(t−τ) dτ=e−t∫−∞∞eτu(τ)u(t−τ) dτ⏟r1(t)−e−t∫−∞∞eτu(τ−t0)u(t−τ) dτ⏟r2(t)

r1 的积分限：u(τ)u(t−τ)≠0 要求 τ>0 且 t−τ>0，即 0<τ<t——这还要求 t>0（所以结果乘 u(t)）：

r1(t)=e−t[∫0teτ dτ]u(t)=e−t(et−1)u(t)=(1−e−t)u(t)

r2 的积分限：u(τ−t0)u(t−τ)≠0 要求 t0<τ<t，即 t>t0：

r2(t)=e−t[∫t0teτ dτ]u(t−t0)=[1−e−(t−t0)]u(t−t0)
r(t)=(1−e−t)u(t)−[1−e−(t−t0)]u(t−t0)

图像：0<t<t0 时从 0 按 1−e−t 上升；t>t0 后按指数衰减回 0。

  • 输出有「追赶」输入的趋势（输入跳到 1，输出慢慢升上去）
  • 这是有记忆的系统：输出不仅取决于当前输入，还取决于过去的输入

（验算：t0=1 时 r(0.5)=1−e−0.5≈0.393，r(2)=(1−e−2)−(1−e−1)≈0.233，和数值积分一致。）

定积分限的套路：被积函数里每个 u(⋅) 都给出一个不等式（u(τ−a) ⇒ τ>a；u(t−τ) ⇒ τ<t）。取交集得到 τ 的范围；下限 < 上限的条件就是结果前面的 u(⋅)。

6 · 卷积计算：图解法

函数式复杂时，图解法更容易直观地确定积分限。

g(t)=∫−∞∞f1(τ)f2(t−τ) dτ

四步：

  1. 换元：f1(t)→f1(τ)（积分变量换成 τ）
  2. 反转 + 平移：f2(t)→f2(τ)→reversalf2(−τ)→shift tf2(t−τ)
  3. 相乘：f1(τ)⋅f2(t−τ)
  4. 积分：对乘积求面积

t 从 −∞ 到 +∞，相当于 f2(t−τ) 从左往右滑过 f1(τ)。

f2(t−τ) 的位置：f2(−τ) 的 τ=0 点移到 τ=t。如果 f2 在 [C,D] 上非零，则 f2(t−τ) 在 τ∈[t−D,t−C] 上非零。

6.1 例 3（必会，分五段）

f1(t)：[−1,1] 上高 1；f2(t)：[0,3] 上高 2。

  • f1(τ)：[−1,1]
  • f2(−τ)：[−3,0]；f2(t−τ)：[t−3,t]（高 2）

按两者的重叠情况分段：

段 t 的范围 重叠区间 g(t)
① t<−1 无（f2(t−τ) 的右端 t<−1） 0
② −1<t<1 [−1,t]（右端进入） ∫−1t2 dτ=2t+2
③ 1<t<2 [−1,1]（f1 被完全覆盖，t−3<−1） ∫−112 dτ=4
④ 2<t<4 [t−3,1]（左端离开） ∫t−312 dτ=2(4−t)=−2t+8
⑤ t>4 无（t−3>1） 0
g(t)={2t+2,−1<t<14,1<t<2−2t+8,2<t<40,else

梯形：从 t=−1 升到 4（在 t=1），平到 t=2，降到 0（在 t=4）。（数值验算一致。）

分段的分界点怎么找：f2(t−τ) 的两个端点 t−3、t 依次经过 f1 的两个端点 −1、1：t=−1、t=1、t−3=−1（t=2）、t−3=1（t=4）。

6.2 结果的范围

若 f1 在 [A,B] 上，f2 在 [C,D] 上，则 g=f1∗f2 在

[A+C, B+D]

上非零。下限 = A+C，上限 = B+D；g 的宽度 = 两个信号宽度之和。

（例 3：[−1+0,1+3]=[−1,4]，宽度 2+3=5 ✓）

补充规律：两个等宽矩形卷积得三角形；不等宽矩形卷积得梯形；平顶的高度 = 窄矩形的面积 × 宽矩形的高度。

9 · 易错点

  • 解析法里积分限由 u(⋅) 的乘积决定，别直接写 −∞ 到 ∞。
  • 结果前面的 u(t)、u(t−t0) 来自「下限 < 上限」的条件，别漏。
  • 图解法：反转的是 f2（f2(−τ)），然后向右平移 t；f2(t−τ) 的非零区间是 [t−D,t−C]。
  • 分段时每个分界点都要找全（四个端点两两相遇）。
  • 并联是相加，串联是卷积。
  • f∗δ′(t)=f′(t)；f∗u(t)=∫−∞tf。
  • 卷积结果宽度 = 两宽度之和（不是乘积，也不是较大者）。
