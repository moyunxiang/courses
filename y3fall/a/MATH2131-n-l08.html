1 · 复习

T∈ℒ(V,W)，dim⁡V=n，dim⁡W=m，V≃ℬKn，W≃ℬ′Km：

  • A:=[T]ℬ′ℬ:Kn→Km，A∈ℒ(Kn,Km)（w.r.t. ℰ），A∈Mm×n(K)
  • i-th column of A = [T(𝐛i)]ℬ′∈Km（𝐛i∈ℬ）
  • ★ A⋅𝐛=T(𝐛)（if V=Kn，W=Km）；A⋅B=T∘S

Fundamental Thm（Rank A=dim⁡Col A，nullity=dim⁡Nul A）：

  • Rank A=Row Rank A（=Rank AT）
  • （Rank–Nullity，dim⁡V<∞）dim⁡V=dim⁡Col A+dim⁡Nul A，即 dim⁡V=dim⁡Im T+dim⁡Ker T

2 · Invertible Matrix

A represents T∈ℒ(Kn,Kn)（方阵）。

Def. A is invertible if it represents an isomorphism T   ⟺   ∃! n×n matrix A−1 representing T−1∈ℒ(Kn,Kn) s.t.

A⋅A−1=A−1⋅A=In×n=(10⋱01)

Thm（Invertible Matrix Theorem）. A is invertible iff any one of below holds：

  1. Columns of A form a basis
  2. Col A=Kn（A is surjective）
  3. Nul A={𝟎}（A is injective）
  4.   ⟺   nullity =0
  5. Rank A=Row Rank A=n
  6. RREF=In×n

为什么方阵时 2 ⟺ 3？ Rank–nullity：dim⁡Nul A+dim⁡Col A=n。所以 Col A=Kn（rank n）⟺ nullity 0 ⟺ Nul A={𝟎}。对方阵，单射 ⟺ 满射——这是有限维的特别之处。

其余：1 ⟺ 列 l.i. 且 span Kn ⟺ 2 + 3；5 是 2 的维数说法；6：rank n 意味着 n 个 pivot，方阵的 RREF 只能是 I。

3 · 解方程与求逆

3.1 Solve A𝐱=𝐛

A invertible ⇒ unique solution 𝐱=A−1⋅𝐛。

做法：

A𝐱=𝐛  →row operations  I𝐱=𝐮  ⇒  𝐱=𝐮 is the solution!

即对增广矩阵 (A∣𝐛) 做行变换到 (I∣𝐮)（同样的行变换同时作用在两边）。

3.2 Inverse

A−1=(𝐜1 𝐜2 ⋯ 𝐜n) 满足 A⋅A−1=(A𝐜1 ⋯ A𝐜n)=In×n   ⟺   A⋅𝐜i=𝐞i（对每个 i）

所以第 i 列 𝐜i 就是方程 A𝐱=𝐞i 的解：(A∣𝐞i)→(I∣𝐜i)。n 个方程用的是同样的行变换，一起做：

(A∣I)  →row ops  (I∣A−1)

2×2 公式：

(abcd)−1=1ad−bc(d−b−ca)if ad−bc≠0

4 · Change of Basis

T=I∈ℒ(V,V)，dim⁡V=n。同一个 𝐱∈V 在两组 basis 下：

  • ℬ：[𝐱]ℬ=(c1,…,cn)T   ⟺   𝐱=c1𝐛1+⋯+cn𝐛n
  • ℬ′：[𝐱]ℬ′=(c1′,…,cn′)T   ⟺   𝐱=c1′𝐛1′+⋯+cn′𝐛n′

两组坐标什么关系？ Recall [𝐱]ℬ′=[I]ℬ′ℬ[𝐱]ℬ。

Thm. ∃ n×n matrix Pℬ′ℬ s.t. [𝐱]ℬ′=Pℬ′ℬ[𝐱]ℬ：

Pℬ′ℬ:=[I]ℬ′ℬ=([𝐛1]ℬ′  [𝐛2]ℬ′ ⋯ [𝐛n]ℬ′)
Change of coordinate matrix from ℬ to ℬ′（第 i 列：旧基 𝐛i 用新基表示的坐标）

Prop. Pℬ′ℬ is invertible（it represents I），with inverse Pℬℬ′：[𝐱]ℬ=Pℬℬ′[𝐱]ℬ′

Prop. Pℬ′′ℬ′⋅Pℬ′ℬ=Pℬ′′ℬ（I∘I=I）

4.1 怎么求（V=Kn）

通过标准基 ℰ 中转：ℬ→ℰ→ℬ′。

  • Pℰℬ=(⋯[𝐛i]ℰ⋯)=(⋯𝐛i⋯)：直接把 𝐛i 排成列
  • 所以
Pℬ′ℬ=Pℬ′ℰ⋅Pℰℬ=(Pℰℬ′)−1⋅(Pℰℬ)

Rem. Pℬ′ℬ does NOT send ℬ to ℬ′!!（也 NOT ℬ′ to ℬ）——它变换的是坐标。 ★ Pℰℬ：sends ℰ→ℬ!（Pℰℬ𝐞i=𝐛i）

5 · Similar Matrices

T∈ℒ(V,V)，ℬ,ℬ′ of V，𝐱∈V：

[𝐱]ℬ→ A=[T]ℬ [T𝐱]ℬPℬ′ℬ↓↓Pℬ′ℬ[𝐱]ℬ′→ B=[T]ℬ′ [T𝐱]ℬ′

两条路走到右下角相同：B⋅P=P⋅A ⇒

B=P⋅A⋅P−1P=Pℬ′ℬ

Def. A is similar to B   ⟺   ∃ invertible P（change of basis）s.t. B=PAP−1. Write A∼B.

Prop. A∼B is an equivalence relation：

  • A∼A（P=I）
  • A∼B  ⟺  B∼A（B=PAP−1 ⇒ A=P−1BP，取逆 P−1）
  • A∼B，B∼C ⇒ A∼C（B=PAP−1，C=QBQ−1 ⇒ C=(QP)A(QP)−1）

⇒ equivalence class

Rem. Similar matrices represent the same linear transformation under different basis.

  • equivalence class [A]   ⟺   linear transformation T
  • Any quantities defined in terms of T only（no basis mentioned）must be the same for all similar matrices representing T（and vice versa）：rank、nullity、eigenvalues、det、trace……

（例如 trace：Tr(PAP−1)=Tr(AP−1P)=Tr(A)，用 L07 的 Tr(XY)=Tr(YX)。）

6 · Vandermonde Matrix 与 Lagrange Interpolation

6.1 Fact

Prop（Fact）. Kn[t] 中两个多项式，若在 n+1 个不同的点上取值相同，则它们相同。   ⟺   degree ≤n、有 n+1 个不同根的多项式只有零多项式。

6.2 Evaluation map

Def. Given t0,t1,…,tn∈K（distinct）：

T:Kn[t]→Kn+1p(t)↦(p(t0)p(t1)⋮p(tn))

  • linear ✓
  • Fact ⇒ injective ✓（T(p)=𝟎 ⇒ p 有 n+1 个根 ⇒ p=0）
  • dim：两边都是 n+1 ⇒（rank–nullity）T is isomorphism!

Prop（Standard Basis）. ℰ={1,t,t2,…,tn}，ℰ′={𝐞0,…,𝐞n}：

[T]ℰ′ℰ=(1t0t02⋯t0n1t1t12⋯t1n⋮⋮1tntn2⋯tnn)
—— Vandermonde Matrix

（第 j 列是 tj 在各点的值。因为 T 是同构，Vandermonde 矩阵可逆。）

6.3 求逆：Lagrange interpolation

Inverse 的问题：给定 (λ0,λ1,…,λn)T∈Kn+1，找 p(t)∈Kn[t] s.t. p(ti)=λi。

先做一个特殊情况：λ0=1，λ1=⋯=λn=0。要 p(t1)=⋯=p(tn)=0 ⇒ p 含因子 (t−t1)⋯(t−tn)；再除以它在 t0 的值使 p(t0)=1：

p0(t)=(t−t1)(t−t2)⋯(t−tn)(t0−t1)(t0−t2)⋯(t0−tn)

Prop.

pk(t)=∏j≠kt−tjtk−tj=(t−t0)⋯(t−tk)^⋯(t−tn)(tk−t0)⋯(tk−tk)^⋯(tk−tn)
（帽子 = omit 那一项），满足 T(pk(t))=𝐞k，即 pk(ti)={1i=k0i≠k

Def（Lagrange Interpolation polynomial）.

p(t)=λ0p0(t)+λ1p1(t)+⋯+λnpn(t)
under T：T(p(t))=(λ0,λ1,…,λn)T ✓

为什么对？ 线性：T(p)=∑λkT(pk)=∑λk𝐞k。

6.4 Vandermonde 的逆矩阵

([T]ℰ′ℰ)−1 的第 k 列 = 𝐞k 的 preimage = pk(t) 的系数（相对 ℰ）。

Ex. n=2：

p0(t)=(t−t1)(t−t2)(t0−t1)(t0−t2)=t1t2(t0−t1)(t0−t2)−t1+t2(t0−t1)(t0−t2)t+1(t0−t1)(t0−t2)t2
⇒[p0(t)]ℰ=1(t0−t1)(t0−t2)(t1t2−(t1+t2)1)∈K3

Similarly，

[p1(t)]ℰ=1(t1−t0)(t1−t2)(t0t2−t0−t21)[p2(t)]ℰ=1(t2−t0)(t2−t1)(t0t1−t0−t11)

把这三列排起来就是 (1t0t021t1t121t2t22)−1。

8 · 易错点

  • Pℬ′ℬ 的列是 ℬ 的向量用 ℬ′ 的坐标；它作用在坐标上，不是把基向量送过去。
  • Pℰℬ 就是把 ℬ 的向量排成列；Pℬℰ 是它的逆。
  • 相似是 B=PAP−1，P 必须可逆；PAP−1 和 P−1AP 只是 P 的方向不同。
  • 行变换求逆时，行变换必须同时作用在 A 和 I 上；只能做行变换，不能混用列变换。
  • Lagrange 基 pk 的分母要跳过 j=k 那一项（否则除以 0）。
