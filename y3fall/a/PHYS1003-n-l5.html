0 · 这一讲在讲什么

  1. 回顾：第一定律、QV=nCVΔT、Qp=nCpΔT、Cp=CV+R 的推导
  2. Isothermal process：W=−nRTln⁡VbVa，ΔU=0，Q=−W
  3. Adiabatic process：Q=0，W=ΔU=nCVΔT=pfVf−piViγ−1；pVγ = const、TVγ−1 = const；fire syringe（480 °C）
  4. Heat engines：循环、ΔU=0、效率 e=1−QcQh
  5. Stirling engine：两条等温 + 两条等容；净功 W=nR(Tb−Ta)ln⁡VbVa

必会计算：等温功、绝热功、绝热温度 Tb=Ta(Va/Vb)γ−1（fire syringe：300 K、压缩比 10、γ = 1.4 → 480 °C）；一个循环中各段 Q、W 的正负和大小；Stirling 净功；热机效率。必会概念：四种过程的 ΔU、Q、W 表；顺时针 = engine，逆时针 = heat pump。

1 · 回顾

  • 第一定律 ΔU=Q+Won；Wby=−Won = p-V 图曲线下面积
  • 定容：QV=nCVΔT；定压：Qp=nCpΔT；Cp=CV+R>CV

为什么 Cp=CV+R：U=j2nRT，pV=nRT。

  • 定容：ΔV=0，W=0，Q=ΔU=j2nRΔT ⇒ CV=j2R
  • 定压：Wby=pΔV=nRΔT；Q=ΔU+Wby=j2nRΔT+nRΔT ⇒ Cp=CV+R

2 · Isothermal Process（等温，ΔT=0）

例：沸点处汽化、冰点处融化（相变）；恒温下气球膨胀 / 压缩。

理想气体等温膨胀（T0，Va→Vb，Vb>Va）：p=nRT0V∝1V（p-V 图上的双曲线 = isotherm）

  • ΔT=0⇒ΔU=j2nRΔT=0——内能不变
W=−∫VaVbp dV=−∫VaVbnRT0dVV⇒  Wisothermal=−nRT0ln⁡VbVa<0

第一定律：ΔU=0⇒Q=−W=nRT0ln⁡VbVa>0——必须吸热（吸收的热全部变成对外做功）。

3 · Adiabatic Process（绝热，Q=0）

过程太快来不及换热，或在隔热环境中。

W=ΔU=nCV(Tf−Ti)=nCVΔT
W ΔU 温度
绝热压缩（加热） > 0 > 0 Tf>Ti
绝热膨胀（冷却） < 0 < 0 Tf<Ti

绝热方程：

paVaγ=pbVbγ,TaVaγ−1=TbVbγ−1,γ=CPCV>1

（推导思路：由 −nRTVdV=nCVdT 积分得 TVR/CV = 常数，且 RCV=CP−CVCV=γ−1。）

绝热功：用 T=pVnR：

W=nCV(pfVfnR−piVinR)=CVR(pfVf−piVi)=pfVf−piViγ−1

（CVR=1γ−1。）

内部自由度越多（γ → 1），同样 Δ(pV) 下做功越多——「内能在做功」。单原子 γ=53≈1.67；双原子 γ=75=1.40。

3.1 Fire syringe（绝热压缩点火）

Ta=300 K，VaVb=10，γ=1.4（空气）：

Tb=Ta(VaVb)γ−1=300×100.4≈754 K≈480 ∘C

足以点燃棉花。绝热膨胀的例子：云的形成（cap cloud）——上升空气膨胀降温，水汽凝结。

5 · Heat Engines

循环：例（矩形循环）1→2 等压膨胀（吸热）、2→3 等容降温（放热）、3→4 等压压缩（放热）、4→1 等容升温（吸热）。

闭合循环（顺时针）：ΔU=0，

Wby gas=−Won=Q=Q12+Q23+Q34+Q41=∣Qabsorb∣−∣Qrelease∣

工作原理：从高温热源 Th 吸热 Qh → 部分转化为功 W → 其余 Qc 排给低温热源 Tc；工作物质通常是气体。

ΔU=0=Q+Won,Q=Qh−Qc,Weng=−Won=Qh−Qc
e=WengQh=Qh−QcQh=1−QcQh<100%

（Weng、Qc、Qh 都取正值。）

6 · Stirling Engine（Robert Stirling, 1816）

低温差 Stirling 发动机：利用大气与稍热（一杯热咖啡、人手）或稍冷（一碗冰）的热源之间的热流获取机械能。

段 过程 W（on gas） Q
1→2 等温膨胀（Ta） W12=−nRTaln⁡VbVa<0 Q12=−W12>0（吸热）
2→3 等容降温 0 Q23=nCV(Tb−Ta)<0
3→4 等温压缩（Tb） W34=nRTbln⁡VbVa>0 Q34=−W34<0（放热）
4→1 等容升温 0 Q41=nCV(Ta−Tb)=−Q23>0

净功（单个过程：曲线下面积；循环：环内面积）：

W=W12+W34=nR(Tb−Ta)ln⁡VbVa<0(Ta>Tb)  ∝  ΔT

（W<0：气体对外做净功。Wby=Q12−∣Q34∣。）

温差越大 → 功越大。顺时针循环 = engine（气体对外做净功）；逆时针 = heat pump（外界对气体做净功）。

今天的 Stirling engine：在低温差下工作；热效率 15–30%（与内燃机相当）；应用：太阳能转换、废热回收（不需燃烧化石燃料）。

补充算例：n=1 mol，Ta=373 K，Tb=293 K，Vb/Va=2：∣W∣=8.314×80×ln⁡2≈461 J；Q12=8.314×373×ln⁡2≈2150 J。

8 · 易错点

  • 等温 ΔU=0 但 Q≠0；绝热 Q=0 但 ΔT≠0——别混。
  • 绝热公式里是 γ−1 次方（TVγ−1），压强形式是 γ 次方（pVγ）。
  • 温度必须用 K（fire syringe 算完再减 273）。
  • 效率公式中 Qc、Qh 取绝对值。
  • Stirling 的两段等容热量互相抵消（Q41=−Q23），不进入净功。
