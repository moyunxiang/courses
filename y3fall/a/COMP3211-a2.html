Q1 Uninformed Search

1.1

(a)

  • BFS: S→B→G, cost 9, 6 expanded (S, A, B, C, D, E)
  • DFS: S→A→D→G, cost 9, 3 expanded (S, A, D)
  • UCS: S→C→F→G, cost 6, 7 expanded (S, A, C, D, B, F, E; then G(6) is popped)

(b) BFS picks the path with the fewest edges and ignores costs; a longer path can be cheaper (S→B→G: 2 edges, cost 9; S→C→F→G: 3 edges, cost 6). BFS is optimal if all edge costs are equal (same positive constant).

(c) Terminate when the goal is removed. At removal g(G) is the smallest g on the frontier and costs are ≥0, so no cheaper path exists; at generation a cheaper path may still be pending (here G is first generated with g=9 via D, optimum is 6).

from collections import deque

def bfs(problem):
    frontier = deque([([problem.start], 0)])        # FIFO of (path, cost)
    num_expanded = 0
    while frontier:
        path, cost = frontier.popleft()
        state = path[-1]
        if problem.is_goal(state):                   # goal test on removal
            return path, cost, num_expanded
        num_expanded += 1
        for nxt, c in problem.successors(state):
            frontier.append((path + [nxt], cost + c))
    return None, float('inf'), num_expanded

def dfs(problem):
    stack = [([problem.start], 0)]
    num_expanded = 0
    while stack:
        path, cost = stack.pop()
        state = path[-1]
        if problem.is_goal(state):
            return path, cost, num_expanded
        num_expanded += 1
        for nxt, c in reversed(list(problem.successors(state))):   # reverse alphabetical push
            stack.append((path + [nxt], cost + c))
    return None, float('inf'), num_expanded

def uniform_cost_search(problem):
    frontier = PriorityQueue()
    frontier.push((problem.start, [problem.start]), 0)
    best_g = {problem.start: 0}
    num_expanded = 0
    while not frontier.empty():
        (state, path), g = frontier.pop()
        if g > best_g.get(state, float('inf')):
            continue                                 # stale entry
        if problem.is_goal(state):
            return path, g, num_expanded
        num_expanded += 1
        for nxt, c in problem.successors(state):
            new_g = g + c
            if new_g < best_g.get(nxt, float('inf')):   # cheaper path found
                best_g[nxt] = new_g
                frontier.push((nxt, path + [nxt]), new_g)
    return None, float('inf'), num_expanded

(a) The only solution S→D→K→D→G visits D twice, and D has different successors before and after the key (D→G locked / unlocked), so the node alone does not determine the legal actions. State = (location, has_key), has_key ∈ {False, True}; start (S, False); goal: location = G.

(b) (notebook)

class KeyDoorProblem:
    def __init__(self, graph, start, goal, key='K', locked_edge=('D', 'G')):
        self.graph, self.goal, self.key, self.locked_edge = graph, goal, key, locked_edge
        self.start = (start, start == key)           # (location, has_key)

    def is_goal(self, state):
        return state[0] == self.goal

    def successors(self, state):
        location, has_key = state
        result = []
        for nxt, cost in self.graph.get(location, []):           # alphabetical
            if (location, nxt) == self.locked_edge and not has_key:
                continue                                         # door locked
            result.append(((nxt, has_key or nxt == self.key), cost))
        return result

Q2 Informed Search

2.1

  • Misplaced tiles: admissible. Each misplaced tile needs ≥1 move.
  • Manhattan: admissible. Each move moves one tile one square.
  • Row/column count: admissible. A tile outside its goal row needs ≥1 vertical move, outside its goal column ≥1 horizontal move; each move does one of these for one tile (≤ Manhattan).
  • Nilsson: not admissible. Counterexample, one move from the goal (h∗=1): 1_3824765: P=1, S=2 (1→blank)+1 (centre)=3, h=1+3⋅3=10>1. (Also A* + Nilsson returns cost 28 on Puzzle 4; optimum 16.)

def misplaced_tiles(state):
    return sum(1 for i, t in enumerate(state) if t != 0 and t != GOAL[i])

def manhattan_distance(state):
    total = 0
    for i, t in enumerate(state):
        if t != 0:
            r, c = divmod(i, 3); gr, gc = GOAL_POSITIONS[t]
            total += abs(r - gr) + abs(c - gc)
    return total

def nilsson_sequence_score(state):
    s = 0
    for k in range(8):
        t, nxt = state[PERIMETER[k]], state[PERIMETER[(k + 1) % 8]]   # clockwise, wraparound
        if t != 0 and nxt != t % 8 + 1:                              # 1->2->...->8->1
            s += 2
    if state[4] != 0:
        s += 1                                                       # tile in centre
    return manhattan_distance(state) + 3 * s

def row_column_distance(state):
    total = 0
    for i, t in enumerate(state):
        if t != 0:
            r, c = divmod(i, 3); gr, gc = GOAL_POSITIONS[t]
            total += (r != gr) + (c != gc)
    return total

def astar(problem, heuristic):
    start = problem.start
    if problem.is_goal(start):
        return [start], 0, 0
    frontier = PriorityQueue()
    best_g, parent = {start: 0}, {start: None}
    frontier.push((start, 0), heuristic(start))                     # f = g + h
    num_expanded = 0
    while not frontier.empty():
        (state, g), _ = frontier.pop()
        if g != best_g[state]:
            continue                                                 # stale entry
        if problem.is_goal(state):
            path = []
            while state is not None:
                path.append(state); state = parent[state]
            return path[::-1], g, num_expanded
        num_expanded += 1                                            # re-expansions count
        for nxt, cost in problem.successors(state):
            new_g = g + cost
            if new_g < best_g.get(nxt, float('inf')):                # reopen if cheaper
                best_g[nxt], parent[nxt] = new_g, state
                frontier.push((nxt, new_g), new_g + heuristic(nxt))
    return None, float('inf'), num_expanded

Q3 CSP

Binary constraint on each adjacent pair (Fi,Fi+1): Fi≠Fi+1; Fi=E⇒Fi+1=C; not both in {C,S}.

(a)

  • Rule 1: F5∈{C,S}. Rule 2: S∉D1,D2,D3. Rule 3 with F0=M: M∉D1.
  • D1={E,C}, D2={M,E,C}, D3={M,E,C}, D4={M,E,C,S}, D5={C,S}.

(b)

  • Step 1, F4→F5: remove C,S (safe next to safe) ⇒ D4={M,E} (M: F5=C; E: F5=C).
  • Step 2, F3→F4: remove E (needs F4=C) ⇒ D3={M,C}.
  • Step 3, F2→F3: M→C, E→C, C→M all supported ⇒ no pruning, D2={M,E,C}.
  • Step 4, F1→F2: E→C, C→M supported ⇒ no pruning, D1={E,C} (same if D2 is checked against D1: M,E after C, C after E).
  • Final: D1={E,C}, D2={M,E,C}, D3={M,C}, D4={M,E}, D5={C,S}.

(c)

  • (i) 45= 1024
  • (ii) 2⋅3⋅3⋅4⋅2= 144
  • (iii) 2⋅3⋅2⋅2⋅2= 48

(d) Search tree (order E, M, S, C within each reduced domain):

root
└─ F1=E  ✓
   ├─ F2=E  X  (Rule 3: E,E adjacent; Rule 4: E not followed by C)
   ├─ F2=M  X  (Rule 4: E not followed by C)

F1..F5=E,C,M,E,C (full map: M, E, C, M, E, C, Boss).

(e) F1=C prunes only its neighbour F2 (C: Rule 3 and Rule 5): D2={M,E}, D3={M,C}, D4={M,E}, D5={C,S}.

(f) F1..F5=C,E,C,M,S (map M, C, E, C, M, S, Boss).

Q4 Genetic Algorithm

def fitness(state, dataset):
    correct = 0
    for row in dataset:
        total = sum(s * m for s, m in zip(row[:-1], state))      # unnormalized total
        correct += (total >= 50) == (row[-1] == 1)
    return correct / len(dataset)                                 # accuracy

def crossover(parent1, parent2):
    return [a if random.random() < 0.5 else b for a, b in zip(parent1, parent2)]   # uniform

def mutate(state, mutation_rate=0.05):
    return [max(0.0, g + random.gauss(0, 1)) if random.random() < mutation_rate else g
            for g in state]

def tournament_select(population, scores, k=3):
    best = max(random.sample(range(len(population)), k), key=lambda i: scores[i])
    return population[best]

# main loop body (population_size = 30, generations = 200, mutation_rate = 0.2, seed 3211)

        new_population.append(mutate(crossover(p1, p2), 0.2))
    population = new_population
