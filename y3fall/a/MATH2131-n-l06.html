  1. 复习：linear transformation、由 basis 的像决定
  2. Matrix = linear transformation Kn→Km；列 = 标准基的像
  3. Kernel / Image 是 subspaces
  4. Composition 是 linear；ℒ(V,V) 是 ring

  7. T 关于 basis ℬ,ℬ′ 的矩阵 [T]ℬ′ℬ
  8. Matrix multiplication 对应 composition

必考：证明 injective   ⟺  Ker T={𝟎}；isomorphism 的逆唯一且线性（证明）；dim⁡V=dim⁡W；求 [T]ℬ′ℬ（第 i 列 = [T(𝐛i)]ℬ′）；分清 ≃ 和 =（{(x,y,0)T}≃ℝ2 但 ≠ℝ2）。

1 · 复习

T:V→W（vector spaces over K，各有 +,⋅）：

  1. T(𝐮+𝐯)=T(𝐮)+T(𝐯)，𝐮,𝐯∈V
  2. T(c⋅𝐯)=c⋅T(𝐯)，c∈K

ℒ(V,W) = set of linear transformations。

Prop：T 由 basis ℬ={𝐛i} 的像 {T(𝐛i)} 唯一决定：T(𝐯)=c1T(𝐛1)+⋯+cnT(𝐛n)，∀𝐯∈V。

2 · Matrix = linear transformation Kn→Km

Def. Matrix = linear transformation when V=Kn，W=Km：T∈ℒ(Kn,Km). T is represented by an m×n matrix w.r.t. the standard basis 𝐞1,…,𝐞n：

A=(∣∣∣𝐚1𝐚2⋯𝐚n∣∣∣)m×n𝐚i:=T(𝐞i)∈W=Km

  • 第 i 列 = 标准基第 i 个向量的像
  • 尺寸：n 列（domain 维数），m 行（target 维数）
  • A 的加、减、数乘 as usual（entrywise）——对应 ℒ(Kn,Km) 的运算

3 · Kernel 与 Image

Def. T∈ℒ(V,W).

  • Kernel / null space：Ker T:={𝐯∈V:T(𝐯)=𝟎}⊂V
  • Image / range：
    Im T:={𝐰∈W:𝐰=T(𝐯) for some 𝐯∈V}⊂W

（「null space」「range」是 T 是矩阵时常用的叫法。）

Thm. Ker T⊂V，Im T⊂W are subspaces.（check subspace criterion）

Pf（补充）.

  • Ker：T(𝟎)=𝟎 ⇒ 𝟎∈Ker；若 T(𝐮)=T(𝐯)=𝟎，则 T(c𝐮+𝐯)=cT(𝐮)+T(𝐯)=𝟎 ✓
  • Im：𝟎=T(𝟎)∈Im；cT(𝐮)+T(𝐯)=T(c𝐮+𝐯)∈Im ✓

Ex. Ker(ddt) on K[t] = {constant functions} ⊂K[t]。

4 · Composition

Prop. If S∈ℒ(U,V)，T∈ℒ(V,W)，then composition T∘S∈ℒ(U,W) is linear.（T∘S(𝐮)=T(S(𝐮))）

Pf.

T(S(c𝐮+𝐯))=T(cS(𝐮)+S(𝐯))=cTS(𝐮)+TS(𝐯)

第一步用 S 线性，第二步用 T 线性。∎

Cor. ℒ(V,V) is a ring（product = composition）.

（加法是第 3 节的 S+T；乘法是复合；单位元是 I。一般不交换，不是所有元素都有逆——所以只是 ring。）

5 · Injective / Surjective

Def. T∈ℒ(V,W) is

  • one-to-one / injective：T(𝐮)=T(𝐯)⇒𝐮=𝐯   ⟺   T(𝐮)=𝟎⇒𝐮=𝟎
  • onto / surjective：∀𝐰∈W，∃ 𝐯∈V s.t. 𝐰=T(𝐯)（𝐯 叫 preimage，原像；课件写作 premage）

injective 的两种说法为什么等价？ 由线性，T(𝐮)−T(𝐯)=T(𝐮−𝐯)，且 T(𝟎)=𝟎：

  • (⇒) T(𝐮)=𝟎=T(𝟎) ⇒ 𝐮=𝟎
  • (⇐) T(𝐮)=T(𝐯) ⇒ T(𝐮−𝐯)=𝟎 ⇒ 𝐮−𝐯=𝟎

Prop.

  1. T surjective   ⟺   T(V)=W（即 Im T=W）   ⟺   T maps a spanning set of V to a spanning set of W
  2. T injective   ⟺   Ker T={𝟎}   ⟺   T maps l.i. set to l.i. set   ⟺   dim⁡T(U)=dim⁡U（对任意 subspace U）

Pf of 1（spanning）. 设 Span{𝐯1,…,𝐯n}=V。∀𝐰∈W，∃ 𝐯=c1𝐯1+⋯+cn𝐯n 使 T(𝐯)=𝐰，即 𝐰=c1T(𝐯1)+⋯+cnT(𝐯n)，属于 Span{T(𝐯1),…,T(𝐯n)}。所以这个 span =W。

Pf of 2（l.i.）. 设 {𝐯i} l.i.，c1T(𝐯1)+⋯+cnT(𝐯n)=𝟎 ⇒ T(c1𝐯1+⋯+cn𝐯n)=𝟎 ⇒（Ker = 0）c1𝐯1+⋯+cn𝐯n=𝟎 ⇒ ci=0 ✓。 维数版本：{𝐛1,…,𝐛k} 是 U 的 basis ⇒ {T(𝐛1),…,T(𝐛k)} 是 T(U) 的 basis。

5.1 例

例子 性质
U⊂V，inclusion I∣U:U↪V，𝐮↦𝐮 injective
T∈ℒ(V,W) 看成 T:V→T(V)⊂W surjective（把 target 缩成 image）
V=U⊕W，𝐯=𝐮+𝐰（唯一），π:V→W，𝐯↦𝐰 surjective、linear

最后一个叫 natural projection map from V onto W：

  • well-defined：因为 direct sum 的分解唯一（不唯一的话，𝐯 该送到哪个 𝐰 就说不清）
  • "canonical"：does not depend on choice of basis

6 · Isomorphism

Def. T∈ℒ(V,W) is an isomorphism / bijective if T is both injective and surjective （∀𝐰∈W，∃! 𝐯∈V s.t. T(𝐯)=𝐰）.

If T:V→W is isomorphism，we write V≃W（are isomorphic）：「V and W looks exactly the same as vector space」.

6.1 例

同构 映射
Kn[t]≃Kn+1 a0+a1t+⋯+antn↦(a0,a1,…,an)T（"coordinate" map）
Mm×n(K)≃Kmn 把元素排成一列（按标准基 ℰ：每个位置一个 1 的矩阵）——"coord"
{(x,y,0)T:x,y∈ℝ}⊂ℝ3 ≃ℝ2（≠ℝ2） (x,y,0)T↦(x,y)T
ℂ≃ℝ2（as vector space over ℝ） a+bi↦(a,b)T
U×W=U′⊕W′，U′≃U，W′≃W (𝐮,𝟎)↔𝐮

6.2 Coordinate mapping

Thm. If ℬ={𝐛1,…,𝐛n} basis of V（dim⁡V=n），the coordinate mapping w.r.t. ℬ

ψV,ℬ:V→Kn𝐯=c1𝐛1+⋯+cn𝐛n↦[𝐯]ℬ=(c1⋮cn)
（unique expression ⇒ well-defined）is an isomorphism V≃Kn.

意义：任何 n 维空间都同构于 Kn。例：Kn[t]≃Kn+1，Mm×n≃Kmn。

6.3 Isomorphism 的性质

Prop. If T∈ℒ(V,W) is isomorphism，then

  • dim⁡V=dim⁡W
  • ∃! T−1∈ℒ(W,V) s.t. T−1∘T=IV，T∘T−1=IW

Pf.

（dim⁡）injective 把 V 的 basis 送到 l.i. set，surjective 送到 spanning set ⇒ basis 的像是 W 的 basis，个数相同。

（∃）∀𝐰∈W，∃! 𝐯∈V s.t. T(𝐯)=𝐰。定义 T−1(𝐰):=𝐯。

  • T−1∘T(𝐯)=T−1(𝐰)=𝐯 ⇒ =IV
  • T∘T−1(𝐰)=T(𝐯)=𝐰 ⇒ =IW

（!）唯一：若 T′ 也是 inverse，

T−1=T−1∘I=T−1∘(T∘T′)=(T−1∘T)∘T′=I∘T′=T′

（linear）设 T(𝐯1)=𝐰1，T(𝐯2)=𝐰2：

  • T−1(𝐰1)+T−1(𝐰2):=𝐯1+𝐯2=T−1(𝐰1+𝐰2)（因为 T(𝐯1+𝐯2)=𝐰1+𝐰2）
  • c⋅T−1(𝐰):=c𝐯=T−1(c𝐰)（因为 T(c𝐯)=c𝐰）∎

Prop. S,T are iso ⇒ (S∘T)−1=T−1∘S−1.（顺序反过来：先脱袜子再脱鞋）

7 · T 关于两组 basis 的矩阵

dim⁡V=n，dim⁡W=m，T∈ℒ(V,W)，ℬ basis of V，ℬ′ basis of W：

V→TWψV,ℬ↓↓ψW,ℬ′Kn→ [T]ℬ′ℬ Km

Def. [T]ℬ′ℬ：the (m×n) matrix representing T w.r.t. ℬ（of V）and ℬ′（of W）. i.e. if T(𝐯)=𝐰 then [T]ℬ′ℬ:[𝐯]ℬ↦[𝐰]ℬ′.

i-th column of [T]ℬ′ℬ is image of 𝐞i=[𝐛i]ℬ，=[T(𝐛i)]ℬ′.

Rem. [T]ℬ′ℬ:=ψW,ℬ′∘T∘ψV,ℬ−1∈ℒ(Kn,Km).

Rem. T∈ℒ(V,V)，ℬ=ℬ′ 时写 [T]ℬ 代替 [T]ℬℬ.

求 [T]ℬ′ℬ 的套路：

  1. 对每个 𝐛i∈ℬ 算 T(𝐛i)∈W
  2. 把 T(𝐛i) 用 ℬ′ 展开，得到坐标 [T(𝐛i)]ℬ′
  3. 按顺序作为第 1,2,…,n 列

（例子：Worksheet 02 P3，ddt 的矩阵，见 L07。）

8 · Matrix Multiplication

A∈Mm×n(K)，B∈Mn×r(K)，then A⋅B∈Mm×r(K)：

(A⋅B)ij:=∑k=1naikbkj1≤i≤m, 1≤j≤r
（A 的第 i 行 横着走，B 的第 j 列 竖着走，对应相乘相加）

Prop. If A（m×n）represents T∈ℒ(Kn,Km)（w.r.t. ℰ），B（n×r）represents S∈ℒ(Kr,Kn)（w.r.t. ℰ），then A⋅B（m×r）represents T∘S∈ℒ(Kr,Km).

这就是矩阵乘法这样定义的原因：它恰好对应映射的复合。（证明见 L07。）

10 · 易错点

  • [T]ℬ′ℬ 的第 i 列要用 **ℬ′（target 的基）**展开 T(𝐛i)，不是用 ℬ。
  • m×n 矩阵对应 Kn→Km（列数 = domain 维数）。
  • {(x,y,0)T} 同构于 ℝ2，但不等于 ℝ2。
  • (S∘T)−1=T−1∘S−1，顺序反过来。
  • 证 injective 用 Ker T={𝟎} 最快，但要先说明 T 是 linear。
