0 · 这一讲在讲什么

问题：X 不服从正态时，Xˉ 的精确分布很难求 → 用大样本近似。

  1. Convergence in probability →p：WLLN（Chebyshev 证明）；Sn−12→σ2、Sn2→σ2（Markov、MSE 分解）；Continuous Mapping Theorem
  2. Convergence in distribution →d：CLT（mgf 证明）、Lévy–Lindeberg CLT；两种收敛的关系
  3. Slutsky's lemma：n(Xˉ−μ)Sn−1→dN(0,1)
  4. 应用：Bernoulli θ 的近似 CI（两种做法）；变换法（θ∈(0,1)）
  5. Delta method（一阶、二阶）

必会证明：WLLN（Chebyshev）；CLT（mgf + Taylor + (1+bn/n)n→eb）；n(Xˉ−μ)Sn−1→dN(0,1)（CLT + Slutsky + CMT）。必会计算：Bernoulli 的 Sn−12=nn−1Xˉ(1−Xˉ)；两种近似 CI；delta method 求 g(Xˉ) 的渐近分布；二阶 delta method。

1 · 两种收敛

数列：yn→y ⟺ lim⁡yn=y ⟺ 对每个 ϵ>0，n 够大时 ∣yn−y∣<ϵ。例：1n→0。

随机变量序列 {Yn} 的收敛有多种模式，本课学两种。

1.1 Convergence in probability

Yn→pY：对每个 ϵ>0，P(∣Yn−Y∣<ϵ)→1（等价地 P(∣Yn−Y∣≥ϵ)→0）。

1.2 Convergence in distribution

Yn→dY：FYn(t)→FY(t) 对 FY 的所有连续点 t 成立。

1.3 关系（证明略）

Yn→pY  ⇒  Yn→dY

反过来一般不成立，除非 Y=c 是常数：

Yn→dc  ⇒  Yn→pc

（手写 9/22：→p 更强——要求随机变量本身接近；→d 只要求 cdf 接近。）

2 · WLLN

WLLN：{Xi} 是 X 的 rs，E(X2)<∞（⇒ μ、σ2 有限），则 Xˉn→pμ。

Chebyshev 不等式：μW<∞，对任意 k>0：P(∣W−μW∣≥k)≤σW2k2。

证明：

P(∣Xˉn−μ∣≥ϵ)≤Var(Xˉn)ϵ2=σ2nϵ2→0

矩的说明（手写 9/17）：σ2=E(X2)−[E(X)]2；高阶矩存在 ⇒ 低阶矩存在：E(X2)<∞⇒E(X)<∞。

例（手写 9/22）：X∼Binomial(1,θ)。n=1,2,3,… 时 Xˉn 取值 {0,1}、{0,12,1}、{0,13,23,1}…；E(Xˉn)=θ，Var(Xˉn)=θ(1−θ)n→0 ⇒ 分布越来越集中在 θ，极限是 θ 处的单点分布。

3 · S2 的收敛

3.1 Sn−12→pσ2

Chebyshev（E(Sn−12)=σ2）：P(∣Sn−12−σ2∣≥ϵ)≤Var(Sn−12)ϵ2，且

Var(Sn−12)=1n(μ4−n−3n−1σ4)→0,μ4=E(X−μ)4

只需假设 E(X4)<∞（有限四阶矩）。

3.2 Sn2→pσ2

Sn2 有偏：E(Sn2)=n−1nσ2≠σ2，Chebyshev 不能直接用。改用

Markov 不等式：U≥0，k>0：P(U≥k)≤E(U)k。（Chebyshev 是 U=(W−μW)2 的特例。）

P(∣Sn2−σ2∣≥ϵ)≤E[(Sn2−σ2)2]ϵ2=Var(Sn2)+[E(Sn2)−σ2]2ϵ2

MSE 分解（手写 9/17 p.3）：

E[(Sn2−σ2)2]=E[(Sn2−ESn2+ESn2−σ2)2]=E[(Sn2−ESn2)2]⏟Var(Sn2)+(ESn2−σ2)2⏟bias2+0

（交叉项 2(ESn2−σ2)E[Sn2−ESn2]=0。）

用 Sn2=n−1nSn−12：Var(Sn2)=(n−1n)2Var(Sn−12)→0，bias =−σ2n→0 ⇒ 分子 →0。

3.3 Sn−1→pσ：Continuous Mapping Theorem

CMT：Yn→pc，h 连续 ⇒ h(Yn)→ph(c)。

h(t)=t：Sn−1→pσ，Sn→pσ；同理 1Sn−1→p1σ、σSn−1→p1。

4 · CLT

CLT（classical）：rs，均值 μ，方差 σ2>0，mgf MX(t) 在 0 的邻域存在，则 n(Xˉn−μ)σ→dZ∼N(0,1)。

Lévy–Lindeberg CLT（证明略）：只需 σ2 正且有限，不要求 mgf。

动机（手写 9/22）：Var(Xˉn)→0，分布塌缩成一点；放大 n 倍：Var[n(Xˉn−θ)]=n⋅σ2n=σ2——稳定，有一个极限分布，CLT 告诉我们是正态。

mgf 极限引理：lim⁡MWn(t)=MY(t) 对 0 的邻域内所有 t ⇒ Wn→dY。

证明（手写 9/22 p.3–4）：令 Vi=Xi−μσ（i.i.d.，EV=0，EV2=1），Wn=n(Xˉn−μ)σ=1n∑Vi。

MWn(t)=E(etn∑Vi)=∏i=1nMVi(tn)=[MV1(tn)]n

（第二步用独立，第三步用同分布；MV(tn)=e−μtσnMX(tσn) 在 −σhn<t<σhn 存在，n→∞ 时覆盖全部 t。）

Taylor：ea=1+a+a22+⋯

MWn(t)=[E(1+tnV1+t22nV12+⋯)]n=[1+0+t22n+⋯]n=(1+12t2+⋯n)n→et2/2

（用 lim⁡(1+bnn)n=eb 若 bn→b；高阶项 →0。）et2/2 是 N(0,1) 的 mgf。∎

5 · Slutsky's Lemma

若 Yn→dV，Wn→pc，则 (i) Yn±Wn→dV±c；(ii) WnYn→dcV；(iii) YnWn→dVc（c≠0）。

核心应用：μ4 有限 ⇒ σSn−1→p1，由 CLT + Slutsky (ii)：

n(Xˉn−μ)Sn−1=n(Xˉn−μ)σ⋅σSn−1→dZ∼N(0,1)

不需要正态假设、σ 未知、n 大时，可以用它构造 μ 的 CI：Xˉ±zα/2Sn−1n。（正态时精确分布是 t(n−1)；非正态大样本用 z。）

6 · 例：Bernoulli 参数 θ 的近似 CI（手写 9/24）

X∼Binomial(1,θ)，0<θ<1。E(X)=θ，σ2=θ(1−θ)∈(0,14]，有限且正 ⇒ CLT 成立：

1−α≈P(−zα/2<n(Xˉ−θ)σ<zα/2)=P(Xˉ−zα/2σn<θ<Xˉ+zα/2σn)

**但 σ2=θ(1−θ) 未知！**两种补救：

6.1 方法一：用 Sn−1（Slutsky）

E(X4)=∑x4P(X=x)=P(X=1)=θ<∞ ✓ ⇒ n(Xˉ−θ)Sn−1→dN(0,1)。

因为 X∈{0,1}，X2=X：

Sn−12=1n−1∑(Xi2−2XiXˉ+Xˉ2)=1n−1∑(Xi−2XiXˉ+Xˉ2)=1n−1[nXˉ−2nXˉ2+nXˉ2]=nn−1Xˉ(1−Xˉ)
Xˉ±zα/21n−1Xˉ(1−Xˉ)

6.2 方法二：直接替换 θ(1−θ)（CMT + Slutsky）

h(θ)=θ(1−θ)，找一个 →ph(θ) 的 estimator：Xˉ→pθ（WLLN），CMT ⇒ h(Xˉ)=Xˉ(1−Xˉ)→ph(θ)。

n(Xˉ−θ)Xˉ(1−Xˉ)=n(Xˉ−θ)h(θ)⏟→dZ⋅h(θ)h(Xˉ)⏟→p1→dZ
Xˉ±zα/21nXˉ(1−Xˉ)

（两种只差 n−1 vs n，大 n 时几乎一样。）

7 · 变换法（手写 9/29）

问题：正态近似的均值不受限制，但 θ∈(0,1)——CI 端点可能跑出 (0,1)。

补救：(i) 变换 θ 到 (−∞,∞)；(ii) 用 CLT（± Slutsky）给变换后的参数构造区间；(iii) 反变换回 θ。

例（g 不唯一）：

θ∈(0,1)  →  ln⁡θ∈(−∞,0)  →  −ln⁡θ∈(0,∞)→  g(θ)=ln⁡(−ln⁡θ)∈(−∞,∞)

g(Xˉ) 的渐近分布：CLT n(Xˉ−θ)→dσZ；Taylor g(Xˉ)≈g(θ)+g′(θ)(Xˉ−θ)：

n[g(Xˉ)−g(θ)]≈g′(θ)n(Xˉ−θ)→dN(0,[g′(θ)σ]2)

1−α≈P(−zα/2≤n[g(Xˉ)−g(θ)]∣g′(θ)σ∣≤zα/2)=P(g(θ)∈(A,B))

反变换：g(t)=ln⁡(−ln⁡t) ⇒ t=e−eg，g 递减，所以

1−α≈P(e−eB≤θ≤e−eA)

（端点自动在 (0,1) 内：eA>0⇒eeA>1⇒e−eA<1。）

g′(θ)σ 的两种情况：

  • 常数 k（variance-stabilizing）：取 ddθg(θ)=kθ(1−θ)，pivot 里没有未知量，简单
  • θ 的函数 h(θ)：用 h(Xˉ) 代替（WLLN + CMT，需 ∣h∣ 连续），Slutsky：
n[g(Xˉ)−g(θ)]∣h(Xˉ)∣=n[g(Xˉ)−g(θ)]∣h(θ)∣⏟→dN(0,1)⋅∣h(θ)∣∣h(Xˉ)∣⏟→p1→dN(0,1)

8 · Delta Method

一阶 delta method：n(Yn−a)→dN(0,b2)（b>0），g′(a) 存在且 ≠0，则

n(g(Yn)−g(a))→dN(0,[g′(a)b]2)

证明思路：g(Yn)≈g(a)+g′(a)(Yn−a)，减 g(a) 乘 n。（严格证明要处理余项，本课不要求。）

Corollary（+ CLT）：n(g(Xˉn)−g(μ))→dN(0,[g′(μ)σ]2)。

例：g(t)=1t，μ≠0：g′(μ)=−1μ2

n(1Xˉn−1μ)→dN(0,σ2μ4)

对 1μ 做推断时用 Slutsky 把 σ2μ4 换成 Sn−12Xˉn4。

二阶 delta method（手写 9/29 p.4）：g′(a)=0，g′′(a)≠0 时一阶失效。Taylor 到二阶：

g(Yn)−g(a)≈g′′(a)2(Yn−a)2
所以
n[g(Yn)−g(a)]≈g′′(a)2b2[n(Yn−a)b]2
2n[g(Yn)−g(a)]g′′(a)b2→dχ2(1)

（n(Yn−a)b→dN(0,1)，平方 →χ2(1)。注意是 n 而不是 n。）

补充算例：Bernoulli，g(t)=t(1−t)，a=θ=12：g′(12)=0，g′′=−2，b2=14 ⇒ 2n[Xˉ(1−Xˉ)−14]−2⋅14=−4n[Xˉ(1−Xˉ)−14]→dχ2(1)。

9 · 考点清单

考点 至少要会
两种收敛 定义；p⇒d；d 到常数 ⇒p
WLLN 条件 E(X2)<∞；Chebyshev 证明
S2 收敛 Sn−12：Chebyshev + Var 公式，需 EX4<∞；Sn2：Markov + MSE = Var + bias²
CMT Sn−1→σ，σ/Sn−1→1
CLT 条件；mgf 证明每一步的理由
Slutsky 三条；n(Xˉ−μ)/Sn−1→N(0,1)
Bernoulli CI Sn−12=nn−1Xˉ(1−Xˉ)；两种区间
变换法 三步；ln⁡(−ln⁡θ) 的反变换（注意递减翻转端点）
Delta method 一阶公式、1/Xˉ 例；二阶 → χ2(1)

10 · 易错点

  • WLLN 只要 E(X2)<∞；Sn−12→σ2 要 E(X4)<∞。
  • Sn2 有偏，不能直接用 Chebyshev（Chebyshev 以均值为中心）——用 Markov + MSE。
  • Slutsky 要求其中一个收敛到常数（依概率）。
  • CLT 的 classical 版要 mgf 存在；Lévy–Lindeberg 只要有限正方差。
  • 正态 + σ 未知：精确 t(n−1)；非正态 + 大 n：近似 N(0,1)。
  • Delta method 方差是 [g′(a)]2b2（平方）；g′(a)=0 时换二阶，乘 n 不是 n。
  • 反变换函数递减时，区间端点要对调。
