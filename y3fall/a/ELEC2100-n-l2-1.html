1 · 时域分析概览

  • Input/output description：一个 n 阶微分（差分）方程
  • State variable description：n 个一阶微分（差分）方程
  • 不经变换、直接解方程：直观、物理意义清楚，是学变换域方法的基础
  • Chapter 2 先讲 input/output description

LTI 系统的一般微分方程：

andnr(t)dtn+an−1dn−1r(t)dtn−1+⋯+a1dr(t)dt+a0r(t)=bmdme(t)dtm+bm−1dm−1e(t)dtm−1+⋯+b1de(t)dt+b0e(t)
  • n、m 是整数，系数都是常数；系统阶数由最高阶导数决定（n）
  • 系统变复杂（高阶）怎么办？信号变复杂（DC、正弦、指数、衰减指数、随机波形）怎么办？

本章的思路：

  • 求出系统的 impulse response h(t)：δ(t)→h(t)
  • 任意输入的零状态响应用卷积：rzs(t)=e(t)∗h(t)
  • 离散系统同理

2 · 微分方程的经典解法（参考）

完全解=齐次解（homogeneous）+特解（particular）
  • 齐次解：特征方程 → 特征根 → 齐次解
  • 特解：和输入形式相同；待定系数，代入原方程求
  • 齐次解的系数：用系统的初始条件定
  • 另一种分法：zero-input response（用经典法）+ zero-state response（用卷积）；或用变换域方法

3 · 系统响应的分类

三种分法：

  • Zero-input + Zero-state（本课重点）
  • Natural + Forced（自由响应 + 强迫响应：分别对应齐次解和特解）
  • Transient + Steady-state（暂态 + 稳态：t→∞ 时消失的部分 + 剩下的部分）

3.1 Zero-input + Zero-state

r(t)=H[x(0−)]+H[e(t)]=rzi(t)+rzs(t)
Zero-input response rzi Zero-state response rzs
怎么来 输入置 0，只由系统的初始储能（初始状态）产生 初始状态置 0（无初始储能），只由外部激励产生
方程 齐次方程 原方程
解的形式 只有齐次解（特解为 0） 特解 + 齐次解
边界条件 不跳变：rzi(k)(0+)=rzi(k)(0−)=r(k)(0−)，k=0..n−1 rzs(k)(0−)=0；但 0+ 处可能跳变
数学上 带初始条件的齐次方程的解 输入与 impulse response 的卷积

3.2 初始点的跳变

激励加入的瞬间（t=0+），状态变量可能突变，违反连续性条件：

  • 电容：vC(0−)=0，阶跃电压源接上后 vC(0+)=E ⇒ iC(t)=CdvCdt=CE δ(t)
  • 电感：电流 iL 突变到 Is ⇒ vL(t)=LdiLdt=LIs δ(t)

（理想电压源直接加在电容上，或理想电流源串电感时，会产生冲激。）

零状态响应在 0+ 的跳变量 rzs(k)(0+) 求起来复杂 ⇒ 引入卷积方法。

3.3 零状态响应的意义

  • 大多数实际通信、电子系统只需研究零状态响应
  • 可以用卷积求
  • 可以通过输入输出关系做系统的「识别」和固有特性分析

4 · Impulse Response 与 Step Response

4.1 定义

Unit impulse response h(t)：系统在单位冲激 δ(t) 激励下的零状态响应

δ(t)→zsh(t)h(k)(0−)=0 (k=0,1,…,n−1)

Unit step response g(t)：系统在单位阶跃 u(t) 激励下的零状态响应

u(t)→zsg(t)g(k)(0−)=0

4.2 两者的关系

由 1.3 讲的 LTI 微积分特性（输入求积分 ⇒ 输出也求积分）：

u(t)=∫−∞tδ(τ) dτ⇒g(t)=∫−∞th(τ) dτh(t)=dg(t)dt

4.3 典型系统的 h(t)

（输入 δ(t)，看输出是什么。）

系统 输入输出关系 h(t)
Scalar multiplier r(t)=a e(t) a δ(t)
Differentiator r(t)=de(t)dt δ′(t)
Integrator r(t)=∫−∞te(τ)dτ ∫−∞tδ(τ)dτ=u(t)
Delayer r(t)=e(t−τ) δ(t−τ)

4.4 用 h(t) 判断因果性和稳定性（必考）

因果系统 ⟺

h(t)=0,t<0
（冲激在 t=0 才加入，因果系统不能在此之前有响应） 推广到信号：causal signal x(t)=0（t<0）

（BIBO）稳定系统 ⟺

∫−∞∞∣h(t)∣ dt<∞
（h(t) 绝对可积）

补充算例：

h(t) 因果？ 稳定？
e−2tu(t) ✓ ✓（∫0∞e−2tdt=12）
u(t)（积分器） ✓ ✗（∫0∞1 dt=∞）
e−∣t∣ ✗（t<0 非零） ✓（积分 =2）
etu(t) ✓ ✗
δ(t−2)（延迟 2） ✓ ✓
δ(t+1)（超前 1） ✗ ✓

为什么绝对可积就稳定？（补充） 输入有界 ∣e(t)∣≤M：

∣r(t)∣=∣∫e(τ)h(t−τ)dτ∣≤M∫∣h(t−τ)∣dτ=M∫∣h∣<∞

4.5 小结

  • Impulse response 能完全刻画系统行为（LTI 系统由 h(t) 唯一确定）
  • 求 h(t) 的三种时域方法：(1) 奇异函数平衡法（singularity function balance）；(2) 时域直接求解；(3) 卷积积分
  • 时域法物理直观但计算繁琐；用变换域（如 Laplace）求 h(t)、g(t) 更简单

5 · 卷积的引入（核心推导）

5.1 动机

已知 δ(t)→h(t)。由 LTI：

f2(t)=δ(t)+1.5 δ(t−2)  ⟶  r2(t)=h(t)+1.5 h(t−2)

（线性：系数 1.5 带出来；时不变：延迟 2 的冲激产生延迟 2 的响应。）

任意信号 f(t) 的零状态响应怎么求？——把它拆成很多冲激的叠加。

5.2 把信号分解成冲激

把 e(t) 切成宽 Δτ 的窄脉冲。在 t=τ 处的窄脉冲：幅值 e(τ)，宽 Δτ：

ei(t)=e(τ)[u(t−τ)−u(t−τ−Δτ)]

τ 从 −∞ 到 ∞，e(t) 近似为这些窄脉冲之和：

e(t)≈∑τ=−∞∞e(τ)[u(t−τ)−u(t−τ−Δτ)]=∑τe(τ)u(t−τ)−u(t−τ−Δτ)ΔτΔτ

令 Δτ→0：

  • Δτ→dτ，∑→∫
  • 差商 u(t−τ)−u(t−τ−Δτ)Δτ→du(t−τ)dt=δ(t−τ)
e(t)=∫−∞∞e(τ) δ(t−τ) dτ

任何信号都可以表示成时移单位冲激的加权叠加（权重 e(τ)，位置 τ）——这正是 sifting 性质。

5.3 零状态响应 = 卷积

把这个分解送进 LTI 系统（h(t)）：

δ(t)→h(t)δ(t−τ)→h(t−τ)（时不变）e(τ) δ(t−τ)→e(τ) h(t−τ)（线性：齐次）∫−∞∞e(τ)δ(t−τ) dτ→∫−∞∞e(τ)h(t−τ) dτ（线性：叠加）

左边就是 e(t)，右边就是零状态响应：

rzs(t)=∫−∞∞e(τ) h(t−τ) dτ=e(t)∗h(t)

卷积的定义：两个函数 f1(t)、f2(t) 的卷积积分

f(t)=f1(t)∗f2(t)=∫−∞∞f1(τ)f2(t−τ) dτ
一种把两个函数（通常是信号和系统的 impulse response）组合成第三个函数的运算，表示一个如何改变另一个。

5.4 物理意义

rzs(t)=∫−∞∞e(τ) h(t−τ) dτ
符号 含义
τ 信号（某个冲激分量）发生的时刻
e(τ) 在 τ 时刻的激励（冲激的强度）
t 观察响应的时刻
h(t−τ) 在 τ 时刻加的单位冲激，在 t 时刻引起的响应

一句话：t 时刻的输出 = 过去每个时刻 τ 的输入 e(τ)，各自经过 t−τ 时间后的「余响」h(t−τ) 的总和。课件动画：把输入切成窄脉冲，每个脉冲产生一个缩放、延迟的 h，把它们加起来就是（近似的）输出；脉冲越窄越接近真实输出。

（因果系统 h(t−τ)=0 当 τ>t——未来的输入不影响现在，积分上限可以改成 t。）

7 · 易错点

  • h(t) 和 g(t) 都是零状态响应。
  • g(t)=∫−∞th(τ)dτ（step 响应是 impulse 响应的积分），不是导数。
  • 积分器的 h(t)=u(t)，它不稳定（u 不绝对可积）。
  • 因果判断看 h(t) 在 t<0 是否为 0；稳定判断看绝对值的积分。
  • 卷积是 e(τ)h(t−τ)，对 τ 积分，结果是 t 的函数。
  • 零状态响应用卷积；零输入响应用齐次方程 + 初始条件，不能用卷积。
