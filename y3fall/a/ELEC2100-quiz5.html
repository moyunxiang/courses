Question Types → Templates

T1 · ROC of a signal

Steps: split into right-sided and left-sided terms → right term gives Re > (its pole), left term gives Re < (its pole) → intersect.

Example: e−2tu(−t) ⇒ −∫−∞0e−(s+2)tdt converges only for Re{s}<−2 ⇒ F=−1s+2, ROC Re{s}<−2.

Example: e−2tu(t)+e−5tu(−t) needs Re{s}>−2 and <−5 ⇒ empty, so there is no Laplace transform.

T2 · Transform via properties

Steps: rewrite as a table pair with a shift, modulation or scale → apply the property → update the ROC.

Example: e−tu(t−2)=e−2 e−(t−2)u(t−2) ⇒ F(s)=e−2(s+1)s+1, Re{s}>−1.

Example (HW3 Q3d): f(2t) ⇒ 12F(s2); ROC Re{s}>−2 becomes Re{s}>−4.

T3 · Inverse transform (partial fractions)

Steps: improper → long-divide first → factor the denominator → cover-up Ai=(s−pi)F(s)∣s=pi → table → check the ROC (right-sided ⇒ u(t) terms).

  • Real poles: s+4(s+1)(s+2)=3s+1−2s+2 ⇒ (3e−t−2e−2t)u(t)
  • Complex poles (complete the square): s+3s2+2s+5=(s+1)+2(s+1)2+22 ⇒ e−t(cos⁡2t+sin⁡2t)u(t)
  • Double pole: 1s(s+1)2=1s−1s+1−1(s+1)2 ⇒ (1−e−t−te−t)u(t)
  • Improper: s2(s+1)(s+2)=1+1s+1−4s+2 ⇒ δ(t)+(e−t−4e−2t)u(t)

T4 · Initial / final value

Steps: IVT needs a strictly proper F (otherwise drop the polynomial part). FVT only if every pole of sF(s) is in the LHP.

Example: F=s+2s(s+4) ⇒ f(0+)=lim⁡s→∞s+2s+4= 1, f(∞)=lim⁡s→0s+2s+4= 12. Check: f=12+12e−4t.

Trap: F=2s2+4 gives f=sin⁡2t, which has poles on the jω-axis ⇒ no final value, even though lim⁡sF=0.

T5 · System function: ODE, poles, stability, damping

Steps: H(s) ↔ ODE (coefficients map directly) → factor → causal ⇒ ROC right of the rightmost pole → stable? → oscillatory / damping from the pole type.

Example: H=s+1s2+6s+25, causal ⇒ ODE y′′+6y′+25y=x′+x; zero −1; poles −3±j4; ROC Re{s}>−3 ⇒ stable, oscillatory, under-damped (α=3<ω0=5).

T6 · Pole pattern / ROC from facts (T12)

  • Real f ⇒ complex poles come in conjugate pairs.
  • Real and even ⇒ also mirrored (p, p∗, −p, −p∗). The signal is two-sided, so the ROC is a strip containing the jω-axis.
  • Convolution can cancel a pole: F1=s+3s+10, F2=1s+3 (both right-sided) ⇒ F=1s+10, ROC Re{s}>−10 (larger than R1∩R2).
  • Differentiation can cancel a pole at 0: X=1s(s+3), y=x′ ⇒ Y=1s+3, ROC Re{s}>−3.

T7 · DFT value / circular convolution (if Ch 4 end is included)

Example: x={1,1,0,0} ⇒ X[k]=1+(−j)k ⇒ {2, 1−j, 0, 1+j}.

Example: {1,1,0,0}⊛4{1,2,3,4}: y[n]=h[n]+h[((n−1))4] ⇒ {5,3,5,7}. Check: linear {1,3,5,7,4}, then wrap 4 onto n=0.

Common Mistakes

  1. Forgetting the ROC: e−atu(t) and −e−atu(−t) have the same F(s). Only the ROC tells them apart.
  2. Scaling: f(at)→1∣a∣F(sa), and the ROC boundary is multiplied by a. Don't use aF(as).
  3. Shifted step: e−tu(t−2) is not e−2s1s+1; the missing factor is e−2.
  4. Applying FVT when poles are on the jω-axis or in the RHP (e.g. 1s−1 or ωs2+ω2). Its answer is meaningless.
  5. IVT on an improper F: remove the polynomial (δ) part first.
  6. Stability: check that the ROC includes the jω-axis. LHP poles alone imply stability only for causal systems. A RHP zero does not affect stability.
  7. Damping: real distinct poles ⇒ over-damped (not oscillatory). Complex LHP ⇒ under-damped (oscillatory).
  8. Circular convolution: wrap index ((n−m))N. Pad both sequences to the same N first.
