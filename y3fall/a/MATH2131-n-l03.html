1 · 复习：Subspace

Vector space V over K：+:V×V→V，⋅:K×V→V，加 8 条规则；记住 −𝐮=(−1)⋅𝐮。K 是 field（ℚ,ℝ,ℂ），其元素叫 scalars（numbers）。

Subspace = vector space inside a vector space。U⊂V is a subspace if

  1. 𝟎∈U   ⟺  （在有 2 的前提下）U is non-empty
  2. Closure：𝐮,𝐯∈U⇒𝐮+𝐯∈U；k∈K,𝐮∈U⇒k𝐮∈U   ⟺   𝐮+k𝐯∈U

例：ℝ3 中过原点的平面（如 x+y+z=0）；Kn[t]⊂K[t]（degree ≤n）。

1.1 例：ring 中包含域 K

若 V 是一个 ring，且包含 field K⊂V，则 V 也是 K 上的 vector space。

为什么？ ring 有 +:V×V→V 和 ⋅:V×V→V。把乘法限制到 K×V→V（左边只允许 K 中的元素）就是标量乘法；8 条公理由 ring 的公理直接给出。

  • K⊂K[t]（常数多项式）
  • K⊂Mn×n(K)（把 c 看成对角常数矩阵 cI）
  • ℝ⊂ℂ ⇒ ℂ is a vector space over ℝ

（这些也是 subspace 的例子：K 是 K[t] 的 subspace。）

1.2 例：用 Span 证明 subspace

U={(a−3bb−aab)∈ℝ4:a,b∈ℝ}

方法 1：Subspace criterion

  • a=b=0 给出 𝟎∈U
  • 两个元素相加：
(a1−3b1b1−a1a1b1)+(a2−3b2b2−a2a2b2)=((a1+a2)−3(b1+b2)(b1+b2)−(a1+a2)a1+a2b1+b2)∈U

（取 a=a1+a2，b=b1+b2）；scaling 同理

方法 2：写成 Span（更快）

U={a(1−110)+b(−3101):a,b∈ℝ}=Span{(1−110),(−3101)}

Span 一定是 subspace（下面的定理），完成。

2 · Linear combination 与 Span

Def. A linear combination of S⊂V（subset of a vector space over K）is any FINITE sum

c1𝐯1+c2𝐯2+⋯+cr𝐯r∈Vci∈K, 𝐯i∈S, r∈ℤ≥0

  • 必须是有限和。即使 S 是无穷集，每个 linear combination 也只用到其中有限个。
  • Rem：允许 r=0（空和）⇒ 结果是 𝟎。所以 𝟎 永远是 linear combination。

Def. Span(S) = set of all linear combinations of S.

Rem：允许 S=∅ ⇒ Span(∅):={𝟎}。

Thm. Span(S) is a subspace of V.

Pf.

  1. r=0 ⇒ 𝟎∈Span(S) ✓
  2. 两个 linear combination 相加还是（有限的）linear combination；乘以标量也是 ✓

Thm. Span(V)=V.

Pf.

  • Span V⊂V：by definition（linear combination 的结果在 V 里）
  • V⊂Span V：任何 𝐯∈V 就是 r=1、c1=1 的 linear combination

几何：Span(𝐮,𝐯)（不共线）是过原点的平面，包含 𝐮+𝐯、2𝐮+3𝐯、−𝐮 等所有组合。

3 · Linear (in)dependence

Def. A set of vectors {𝐯1,𝐯2,…,𝐯r}⊂V is linearly dependent（not l.i.）if

c1𝐯1+c2𝐯2+⋯+cr𝐯r=𝟎
for some ci∈K, not all of them are 0（nontrivial）.

Def. {𝐯1,…,𝐯r} is linearly independent（l.i.）if it is not linearly dependent：

If c1𝐯1+⋯+cr𝐯r=𝟎 then all ci=0.

逻辑小注（课件旁注）：「If P then Q」等价于 ¬P∨Q；它的否定是 P∧¬Q。所以「不是 l.i.」= 「存在一组系数，使组合为 𝟎，且不全为 0」。

证 l.i. 的标准步骤：设 c1𝐯1+⋯+cr𝐯r=𝟎，列出方程，解出所有 ci=0。 证 l.d.：找出一组不全为 0 的系数（给出具体的 linear relation）。

3.1 一个向量（r=1）

{𝐯} is l.i.  ⟺  (c𝐯=𝟎⇒c=0)  ⟺  𝐯≠𝟎
{𝐯} is not l.i.  ⟺  (c𝐯=𝟎 but c≠0)  ⟺  𝐯=𝟎

（用了上一讲的 c𝐯=𝟎  ⟺  c=0 或 𝐯=𝟎。）

3.2 两个向量（Prop）

{𝐮,𝐯} is l.i.   ⟺   𝐮,𝐯 are not multiples of each other（包括 𝟎 的情况）

等价地：{𝐮,𝐯} is not l.i.   ⟺   𝐮,𝐯 are multiples of each other.

Pf.

(⇒) c1𝐮+c2𝐯=𝟎，其中 c1 或 c2≠0。WLOG（without loss of generality）设 c1≠0，则

𝐮=−c2c1𝐯

是 𝐯 的倍数 ✓

(⇐) WLOG 𝐮=c𝐯，则 1⋅𝐮−c𝐯=𝟎，系数 1≠0，是 nontrivial linear combination ✓ ∎

WLOG 的意思：c1≠0 和 c2≠0 两种情况完全对称，只证一种，另一种换名字即可。

3.3 更多例子

例子 结论 理由
任何含 𝟎 的集合 not l.i. 取 𝐯1=𝟎，c1=2131（任何非零数），其余 ci=0 ⇒ linear relation

3.4 Linear dependence depends on fields!

{sin⁡t,cos⁡t,eit}⊂V={ℂ-valued functions over ℝ}：

  • over ℂ：not l.i.，因为 Euler 公式 eit=cos⁡t+isin⁡t，即 isin⁡t+cos⁡t−eit=0（系数 i 在 ℂ 里）
  • over ℝ：l.i.，系数只能是实数，凑不出 i

补充（over ℝ 为什么 l.i.）：设 asin⁡t+bcos⁡t+c eit=0，a,b,c∈ℝ。取虚部：csin⁡t=0 对所有 t，所以 c=0；剩下 asin⁡t+bcos⁡t=0，代 t=0 得 b=0，代 t=π/2 得 a=0。

4 · Bases

4.1 直觉（ℝ2）

  • too few：一个向量，只能表示一条线上的点 ✗
  • 刚好：两个不共线的向量，平面上每个点都能被唯一地表示为它们的组合 ✓（express the location uniquely as a span of some subset）
  • too many：三个向量，能表示所有点，但表示方法不唯一 ✗

4.2 定义

Def. ℬ⊂V（ordered subset）is a basis of V iff

  1. ℬ is linearly independent，and
  2. V=Span(ℬ)
  • 有限时写成 {𝐛1,𝐛2,…,𝐛n}
  • ordered：顺序重要（影响坐标向量）
  • 1 保证「不多余」（唯一性），2 保证「够用」（存在性）

4.3 Standard bases

  • Kn：ℰ={𝐞1,…,𝐞n}，𝐞i 第 i 个分量是 1，其余是 0
  • Kn[t]：ℰ={1,t,t2,t3,…,tn}

4.4 Goals（之后几讲要证的）

  • Any vector space has a basis（∞-dim 的情形也对，但要用 Axiom of Choice）
  • ★ Any vector is a unique linear combination of a given basis（下面马上证）
  • Any basis has the same size → 这个 size 就是 dimension of V

4.5 Unique Representation Theorem

Thm. ℬ={𝐛1,𝐛2,…,𝐛n}⊂V. If ℬ is a basis, then ∀𝐯∈V, ∃! c1,…,cn∈K s.t.

𝐯=c1𝐛1+c2𝐛2+⋯+cn𝐛n

（∃! = exists unique）

Pf.

  • Exists：ℬ spans V ✓
  • Unique：设另有 𝐯=c1′𝐛1+⋯+cn′𝐛n。两式相减：
𝟎=(c1−c1′)𝐛1+(c2−c2′)𝐛2+⋯+(cn−cn′)𝐛n

ℬ is l.i. ⇒ ci−ci′=0 ⇒ ci′=ci，∀i ∎

看清楚：存在性来自 span，唯一性来自 l.i.——basis 的两个条件各管一半。

4.6 Coordinate vector

Def. [𝐯]ℬ=(c1c2⋮cn)∈Kn：𝐯∈V w.r.t. ℬ 的 coordinate vector

Rem：depends on the ordering of ℬ.

例（K=ℝ）：p(t)=1⋅t3+2t2+3t+4⋅1∈ℝ3[t]

  • ℰ={1,t,t2,t3}：[p(t)]ℰ=(4321)∈ℝ4
  • 若 ℰ′={t3,t2,t,1}（顺序反过来）：[p(t)]ℰ′=(1234)
  • 若把 p(t) 看作 ℝ6[t] 的元素，ℰ={1,t,…,t6}：[p(t)]ℰ=(4,3,2,1,0,0,0)T∈ℝ7

意义：选定一组基后，任何 n 维空间里的向量都可以用 Kn 里的一列数表示——抽象空间「变成」Kn。

7 · 易错点

  • Linear combination 只能是有限和。
  • l.d. 的定义是「存在不全为 0 的系数」，不是「所有系数都不为 0」。
  • 证 l.i. 时，要从「组合 =𝟎」出发推出系数全 0，不能反过来写。
  • 坐标向量依赖基的顺序；{1,t,t2,t3} 和 {t3,t2,t,1} 给出相反的列。
  • 判断 l.i. 一定要看清在哪个域上。
