2 · Local Search 的动机

Motivation of local search

  • 很多优化问题里，path is irrelevant；the goal state itself is the solution
    • n-queens：找满足约束的 configuration（任意两个 queen 不同行、同列、同对角线）
    • TSP（travelling salesperson problem）：找最优 configuration（每个城市只访问一次的最短回路）
    • State space = 一组「complete」configurations
  • 这时可以用 iterative improvement（local search）：keep a single "current" state, try to improve it

2.1 例：n-queens

  • Basic idea：
    • 先给所有变量赋值（从 complete configuration 出发）
    • 再用 modification operators 把 configuration 往解的方向移，例如把一个有冲突的 queen 移到同一列的另一格
  • 目标：move a queen to reduce number of conflicts（attacks）

2.2 Local search 的特点

  • 只维护一个 current node，一般只移动到它的 neighbors
  • Very little memory（通常是常数）
  • 在很大的 state space 里也常常能找到还不错的解

和 L6–L8 的对比：之前的搜索要维护 frontier、记录路径，保证找到（最优）解；local search 不记路径、不保证最优，但省内存、能处理巨大的空间。

3 · Hill Climbing

3.1 思路

  • Start wherever（任意起点）
  • Repeat：move to the best neighboring state
  • If no neighbors better than current, quit
  • only look at immediate neighbors

3.2 算法

function HILL-CLIMBING(problem) returns a state that is a local maximum
  inputs: problem, a problem
  local variables: current, a node
                   neighbor, a node
  current <- MAKE-NODE(INITIAL-STATE[problem])
  loop do
    neighbor <- a highest-valued successor of current
    if VALUE[neighbor] <= VALUE[current] then return STATE[current]
    current <- neighbor
  end

注意返回的是 local maximum：邻居都不比自己好就停，不管是不是全局最好。

3.3 State space landscape

横轴 state space，纵轴 objective function：

  • Global maximum：整个图最高点
  • Local maximum：比周围都高、但不是最高
  • Problem：会卡在 local maxima（not optimal），而且起点非常关键
  • Flat local maximum 和 shoulder（平台但之后还能上升）都是 plateaus（平坦区域）：hill climbing 在 plateau 上找不到「更好」的邻居，会迷路（not complete）

3.4 8-queens 的例子

  • 左图：一个 8-queens state，heuristic cost（互相攻击的 queen 对数）h=17。每格的数字是「把该列的 queen 移到这里后的 h」；最好的几步都是 12。
  • 走 5 步后到右图：h=1，但每个 successor 的 cost 都更高 → 这是一个 local minimum，hill climbing 卡在这里。
  • 结论：Hill climbing 在 n-queens 上可能到不了 goal state。

（这里是最小化 cost h，所以叫 local minimum；和「最大化 objective」是同一件事反过来。）

3.5 怎么跳出 local optimum？

  • Random restart（随机换个起点重来）：朴素的办法
  • 更好的办法？→ simulated annealing

4 · Simulated Annealing

4.1 灵感

Annealing（退火）：冶金里把金属或玻璃加热到高温，再慢慢冷却，让材料达到低能量的晶体状态。

Key idea：允许「bad」moves，概率取决于「temperature」

  • High temperature ⇒ more bad moves allowed，把系统从 local optimum 里「摇」出来
  • 按某个 schedule 逐渐降温

4.2 算法

function SIMULATED-ANNEALING(problem, schedule) returns a state
  current <- problem.initial-state
  for t = 1 to infinity do
    T <- schedule(t)
    if T = 0 then return current
    next <- a randomly selected successor of current
    dE <- next.value - current.value
    if dE > 0 then current <- next
    else current <- next only with probability e^(dE/T)
  • ΔE>0：next 更好 → 一定接受
  • ΔE≤0：next 更差（或一样）→ 以概率 eΔE/T 接受

What is the range of eΔE/T? —— [0,1]，因为这时 ΔE/T≤0。

4.3 温度 T 的作用

  • Large T：ΔE/T 接近 0，概率接近 1 → 坏步很容易被接受（几乎随机游走）
  • T→0：ΔE/T→−∞，概率 → 0 → 几乎不接受坏步，more or less like hill-climbing
  • 坏得越多（ΔE 越负），越不容易被接受
  • Can approximate global optimum if T decreases slowly enough

补充算例（帮助理解，课件没给数）：ΔE=−2 时

T eΔE/T
10 e−0.2≈0.82
1 e−2≈0.14
0.1 e−20≈2×10−9

和 hill climbing 的区别：hill climbing 选最好的邻居、永不后退；SA 选随机的邻居，好的必接受、坏的按概率接受。

5 · Local Beam Search

Basic idea

  • 同时保留 K 份 local search 的状态，随机初始化
  • 每轮：
    • 从 K 个 current states 生成所有 successors
    • 从这些 successors 里选最好的 K 个作为新的 current states

Why is this different from K local searches in parallel? —— The searches communicate!

  • K 个独立搜索：每条只管自己，差的那条一直在差的地方转。
  • Beam search：K 个 state 的 successors 放在一起比较，好区域的 successors 会挤掉差区域的——资源自动集中到有希望的地方。

What does this remind you of? —— Evolution!（→ genetic algorithm）

6 · Genetic Algorithm

6.1 基本思路

  • State 表示成有限字母表上的 string（数字、字母等）
    • 8-queens：State = 8 个 queen 各自在哪一行，每列一个
    • 例：[1, 6, 2, 5, 7, 4, 8, 3]，或课件图里的 86427531（第 i 个数字 = 第 i 列 queen 所在的行）
  • Initialization：随机生成 k 个 states（population）
  • Successor 由两个 parent states 组合产生
  • Evaluation function（fitness function）：
    • 越好的 state 值越高
    • 和 heuristic cost 方向相反，例如 8-queens 用不互相攻击的 queen 对数
  • 用「simulated evolution」产生下一代：random selection、crossover、random mutation

6.2 完整手算例子（k=4，8-queens）

Step A：Fitness

  • Fitness = number of non-attacking pairs of queens
  • min = 0，max =(82)=8×7/2=28（8 个 queen 选 2 个的组合数；28 表示没有任何攻击，即是解）

Fitness proportion：

Pr⁡(hi)=Fitness(hi)∑j=1KFitness(hj)
State Fitness 比例
24748552 24 24/78 = 31%
32752411 23 23/78 = 29%

（总和 24+23+20+11=78）

Step B：Selection

  • Fitness proportionate selection（roulette wheel selection，轮盘赌）：按上面的比例抽样
  • 好的个体可能被选好几次，差的可能一次都没选上
  • 课件抽到：32752411、24748552、32752411、24415124（32752411 被选了两次，32543213 没被选上）

Step C：Pairing

  • 按概率独立抽样，每次抽一个当一个 parent，两次组成一对
  • 课件：(32752411, 24748552)、(32752411, 24415124)

Step D：Crossover

  • 从两个 parent 各复制一部分，产生两个新 offspring
  • Rationale：希望把好个体的优点组合起来
  • 课件第一对在第 3 位后切，第二对在第 5 位后切：
Parents 切点 Offspring
327 | 52411 与 247 | 48552 第 3 位后 32748552、24752411
32752 | 411 与 24415 | 124 第 5 位后 32752124、24415411

Single-point vs two-point crossover（课件另一组例子，parents 32752411、24748552）：

类型 切法 Offspring
Single-point 切一刀（第 3 位后），后半段互换 32748552、24752411
Two-point 切两刀（第 3、5 位后），中间段互换 32748411、24752552

Step E：Mutation

  • 以一定概率随机改 string 里的某一位
  • 作用：保证搜索空间里没有状态的被访问概率为 0（increase variety）
  • 课件：32748552 → 32748152（第 6 位 5→1）；24752411 不变；32752124 → 32252124（第 3 位 7→2）；24415411 → 24415417（第 8 位 1→7）

6.3 Summary of steps

  1. Representing individuals（states）
  2. Generating an initial population（K states）
  3. Applying a fitness function（quality of K states）
  4. Selecting parents for pairing based on their fitness
  5. Crossover of parents to produce new generation
  6. Mutation of new generation to bring diversity
  7. Repeat step 3 to step 6 until solution is reached（iterative algorithm）

整体：natural selection scheme（biologically inspired）——每步按 fitness 重新抽样（selection），两两 crossover 组合，再加 mutation 增加多样性。

6.4 Crossover 的效果

课件图：32752411 和 24748552 交叉得到 32748552——棋盘上看，左半边来自一个 parent、右半边来自另一个。Has the effect of "jumping" to a completely different new part of the search space（quite non-local optimization）。这和 hill climbing「只走一步到邻居」很不一样。

7 · Summary

  • 很多 configuration 和 optimization 问题可以写成 local search
  • 四类算法：
算法 特点
Hill-climbing simple and general；会卡在 local maxima
Simulated annealing 靠 temperature 跳出 local optimum；降温够慢时可近似 global optimum
Local beam search 多个互相交流的搜索

  • Many machine learning algorithms are local searches（gradient descent）!!——GD 就是在连续空间里沿着最陡方向「爬山」（下山）。

9 · 易错点

  • Hill climbing 选的是最好的邻居；simulated annealing 选的是随机的邻居。
  • SA 的接受概率是 eΔE/T，其中 ΔE≤0；不是 e−ΔE/T（那会大于 1）。若题目是最小化 cost，ΔE 的符号要相应调整。
  • T→0 时 SA 退化成（随机版的）hill climbing，不是随机游走；T 很大时才接近随机游走。
  • Fitness 越大越好（和 cost h 相反）；8-queens 的 fitness 最大值是 28，不是 8。
  • Two-point crossover 交换的是中间段。
  • Local beam search ≠ K 个独立的 hill climbing：它从所有 successors 里统一选 K 个。
