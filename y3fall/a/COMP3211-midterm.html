Common Mistakes

  1. Hinge: ∇=−ϕ(x)y (with y) if m<1, 0 if m≥1.
  2. ∇TrainLoss has both 1n and 2.
  3. Mul gate: each input gets g× other input; multiple uses ⇒ sum.
  4. K-means: local min only, init-dependent; assign and update both ΔLoss≤0.
  5. Tune on val, test once; K-fold reports the mean.
  6. DFS space O(bm) (not bm); IDS O(bs); BFS optimal only for unit costs.
  7. A* optimal needs admissible h (never overestimates); greedy h, UCS g, A* g+h.
  8. MRV: fewest remaining values (fail-first); LCV: value constraining least (succeed-first).
  9. AC prunes the tail X of X→Y; then re-check all arcs ⋅→X.
