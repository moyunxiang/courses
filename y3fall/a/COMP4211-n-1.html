1 · 什么是 Machine Learning

Simon (1983)：Learning denotes changes in the system that are adaptive in the sense that they enable the system to do the same task or tasks drawn from the same population more effectively the next time.

机器 / 人的学习 = 随经验而改进。

2 · 一个分类系统：Automatic Fish Sorting

「这是苹果吗？」——需要 training examples（apples / not apples）。

步骤 做什么 例子
Pre-processing 去噪、消除无关变化（光照、位置） 去背景、调亮度
Feature extraction 每条鱼变成 feature space 中的一个点 x=[x1,x2]⊤ 长度、亮度、宽度、鳍的数目和形状、嘴的位置
Learning (training) 用 training sample（已知种类）把 feature space 分成两个区域 decision boundary
Classifier linear、quadratic、更复杂的边界 怎么学边界（参数）？
分类新样本 用训练好的 classifier
评价 classification error rate = 被分错的 pattern 的比例；也看 computational complexity、user-friendliness

Generalization：分类器对没见过的鱼还有效吗？——边界太复杂可能在训练集上完美、在新数据上很差（见第 3 讲 overfitting）。

3 · 三种学习范式

范式 训练数据 有没有 teacher 例子
Supervised 输入 + 对应的期望输出 (x,y) 有 教小孩认动物；有标准答案的考试；regression、recommender system、control（ALVINN：30×32 sensor retina → 4 hidden → 30 output，sharp left / straight / sharp right）
Unsupervised 只有输入 x，没有输出 没有；靠 similarity measure 找分组 见下
Reinforcement 输入 + 只有评价性的输出（reward） 只有分数 只给总分、不给正确答案的考试

3.1 Unsupervised 的用途

  • 找 clusters
  • 找 / 预处理特征，供后续 supervised 分类用：PCA（例：eigenface）
  • Content-based image retrieval：可视化图像位置和距离
  • Outlier detection（找最不可能的观测）：network intrusion detection；database cleaning（错别字、标错的数字、难看的数字、坏照片）；fraud detection（信用卡、电话账单、病历）
  • Data generation

3.2 Reinforcement learning

  • 与环境交互以达成目标；state、action、reward；目标是最大化总 reward
  • 例：投资组合——action：做一笔交易；reward：组合回报
  • Mountain car：goal 最短时间到达终点；state = 位置、速度；action = forward / reverse / none；reward 每步 −1 直到到达
  • Acrobot：state = 2 个关节角 + 2 个角速度；reward 每步 −1
  • Robotics：输入 = 传感器信息 + reinforcement signal；避开负 reward（避障、沿墙走）

5 · 易错点

  • Reinforcement ≠ supervised：RL 只告诉「好不好」（分数），不告诉「正确答案」。
  • Outlier detection、PCA 属于 unsupervised（没有标签）。
  • Regression、recommender system、ALVINN（control）是 supervised。
  • 训练误差低 ≠ 好；要看 generalization。
