1 · Multi-Armed Bandits

1.1 动机

  • A/B test：有多个选择（例如 Netflix 显示哪个封面），想选出最能吸引用户的那个
  • 选餐厅：action = 去哪家餐厅；reward = 你的满意度
  • 正式说：在 non-sequential（single action / state）的设定下学会行动
    • 每个 action 带来一个即时 reward
    • 目标：选 action，使期望即时 reward 最大
  • Q：如果你和餐厅员工成了朋友、喜欢和他们聊天呢？——那就不是 stateless 了！如果 state 会因为你的 action 改变，就是 sequential 设定（下一讲 MDP）。

1.2 名字的由来

  • One-armed bandit = slot machine（老虎机，英文俚语）
  • Multi-armed bandits = 多台老虎机，每次选一台拉

序列：at,rt+1,at+1,rt+2,…——state 不变（a.k.a. stateless）

1.3 问题定义

  • 每个 timestep t，agent 从 K 个 arm 里选一个拉
  • 第 k 个 arm 在 t 时刻被拉，产生 reward rk,t
  • rk,t 来自分布 pk(⋅)，均值 μk
  • Agent 不知道 reward 分布，也不知道均值
  • Objective：maximize cumulative rewards
  • 如果知道哪个 arm 的 μk 最大，每次都拉它就行（但不知道是哪个）

Definition. The action-value function for action a is its mean reward：

Q∗(a)=𝔼[rt∣at=a]

1.4 两种常见 bandit

背景：

  • Bernoulli：Bern(x∣μ)=μx(1−μ)1−x，即 p(x=1)=μ，p(x=0)=1−μ；𝔼[x]=μ，var[x]=μ(1−μ)
  • Gaussian：Norm(x∣μ,σ)=12πσ2exp⁡(−(x−μ)22σ2)
Bandit reward 均值的含义
Bernoulli bandits 成功 / 失败（0 / 1） 成功概率 μk∈[0,1]（例：三台机器分别 0.6、0.4、0.45 的时间赢）
Gaussian bandits 实数 arm k 的平均 reward = 它的 Gaussian 的均值

2 · Basic Concepts

2.1 估计 action value

要估计 Qt(a)≈Q∗(a)，∀a。先看一个 action：它收到 t−1 个 reward 之后的估计：

Qt:=r1+r2+⋯+rt−1t−1

Q：弱点？ A：每次都要存所有 reward 再重新求和——最好能增量地算。

2.2 增量更新（考试重点）

Qt+1=Qt+1t[rt−Qt]

推导：

Qt+1=1t∑i=1tri=1t(rt+∑i=1t−1ri)=1t(rt+(t−1)⋅1t−1∑i=1t−1ri)=1t(rt+(t−1)Qt)=1t(rt+tQt−Qt)=Qt+1t[rt−Qt]

这是学习规则的通用形式（以后 TD、Q-learning 都长这样）：

NewEstimate←OldEstimate+StepSize [Target−OldEstimate]
  • Target−OldEstimate 叫 error
  • 直觉：估计偏低（rt>Qt）就往上调，偏高就往下调；调多少由 step size 决定
  • 这里 step size =1t，越往后每个新样本的影响越小（因为是在求平均）

2.3 Exploration / Exploitation dilemma

Greedy action：

at∗=arg⁡max⁡aQt(a)
  • at=at∗：exploiting
  • at≠at∗：exploring
  • You can't do both, but you need to do both

更一般地，online decision-making 的基本选择：

  • Exploitation：根据当前信息做最好的决定
  • Exploration：收集更多信息
  • 最好的长期策略可能需要短期牺牲；要收集足够的信息才能做出整体最好的决定
  • 这个两难不只是计算 RL 的问题，而是任何智能体决策的根本问题
  • High-level idea：You can never stop exploring, but maybe you should explore less over time.

2.4 Evaluation metric：Regret

  • Action-value：Q∗(a)=𝔼[rt∣at=a]，∀a∈{1,…,K}
  • Optimal value：V∗=max⁡aQ∗(a)=Q∗(a∗)
  • Regret（一步的期望机会损失）：
lt=𝔼[V∗−Q∗(at)]
  • Total regret：
LT=∑t=1T𝔼[V∗−Q∗(at)]
  • Maximize cumulative expected reward = minimize total regret

补充（常用写法）：令 gap Δa=V∗−Q∗(a)，NT(a) 为 T 步内选 a 的次数，则 LT=∑a𝔼[NT(a)] Δa。好算法要让 gap 大的 arm 被选得少。

Linear vs sublinear regret：如果每一步都有一个不趋于 0 的期望损失，total regret 随 T 线性增长——意味着算法一直在犯同样的错。好的算法 regret 增长得比 T 慢（如 log⁡T）。

3 · Action Selection

3.1 Fixed Exploration Period + Greedy

  1. 先分配一段固定时间做 exploration：均匀随机地试所有 bandit
  2. 估计所有 action 的平均 reward：
Qt(a)=1Nt(a)∑i=1t−1ri⋅𝟙(ai=a)

（Nt(a)：之前选 a 的次数；𝟙：示性函数）

  1. 选估计最优的 action：at=arg⁡max⁡aQt(a)
  2. GOTO 2（继续更新估计——但只更新被选中的那个）

例：exploration 结束后估计为 Q(a1)=0.3，Q(a2)=0.5，Q(a3)=0.1。

  • Q1：greedy 会一直选第二个吗？ 会选 a2；之后只更新 a2 的估计。只要 Q(a2) 不掉到 0.3 以下就一直选它；a3 再也不会被试——哪怕它真实的均值其实最高（只是 exploration 期间运气不好）。
  • Q2：greedy 会永远锁定在次优 action 吗？ 会。Greedy action selection has linear total regret.

3.2 ε-Greedy

  • Greedy 总是 exploit；怎样保持 exploration？→ ε-greedy
  • 通常 greedy，但以概率 ε 随机选一个 action（可能又选到 greedy action）
  • 平衡 exploration 和 exploitation 的最简单方法

A simple bandit algorithm

Initialize, for a=1 to k：Q(a)←0，N(a)←0

Repeat forever：

  • A←arg⁡max⁡aQ(a) with probability 1−ε（breaking ties randomly）；a random action with probability ε
  • R←bandit(A)
  • N(A)←N(A)+1
  • Q(A)←Q(A)+1N(A)[R−Q(A)]

课件 Q：两个 action、ε = 0.2，选到 greedy action 的概率？

P(greedy)=(1−ε)⏟exploit+ε⋅12⏟随机时恰好选中=0.8+0.1=0.9

一般地，∣𝒜∣ 个 action：P(greedy)=1−ε+ε∣𝒜∣。

ε-greedy 的 regret：

  • 永远在 explore：以 1−ε 选 arg⁡max⁡aQt(a)，以 ε 随机选（与 Q 估计无关）
  • ε-greedy 也是 linear total regret！ 常数 ε 时每步 regret：
lt≥ε∣𝒜∣∑a∈𝒜Δa

（即使已经完全学会，每步仍有 ε 的概率随机乱选，平均损失一个固定量）

3.3 Gaussian bandits 实验（Sutton & Barto 10-armed testbed）

  • 采样 2000 个 10-armed bandit：Q∗(a)∼𝒩(0,1)，rt∼𝒩(Q∗(a),1)
  • 曲线：ε=0.1 前期上升最快；ε=0.01 慢一些但后期追上；ε=0（greedy）很快停在低水平
  • Q1：无穷步之后谁的平均 reward 最大？ —— ε = 0.01：两者都会找到最优 arm，但 ε = 0.01 只有 1% 的时间乱选（ε = 0.1 有 10%），greedy 可能锁死在次优
  • Q2：性能是否依赖 action value 估计的初始化？ —— 是。例如 optimistic initialization（初始 Q 设得很高）：每个 action 试了之后估计都会下降，于是 greedy 也会被「逼着」轮流试所有 action，起到 exploration 的作用

3.4 Decaying ε-Greedy

  • 永不 explore ⇒ linear regret（greedy）
  • 永远 explore ⇒ linear regret（ε-greedy）
  • Decaying ε-greedy：设计衰减序列 ε1,ε2,…（早期多探索，后期少探索）
  • 但怎么衰减才好？→ 需要考虑我们对 action 估计的不确定性！

4 · Upper Confidence Bounds（UCB）

4.1 不确定性指导 exploration

问题：只用均值估计，没有考虑估计本身有多不确定。

课件例：

arm 拉的次数 赢的次数 Qt
a1 1000 600 0.6
a2 1000 400 0.4
a3 10 4 0.4

a2 和 a3 的估计都是 0.4，但 a3 只试了 10 次，真值可能远高于 0.4；a2 试了 1000 次，基本确定就是 0.4。

  • 越不确定的 action，越值得 explore，因为它可能其实更好

4.2 UCB 思路

  • 为每个 action 估计一个 upper confidence Ut(a)，使得以高概率
Q∗(a)≤Qt(a)+Ut(a)

（Qt(a)：估计的均值；Ut(a)：估计的置信上界宽度）

  • 选 UCB 最大的 action：
at=arg⁡max⁡a[Qt(a)+Ut(a)]
  • Ut(a) 应依赖 a 被选过的次数 Nt(a)：
    • Nt(a) 小 ⇒ Ut(a) 大（估计不确定）
    • Nt(a) 大 ⇒ Ut(a) 小（估计准确）

这就是「optimism in the face of uncertainty」：不确定时，按最乐观的可能去试。如果它真的好，赚到了；如果不好，试了之后 U 变小，自然就不选了。

4.3 Hoeffding's Inequality

Theorem. Z1,…,Zn 独立、有界，Zi∈[a,b]（−∞<a≤b<∞）。则对所有 t≥0：

p(1n∑i=1nZi−𝔼[Zi]≥t)≤exp⁡(−2nt2(b−a)2)
p(1n∑i=1nZi−𝔼[Zi]≤−t)≤exp⁡(−2nt2(b−a)2)

含义：样本均值偏离真实均值超过 t 的概率，随样本数 n 指数下降。

对每个 action 的 rewards 用 Hoeffding（reward 在 [0,1] 时 b−a=1）：

p(Qt(a)−Ut(a)≥Q∗(a))≤c⋅exp⁡(−2Nt(a)Ut(a)2)p(Qt(a)+Ut(a)≤Q∗(a))≤c⋅exp⁡(−2Nt(a)Ut(a)2)
  • t：总共玩了多少次（任何 action）
  • Nt(a)：t 次中玩 a 的次数
  • Ut(a)：让 margin 依赖于交互次数

4.4 解出 Ut(a)

令「上界失败」的概率等于 p：

e−2Ut(a)2Nt(a)=p  ⇒  Ut(a)=−log⁡p2Nt(a)
  • 随着玩得越多，减小 p，例如 p=t−k，k=2：−log⁡p=2log⁡t
  • 这保证 t→∞ 时选到最优 action
Ut(a)=2log⁡t2Nt(a)=log⁡tNt(a)

4.5 UCB 算法

at=arg⁡max⁡a[Qt(a)+clog⁡tNt(a)]
  • 一个随时间逐渐减少 exploration 的聪明办法：估计真值的上界，选上界最大的
  • c：超参数，权衡 exploration 与 exploitation
  • 置信项随总次数 t 增长（log⁡t，很慢），随该 action 被试的次数 Nt(a) 缩小
  • 保证每个 action 都会被试无穷多次（没被选的 action，log⁡t 一直涨，迟早会被选），但仍然平衡 exploration / exploitation
  • 课件图：UCB（c=2）的平均 reward 高于 ε-greedy（ε=0.1）

补充算例（用 4.1 的表，t=2010，log⁡t≈7.61，c=1）：

arm Qt log⁡t/Nt UCB
a1 0.6 7.61/1000≈0.087 0.687
a2 0.4 0.087 0.487
a3 0.4 7.61/10≈0.872 1.272

UCB 选 a3：它只被试了 10 次，太不确定了，值得再试。

5 · Gradient Bandits

Q：有没有 policy-based 的解法？（不估计 value，直接学选择概率）

  • 每个 action 一个 score 参数 sa（共 m 个，要优化）
  • 选择概率是 softmax：
π(a)=esa∑b∈𝒜esb,∀a∈𝒜
  • Expected reward objective：
J(sa1,…,sam)=∑a∈𝒜π(a)⋅𝔼[r∣a]

5.1 求梯度

对每个 a，∂J∂sa（求和变量记作 a′）：

∂J∂sa=∂(∑a′π(a′) 𝔼[r∣a′])∂sa=∑a′𝔼[r∣a′]⋅∂π(a′)∂sa=∑a′π(a′) 𝔼[r∣a′]⋅∂log⁡π(a′)∂sa=𝔼a′∼π, r∼r(a′)[r⋅∂log⁡π(a′)∂sa]

第二步用了 log-derivative trick：∂π∂s=π⋅∂log⁡π∂s。这样能把求和变回对 π 的期望，于是可以用采样来估计——这是以后 policy gradient（3.1）的核心技巧。

5.2 Softmax 的 log 导数

∂log⁡π(a′)∂sa=∂∂sa(sa′−log⁡∑besb)=𝟙a=a′−π(a)

（第一项对 sa 求导：a=a′ 时为 1；第二项求导得 esa∑besb=π(a)。）

所以

∂J∂sa=𝔼a′∼π, r∼r(a′)[r⋅(𝟙a=a′−π(a))]

Gradient Bandits：每一步用一个样本 (at,rt) 近似梯度：对所有 a∈𝒜，梯度 ≈rt⋅(𝟙a=at−π(a))。做梯度上升：

sa←sa+α rt(𝟙a=at−π(a))

直觉：选中的 action 得到正 reward，它的 score 上升（1−π(at)>0），其他 action 的 score 下降（−π(a)<0）。

补充算例：3 个 arm，初始 s=(0,0,0)，π=(13,13,13)，α=0.1，选了 a1 得 r=1：

  • sa1←0+0.1⋅1⋅(1−13)=0.067
  • sa2,sa3←0+0.1⋅1⋅(0−13)=−0.033
  • 新的 π≈(0.356,0.322,0.322)：a1 的概率上升

（Sutton & Barto 的版本把 rt 换成 rt−rˉt，减去平均 reward 作为 baseline，减小方差；课件没讲，L3.1 policy gradient 会用到。）

7 · 易错点

  • 增量更新的 step size 是 1t（t = 该 action 已收到的 reward 数），不是总步数。
  • ε-greedy 随机时也可能选到 greedy action，所以 P(greedy)=1−ε+ε/∣𝒜∣，不是 1−ε。
  • Greedy 和常数 ε-greedy 都是 linear regret，原因不同：前者可能永远锁死，后者永远在乱试。
  • UCB 的 log⁡t 用的是总步数 t，分母是该 action 的次数 Nt(a)。
  • Gradient bandit 的梯度对所有 action 都要更新，不只是选中的那个。
  • Regret 是对 Q∗（真值）算的，不是对估计 Qt。
