0 · 这一讲在讲什么

  1. Adaline（Adaptive Linear Element）：一层可调权重 + linear output unit = linear regression
  2. Gradient descent 找权重；error surface 是碗形——只有一个全局最小
  3. Learning rate：太大会越过最小值；learning rate schedule；实用技巧
  4. Batch GD vs SGD vs mini-batch

必会概念：Adaline 与 perceptron 的区别（linear vs threshold 输出）；为什么 Adaline 的 GD 一定收敛到全局最小（二次误差面）；η 太大的后果；batch / SGD / mini-batch 的取舍。

1 · Adaline

一个 feed-forward 网络，一层可调权重，连接到一个或多个 linear units（作为 output units）。

2 · 找权重：梯度下降

思路：从任意点出发，一直往下坡走。

  • 一般的 error surface 可能很复杂，会卡在局部最优
  • 但 Adaline 的 error surface 是二次的（碗形 / 抛物面）：E(𝐰)=12∑d(td−od)2，od 是 𝐰 的线性函数 ⇒ 只有一个全局最小

梯度（补充推导）：

∂E∂wi=∑d(td−od)∂∂wi(td−𝐰⋅𝐱d)=−∑d(td−od)xid
wi←wi+η∑d(td−od)xid

（形式像 perceptron rule，但 o 是线性输出、不是 0/1——这就是 delta rule / LMS。）

3 · 收敛与 Learning Rate

  • 误差面只有一个全局最小 ⇒ 只要学习率合适，GD 会收敛到最小误差的权重
  • η 足够小：稳定收敛
  • η 太大：可能**越过（over-step）**最小值，来回震荡甚至发散

Learning rate schedule：随 GD 步数增加逐渐减小 η。

实用技巧：先在一个小子集上实验；算法在小子集上表现好时，保持同样的 η，再跑全量训练集。

4 · Batch Learning vs SGD

Batch learning：对整个数据集的梯度求和再更新——大数据集上很贵。

Stochastic Gradient Descent (SGD)：每个样本或每个小批量就更新一次。

每次迭代用 特点
全部样本（GD） 准确但慢
1 个样本（SGD） 快但波动大
b 个样本（mini-batch） 折中

SGD：「大体上」朝正确方向走，但不总是；需要更小的 step size。

考点 至少要会

vs perceptron 输出单元、学习方式
Error surface 二次 → 单一全局最小
η 太小慢、太大越过；schedule；小子集技巧
GD / SGD / mini-batch 准确 vs 快；SGD 要小步长

6 · 易错点

  • Adaline 的输出是线性的（训练时不过 threshold）。
  • 「只有全局最小」只对 Adaline 这种二次误差面成立；MLP 有局部最小（4.5）。
  • SGD 不是每步都朝正确方向；需要更小的 η。
