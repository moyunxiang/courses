Unofficial practice paper written from the nine Quiz 2 slide decks (4-ann-*, 5-cnn-*). Same rules as the real quiz: 80 minutes, closed book, no calculator. Every number can be computed by hand. Total 100 points.

Conventions (from the slides): step(x)=1 if x≥0, else 0; I0=1 is the bias input; logs are base 2 unless stated; "convolution" in a CNN means no kernel flip unless the question says otherwise.

Part I · Questions

Q1 · True or false (10 pts, 1 each)

(a) A single perceptron can represent every linearly separable Boolean function of two inputs. (b) The perceptron learning rule converges for any training set if α is small enough. (c) Adaline's squared-error surface has exactly one global minimum. (d) An MLP whose hidden units are all linear is more expressive than a single-layer network. (e) ReLU units can have zero gradient. (f) RBF hidden units respond significantly over the whole input space. (g) Cross-entropy satisfies H(p,q)=H(q,p). (h) In backprop, when a variable feeds two downstream nodes, its gradient is the sum of the two contributions. (i) A max-pooling layer has learnable weights. (j) The number of parameters of a convolutional layer depends on the height and width of the input image.
