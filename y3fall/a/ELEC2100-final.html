Common Mistakes

  1. AM: modulated spectrum is 12G (not G); demodulated baseband is 12G ⇒ LPF gain 2. Demod carrier must match frequency and phase.
  2. Sampled spectrum carries 1T; reconstruction LPF has gain T; cutoff anywhere in [ωm, ωs−ωm].
  3. Units: ω (rad/s), f (Hz), Ω (rad/sample) — Ω=ωT=2πffs; DTFT has period 2π; highest DT frequency is π.
  4. Aliased frequency = nearest copy folded into [0,fs2], e.g. 20 kHz at fs=25 kHz → 5 kHz (Prelab 4).
  5. Products widen bandwidth (x2: 2fm); convolutions do not.
  6. DTFS analysis has 1N (course convention, Table_DT Parseval); DFT / fft has none ⇒ fft(x)/N.
  7. Laplace time shift needs f(t−t0)u(t−t0); unilateral derivative sF−f(0−) — don't drop initial conditions.
  8. FVT only if all poles of F in LHP (or one simple pole at 0); IVT needs a proper F.
  9. Causal + stable ⇔ poles strictly in LHP; simple jω-axis poles are marginal (not BIBO stable). Non-causal: check whether the ROC contains the jω axis.
  10. F(jω)=F(s)∣s=jω only if the ROC contains the jω axis: u(t) has 1s but FT πδ(ω)+1jω.
