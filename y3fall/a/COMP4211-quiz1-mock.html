Unofficial practice paper written from the three lecture slides (1-intro, 2-linear, 3-model-slct). Same rules as the real quiz: 80 minutes, closed book, no calculator. All numbers are chosen to be computable by hand. Total 100 points.

Notation follows the slides: ϕ(x) = feature vector, score =w⋅ϕ(x), margin m=(w⋅ϕ(x)) y, TrainLoss(w)=1∣Dtrain∣∑Loss(x,y,w).

Part I · Questions

Q1 · Learning paradigms and tasks (10 pts)

For each scenario, state (i) the learning paradigm (supervised / unsupervised / reinforcement) and (ii) if supervised, the task type (binary classification / multiclass classification / regression / structured prediction). Give a one-line reason.

  1. Predict the price of a flat from its size, floor and district, given past transactions.
  2. Group news articles into topics; no topic labels are available.
  3. A robot learns to walk; it receives +1 for each step forward and −10 when it falls.
  4. Decide whether a credit-card transaction is fraudulent, given historical transactions labelled fraud / not fraud.
  5. Generate a caption sentence for an input image, given images paired with human-written captions.

Q2 · True or false (10 pts)

State T or F. For each F, give a one-line correction.

  1. The gradient ∇wTrainLoss(w) points in the direction in which TrainLoss decreases the fastest.
  2. The zero-one loss can be minimized directly by gradient descent.
  3. The hinge loss of an example is 0 whenever the example is correctly classified.
  4. For fw(x)=sign⁡(w⋅ϕ(x)), the decision boundary {x:w⋅ϕ(x)=0} is orthogonal to w.
  5. The logistic loss log⁡(1+e−m) is strictly positive for every margin m.
  6. The model with the lowest training error always has the lowest testing error.
  7. In k-fold cross-validation, every example is used for validation exactly once.
  8. Making a model more complex typically decreases bias and increases variance.
  9. Using the test set to choose the number of hidden units is fine, as long as the weights are never trained on the test set.
  10. In reinforcement learning, the learner is told the correct action for each state.

Q2

  1. F. The gradient is the direction in which TrainLoss increases fastest; gradient descent moves along −∇.
  2. F. ∇w1[m≤0]=0 almost everywhere, so gradient descent never moves.
  3. F. Hinge loss max⁡{1−m,0} is 0 only when m≥1; a correct example with 0<m<1 has hinge loss 1−m>0.
  4. T. For ϕ(x)=x: any two boundary points a,b satisfy w⋅a=w⋅b=0, so w⋅(a−b)=0.
  5. T. e−m>0⇒1+e−m>1⇒log⁡(1+e−m)>0.
  6. F. Low training error can come from overfitting; select by testing / validation error.
  7. T. The k folds are disjoint and cover all m examples, and each fold is the validation set in exactly one run.
  8. T. Complex model: small bias, large variance (sensitive to the finite training set).
  9. F. Test data must not be used in any way to learn the hypothesis, including model selection; use a validation set.
  10. F. RL receives only rewards (evaluative feedback), not the correct answer.

Q6

(a) Degree 3. It has the lowest validation error (0.12), and validation error estimates the testing error. Training error is not used: degree 9 has the lowest training error but the highest validation error.

(b) Degree 9 overfits. Let h = the degree-9 model and h′ = the degree-3 model. Every cubic is a degree-9 polynomial (higher coefficients =0), so h′∈H9. Then:

errorS(h)=0.00<0.10=errorS(h′),error^D(h)=0.45>0.12=error^D(h′)

where error^D is the validation estimate of the testing error. This matches the definition: smaller training error but larger error over the distribution.

(c)

  • Degree 1: too simple, so large bias (it cannot get close to the ground truth; training error is already high at 0.30) and small variance (training ≈ validation error, 0.30 vs 0.32).
  • Degree 9: too complex, so small bias (training error 0) and large variance (it fits the particular finite training set; the validation error jumps to 0.45).

(d) Optionally retrain the degree-3 model on training + validation data, then report its error on a separate test set that was never used. The value 0.12 is optimistically biased: the validation set was used to choose the model, so it is no longer independent of the hypothesis.
