1 · Part I：DT 卷积和下标

1.1 输入

x[n] 就是学号 8 位数字，nx=A,…,A+7。MATLAB 里 sid - '0' 把字符串直接变成数字向量（字符减 '0' 的 ASCII 码），不用循环。

1.2 两个系统

h1[n]=δ[n−1]+δ[n−4],h2[n]=u[n−A−2]−u[n−A−6]
  • h1：在 n=1 和 n=4 各一个 1。从 n=0 开始写就是 [0 1 0 0 1]
  • h2：两个阶跃相减 = 一段矩形窗，n=A+2,…,A+5 共 4 个 1 ⇒ ones(1,4)（题目要求用 ones，不准用 dirac / heaviside）

1.3 串联 = 卷积

x→h1→h2→y⇒ y=(x∗h1)∗h2=x∗(h1∗h2)⇒ h=h1∗h2

1.4 下标规则（关键）

conv 只算数值，不知道下标。两条规则：

  • 起点相加：ny(1)=nx(1)+nh(1)
  • 终点相加：ny(end)=nx(end)+nh(end)
  • 长度自动对上：Ly=Lx+Lh−1

为什么：y[n]=∑kx[k]h[n−k] 非零要求 k 和 n−k 都在各自范围内，最小的 n 就是两个起点之和。

学号 21151084（A=0）：h=[0,1,1,1,2,1,1,1]，nh=2..9；y 有 15 点，ny=2..16。h 里的 2 来自 h1 的两个脉冲（间隔 3）各自把 4 点矩形窗搬过去，在 n=6 处重叠。

1.5 画图

subplot(3,1,k) 三行一列；stem(n, x, 'b') 蓝、'r' 红、'g' 绿；每张都要 xlabel / ylabel。横轴用自己的下标向量，不要省略（省略就从 1 开始，位置全错）。

2 · Part II：回声

2.1 时延换成采样点

t0=0.18 s⇒N=t0fs

song2a.wav 的 fs=132300 Hz（单声道），N=23814。用 round 防浮点误差。

2.2 CT → DT

h1(t)=δ(t)→h1[n]=δ[n]h2(t)=0.7 δ(t−0.18)→h2[n]=0.7 δ[n−N]

2.3 并联相加 = 相加

h[n]=h1[n]+h2[n]=δ[n]+0.7 δ[n−N]⇒ y[n]=x[n]+0.7 x[n−N]
  • 向量写法：h1 = [1 zeros(1,N)]，h2 = [zeros(1,N) 0.7]，两者要等长才能相加（都是 N+1）
  • δ[n−N] 前面有 N 个零（下标 0..N−1），第 N+1 个元素才是脉冲

2.4 听起来什么样

原声 + 0.18 s 后的 0.7 倍副本 ⇒ 回声（echo）。0.18 s 刚好能分辨出两次声音。

  • conv 对 200 万点 × 2.4 万点的向量是直接算的，可能要跑几十秒，正常
  • 两个 sound 之间要 pause，否则会叠在一起播；输出可能略超 [−1,1]，sound 会削顶，影响不大

3 · Part III：二维滤波

3.1 怎么算

  • convn(double(img), h, 'same')：图像是 600×600×3；2-D 的 h 会对每个颜色通道分别卷积
  • 先转 double：uint8 不能直接参与卷积，而且负数和大于 255 的值会被截断
  • 'same'：输出和原图一样大（题目要求）
  • 显示时 uint8(y)：负数变 0，超过 255 变 255

3.2 三个核

核 系数和 作用 结果长什么样
h1：周围 −1、中间 8 0 边缘检测（Laplacian，高通） 平坦区域黑，边缘亮
h2：只有中间 1 1 恒等（二维 δ） 和原图一样
h3=h1+h2：中间 9 1 锐化 原图 + 边缘，轮廓更清楚

为什么系数和决定平坦区域：平坦区域每个像素都约等于同一个值 c，卷积结果 = c×（系数和）。和为 0 ⇒ 变黑；和为 1 ⇒ 不变。

为什么 h3 是锐化：并联相加 ⇒ y3=y1+y2 = 边缘 + 原图——和 Part II 的回声是同一个结构（恒等 + 另一个系统）。

5 · 易错点

  • A 这次是学号第 6 位。
  • conv 不给下标：ny 起点 = 两个起点之和，终点 = 两个终点之和。
  • h2 用 ones，不用 dirac / heaviside。
  • 并联时两个向量先补零到同样长度再相加。
  • δ[n−N] 前面是 N 个零，不是 N−1 个。
  • convn 前先 double，显示时再 uint8；记得 'same'。
  • 颜色：输入蓝、h 红、输出绿；三张图都标轴。
  • 任何地方出现 for / while / if-else 都违规；交 PDF，先从头跑一遍。
