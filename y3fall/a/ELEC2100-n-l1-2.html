  2. 用 u(t) 表示其他信号：gate function、signum、截断信号
  3. δ(t) 的三种定义和性质：sifting、parity（偶）、time scaling δ(at)=1∣a∣δ(t)、与 u(t) 的微积分关系
  4. Doublet 的性质：∫δ′(t)f(t)dt=−f′(0)；奇函数；f(t)δ′(t)=f(0)δ′(t)−f′(0)δ(t)
  5. 信号分解：DC + AC；even + odd；real + imaginary

必考计算：用 sifting 性质算含 δ 的积分（注意 δ(at−b) 要先化简、积分区间是否包含冲激点）；用 u(t) 写分段信号；求偶分量 / 奇分量；δ′ 的积分。证明题：δ(at)=1∣a∣δ(t)（分 a>0、a<0）。

1 · Singularity signals

本身有间断点（跳变），或其导数 / 积分有间断点的函数，统称 singular signals / singularity functions。

四个：unit ramp R(t)、unit step u(t)、unit impulse δ(t)、doublet δ′(t)。

1.1 Unit ramp

R(t)={0,t<0t,t≥0

延迟：R(t−t0)={0,t<t0t−t0,t≥t0——由 argument t−t0=0 确定起点是 t0。

1.2 Unit step

u(t)={0,t<01,t>0
  • t=0 处无定义，或取 12
  • 规则：argument > 0 时值为 1，argument < 0 时值为 0
  • 延迟：u(t−t0) 在 t=t0 处跳变

1.3 用 u(t) 表示其他信号

Gate function（矩形窗），宽 τ、以 0 为中心：

Gτ(t)=u(t+τ2)−u(t−τ2)
  • 任何信号乘以 gate function，只留下「门」内的部分

Signum function：

sgn(t)={1,t>0−1,t<0=−u(−t)+u(t)=2u(t)−1

截断信号：从 0 线性升到 K（在 t=τ），之后为 0：

f(t)=Kτt[u(t)−u(t−τ)]

写分段信号的套路：每一段的表达式 × 该段的 gate（u(t−起点)−u(t−终点)），再加起来。

2 · Unit Impulse δ(t)

2.1 物理背景

力学中的冲击力：碰撞时突然增大又迅速消失——作用时间极短、幅值可以极大（打乒乓球、踢足球）。其他领域的类比：质点、点电荷、点光源强度尖峰。

2.2 定义 1：脉冲信号的极限

宽 τ、高 1τ（面积 1）的矩形脉冲：

p(t)=1τ[u(t+τ2)−u(t−τ2)]

τ→0：宽度变窄、高度变高，面积始终为 1：

δ(t)=lim⁡τ→0p(t)=lim⁡τ→01τ[u(t+τ2)−u(t−τ2)]
  • 画图：在 t=0 一根箭头，旁边标 (1)——强度（面积）为 1
  • Kδ(t−t0)：在 t0 处、强度 K 的冲激（标 (K)）

其他也能取极限得到 δ(t) 的脉冲（面积都是 1）：

三角脉冲：δ(t)=lim⁡τ→01τ(1−∣t∣τ) (∣t∣<τ)双边指数：δ(t)=lim⁡τ→012τe−∣t∣/τGaussian：δ(t)=lim⁡τ→01τe−π(t/τ)2Sa：δ(t)=lim⁡k→∞kπSa(kt)

2.3 定义 2：Dirac 定义

∫−∞∞δ(t) dt=1,δ(t)=0 (t≠0)
∫−∞∞δ(t) dt=∫0−0+δ(t) dt=1
  • 只在 t=0 非零
  • 积分为 1
  • t=0 时 δ(t)→∞，无界

（Dirac，1902–1984，英国理论物理学家，量子力学奠基人之一，1933 年 Nobel 奖；引入 bra-ket 记号和 delta 函数。）

2.4 定义 3：广义函数（distribution）

∫−∞∞δ(t)f(t) dt=f(0)
  • f(t) 是 test function：连续、各阶导数连续，并且在某个有限区间 (a,b) 外为 0
  • δ(t) 完全由它在积分中的作用刻画（看它和别的函数相乘再积分的结果，而不是逐点的值）
  • 为了信号分析的需要，δ(t) 被构造成广义函数：运算中可以当连续信号处理，但作为 distribution 有特殊性质

3 · δ(t) 的性质（必考）

3.1 Sifting（取样 / 筛选）性质

若 f(t) 在 t=0 连续且处处有界：

f(t)δ(t)=f(0)δ(t),∫−∞∞δ(t)f(t) dt=f(0)

平移版本：

f(t)δ(t−t0)=f(t0)δ(t−t0),∫−∞∞δ(t−t0)f(t) dt=f(t0)

直觉：δ(t−t0) 只在 t0 处「存在」，所以乘积只与 f(t0) 有关——它把 f 在 t0 的值「筛」出来。

补充算例：

  • ∫−∞∞(t2+1)δ(t−2) dt=22+1=5
  • ∫−11etδ(t−2) dt=0（冲激点 t=2 不在积分区间内）
  • (t+3)δ(t+1)=(−1+3)δ(t+1)=2δ(t+1)（注意结果还是冲激，不是数）

3.2 Parity：δ(t) 是偶函数

δ(−t)=δ(t)
  • 由定义 1：矩形脉冲是偶函数，极限也是偶函数
  • 用 sifting 证明（看「作用」）：令 −t=τ：
∫−∞∞δ(−t)f(t) dt=∫∞−∞δ(τ)f(−τ) d(−τ)=∫−∞∞δ(τ)f(−τ) dτ=f(0)

和 ∫δ(t)f(t)dt=f(0) 相同 ⇒ δ(−t)=δ(t)

3.3 Time scaling（证明题）

δ(at)=1∣a∣δ(t)

直觉：p(t) 面积 1；p(at) 宽度变成 τa、高度不变，面积变成 1a。τ→0 时 p(at)→1aδ(t)。

证明（证两边乘 f(t) 后积分相等，分两种情况）：

(1) a>0：令 at=τ，t=τa：

∫−∞∞δ(at)f(t) dt=∫−∞∞δ(τ)f(τa)d(τa)=1af(0)

而 ∫1aδ(t)f(t)dt=1af(0)，相等 ✓

(2) a<0：令 −∣a∣t=τ，t=−τ∣a∣；t 从 −∞→+∞ 时，τ 从 +∞→−∞（上下限对调）：

∫−∞+∞δ(−∣a∣t)f(t) dt=∫+∞−∞δ(τ)f(−τ∣a∣)d(−τ∣a∣)=1∣a∣∫−∞+∞δ(τ)f(−τ∣a∣)dτ=1∣a∣f(0)

✓（负号和上下限对调抵消，所以是 ∣a∣）

推论：

δ(at−t0)=δ(a(t−t0a))=1∣a∣δ(t−t0a)

补充算例：∫−∞∞(t2) δ(2t−4) dt=∫t2⋅12δ(t−2) dt=12⋅4=2（常见错误：直接代 t=2 得 4，漏了 12）

3.4 与 u(t) 的关系（微积分性质）

∫−∞∞δ(t−t0) dt=1,δ(t)=du(t)dt,u(t)=∫−∞tδ(τ) dτ

三者关系（−∞<t<∞）：

R(t)  → 求导   u(t)  → 求导   δ(t),δ(t)  → 积分   u(t)  → 积分   R(t)

（u(t) 在 0 处跳变 1 ⇒ 导数是强度 1 的冲激——这就是 1.1 里「跳变处导数为冲激」的来由。）

4 · Doublet δ′(t)

4.1 定义

δ′(t)=dδ(t)dt

直观：取一个面积 1 的三角脉冲 s(t)（底 [−τ,τ]，高 1τ）。它的导数 s′(t)：在 (−τ,0) 为 +1τ2，在 (0,τ) 为 −1τ2。τ→0 时 s→δ，s′ 变成一对强度都无界的冲激：在 0− 处向上、0+ 处向下——这就是 doublet（画图时标 (1τ) 和 (−1τ)）。

4.2 性质

① 筛选导数（分部积分）：

∫−∞∞δ′(t)f(t) dt=−f′(0)

证明：

∫−∞∞f(t) dδ(t)=f(t)δ(t)∣−∞∞⏟0−∫−∞∞δ(t)f′(t) dt=−f′(0)
  • 平移：∫δ′(t−t0)f(t) dt=−f′(t0)
  • 推广：∫δ(n)(t)f(t) dt=(−1)nf(n)(0)

补充算例：∫−∞∞e−2tδ′(t) dt=−ddte−2t∣t=0=−(−2)=2

② δ′(t) 是奇函数：

δ′(−t)=−δ′(t),δ′(t0−t)=−δ′(t−t0)
∫−∞∞δ′(τ) dτ=0,∫−∞tδ′(τ) dτ=δ(t)

（奇函数在对称区间积分为 0；对 δ′ 积分回到 δ。）

③ 乘积性质（和 δ 的不一样！）：

f(t)δ′(t)=f(0)δ′(t)−f′(0)δ(t)

对比 f(t)δ(t)=f(0)δ(t)。

证明：由乘积求导

[f(t)δ(t)]′=f(t)δ′(t)+f′(t)δ(t)

左边用 sifting：[f(0)δ(t)]′=f(0)δ′(t)；右边第二项用 sifting：f′(t)δ(t)=f′(0)δ(t)。所以

f(0)δ′(t)=f(t)δ′(t)+f′(0)δ(t)  ⇒  f(t)δ′(t)=f(0)δ′(t)−f′(0)δ(t)

4.3 性质总表

性质 式子
(1) Sifting f(t)δ(t−t0)=f(t0)δ(t−t0)；∫f(t)δ(t−t0)dt=f(t0)
(2) Parity δ(−t)=δ(t)
(3) Scaling δ(at)=1∣a∣δ(t)
(4) Calculus ∫δ(t−t0)dt=1；δ(t)=du(t)dt
(5) Doublet δ′(t)=dδdt；δ′(−t)=−δ′(t)；∫δ′=0；∫−∞tδ′(τ)dτ=δ(t)；∫f(t)δ′(t)dt=−f′(0)；f(t)δ′(t)=f(0)δ′(t)−f′(0)δ(t)
(6) Convolution（Ch2） f(t)∗δ(t)=f(t)

5 · 信号的分解

5.1 DC + AC

f(t)=fD(t)+fA(t)
  • DC component fD：信号的平均值（常数）
  • AC component fA：减去平均值后剩下的部分（平均为 0）
1T∫t0t0+Tf(t) dt=1T∫t0t0+T[fA(t)+fD(t)]dt=fD(t)

功率分解：

P=1T∫t0t0+Tf2(t) dt=1T∫[fD+fA]2dt=1T∫fD2 dt+2fDT∫fA(t) dt⏟=0 (AC 平均为 0)+1T∫fA2 dt=fD2+1T∫t0t0+TfA2(t) dt

信号平均功率 = DC 功率 + AC 功率（交叉项为 0）

5.2 Even + Odd（必考）

对任意实信号：

f(t)=fe(t)+fo(t),fe(t)=fe(−t),fo(t)=−fo(−t)

怎么求：f(−t)=fe(−t)+fo(−t)=fe(t)−fo(t)，和 f(t)=fe+fo 联立：

fe(t)=12[f(t)+f(−t)],fo(t)=12[f(t)−f(−t)]

功率分解：

P=lim⁡T→∞1T∫−T/2T/2[fe+fo]2dt=Pe+Po+lim⁡2T∫−T/2T/2fefo dt⏟=0
  • 交叉项 fefo 是奇函数，在对称区间上积分为 0

平均功率 = 偶分量功率 + 奇分量功率

课件例：f(t) 是周期锯齿波（在一个周期内从 0 线性升到 2A 再跳回）。先画 f(−t)（关于纵轴翻折），再：

  • fe=12[f(t)+f(−t)]：三角波，幅值 A
  • fo=12[f(t)−f(−t)]：方波，幅值 A

画图套路：画出 f(−t) → 逐点相加除以 2（偶）、相减除以 2（奇）。检查：fe 关于纵轴对称，fo 关于原点对称，fe+fo=f。

补充算例：f(t)=et：fe=et+e−t2=cosh⁡t，fo=et−e−t2=sinh⁡t。f(t)=u(t)：fe=12（t≠0），fo=12sgn(t)。

5.3 Real + Imaginary

复值信号：

f(t)=fr(t)+jfi(t),f∗(t)=fr(t)−jfi(t)
fr(t)=12[f(t)+f∗(t)],jfi(t)=12[f(t)−f∗(t)]
  • 现实信号是实的，但复信号便于分析实信号

7 · 易错点

  • δ(2t−4)=12δ(t−2)，不是 δ(t−2)。
  • 积分区间不包含冲激点时，积分为 0。
  • f(t)δ(t) 的结果是 f(0)δ(t)（还是一个冲激），不是 f(0)；只有积分后才是数。
  • ∫δ′(t)f(t)dt=−f′(0)，有负号。
  • f(t)δ′(t)≠f(0)δ′(t)，还要减 f′(0)δ(t)。
  • δ(t) 是偶函数，δ′(t) 是奇函数。
  • u(0) 无定义或取 12。
  • 求奇偶分量时先正确画出 f(−t)（关于纵轴翻折）。
