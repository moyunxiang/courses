3 · Linear Regression

3.1 Hypothesis class

f𝐰(x)=𝐰⋅ϕ(x)

weight vector 𝐰=[w1,w2]，feature vector ϕ(x)=[1,x]。

𝐰⋅ϕ(x) 叫 score。ℱ={f𝐰:𝐰∈ℝ2}。

例：f𝐰(3)=[1,0.57]⋅[1,3]=1+1.71=2.71。

Loss(x,y,𝐰)=(f𝐰(x)−y)2（squared loss；f𝐰(x)−y 叫 residual）
TrainLoss(𝐰)=1∣𝒟train∣∑(x,y)∈𝒟trainLoss(x,y,𝐰)

4 · Linear Classification

4.1 Hypothesis class

f𝐰(x)=sign(𝐰⋅ϕ(x)),ℱ={f𝐰:𝐰∈ℝ2}

Decision boundary：{x:𝐰⋅ϕ(x)=0}（与 𝐰 垂直；𝐰 指向 +1 一侧）。

课件例：𝐰=[−0.6,0.6]，ϕ(x)=[x1,x2]

  • f([0,2])=sign(1.2)=+1
  • f([−2,0])=sign(1.2)=+1
  • f([1,−1])=sign(−1.2)=−1
  • 边界：−0.6x1+0.6x2=0  ⟺  x2=x1

4.2 Score 与 margin

Score =𝐰⋅ϕ(x)：多有信心预测 +1。

Margin =(𝐰⋅ϕ(x)) y：预测得多正确（>0 分对，<0 分错）。

4.3 Zero-one loss

Loss0-1(x,y,𝐰)=𝟏[f𝐰(x)≠y]=𝟏[(𝐰⋅ϕ(x))y⏟margin≤0]

问题：∇𝐰Loss0-1=∇𝟏[⋅]=0 几乎处处（阶梯函数）——梯度下降无法使用。

4.4 Hinge loss

Losshinge(x,y,𝐰)=max⁡{1−(𝐰⋅ϕ(x))y, 0}
  • 是 0-1 loss 的上界（margin ≤0 时 ≥1；margin >0 时 ≥0）
  • margin ≥1 时 loss =0
∇Losshinge(x,y,𝐰)={−ϕ(x)yif 1−(𝐰⋅ϕ(x))y>00otherwise

4.5 Logistic loss（digression：logistic regression）

Losslogistic(x,y,𝐰)=log⁡(1+e−(𝐰⋅ϕ(x))y)

直觉：即使 margin 已经超过 1，仍继续增大 margin（loss 永远 >0）。

梯度（补充）：∇=−ϕ(x)y⋅e−m1+e−m，m = margin。

7 · 易错点

  • TrainLoss 是平均（除以样本数）。
  • Squared loss 的梯度有因子 2。
  • Margin = score × y，不是 score；margin =0 时 0-1 loss 算错（≤0）。
  • Hinge 梯度在 margin <1 时就非零（不只是分错时），且带负号 −ϕ(x)y。
  • Gradient descent 是减梯度。
