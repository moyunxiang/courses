1 · 典型离散信号

1.1 表示方法

  • 对连续信号等间隔 Ts 采样：x(t)→x(nTs)，记作 x[n]，n=0,±1,±2,…
  • 序列形式：x[n]={9,8↑,4,1}——箭头标出 n=0 的位置
  • 波形：每根竖线的长度表示对应序列值的大小

例：x[n]={2n,n≥00,n<0 ⇒ x[n]={…,0,0,1↑,2,4,8,… }

按长度分类：

类型 n 的范围
One-sided（单边） n≥0
Two-sided（双边） −∞<n<∞
Finite-length（有限长） n1≤n≤n2

1.2 Unit sample sequence δ[n]（Kronecker delta）

δ[n]={1,n=00,n≠0

和 δ(t) 不同：δ[n] 在 n=0 的值就是 1（有限、确定的），不需要极限或广义函数。

  • Time-shifting：δ[n−j]=1 当 n=j，否则 0
  • Scaling：c δ[n]、c δ[n−j]
  • Sampling：f[n]δ[n]=f[0]δ[n]

用 δ[n] 表示任意序列（Ch2 卷积的基础）：

x[n]=∑m=−∞∞x[m] δ[n−m]

（x[m] 是权重，δ[n−m] 指定位置。）

例：x[n]={1,1.5↑,0,−3,0,… }（n=−1 处为 1，n=0 处为 1.5，n=2 处为 −3）：

x[n]=δ[n+1]+1.5 δ[n]−3 δ[n−2]

1.3 Unit step sequence u[n]

u[n]={1,n≥00,n<0

（注意 u[0]=1，确定，不像 u(0) 无定义。）

u[n]=δ[n]+δ[n−1]+δ[n−2]+⋯=∑k=0∞δ[n−k]δ[n]=u[n]−u[n−1]

（离散里「求导」变成差分，「积分」变成累加。）

1.4 Rectangular sequence RN[n]

RN[n]={1,0≤n≤N−10,n<0, n≥N=u[n]−u[n−N]

例：R3[n]=δ[n]+δ[n−1]+δ[n−2]（N 个点：0 到 N−1）

1.5 Ramp、单边指数

  • Ramp：x[n]=n u[n]
  • 单边指数：x[n]=anu[n]
a 波形
a>1 单调增长
0<a<1 单调衰减
a<−1 正负交替、幅度增长
−1<a<0 正负交替、幅度衰减

1.6 Sinusoidal sequence（周期性必考）

对 xa(t)=sin⁡(2πf0t)=sin⁡(ω0t) 以采样间隔 Ts（采样频率 fs=1/Ts）采样：

xa(Tsn)=sin⁡(ω0Tsn)  ⇒  x[n]=sin⁡(Ω0n)
Ω0=ω0Ts=ω0fs=2πf0fs

（digital angular frequency，单位 radians / sample）

周期性：要求 x[n+N]=x[n]，N 必须是正整数。sin⁡(Ω0(n+N))=sin⁡(Ω0n+NΩ0)，需要 NΩ0=2πm（m 整数）。看 2πΩ0：

情况 结论 周期
① 2πΩ0 是正整数 周期 N=2πΩ0
② 2πΩ0=Nm 是有理数（既约分数） 周期 N=m2πΩ0（即分子 N）
③ 2πΩ0 是无理数 非周期 ——

例 1：sin⁡(0.2πn)：2π0.2π=10（整数）⇒ N=10；每 10 个样本重复，包络正弦走 1 个完整周期。

例 2：sin⁡(4π11n)：2π4π/11=112（有理数，N=11，m=2）⇒ N=11；每 11 个样本重复，包络正弦走 2 个完整周期。

例 3：sin⁡(0.4n)：2π0.4=5π（无理数）⇒ 非周期。

和连续的区别：连续正弦 sin⁡(ωt) 对任何 ω 都是周期的；离散正弦不一定周期——因为 N 必须是整数。只有 Ω0 是 π 的有理倍数时才周期。

1.7 Complex exponential sequence

x[n]=ejΩ0n=cos⁡Ω0n+jsin⁡Ω0n

极坐标形式：x[n]=∣x[n]∣ejarg⁡x[n]，其中 ∣x[n]∣=1，arg⁡x[n]=Ω0n。

2 · 离散信号的运算

2.1 加、乘、数乘

  • Summation：z[n]=x[n]+y[n]（对齐同一个 n 再相加）
  • Multiplication：z[n]=x[n]⋅y[n]
  • Scaling：z[n]=a x[n]

例：x[n]={1↑,2,3,4}，y[n]={1↑,1,1}（都从 n=0 开始）：

  • x+y={2↑,3,4,4}
  • x⋅y={1↑,2,3,0}（n=3 处 y=0）

2.2 平移、反转

  • z[n]=x[n−m]：m>0 右移；z[n]=x[n+m]：m>0 左移
  • 例：x[n] 在 n=−1,0,1 上为 1、2、3 ⇒ x[n−1] 在 n=0,1,2 上为 1、2、3
  • Reversal：z[n]=x[−n]

2.3 差分（离散的「导数」）

  • Forward difference：Δx[n]=x[n+1]−x[n]
  • Backward difference：∇x[n]=x[n]−x[n−1]

2.4 累加（Running sum，离散的「积分」）

z[n]=∑k=−∞nx[k]

例：x[n]=n（0≤n≤4），否则 0：

n 0 1 2 3 4 >4
y[n] 0 1 3 6 10 10

2.5 Reshaping：抽取与内插

  • Decimation（抽取 / 压缩）：x[n]→x[Nn]，N 正整数——只保留每 N 个中的一个，其余丢掉
  • Interpolation（内插 / 扩展）：x[n]→x[nN]——nN 不是整数的位置补 0（或按需插值）

（名字来自罗马军团的 decimation：十人抽一。）

例 5：x[n]=n（1≤n≤6）：

  • x[2n]：n=1,2,3 处为 x[2]=2、x[4]=4、x[6]=6（奇数位的值丢失）
  • x[n2]：n=2,4,…,12 处为 1、2、…、6，奇数 n 处为 0

和连续的区别：连续的 f(2t) 不丢信息；离散的 x[2n] 会丢信息（只取偶数点）。

2.6 能量和功率

E=∑n=−∞∞∣x[n]∣2EK=∑n=−KK∣x[n]∣2

例 6：x[n]={1,2,3,4}（n=1..4）：E=12+22+32+42=30

平均功率：

P=lim⁡K→∞12K+1∑n=−KK∣x[n]∣2（非周期）
P=1N∑n=0N−1∣x[n]∣2（周期 N）

（注意离散里区间 [−K,K] 有 2K+1 个点。）

3 · 系统特性（必考）

重点：在确定性信号激励下，研究**集总参数、线性、时不变（LTI）**系统。

3.1 连续 / 离散

r(t)=H[e(t)]；y[n]=H[x[n]]。

3.2 Instantaneous（memoryless）vs Dynamic

方程 例
Instantaneous（即时 / 无记忆） 代数方程：输出只取决于同一时刻的输入 电阻 vR(t)=RiR(t)
Dynamic（有记忆） 微分 / 差分方程：输出取决于过去的输入 电容 vC(t)=1C∫−∞tiC(τ)dτ

3.3 Lumped vs Distributed

方程 例
Lumped-parameter 常微分方程（只依赖时间 t） 低频电路（RLC）
Distributed-parameter 偏微分方程（依赖 t,x,y,z） 波导、传输线

3.4 Invertible vs Non-invertible

  • Invertible：不同激励产生不同响应——能从输出唯一确定输入（例：r(t)=αe(t)，0<α<1）
    • 应用：用逆系统做系统补偿
  • Non-invertible：不同输入产生相同输出——例如 e(t) 和 −e(t) 产生相同输出（如 r(t)=e2(t)），无法唯一确定输入

3.5 Linear systems

线性 = 齐次性 + 叠加性：

  • Homogeneity：e(t)→r(t) ⇒ Ke(t)→Kr(t)
  • Superposition：e1→r1，e2→r2 ⇒ e1+e2→r1+r2

合起来（连续 / 离散同理）：

c1e1(t)+c2e2(t)  ⟶  c1r1(t)+c2r2(t)

判断方法：「先线性组合再过系统 = 先过系统再线性组合」

H[C1e1(t)+C2e2(t)]=?C1H[e1(t)]+C2H[e2(t)]
相等则线性，否则非线性。 注意：外部激励和系统的非零初始状态要分开处理（有初始状态时，看 zero-state response 是否线性）。

例 1：r(t)=e2(t) 线性吗？

  • e1→r1=e12，e2→r2=e22
  • 先组合再过系统：H[C1e1+C2e2]=(C1e1+C2e2)2=C12e12+C22e22+2C1C2e1e2
  • 先过系统再组合：C1r1+C2r2=C1e12+C2e22
  • 不相等 ⇒ 非线性

3.6 Time-invariant systems

定义：零初始条件下，输出与输入施加的时刻无关——e(t)→r(t) ⇒ e(t−t0)→r(t−t0)。否则 time-varying。

  • 电路角度：元件参数是否随时间变化；方程角度：系数是否随时间变化

判断方法：「先时移再过系统 = 先过系统再时移」

H[e(t−τ)]=?r(t−τ)

例 2：r(t)=de(t)dt

  • (1) 先时移：e(t−t0) → 系统 → de(t−t0)dt
  • (2) 先过系统：r(t)=de(t)dt，再时移（t→t−t0）：de(t−t0)d(t−t0)=de(t−t0)dt
  • 相同 ⇒ 时不变

例 3：r(t)=cos⁡(ω0t) e(t)（调幅系统）

  • (1) 先时移再过系统：cos⁡(ω0t) e(t−t0)
  • (2) 先过系统再时移：cos⁡(ω0(t−t0)) e(t−t0)
  • 不同 ⇒ 时变

常见陷阱：时移只作用在输入上时，系统里显式的 t（如 cos⁡ω0t、t e(t)）不跟着变；先过系统再时移时，所有的 t 都要换成 t−t0。

补充练习（同样方法）：

系统 线性？ 时不变？ 理由
r(t)=t e(t) ✓ ✗ 系数 t 随时间变
r(t)=e(t)+1 ✗ ✓ e=0 时输出不为 0
r(t)=e(2t) ✓ ✗ 先移位：e(2t−t0)；先过系统：e(2(t−t0))
y[n]=x[n]+x[n−1] ✓ ✓

离散时不变：x[n]→y[n] ⇒ x[n−N]→y[n−N]。

3.7 LTI 系统的微分 / 积分特性

LTI 系统 e(t)→r(t)，则

de(t)dt→dr(t)dt∫−∞te(τ)dτ→∫−∞tr(τ)dτ

证明（用线性和时不变）：

de(t)dt=lim⁡Δt→0e(t)−e(t−Δt)Δt
  • 时不变：e(t−Δt)→r(t−Δt)
  • 线性：e(t)−e(t−Δt)Δt→r(t)−r(t−Δt)Δt
  • 取极限得 dr(t)dt ✓（可推广到高阶）

（用处：知道 u(t) 的响应，求导就得到 δ(t) 的响应——Ch2。）

3.8 Causal systems

因果系统：只有输入激励时才产生响应——输出不会超前于输入。 判断：看输出是否依赖未来的输入。

例 4：

  • r(t)=e(t)+e(t−2)：当前响应 = 当前激励 + 过去激励 ⇒ 因果

  • r(t)=e(t)+e(t+2)：包含未来激励 ⇒ 非因果

  • 实时系统的实现要求因果

  • 非因果系统也有实际意义：信号压缩 / 扩展、语音信号处理（录好后处理，可以「看到未来」）

  • 因果信号：e(t)=e(t)u(t)，等价于 t<0 时 e(t)=0

（补充：r(t)=e(2t) 是非因果的——t=1 时要用 e(2)。r(t)=e(−t) 也非因果。）

3.9 Stable systems

BIBO（bounded input bounded output）stable：对任何有界输入都只产生有界输出。

  • 工程上至关重要：输入不发散，输出也不发散
  • （补充：r(t)=∫−∞te(τ)dτ 不稳定——输入 u(t) 有界，输出 t u(t) 无界。r(t)=e2(t) 稳定。）

总结：LTI 系统，从实现角度希望它因果且稳定。

4 · LTI 系统的表示

4.1 连续系统：微分方程

  • 根据实际系统的物理特性写出微分方程；给定激励和初始状态求响应；分析后回到物理实际
  • 也可以用结构图（方框图、信号流图）
  • 求响应的途径：电路 → 微分方程 / 单位冲激响应 / 系统函数（Laplace）/ 结构图

例 1（RLC 电路）：e(t) 串联 L，再接 R∥C，求 vC(t) 的微分方程。

元件约束（关联参考方向）：

iC(t)=CdvC(t)dtvL(t)=LdiL(t)dt

网络拓扑约束：

KVL:e(t)=LdiL(t)dt+vC(t)(1)KCL（节点 a）:iL(t)=vC(t)R+CdvC(t)dt(2)

消去 iL：把 (2) 代入 (1)：

e(t)=Lddt[vC(t)R+CdvC(t)dt]+vC(t)

整理（两边除以 LC）：

d2vC(t)dt2+1RCdvC(t)dt+1LCvC(t)=1LCe(t)
  • 方程没有非线性项（如相乘）⇒ 线性
  • 所有系数是常数 ⇒ 时不变
  • 微分方程的阶数 = 系统的阶数（两个储能元件 ⇒ 二阶）

4.2 连续系统方框图

元件 关系
Adder r(t)=e1(t)+e2(t)
Multiplier（非线性运算） r(t)=e1(t)⋅e2(t)
Scalar multiplier（系数乘法器） r(t)=a e(t)
Differentiator r(t)=de(t)dt
Integrator r(t)=∫−∞te(τ)dτ
Time-delay r(t)=e(t−τ)

4.3 离散系统：差分方程与方框图

  • Scalar multiplier：x[n]→a x[n]
  • Unit delay element z−1：y[n]→y[n−1]（本质上是一个移位寄存器：推出旧值、移入新值）

例 2（无反馈）：

y[n]=12x[n]+12x[n−1]

（两点平均——一个简单的低通滤波器。）

例 3（有反馈）：

y[n]=x[n]+a y[n−1]（一阶后向差分方程）

另一种画法得到 y[n+1]=x[n]+a y[n]（一阶前向差分方程）。本课用后向差分方程。

例 4（二阶）：从方框图读出

y[n]=x[n]−3x[n−2]+5y[n−1]−6y[n−2]

即

y[n]−5y[n−1]+6y[n−2]=x[n]−3x[n−2]
  • 二阶系统可以有多种结构图，但至少需要两个延迟单元

读方框图的套路：从输出端的加法器写起，每经过一个 z−1 下标减 1，每经过一个系数就乘上它；加法器的「−」号别漏。

一般形式：

∑k=0Nak y[n−k]=∑r=0Mbr x[n−r]
  • 差分方程的阶：未知序列（y）自变量的最高值与最低值之差（例 4：n 与 n−2，阶数 2）

5 · LTI 系统分析方法概览

  • 研究目标：LTI 系统的基本分析方法，应用于通信中的信号传输与处理
  • 步骤：(1) 建立数学模型（写方程）；(2) 求响应（给定输入求输出）

两种建模方法：

Input-output description State-variable analysis
关注 只关心激励与响应的关系，不管内部变量 能求出响应和内部变量（电容电压、电感电流）
适用 SISO MIMO
方程 一个 n 阶常微分方程 一组耦合的一阶微分方程

求解方法：

  1. 时域：连续系统——微分方程（经典解法）；离散系统——差分方程；卷积积分 / 卷积和（Ch2）
  2. 变换域：Fourier transform（Ch3–4）、Laplace transform（Ch5）、Z transform、DFT

7 · 易错点

  • 离散正弦不一定周期；2πΩ0 是无理数（如 Ω0=0.4）就不周期。
  • 2πΩ0=112 时周期是 11，不是 5.5。
  • δ[0]=1（不是无穷）；u[0]=1。
  • RN[n] 有 N 个点（0 到 N−1）。
  • 判断时不变：先过系统再时移时，系统里显式的 t 也要替换。
  • r(t)=e(t)+1 不是线性系统（齐次性不满足）。
  • 微分系统时不变；调幅 cos⁡(ω0t)e(t) 时变。
  • 因果看「是否用到未来输入」，e(t−2) 是过去（因果），e(t+2) 是未来（非因果）。
  • 方框图读差分方程时注意 z−1 的个数和加法器的正负号。
