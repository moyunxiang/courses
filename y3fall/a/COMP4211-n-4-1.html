0 · 这一讲在讲什么

  1. 生物神经元：dendrite、soma、axon、synapse；信号如何传递
  2. 人工神经网络：用大量简单计算单元组成的网络来模拟大脑
  3. 结构三要素：unit、link、weight；unit 分 input / hidden / output
  4. 学习 = 更新权重；feedforward vs feedback

这一讲是概念铺垫，考点主要是名词对应：生物 ↔ 人工的对应关系；三种 unit；学习改的是什么；feedforward 与 feedback 的区别。

1 · 生物神经元

  • 人脑约 1011（100,000,000,000）个神经元；每个神经元接收约 1,000 个其他神经元的输入
  • 结构：dendrite（树突，接收）→ cell body / soma（胞体，含 nucleus）→ axon（轴突，输出）→ axonal arborization → synapse（突触，连接下一个细胞）

信号传递：

  1. 多个脉冲同时到达
  2. 相加
  3. 足够强时，沿 axon 发出电脉冲
  4. 到达 synapses，向其他细胞释放 transmitters

2 · 人工神经网络

用由简单计算单元组成的复杂网络作为数学模型，模仿大脑的功能。

结构三要素：(i) unit、(ii) link、(iii) weight

课件示意：I1,I2（input）→ H3,H4（hidden）→ O5（output），权重 w13,w14,w23,w24,w35,w45。

Unit 类型：input units、hidden units、output units。

生物 人工
神经元 unit
synapse 强度 weight wij
脉冲相加 加权求和 ∑jwjIj
足够强才发放 activation（threshold）function

例子：deep learning。

3 · 学习

学习通常通过更新权重进行。

Demo：TensorFlow Playground。

4 · Feedforward vs Feedback

连接 输出依赖
Feedforward 只从输入往输出方向，无环 只依赖当前输入
Feedback（recurrent） 有环，输出 / 状态回传 也依赖之前的状态（见第 6 讲 RNN）

5 · 考点清单

考点 至少要会
生物神经元 四个部件；信号传递四步
结构三要素 unit / link / weight
Unit 类型 input / hidden / output
学习 更新 weights
Feedforward / feedback 有无环

6 · 易错点

  • 学习改的是 weight，不是网络结构。
  • Feedback 网络 = 有环（RNN）；feedforward 无环（perceptron、MLP、CNN）。
