1 · 为什么需要 RNN

  • Feedforward：输出只依赖当前输入
  • 序列学习：video processing、machine translation、speech recognition（连续时间帧的声学特征）
  • 序列数据需要 feedback 机制：hidden layers 和输出依赖于之前的 hidden states

2 · RNN

Unfolding：展开成同一个网络的多份拷贝，每份把旧的 state 传给下一份。

  • State：保存过去序列的一些重要方面
ht=fW(ht−1,xt)

新状态 = 函数（旧状态，当前时间步输入 xt）。

同一组权重用于不同时间步的神经元。

3 · Simple RNN

ht=tanh⁡(Whhht−1+Wxhxt),yt=Whyht

每个时间步重用同一个权重矩阵。（RNN 有很多变体。）

计算图（Goodfellow 等 Deep Learning 的记号）：

𝐚(t)=𝐛+W𝐬(t−1)+U𝐱(t)𝐬(t)=tanh⁡(𝐚(t))𝐨(t)=𝐜+V𝐬(t)𝐲^(t)=softmax(𝐨(t))

U：input → state；W：state → state；V：state → output。此例中每个时间步都算 loss L(t)（label y(t)），总 loss 是各步之和。

4 · BPTT 与梯度问题

Backpropagation through time (BPTT)：在展开的计算图上做 backprop；所有时间步的 loss 汇总；共享权重的梯度是各时间步梯度之和（分支处梯度相加，4.6）。

4.1 Vanishing gradients

传话游戏：每个人都含糊一点点，传到最后信息全没了。

  • ht=tanh⁡(Whhht−1+Wxhxt)
  • 反向时，梯度信号在每个时间步都乘以同一个矩阵 Whh（还有 tanh 的导数 ≤1）
  • 梯度变得极小 ⇒ 学习变得很慢甚至停止 ⇒ 学不到长程依赖

4.2 Exploding gradients

传话游戏：每个人都夸大一点点。

  • 梯度信号变得极大 ⇒ 数值不稳定（如 loss 变成 NaN）

Simple RNN 不适合长序列。

（直觉补充：T 步后梯度大致 ∝WhhT；Whh 的最大特征值 <1 ⇒ 消失，>1 ⇒ 爆炸。）

5 · LSTM（Long Short-Term Memory）

5.1 Input gate：是否写入 cell

C~t=tanh⁡(WC[ht−1,xt]+bC)（候选向量，可加到状态上）
it=σ(Wi[ht−1,xt]+bi)（input gate）

允许输入信号改变 memory cell 的状态，或阻止它。

5.2 Cell state

让梯度直接沿 cell state 回传，不会被非线性激活反复压缩，也不会反复乘主权重矩阵。

（这就是 LSTM 缓解梯度消失的关键：cell state 的更新是加法。）

5.3 Forget gate：是否擦除 cell

ft=σ(Wf[ht−1,xt]+bf)
Ct=ft⊙Ct−1+it⊙C~t,⊙：逐元素乘
  • 让 cell 记住或忘记之前的状态
  • 只要 forget gate 开着（ft≈1），信息就留在 cell 里

5.4 Output gate

ot=σ(Wo[ht−1,xt]+bo),ht=ot⊙tanh⁡(Ct)

允许 / 阻止 memory cell 的状态影响其他神经元。

5.5 汇总

Gate 公式 激活 作用
候选 C~t tanh⁡(WC[ht−1,xt]+bC) tanh 要写入的新内容
Input it σ(Wi[⋅]+bi) sigmoid 写多少
Forget ft σ(Wf[⋅]+bf) sigmoid 留多少旧状态
Output ot σ(Wo[⋅]+bo) sigmoid 输出多少
Cell Ct=ft⊙Ct−1+it⊙C~t
Hidden ht=ot⊙tanh⁡(Ct)

（gate 用 sigmoid：输出在 (0,1)，像「开关的开度」。）

6 · Gradient Clipping（解决梯度爆炸）

在更新权重之前把梯度显式限制在一个最大阈值 c：

𝐠←c⋅𝐠∥𝐠∥if ∥𝐠∥>c

（方向不变，只缩小长度。补充例：𝐠=(3,4)，c=1：∥𝐠∥=5>1 ⇒ 𝐠←(0.6,0.8)。）

7 · Multi-layer (Stacked) RNN

  • 标准 RNN：「深」在时间上
  • Stacked RNN：多层 RNN 叠起来，增加空间上的深度
  • 学习层次化表示：低层学低级、局部的序列动态；高层学复杂、高级的抽象
  • 很少叠超过 2–4 层（否则计算昂贵、梯度不稳定）

8 · 与其他网络结合 / 应用

任务 输入 → 输出 做法
Image captioning 图像 → 词序列 CNN 提取图像特征，LSTM 接在 CNN 的卷积层之后
Activity recognition 图像序列 → 活动
Machine translation 词序列 → 词序列

10 · 易错点

  • 所有时间步共享同一组 Whh,Wxh,Why。
  • Gate 用 sigmoid，候选 C~t 和输出前的 Ct 用 tanh。
  • Ct 是 ft⊙Ct−1 加 it⊙C~t（加法，这是梯度能流动的原因）。
  • ht=ot⊙tanh⁡(Ct)，不是 ot⊙Ct。
  • Clipping 解决的是爆炸；LSTM 主要解决消失。
