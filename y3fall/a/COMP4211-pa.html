Step 3

Experiment 1 — Learning rate (Table 3.1a/b, Figure 3.1a/b)

  • 0.001: slowest but smoothest; loss still falling at epoch 20 (MLP ep 20, CNN ep 17) → under-trained. MLP 0.5168 (best for MLP), CNN 0.7081 (train 0.7256, underfits).
  • 0.01: fastest drop. CNN train loss < 0.1 by ep 19, val 0.7901 (best for CNN), but val loss rises after ep 7 (overfitting). MLP loss oscillates by ±0.1–0.2 per epoch (step too large for 12,288 inputs; with momentum 0.9 the effective step is η/(1−0.9)=10η) → 0.5015, below 0.001.
  • 0.1: diverges in epoch 1 for both: loss stuck at ln⁡10≈2.30 and accuracy 0.1111 = always predicting one class (AnnualCrop, 2100/18900) → no learning.

Experiment 2 — Batch size (Table 3.2a/b, Figure 3.2a/b)

Updates per epoch: 591 / 296 / 148 for 32 / 64 / 128; smaller batch = more, noisier updates at the same η.

  • MLP: bs 32 is unstable (loss ≈ 1.8–2.0 throughout, best ep 2, 0.3175); bs 128 gives the smoothest, lowest loss (≈ 1.25 at ep 20) and best val 0.5183 (bs 64: 0.5015).
  • CNN: bs 32 lowers training loss fastest but its val loss bottoms at ep 5 and then rises most → 0.7607; bs 128 learns slower, reaches the lowest val loss (≈ 0.62) → 0.7983 (best).
  • Same data seen, so the difference is update count × gradient noise: fewer, less noisy steps avoid divergence (MLP) and delay overfitting (CNN).

Experiment 3 — MLP width (Table 3.3, Figure 3.3)

  • Params 787,146 / 1,574,282 / 3,148,554 (first layer 12288×w dominates).
  • Extra units do not reduce training loss: all three end at ≈ 1.3–1.55 with the same oscillation; checkpoint train acc 0.5381 / 0.5262 / 0.4949.
  • Val acc 0.5106 / 0.5015 / 0.4758 → no improvement; best 64. The MLP is limited by unstable optimisation at η=0.01, not by capacity, so more parameters do not help.

Experiment 4 — MLP depth (Table 3.4, Figure 3.4)

  • Params 1,574,282 / 1,590,794 / 1,623,818 (+16,512 per 128×128 layer).
  • Deeper nets lower training loss faster and more steadily: ≈ 1.13–1.18 at ep 20 (min 1.10) vs ≈ 1.3–1.6 for 1 layer.
  • Lower training loss does improve validation: train 0.5262 / 0.5932 / 0.6149, val 0.5015 / 0.5637 / 0.5847 (best 4 layers); train–val gap stays ≈ 0.03 because the MLPs underfit.

Experiment 5 — CNN filters (Table 3.5, Figure 3.5)

  • Params 264,250 / 530,090 / 1,068,682: doubling filters roughly doubles parameters (FC input =f2⋅16⋅16).
  • More feature maps → more features per location → training loss lower (≈ 0.09 at ep 20 for (32,64)); checkpoint train 0.8737 / 0.9772 / 0.9475.
  • Val loss bottoms at ep 7–12 for all and then rises; val 0.7593 / 0.7901 / 0.7901 → 8→16 filters helps, 16→32 doubles parameters with no gain (overfits). Best (16, 32) (tie, first listed).

Experiment 6 — Kernel size (Table 3.6, Figure 3.6)

  • Params 530,090 / 539,050 / 552,490 (conv weights ∝k2: 5,088 → 14,048 → 27,488; FC unchanged).
  • Receptive field of each FC input after two conv+pool blocks: 3k+1 = 10, 16, 22 pixels.
  • Training loss is similar or lower for larger kernels (5×5 ≈ 0.06 at ep 20), but their val loss climbs faster after ep 8 (≈ 1.3–1.4 vs 1.09 at ep 20); val 0.7901 / 0.7647 / 0.7462 → wider neighbourhoods do not help. EuroSAT classes are distinguished by local texture/colour, so 3×3 already sees enough; the extra k2 weights mostly fit training noise. Best 3×3.

Step 4 (item 4)

Final models (Tables 4.1–4.3): MLP 4 hidden layers × 128, η=0.01, bs 64, ep 18; CNN baseline architecture, η=0.01, bs 128, ep 19.

  • vs baselines (val): MLP 0.5015 → 0.5847 (+8.3 pts); CNN 0.7901 → 0.7983 (+0.8 pts). Test: MLP 0.5847, CNN 0.8119.
  • Train gains vs val gains: MLP train 0.5262 → 0.6149 transfers almost one-to-one (gap ≈ 0.03, underfitting). CNN does not: baseline train 0.9772 > final 0.9281 yet lower val; more filters / bs 32 raised train acc (0.9475 / 0.9409) but not val. CNN train–val gap ≈ 0.13–0.19, val loss rising after ep ≈ 7 (Fig 2.1c) → overfitting.
  • MLP vs CNN: CNN is +21 pts on val with 3.1× fewer parameters (530,090 vs 1,623,818).
    • Local connectivity: each conv unit sees only a 3×3 neighbourhood → learns edges/textures; the MLP flattens the image and its first layer (12288×128 = 1,572,864 weights, 99.9% of the baseline MLP) ties every weight to one pixel position, ignoring spatial structure.
    • Parameter sharing: one 3×3 filter is reused at all positions (only 5,088 conv parameters) → the same pattern is detected anywhere; the MLP must relearn it at every location → it plateaus at loss ≈ 1.1–1.5 with large oscillations (Fig 2.1a, 3.4), while the CNN reaches train loss < 0.2 (Fig 2.1c).
    • Misclassified images (Fig 4.1): MLP errors follow global colour (Highway → River, a grey curve on green; PermanentCrop → Pasture; AnnualCrop → Industrial); the CNN classifies the first two correctly and fails only on texture-poor, ambiguous images (AnnualCrop field boundaries → Highway / River, uniform dark Forest → HerbaceousVegetation).

class MLP(nn.Module):
    def __init__(self, width=128, depth=1):
        super().__init__()
        layers, d = [nn.Flatten()], 3 * 64 * 64
        for _ in range(depth):
            layers += [nn.Linear(d, width, bias=True), nn.ReLU()]
            d = width
        self.net = nn.Sequential(*layers, nn.Linear(d, 10, bias=True))

    def forward(self, x):
        return self.net(x)


class CNN(nn.Module):
    def __init__(self, filters=(16, 32), kernel=3):
        super().__init__()
        f1, f2 = filters
        p = {3: 1, 5: 2, 7: 3}[kernel]
        self.net = nn.Sequential(
            nn.Conv2d(3, f1, kernel, stride=1, padding=p, bias=True), nn.ReLU(), nn.MaxPool2d(2, 2),
            nn.Conv2d(f1, f2, kernel, stride=1, padding=p, bias=True), nn.ReLU(), nn.MaxPool2d(2, 2),
            nn.Flatten(), nn.Linear(f2 * 16 * 16, 64, bias=True), nn.ReLU(), nn.Linear(64, 10, bias=True))

    def forward(self, x):
        return self.net(x)
