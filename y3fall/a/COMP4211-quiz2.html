Practice:

  • Initialise with small random weights.
  • Stop after a fixed number of iterations, when the training error falls below a threshold, or at the validation-error minimum (early stopping).

  • GD only guarantees a local minimum (use several random restarts).

6 · Convolution & filters (5-cnn-intro, 5-cnn-img)

  • Why CV: "a picture is worth a thousand words" and huge amounts of image/video data. Typical task: object recognition.
  • Applications: real-time detection, self-driving trucks, face recognition / face payment, biometrics.
(f∗g)(t)=∫f(τ)g(t−τ) dτ

(commutative, associative)

S(i,j)=∑m∑nI(i−m,j−n)K(m,n)

(true convolution: kernel flipped)

S(i,j)=∑m∑nI(i+m,j+n)K(m,n)

(cross-correlation: what NNs call "convolution")

  • Valid output size: (H−K+1)×(W−K+1).
  • Smoothing 19𝟏3×3 blurs; a bigger window blurs more. Weighted averages put more weight in the centre and are normalised by the sum.
  • Averaging ↔ integration (blur); differencing ↔ differentiation (sharpen), f(x+1)−f(x).
  • Edge kernels: (−101) columns → vertical edges; (−101) rows → horizontal edges. The kernel sums to 0, so flat regions give 0.

  • Sparse connectivity (receptive field; it grows with depth; feature hierarchy edges → parts → objects).
  • Parameter sharing (robust to shifts; far fewer parameters).
  • Efficiency example: 320×280 input, 2×1 kernel → 2 numbers vs dense >8×109 vs sparse 178,640.
  • Tensors: feature map C×H×W; filters Co×Ci×Kh×Kw (e.g. 16×3×3×3 → 432 weights + 16 biases). 1×1 conv mixes channels only, for dimension reduction.
  • Conv is linear, so add a nonlinearity (ReLU). Padding stops the maps from shrinking. Pooling (max / average) gives spatial invariance ("7" example); with stride it downsamples and has no learnable parameters.
  • One "complex" conv layer = convolution → detector (ReLU) → pooling.
  • Slide architecture: 2562×3→2562×64→ pool/4 →642×64→642×64→ pool/4 →162×64=16,384→1000→ softmax.

Common Mistakes

  • step(0) =1; the bias input I0=1 must be updated too; no update when T=O.
  • Convergence is guaranteed only for linearly separable data.
  • σ′=σ(1−σ); the gradient has a minus sign: −(t−o)⋯.
  • Add gates give every input the full upstream gradient (it is not split); a variable used twice gets the sum.
  • Momentum multiplies the previous update Δw(t), not the previous gradient.
  • Cross-entropy is not symmetric: p = target, q = model.
  • NNs use cross-correlation (no flip). The kernel [−1,0,1] (horizontal difference) detects vertical edges.
  • Size formula: 2×pad, floor, then +1. Pooling has 0 parameters.
