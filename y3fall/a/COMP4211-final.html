7 · Bayesian classification (9-bayes)

Term Meaning
P(h) prior: before seeing the data
P(h∣D) posterior: after seeing the data
P(D∣h) likelihood of the data under h
P(D) evidence (same for every class)
  • MAP prediction: assign x to arg⁡max⁡iP(Ci∣x)=arg⁡max⁡iP(x∣Ci)P(Ci) (P(x) is constant).
  • Slide examples: P(LC∣Cough)=0.8×0.005/0.05=0.08; covid test: 0.98(0.008)=0.0078<0.03(0.992)=0.0298 → MAP = no covid.
  • Independence: P(X,Y)=P(X)P(Y). Conditional independence: P(X∣Y,Z)=P(X∣Z) ⟺ P(X,Y∣Z)=P(X∣Z)P(Y∣Z) (e.g. thunder ⊥ rain | lightning; coin tosses are dependent, but independent given "biased or not").
  • Naive Bayes: attributes conditionally independent given the class.
P(Ci)=∣Ci∣∣D∣,P(xk∣Ci)=Nk,CiNCi,P(x∣Ci)=∏k=1nP(xk∣Ci)vNB=arg⁡max⁡CiP(Ci)∏kP(xk∣Ci)Laplace: P(xk∣Ci)=Nk,Ci+1NCi+c,c=#distinct values of Ak
  • Why not estimate P(x∣Ci) directly: needs far too much data for every value combination.
  • One zero count makes the whole product 0 → Laplace correction. Slide: counts 0/990/10 of 1000 → 1/1003, 991/1003, 11/1003.
  • Slide buys_computer example: x=(youth, medium, student, fair): P(x∣yes)P(yes)=0.044×0.643=0.028>0.019×0.357=0.007 → yes.
  • Pros: easy, often good. Cons: the independence assumption can cost accuracy (but works surprisingly well).

O · Naive Bayes with Laplace (自编题). Data (weather, wind → play): (sunny, weak, yes), (sunny, strong, no), (rainy, weak, yes), (rainy, strong, no), (sunny, weak, yes), (rainy, weak, no). Classify x=(sunny, strong).

  • P(yes)=P(no)=3/6=0.5
  • Raw: P(strong∣yes)=0/3 → yes-score =0; no-score =0.5⋅13⋅23=0.111
  • Laplace (c=2 for both attributes): P(sunny∣yes)=2+13+2=0.6, P(strong∣yes)=0+15=0.2; P(sunny∣no)=1+15=0.4, P(strong∣no)=2+15=0.6
  • yes: 0.5(0.6)(0.2)=0.06; no: 0.5(0.4)(0.6)=0.12 → play = no

P · Conditional independence proof (slides).

  • P(Y∣X,Z)=P(X∣Y,Z)P(Y∣Z)P(X∣Z)=P(X∣Z)P(Y∣Z)P(X∣Z)=P(Y∣Z)
  • P(X,Y∣Z)=P(X∣Y,Z)P(Y∣Z)=P(X∣Z)P(Y∣Z) ∎

Common Mistakes

  • Linear models: TrainLoss is an average; squared-loss gradient has factor 2; hinge gradient non-zero for m<1.
  • Perceptron: step(0) =1; update the bias too. Add gate passes the full gradient to every input; branches sum.
  • Conv sizes: 2×pad, floor, then +1; pooling has 0 parameters.
  • LSTM ht=ot⊙tanh⁡(Ct); attention divides by dk and sums values over j≤i.
  • k-means converges to a local minimum; PCA needs centering (and scaling), and uses the largest eigenvalue.
  • Bayes: compare P(x∣C)P(C), not P(x∣C) alone (the prior matters: covid example). These products are not posteriors unless divided by their sum.
  • Naive Bayes: P(xk∣Ci) divides by the class count NCi, not ∣D∣; Laplace adds c = number of values of that attribute, not number of classes.
  • Independence ≠ conditional independence (coin tosses).
