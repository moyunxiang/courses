0 · 这一讲在讲什么

线性代数研究的是**「域 K 上的向量空间」**。为了把「数」这件事说清楚，先用公理定义：

  1. Group（群）：一种运算，能「乘」也能「除」
  2. Ring（环）：两种运算，能加、减、乘，但不一定能除
  3. Field（域）：能加减乘除（除数非 0）的「数系」
  4. Vector space 定义的开头（下一讲继续）

这是本课唯一讲 abstract algebra 的地方（讲义 §1.1）。考试常见形式：判断某个集合加上某种运算是不是 group / ring / field，并说明违反了哪条公理；以及 ℚ(2)、ℤ/pℤ 里的具体运算（求逆元）。

1 · Group

Def. A group is a set G with a binary operation（product）

∗:G×G→G
s.t. ∀a,b,c∈G:

  1. (a∗b)∗c=a∗(b∗c) —— associativity
  2. ∃ 1∈G s.t. a∗1=1∗a=a —— identity
  3. ∀a∈G, ∃ b∈G s.t. a∗b=b∗a=1 —— inverse，记 b=a−1

要点：

  • binary operation G×G→G 本身就包含了「封闭」：两个元素运算的结果必须还在 G 里。判断题里先看这一条。
  • 注意没有要求 a∗b=b∗a。

1.1 例：Permutation（置换）

(1 2 3)∘(2 3)=(1 2)(1 2 3)∘(3 2 1)=1

怎么算：∘ 是函数复合，从右往左作用。(2 3) 先作用，(1 2 3) 后作用：

起点 经 (2 3) 再经 (1 2 3) 结果
1 1 2 1 → 2
2 3 1 2 → 1
3 2 3 3 → 3

所以结果是 (1 2)。(3 2 1) 是 (1 2 3) 反着转，两者复合回到恒等，所以 (1 2 3)−1=(3 2 1)。

1.2 例：Invertible n×n matrices

  • 可逆（det⁡≠0）矩阵的乘积 AB 仍可逆 → 运算封闭
  • 单位元 I；逆元 A−1，A⋅A−1=I
  • 这个群叫 GLn(ℝ)，general linear group

课件旁边的反例说明它不交换（两个结果不相等）：

(1101)(1011)=(2111)(1011)(1101)=(1112)

1.3 Abelian group

A group is abelian if 4. a∗b=b∗a∀a,b∈G

记号约定：abelian group 习惯用加法记号：

一般 group abelian group
a∗b a+b
1 0
a−1 −a

例：

  • (ℤ,+) integers
  • ℤ/12ℤ modular arithmetic（钟表加法）：6ˉ+8ˉ=14‾=2ˉ(mod12)
  • 讲义还列了：{ek:k∈ℤ} 在乘法下

Non-abelian 例：permutations（3 个或更多元素，复合）；GLn(ℝ)、SL(n,ℝ)（det⁡=1，n≥2）。

2 · Ring

Def. A ring is a set R with 2 binary operations：

+:R×R→R (addition)⋅:R×R→R (product)
∀a,b,c∈R:

加法部分（R 在 + 下是 abelian group）：

  • (+1) (a+b)+c=a+(b+c)
  • (+2) ∃ 0∈R s.t. a+0=0+a=a
  • (+3) ∀a∈R, ∃ b∈R s.t. a+b=b+a=0（b=−a）
  • (+4) a+b=b+a

乘法部分：

  • (·1) (a⋅b)⋅c=a⋅(b⋅c)
  • (·2) ∃ 1∈R s.t. a⋅1=1⋅a=a —— identity（no inverse！）
  • (·3) c⋅(a+b)=c⋅a+c⋅b，(a+b)⋅c=a⋅c+b⋅c —— distributive law

另外若 (·4) a⋅b=b⋅a，叫 commutative ring。

和 field 的区别一句话：ring 能加、减、乘，不要求能除（乘法没有逆元公理）。

为什么分配律要写两条？ 乘法不一定交换，左乘和右乘要分别规定。

2.1 例

Ring 说明
ℤ commutative ring；no inverse in general（2 在 ℤ 里没有乘法逆元）
ℚ,ℝ,ℂ 都是 ring（其实是 field）
ℝ[t]={antn+an−1tn−1+⋯+a1t+a0:ai∈ℝ} 多项式环，commutative
Mn×n(ℝ)（square matrices） noncommutative ring：AB≠BA（n≥2）

3 · Field

Def. A field is a set K with 2 binary operations +:K×K→K（addition）、⋅:K×K→K（product）s.t. ∀a,b,c∈K:

  • K is an abelian group under + ← can add / subtract
    • (+1) (a+b)+c=a+(b+c)；(+2) ∃0，a+0=0+a=a；(+3) ∀a，∃b，a+b=b+a=0（b=−a）；(+4) a+b=b+a
  • K∖{0} is an abelian group under ⋅ ← can multiply / divide（by ≠0）
    • (·1) (a⋅b)⋅c=a⋅(b⋅c)；(·2) ∃1，a⋅1=1⋅a=a；(·3) ∀a≠0，∃b，ab=ba=1（b=a−1）；(·4) a⋅b=b⋅a
  • Distributive：c⋅(a+b)=c⋅a+c⋅b

几个细节（讲义 Def 1.1）：

  • 讲义的 (∗2) 明确要求 1≠0——所以只有一个元素的集合 {0} 不是 field。课件写成「K∖{0} 是群」，也蕴含这一点（群非空，所以 K 至少有 0 和 1 两个元素）。
  • 为什么是 K∖{0}？0 没有乘法逆元（0⋅b=0≠1），必须去掉。
  • 一句话：field = 允许除法（非零元有逆）的 commutative ring。

3.1 例：ℚ,ℝ,ℂ

本课主要用这三个（特别是 ℝ、ℂ）。

3.2 例：ℚ(2)={a+b2:a,b∈ℚ}

难点是除法封闭：两个这种数相除，结果还能写成 a+b2 吗？方法是分母有理化（乘共轭）：

2+324+52=(2+32)(4−52)(4+52)(4−52)=8−102+122−3016−50=−22+22−34=1117−1172∈ℚ(2)

一般地：(a+b2)−1=a−b2a2−2b2。分母 a2−2b2≠0（只要 a,b 不全为 0），因为 2 是无理数——若 a2=2b2 且 b≠0，则 2=∣a/b∣∈ℚ，矛盾。

3.3 例：ℤ/7ℤ={0ˉ,1ˉ,2ˉ,3ˉ,4ˉ,5ˉ,6ˉ}(mod7)

运算举例：

2ˉ⋅5ˉ=3ˉ2ˉ+5ˉ=0ˉ2ˉ⋅4ˉ=1ˉ(mod7)

乘法逆元表（a⋅a−1=1(mod7)）：

a 1 2 3 4 5 6
a−1 1 4 5 2 3 6

（验算：2⋅4=8=1，3⋅5=15=1，6⋅6=36=1，都 mod 7。）

一般结论（讲义 Example 1.1）：ℤ/pℤ 当 p 是素数时是 field（finite field）。

为什么要素数？ 反例 ℤ/12ℤ：3ˉ⋅4ˉ=12ˉ=0ˉ。如果 3ˉ 有逆元 b，两边乘 b 得 4ˉ=0ˉ，矛盾。所以 ℤ/nℤ（n 合数）只是 commutative ring，不是 field。

3.4 其他例子（讲义）

  • 实系数的有理函数（rational functions）

4 · 三者关系总表

结构 运算 加法 乘法 能做什么
Group 1 种 —— 结合、单位元、逆元 「乘」和「除」
Abelian group 1 种 —— 再加交换 同上
Ring 2 种 abelian group 结合、单位元、分配律 加、减、乘
Commutative ring 2 种 abelian group 再加交换 同上
Field 2 种 abelian group K∖{0} 是 abelian group + 分配律 加、减、乘、除

判断题套路：按顺序检查

  1. 运算封闭吗？（结果在集合里吗）
  2. 结合律
  3. 单位元存在吗？（在这个集合里）
  4. 逆元存在吗？（每个元素的，且在集合里）
  5. 需要的话：交换律、分配律

一条不满足就举出具体反例。例如：

  • (ℕ,+) 不是 group：没有加法逆元（1 的 −1∉ℕ）
  • (ℤ,⋅) 不是 group：2 没有乘法逆元
  • ℤ 不是 field，是 commutative ring
  • M2×2(ℝ) 不是 field：不交换，且非零矩阵 (1000) 不可逆

5 · Vector space 的引入

Vectors 的两个基本操作（课件图）：

  • can add / subtract：𝐮+𝐯（平行四边形法则）
  • can scale：2𝐯、−12𝐯

Def. A vector space over a field K is a set V with 2 binary operations：

+:V×V→V (addition)⋅:K×V→V (scalar multiplication)
satisfying similar axioms to rings!

∀𝐮,𝐯,𝐰∈V，c,d∈K：

公理
(+1) (𝐮+𝐯)+𝐰=𝐮+(𝐯+𝐰)
(+2) ∃ 𝟎∈V，𝐮+𝟎=𝟎+𝐮=𝐮 Abelian group
(+3) ∀𝐮，∃ 𝐯 s.t. 𝐮+𝐯=𝐯+𝐮=𝟎（𝐯=−𝐮）
(+4) 𝐮+𝐯=𝐯+𝐮
(·1) (c⋅d)⋅𝐮=c⋅(d⋅𝐮)
(·2) 1⋅𝐮=𝐮
(·3) c⋅(𝐮+𝐯)=c⋅𝐮+c⋅𝐯，(c+d)⋅𝐮=c⋅𝐮+d⋅𝐮 Distributive law

和 ring 的区别：乘法不是 V×V→V，而是 K×V→V——标量乘向量。两个向量之间没有「乘法」。

7 · 易错点

  • 置换复合 σ∘τ 是先 τ 后 σ。
  • Ring 的乘法不要求逆元；field 的乘法逆元只对非零元素要求。
  • 只说「有单位元 / 有逆元」不够，要说明它们在这个集合里。
  • ℤ/nℤ 只有 n 为素数时才是 field。
  • Vector space 的标量乘法是 K×V→V，不是 V×V→V。
  • Field 要求 1≠0。
