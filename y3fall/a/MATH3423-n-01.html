0 · 这一讲在讲什么

  1. Statistical inference 是什么：用数据（data）对一个 random variable X 的分布下结论
  2. Parametric model：分布形式已知、参数 θ 未知
  3. Random sample：i.i.d. copies；联合 pdf / pmf = 乘积
  4. Statistic / estimator / estimate 的区别
  5. 整门课的路线图：点估计（MME、MLE）→ 性质（有限样本 / 大样本）→ 区间估计 → 假设检验

必会：判断某个式子是不是 statistic（含未知参数就不是）；estimator（随机变量）vs estimate（数）；写出 random sample 的联合 pdf；Xˉ 在正态 / Binomial 下的精确分布。

1 · 什么是 Statistical Inference

  • Statistical = data；Inference = 从已知证据得出关于「某个东西」的结论
  • 「某个东西」= random variable X——在做随机试验之前不可预测（uncertainty），例如抛硬币
  • 怎么描述 X？用 probability distribution
类型 例子
离散 Poisson、Binomial、discrete uniform、multinomial、geometric（negative binomial 的特例）、hypergeometric
连续 normal、continuous uniform、exponential（gamma 的特例）、beta、chi-square（gamma 的特例）、Cauchy（t 的特例）、F

这些都叫 parametric distributions。

Mission：用数据的信息去估计目标 random variable 的 parametric distribution 的参数。

（手写笔记的例子：X∼N(μ,1)，μ 未知——要通过 (i) parameter estimation、(ii) hypothesis testing 去了解 μ。如果 μ 已知，比如 X∼N(0,10)，那 P(X>0)=0.5 之类直接算就行，不需要推断。）

2 · Data 与 Parametric Model

Data：目标 rv X 的实际值，X 的分布没有被完全确定。

  • x1,…,xn：n 个 observations / data / realizations
  • 抽样之后它们都是已知的数
模型 含义
Fully unspecified pdf / pmf 没有显式形式 → non-parametric model
Not fully specified / partially specified pdf / pmf 的函数形式已知，但由未知参数 θ 决定 → parametric model（本课先学这个）

例：N(μ,1)，μ∈ℝ 未知。θ 通常表示参数（可以是向量，如 θ=(μ,σ2)）。

3 · Random Sample

除非另有说明，X1,…,Xn 假设 i.i.d.（independent and identically distributed）；xi 是第 i 个 copy Xi 的实际值。

Random sample（rs） = X 的一组 i.i.d. copies。

联合 pdf（连续）：

fX1,…,Xn(x1,…,xn∣θ)=∏i=1nfX(xi∣θ)

联合 pmf（离散）：pX1,…,Xn(x1,…,xn∣θ)=∏i=1npX(xi∣θ)

（第一个等号用 independence 拆成各自边际的乘积，第二步用 identically distributed 把每个 fXi 换成同一个 fX。）

4 · Statistic、Estimator、Estimate

Statistic：random sample 的函数，不含未知参数。

Xˉ=1n∑i=1nXi,Sn−12=1n−1∑i=1n(Xi−Xˉ)2都是 statistic
1n∑i=1n(Xi−μ)2不是 statistic（除非 μ 已知）
名词 是什么 例子
(Point) estimator T(𝐗) 用来估计 θ 的 statistic——随机变量 Xˉ
Estimate T(𝐱) 代入数据后的实际值——一个数 xˉ
θ^ 两者都常用这个记号

（手写：X1,…,Xn 取平均 → Xˉ，随机变量；x1,…,xn 取平均 → xˉ，一个数。）

5 · 拿到 estimator 之后做什么（课程路线图）

  1. 研究 T 的性质：unbiasedness（有限样本）、convergence（大样本）
  2. 区间估计：构造一个区间而不是一个点
  3. 假设检验：对参数的取值构造统计检验

估计方法：

  • 总体均值 / 方差 → 样本均值 / 方差
  • 一般参数 → 系统方法：(i) Method of Moment Estimation、(ii) Maximum Likelihood Estimation

性质的工具：

大样本 非大样本
WLLN、CLT、convergence in probability / distribution、Slutsky's lemma、delta method、continuous mapping theorem Bootstrapping（对手上这一组数据重抽样）

区间估计和假设检验都需要先知道 estimator 的精确或近似分布。

6 · 例：Xˉ 的分布（手写笔记 p.2）

独立 Binomial 之和：若 Xi∼Binomial(mi,p) 独立，则 ∑Xi∼Binomial(∑mi,p)。

  • X∼Binomial(m,p) 的 rs：X1+⋯+Xn∼Binomial(mn,p)

独立正态之和：X∼N(μ,σ2) 的 rs：

X1+⋯+Xn∼N(nμ,nσ2)  ⇒  Xˉ∼N(μ,σ2n)

（方差：Var(∑Xi)=∑Var(Xi) 用了独立。）

  • 一般分布没有这么好的精确结果 → CLT 给大 n 时 Xˉ 分布的近似

7 · 考点清单

考点 至少要会
是不是 statistic 含未知参数就不是
estimator vs estimate 随机变量 vs 数
parametric vs non-parametric 函数形式是否已知
random sample i.i.d.；联合 pdf = 乘积（说明每一步用了哪个假设）
Xˉ 的精确分布 正态 → N(μ,σ2/n)；Binomial 之和
路线图 MME / MLE；有限 / 大样本性质；CI；检验

8 · 易错点

  • 1n∑(Xi−μ)2 在 μ 未知时不是 statistic。
  • Xˉ 是随机变量，xˉ 是数；写 CI 时先有随机区间，代入数据才得到 CI（见 02-1）。
  • 联合 pdf 拆成乘积要同时用 independence 和 identically distributed。
  • 只估计未知参数；已知的参数不用估。
