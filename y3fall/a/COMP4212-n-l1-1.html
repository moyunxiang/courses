2 · RL Background

2.1 什么是 RL

三类 machine learning：supervised、unsupervised、reinforcement。

Reinforcement Learning：Learning through experience / data to make good decisions under uncertainty（Trial-and-Error Learning）

Mathematical paradigm for learning to act via trial and error.

Supervised Learning Reinforcement Learning
给定数据集，找出能预测 label 的规律 Sequential decision-making：观察世界 → 行动 → 观察 → 行动 → …
一般假设数据 i.i.d. 数据不是 i.i.d.
之前的预测不影响其他预测 之前的 action 决定以后的问题有多难
通常是一步的问题 多步、序列

为什么「数据不是 i.i.d.」很关键？ RL 里 agent 自己的行为决定了它接下来看到什么数据（走到哪里就只能看到哪里）。数据分布随 policy 改变，这让学习和评估都更难。

2.2 Why RL：standard ML models the data

普通 ML 是对数据建模（预测）；本课目标是 Learning to Act：

  • 构建能在动态环境中学会行动、完成目标的 agent
  • 而不是在静态环境里执行预先编好行为的 agent

2.3 RL 从哪来

  • 哲学问题：行为是怎样形成的？由 reinforcement 还是 free will？
  • B.F. Skinner：带来奖赏 / 愉悦的行为倾向于重复；带来惩罚 / 痛苦的行为倾向于消失

2.4 SL vs RL：反馈的类型

Supervised learning Reinforcement learning
学什么 从 expert demonstrations 学：专家直接告诉你正确的 action 从 rewards 学：环境给出 evaluative feedback（这个 action 好还是不好）
导师比喻 导师直接告诉你哪些 idea 值得做 导师只告诉你你的 idea 值不值得做（不告诉你别的 idea）
跳高比喻 Fosbury 示范了背越式轨迹后，运动员很快学会 只说「跳得越高越好」，花了很多年才发现背越式

关键区别：SL 的反馈是 instructive（告诉你正确答案），RL 的反馈是 evaluative（只告诉你好坏），所以 RL 必须自己去试。

2.5 RL 的代表性成果

  • Go：Mastering the Game of Go without Human Knowledge（Nature 2017），超越人类
  • ChatGPT（RLHF）
  • 兴趣暴涨（Deep RL that Matters，AAAI 2018），但也有争议
  • RL in 2025：DeepSeek-R1-Zero（纯大规模 RL、不先做 SFT 就有很强的推理能力）；Google DeepMind 在 IMO 拿到 35/42 金牌分；Pi 的咖啡机器人

3 · Basic RL Concepts

3.1 Sequential decision making

  • Goal：选择 action，最大化总的期望未来 reward（total expected future reward）
  • 可能要在短期和长期 reward 之间权衡（为了以后更多 reward，现在可能要牺牲一点）

3.2 Agent 与 Environment

每一步 t：

Agent Environment
收到 observation ot 收到 action at
收到 scalar reward rt−1 发出 observation ot+1
执行 action at 发出 scalar reward rt

t 在环境走一步时加 1。

3.3 History 与 State

History 是 observations、actions、rewards 的序列：

ht=o1,a1,r1,…,rt−1,ot,at,rt
即到时刻 t 为止的全部可观测变量。

  • 接下来发生什么取决于 history：agent 选 action，environment 选 observation / reward
  • State 是用来决定下一步发生什么的信息
  • 形式上，state 是 history 的函数：st=f(ht)

为什么不直接用 history？ History 随时间无限变长，不方便存储和计算；state 是对它的压缩。

3.4 Environment state vs Agent state

Environment state ste Agent state sta
是什么 环境的私有表示：环境用来产生下一个 observation 和 reward 的数据 agent 的内部表示：agent 用来选下一个 action 的信息
可见吗 通常看不到；即使看得到也可能有很多无关信息 就是 RL 算法用的信息
形式 可以是 history 的任意函数 sta=f(ht)

3.5 Rewards

  • RL：通过与世界交互，学习最大化 reward function 的 policy
  • Reward rt 是一个 scalar feedback signal，表示 agent 在第 t 步做得怎样
  • Agent 的任务是最大化 cumulative reward

Reward hypothesis（课件标「Arguable?」，有争议）：All goals can be described by the maximization of expected cumulative reward.

3.6 Markov State

Definition. A state st is Markov if and only if

p(st+1∣st)=p(st+1∣s1,…,st)

  • Markov state 包含 history 中所有有用的信息
  • 「The future is independent of the past given the present.」
  • h1:t→st→ht+1:∞：一旦知道 state，history 就可以丢掉
  • 即 state 是未来的 sufficient statistic
  • 环境 state ste 是 Markov 的；history ht 也是 Markov 的（ht 包含一切，当然足够）

为什么 Markov 假设这么流行？

  • 简单；把一部分 history 放进 state 通常就能满足
  • 实践中常假设最近一次 observation 就是 history 的 sufficient statistic：st=ot
  • State 表示的选择对三件事影响很大：computational complexity、data required、resulting performance

（例：Atari 游戏只看一帧画面不知道球往哪飞，通常把最近几帧叠起来当作 state。）

3.7 Fully vs Partially Observable

Fully observable Partially observable
观测 agent 直接观测到环境 state agent 间接观测
关系 sta=ste（agent state = environment state） sta≠ste
形式化 MDP（Markov decision process） POMDP（partially observable MDP）
agent state 就是环境 state 必须自己构造，如完整 history sta=ht，或 RNN sta=σ(st−1aWs+otWo)

（例：扑克牌只能看到自己的牌，是 partially observable；下棋看得到整个棋盘，是 fully observable。）

3.8 Maze 例子

  • Action：N、E、S、W；Reward：每走一步 −1；State：agent 的位置
  • Q：full 还是 partial observability？——state 是 agent 的位置，如果 agent 知道自己在哪，就是 fully observable（每步 −1 意味着要尽快走出迷宫）
  • Policy：图中每个格子画一个箭头，表示 π(s)
  • Value function：每个格子写一个数 Vπ(s)（离出口越远越负，例如出口旁边是 −1）
  • Model：agent 内部对环境的模型——dynamics（action 怎样改变 state）、rewards（每个 state 给多少 reward）；模型可能不完美

3.9 RL agent 的三个主要组成部分

An RL agent may include one or more of these components：

  • Policy：agent 的 behavior function
  • Value function：每个 state 和 / 或 action 有多好
  • Model：agent 对环境的表示

Policy

  • policy 是 agent 的行为，是从 state 到 action 的映射
  • Deterministic policy：a=π(s)
  • Stochastic policy：π(a∣s)=p(at=a∣st=s)
  • （Q：为什么要 deep RL？——state 空间太大时，没法用表格存 π，要用神经网络近似）

Value function

  • 对未来 reward 的预测，用来评价 state 的好坏，进而在 action 之间做选择：
Vπ(s)=𝔼π[rt+γrt+1+γ2rt+2+⋯ ∣ st=s]
  • γ 是 discount factor

Model

  • 预测环境下一步会做什么：𝒫 预测下一个 state，r(⋅) 预测下一个（immediate）reward：
𝒫(s′∣s,a)=p(st+1=s′∣st=s,at=a)r(s,a)=𝔼[rt∣st=s,at=a]

3.10 RL agent 的分类

分类 Policy Value Function Model
Value-based 无（implicit，由 value 推出） ✓
Policy-based ✓ 无
Actor-critic ✓ ✓
Model-free policy 和 / 或 value 无
Model-based policy 和 / 或 value ✓

（value-based / policy-based / actor-critic 看「有没有 policy、有没有 value」；model-free / model-based 看「有没有 model」，两种分法是正交的。）

3.11 Learning vs Planning

序列决策的两个基本问题：

Reinforcement Learning Planning
环境 一开始未知 环境的 model 已知
做法 agent 与环境交互 agent 用 model 计算（不需要外部交互）
结果 改进 policy 改进 policy
Atari 例子 游戏规则未知；直接从交互中学；按摇杆、看像素和分数 规则已知；可以查询模拟器（脑中有完美模型）；「在 s 做 a，下一个 state 和分数是什么？」；提前规划出最优 policy（如 tree search）

3.12 Exploration vs Exploitation

  • RL 像 trial-and-error learning：agent 要从对环境的经验中发现好的 policy
  • Exploration：找到更多关于环境的信息
  • Exploitation：利用已知信息来最大化 reward
  • 通常两者都重要

（例：去常去的餐厅 = exploitation；试一家新餐厅 = exploration。只 exploit 可能永远发现不了更好的；只 explore 浪费太多。下一讲的 multi-armed bandit 专门研究这个权衡。）

4 · 与其他 ML 方法比较

4.1 RL 的特点

  • 没有显式 / 密集的 supervision，只有 reward signal
  • 反馈是延迟的，不是即时的
  • 时间很重要（序列、非 i.i.d. 数据）
  • Agent 的 action 影响它之后接收到的数据
  • Active learning（自己收集数据）

4.2 对比表（考试重点）

Plan SL UL RL IL
Policy Optimization ✓ ✓ ✓
Learning from Experience ✓ ✓ ✓ ✓
Generalization ✓ ✓ ✓ ✓ ✓
Delayed Consequences ✓ ✓ ✓
Exploration ✓

（Plan = AI Planning，SL = Supervised，UL = Unsupervised，IL = Imitation Learning）

  • AI planning 假设已经有「决策如何影响环境」的 model（所以不需要从经验中学，也不需要探索）
  • Supervised learning 能拿到正确的 labels
  • Unsupervised learning 没有 labels
  • Imitation learning 通常假设输入是好 policy 的示范；IL 把 RL 化归为 SL，因为很多原因 IL 很流行
  • 只有 RL 需要 exploration——这是 RL 最独特的地方

4.3 RL 的局限

  • Agent 必须有机会试很多次（而且失败）
    • episode 太长时不可能（reward =「拿到一个好 PhD」）
    • 安全攸关时不可能（不能在真实世界用 RL 学开车，失败不可容忍）

4.4 AlphaGo 的世界 vs 真实世界

AlphaGo 真实世界
已知环境（已知实体和动态） 未知环境
行为要能在多样的环境变化间迁移
一个目标 多个目标
reward 由 oracle 环境自动给出 reward 需要自己检测
交互需要时间：真的需要聪明的 exploration

6 · 易错点

  • Agent 在第 t 步收到的 reward 记作 rt−1（上一个 action 的结果），环境在第 t 步发出的是 rt。
  • History 是 Markov 的，但通常不实用；Markov 性说的是「给定当前 state，未来与过去无关」，不是「未来与过去无关」。
  • Fully observable 对应 MDP；partially observable 对应 POMDP，此时 agent state ≠ environment state。
  • Value-based 方法没有显式 policy（由 value 取 argmax 得到）；policy-based 方法没有 value function。
  • Model-free / model-based 是另一个维度，和 value / policy 的分法不冲突。
  • AI planning 不需要 exploration，因为 model 已知；imitation learning 也不 explore，因为有示范。
