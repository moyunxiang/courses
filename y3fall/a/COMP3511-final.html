T1 Semaphore fill-in: bounded buffer / readers-writers

Steps: count semaphores = resources (empty = free slots, full = items) → mutex around the buffer → wait on the counting semaphore before mutex.

Example (自编题): buffer n=5 holding 2 items.

mutex=1, empty=5−2=3, full=2
  • Producer with wait(mutex); wait(empty); and a full buffer: holds mutex, sleeps on empty; the consumer sleeps on mutex ⇒ deadlock (F26 HW3 Q3.1(c)).
  • Readers-writers trace: writer inside, R1 then R2 arrive ⇒ R1 on rw_mutex, R2 on mutex, read_count =1 (HW3 Q3.2(a)).
  • S26 Q3.1 (writer-priority with HIGH / NORMAL writers): each blank is a guard condition. A new reader enters only if no writer is active or waiting and no reader batch is being released. Only the last reader (activeReaders == 0) calls schedule_next(). A NORMAL writer also waits while any HIGH writer is waiting.

T2 RAG: deadlock or not

Steps: find cycles → all resources in the cycle single-instance? ⇒ deadlock. Multi-instance ⇒ try to reduce: grant any process whose requests can be met, release its resources, repeat.

Example (自编题): R1 (1 instance), R2 (2 instances). P1 holds R1 and requests R2; P2 holds R2 and requests R1; P3 holds R2.

cycle P1→R2→P2→R1→P1;P3 finishes⇒R2 free→P1→P2⇒𝐧𝐨 𝐝𝐞𝐚𝐝𝐥𝐨𝐜𝐤
  • Matrices from a RAG (S26 Q3.2): Allocation = assignment edges, Request = request edges, Available = instances − allocated.

Common Mistakes

  • Cycle in a RAG ≠ deadlock when a resource has several instances; reduce the graph first.
  • Banker: compare Need (avoidance) vs Request (detection); after a process finishes add its Allocation, not its Max. A granted-but-unsafe request must be rolled back.
  • Unsafe ≠ deadlocked: unsafe only means deadlock is possible.
  • Bounded buffer: wait(empty) / wait(full) before wait(mutex); signal order does not matter.
  • Segmentation: offset = limit is already illegal (d<limit).
  • TLB miss with a k-level table costs k+1 memory accesses (plus ε); the 2-level walk stops at an invalid PDE.
  • Physical address: concatenate frame and offset (f×2n+d); do not add the page number.
  • OPT: next use counted from the current position; follow the stated tie rule. Do not count hits right after a fault as faults.
  • Thrashing ⇒ decrease multiprogramming; PFF too high ⇒ add frames.
  • Disk: rotational latency is half a rotation; SCAN goes to the disk end, LOOK does not; C-SCAN in S26 counts the return jump.
