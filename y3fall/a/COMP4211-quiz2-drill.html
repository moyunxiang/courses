Part II · Answers

A · Neurons and perceptrons

  1. Dendrite → cell body (soma, with nucleus) → axon → synapse.
  2. Pulses arrive simultaneously → they are added → if strong enough, an electrical pulse goes down the axon → transmitters are released at the synapses.
  3. Units, links, weights. Input, hidden and output units.
  4. The weights.
  5. Feedforward: no cycles; the output depends only on the current input. Feedback (recurrent): has cycles; the output also depends on earlier state.
  6. A feed-forward network with one layer of adjustable weights connected to one or more threshold output units.
  7. O=step(∑j=1nwjIj−θ). With w0=−θ and I0=1: O=step(∑j=0nwjIj).
  8. step(x)=1 if x≥0, else 0, so step(0) = 1.
  9. AND: W=1,1, t=1.5. OR: W=1,1, t=0.5. NOT: W=−1, t=−0.5.
  10. Exactly the linearly separable ones. XOR's classes sit on opposite diagonals, so no line separates them.
  11. Every Boolean function can be written in DNF or CNF, and AND, OR, NOT are each perceptrons: one layer computes the conjuncts, the next their OR.
  12. wj←wj+αIj(T−O) for all j, including I0=1. It changes nothing when T=O.
  13. 𝐰=(1,−3,4). Boundary I2=34I1−14: slope 34, intercept −14.
  14. If the training examples are linearly separable, the rule converges to a solution in finitely many steps, for any initial weights.

B · Adaline and gradient descent

  1. A feed-forward network with one layer of adjustable weights connected to linear output units. In statistics it is linear regression.
  2. Its output unit is linear (not a threshold). It is trained by gradient descent on squared error, so it converges even when the data are not separable.
  3. Its error surface is quadratic (a bowl), so there is a single global minimum.
  4. E=12∑d(td−od)2, and wi←wi+η∑d(td−od)xid.
  5. It overshoots the minimum and oscillates or diverges. Remedies: decrease η over time (a schedule); tune η on a small subset first, then use it on the full set.
  6. Batch GD (all samples per update): accurate but slow. SGD (1 sample): fast but fluctuates, needs a smaller step. Mini-batch (b samples): a compromise.

C · MLP, activations, losses

  1. y3=step(x1+x2−1.5) (an AND unit), y=step(x1+x2−2y3−0.5).
  2. Linear layers collapse: W2W1x=(W2W1)x is one layer. Step is not differentiable, so gradient descent cannot be used.
  3. σ(x)=11+e−x, σ′(x)=σ(x)(1−σ(x)).
  4. exp⁡ ⁣(−(𝐱−𝐰j)⊤(𝐱−𝐰j)2σj2). Its response is local (significant only near 𝐰j); a sigmoid is non-zero over an infinite region.
  5. max⁡(0,x), with gradient 1 if x>0 and 0 if x≤0. Advantages: cheap to compute; sparse activation. Problem: the gradient can be 0.
  6. One layer of sigmoid hidden units can approximate any well-behaved function to arbitrary accuracy.
  7. Multi-class: one output per class, predict arg⁡max⁡iyi. Binary: one output, yes if y>0, no if y≤0.
  8. H(X)=−∑xp(x)log⁡p(x) with 0log⁡0=0. With base 2 the unit is bits. 0≤H≤log⁡n: 0 when one outcome has probability 1, log⁡n when uniform.
  9. 0.94. A pure set has entropy 0; a 50/50 set has entropy 1.
  10. Codes 0 / 10 / 110 / 111, with expected length 1.75 bits =H. A fixed-length code (00/01/10/11) needs 2 bits.
  11. H(p,q)=−∑ipilog⁡qi: the average number of bits to code messages from p using a code built for model q. It is not symmetric, and H(p,p)=H(p).
  12. qi=eαi/∑keαk.
  13. −log⁡qc (c = true class). Binary: −∑i[tilog⁡f(xi;w)+(1−ti)log⁡(1−f(xi;w))].

D · Backpropagation

  1. It is gradient descent: compute the gradient of the loss with respect to every weight and step the opposite way. Differentiable activations make the output differentiable, so the error is a differentiable function of the weights.

  2. ∂E∂wi=−(t−o) o(1−o) xi, and wi←wi+η(t−o)o(1−o)xi.

  3. dℒdy=y−t; dℒdz=dℒdyσ′(z); ∂ℒ∂w=dℒdzx; ∂ℒ∂b=dℒdz.

  4. Forward: for i=1..N in topological order, compute vi from its parents. Backward: vˉN=1; for i=N−1..1,

    vˉi=∑j∈Ch(vi)vˉj ∂vj∂vi

  5. ex→ex; ax→a; 1/x→−1/x2; c+x→1; σ→σ(1−σ).

  6. Add: distributor (each input gets the full upstream gradient). Max: router (all to the larger input). Mul: switcher (upstream × the other input). Branch: gradients add.

  7. q=3, f=−12; ∂f/∂x=−4, ∂f/∂y=−4, ∂f/∂z=3.

  8. Output 0.73. Gradients: w0=−0.20, x0=0.40, w1=−0.40, x1=−0.60, w2=0.20. As one sigmoid gate: 0.73×0.27≈0.20.

  9. Initialise with small random values. Stop after a fixed number of iterations, when the training error is below a threshold, or at the minimum of the validation error. Momentum: Δw(t+1)=−η ∂E/∂w+αΔw(t), α≈0.9. GD guarantees only a local minimum.

E · Convolution and CNNs

  1. A picture is worth a thousand words, and there is a huge amount of image and video data. Typical task: object recognition. Applications: real-time object detection, self-driving trucks, face recognition / paying with your face, biometrics.

  2. Flipped (true convolution): S(i,j)=∑m∑nI(i−m,j−n)K(m,n). NNs (cross-correlation, still called "convolution"): S(i,j)=∑m∑nI(i+m,j+n)K(m,n), with no flip.

  3. 19 times a 3×3 matrix of ones (neighbourhood average) blurs and denoises; a larger window blurs more. Sharpening ↔ differentiation, f(x+1)−f(x); averaging ↔ integration.

  4. (−101) in each row (horizontal difference) → vertical edges. (−101) in each column (vertical difference) → horizontal edges.

  5. Hout=⌊(Hin+2pad−K)/stride⌋+1. pad 0, stride 1 → 6; pad 1, stride 1 → 8; pad 1, stride 2 → 4.

  6. Co×Ci×Kh×Kw (+Co biases); it does not depend on H,W. 16×3×3×3=432 weights (+16 biases); a 3×64×64 input gives a 16×64×64 output.

  7. Sparse connectivity: each unit connects to a local receptive field, which grows with depth. Parameter sharing: the same kernel is used everywhere, so the network is robust to shifts. 1×1 conv: mixes channels only, used for dimension reduction. Efficiency table: convolution stores 2 numbers; a dense matrix >8×109; a sparse matrix 2⋅319⋅280=178,640.

  8. Nonlinearity: convolution is linear, so stacked layers would collapse. Padding: stops each layer shrinking. Pooling: spatial invariance (the "7" example) and downsampling; no parameters. One complex layer = convolution → detector (ReLU) → pooling. Architecture:

    2562×3→2562×64→642×64→642×64→162×64=16,384→1000→softmax
