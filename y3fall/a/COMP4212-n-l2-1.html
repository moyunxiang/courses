0 · 这一讲在讲什么

不知道 MDP 的 p、r，怎样评估一个 policy（估计 Vπ）？答案是采样：用采样到的 return 的平均来代替期望。

  1. Introduction：从 DP 到 model-free
  2. Monte-Carlo learning：first-visit / every-visit、incremental 更新、Blackjack
  3. Temporal-Difference learning：bootstrapping、TD(0)、TD target / TD error、Driving Home、bias / variance、batch MC vs TD（AB 例子）、DP / MC / TD 的统一视角
  4. TD(λ)：n-step return、λ-return

必考：MC 与 TD(0) 的更新式；TD target、TD error；MC vs TD 的优缺点（bias / variance、online、incomplete episode、Markov 性）；Driving Home 两种方法各自的更新量；AB 例子 MC 给 V(A)=0、TD 给 V(A)=0.75 及原因；bootstrapping / sampling 表；n-step return 和 λ-return 的公式与权重。

1 · Introduction

到目前为止，估计 value function 用的是 DP，需要已知 reward 和 dynamics：

Vπ,[k+1](s)=∑aπ(a∣s)(r(s,a)+γ∑s′p(s′∣s,a)Vπ,[k](s′)),∀s

接下来：直接从交互经验中估计 value function 和 policy，不需要已知 dynamics。怎么做？——Sampling! 不用概率分布算期望，而是对采样到的 return 取平均来估计期望。

2 · Monte-Carlo Learning

2.1 MC policy evaluation

  • Goal：从 policy π 下的 episodes 学 Vπ：s1,a1,r1,s2,a2,r2,⋯∼π
  • Return：Gt=rt+γrt+1+⋯+γT−trT
  • Value：Vπ(s)=𝔼[Gt∣st=s]
  • MC 用 empirical mean return 代替 expected return

MC 的特点：

  • 直接从 episodes 学（experience → values、policy）
  • 最简单的想法：value = mean return
  • Model-free：不需要 MDP 转移 / reward 的知识
  • 从完整的 episode 学：no bootstrapping
  • Caveat：只能用在 episodic MDP（所有 episode 都必须终止）——不终止就没有 Gt

2.2 First-visit vs Every-visit

Idea：对访问 s 之后观察到的 return 取平均。

First-Visit MC Every-Visit MC
一个 episode 中第一次访问 s 的时刻 t 一个 episode 中每次访问 s 的时刻 t
N(s)←N(s)+1 N(s)←N(s)+1
S(s)←S(s)+Gt S(s)←S(s)+Gt
V(s)=S(s)/N(s) V(s)=S(s)/N(s)

两者都收敛：由大数定律，N(s)→∞ 时 V(s)→Vπ(s)。

算法框（课件 Q：这是 first-visit 还是 every-visit？）：

Input π；初始化 V(s) 任意，Returns(s)← 空列表

Loop forever（for each episode）：

  • 按 π 生成 episode：S0,A0,R1,S1,A1,R2,…,ST−1,AT−1,RT
  • G←0
  • Loop for each step，t=T−1,T−2,…,0：
    • G←γG+Rt+1
    • Unless St appears in S0,S1,…,St−1：Append G to Returns(St)；V(St)←average(Returns(St))

A：First-visit MC——因为有「Unless St appears in S0,…,St−1」：前面出现过就跳过，只记第一次。

注意算法从后往前算：G←γG+Rt+1 一次就能递推出每个时刻的 return。

2.3 Incremental MC

均值可以增量计算（1.2 讲过）。每个 episode 结束后，对每个 st 及其 return Gt：

N(st)←N(st)+1V(st)←V(st)+1N(st)(Gt−V(st))

Non-stationary 问题中常用 running mean（忘掉旧的 episode），用固定 step size α：

V(st)←V(st)+α(Gt−V(st))

（固定 α 时，越旧的样本权重按 (1−α)k 指数衰减。）

2.4 例：Blackjack（S&B Ch5 p.93）

  • Goal：手牌点数之和尽量大但不超过 21；人头牌算 10，ace 可算 1 或 11
  • stick：停止要牌（结束）；draw：再要一张牌
  • Reward：stick 时，比庄家大 / 相等 / 小 → +1 / 0 / −1；draw 时爆牌（>21）→ −1 并结束，否则 0
  • Transitions：点数 < 12 时自动要牌
  • Q：多少个 state？200 个：
    • 当前点数（12–21）：10 种
    • 庄家明牌（ace–10）：10 种
    • 有没有「usable ace」（能算 11 而不爆）：2 种
    • 10×10×2=200

Policy：点数 ≥ 20 就 stick，否则 draw。MC 学到的 value function 图（10,000 / 500,000 个 episode）：

  • Observation：上面一行（有 usable ace）比较「少见」，所以曲面更颠簸（样本少，估计方差大）
  • 点数 20、21 时 value 高（policy 在这里 stick）

2.5 MC 相对 DP 的优势

  • 环境未知时也能用
  • 即使完全知道 dynamics，用采样的 episode 也有很大优势——例如转移概率很难算的时候（Blackjack 的 p 很难写出来，但模拟一局很容易）
  • 估计单个 state 的 value 的成本与 state 总数无关：从感兴趣的 state 出发采样 episode，平均 return 即可

2.6 MC 估计 action values

  • 没有 model 时，**估计 action values（state-action 对的 value）**特别有用（因为 1.3 讲过：只有 V 时选 action 需要 model，有 Q 就不需要）
  • 问题：很多 state-action 对可能从来没被访问（deterministic policy 在每个 state 只选一个 action）
  • Exploring starts：指定 episode 从某个 state-action 对开始，并且每个对都有非零概率被选为起点

3 · Temporal-Difference Learning

3.1 Bootstrapping

  • 字面：「拉着自己的鞋带把自己提起来」
  • 在 RL 里：在更新某个估计值时，用到了同类的估计值

3.2 从 MC 到 TD(0)

Every-visit MC：把 V(st) 往实际 return Gt 更新：

V(st)←V(st)+α(Gt⏟target：时刻 t 之后的实际 return−V(st))

TD(0)：把 V(st) 往估计的 return 更新：

V(st)←V(st)+α[rt+γV(st+1)−V(st)]
  • TD target：rt+γV(st+1)（对 return 的估计）
  • TD error：δt=rt+γV(st+1)−V(st)

TD 的特点：

  • 直接从 episodes 学；model-free
  • 从不完整的 episode 学，靠 bootstrapping：TD updates a guess towards a guess

为什么 TD target 合理？ Bellman expectation equation 说 Vπ(s)=𝔼[rt+γVπ(st+1)]。TD 用一个采样的 (rt,st+1) 代替期望，用当前估计 V 代替 Vπ。

3.3 例：Driving Home（S&B Ch6 p.122）

State Elapsed Time（分钟） Predicted Time to Go Predicted Total Time
leave office 0 30 30
reach car, raining 5 35 40
exit highway 20 15 35
2ndary road, behind truck 30 10 40
entering home street 40 3 43
arrive home 43 0 43

两种方法建议的修改（α=1，修改的是 predicted total time）：

State 原预测 MC：改成最终实际结果 43 TD：改成下一个 state 的预测
leave office 30 +13 → 43 +10 → 40
reach car 40 +3 → 43 −5 → 35
exit highway 35 +8 → 43 +5 → 40
behind truck 40 +3 → 43 +3 → 43
home street 43 0 0
  • MC：要等到家（episode 结束）才知道 43，才能更新
  • TD：每走一步就能更新（例如刚到车边发现下雨，立刻把出发时的预测 30 往 40 调）

3.4 MC vs TD：何时能学

TD MC
在知道最终结果之前就能学 要等 episode 结束、return 已知
每一步之后在线学
能从不完整序列学 只能从完整序列学
能用于continuing（不终止）环境 只能用于 episodic（终止）环境

3.5 Bias / Variance trade-off（重点）

  • Return Gt=rt+γrt+1+⋯+γT−trT 是 Vπ(st) 的无偏估计
  • 真正的 TD target rt+γVπ(st+1) 也是无偏估计
  • 实际用的 TD target rt+γV(st+1) 是有偏估计（V 只是当前估计，不等于 Vπ）
  • TD target 的方差比 return 小得多：
    • return 依赖很多随机的 action、transition、reward
    • TD target 只依赖一个随机的 action、transition、reward
MC TD
Variance high low
Bias zero some
收敛性 好（即使用 function approximation） TD(0) 收敛到 Vπ(s)（但用 function approximation 不一定）
对初值 不敏感 更敏感（因为 bootstrap 用到初值）
其他 非常简单易用 通常比 MC 更高效

3.6 例：Random Walk（S&B Ch6 p.125）

  • MRP：A B C D E 五个 state，从 C 出发，等概率左右走；左端终止 reward 0，右端终止 reward 1，其他 0
  • 真实 value：A 到 E 依次为 16,26,36,46,56（= 从该处最终走到右端的概率）
  • 图：TD 估计随 episode 数逐渐接近真值；empirical RMS error：TD 比 MC 下降得更快（各种 α 下 TD 曲线都在 MC 下方）

3.7 Batch MC 与 TD

  • MC 和 TD 都收敛：experience → ∞ 时 V(s)→Vπ(s)
  • 但有限经验下的 batch 解呢？ 有 K 个 episode，反复从中采样 episode k∈[1,K] 训练，直到收敛

3.8 例：AB（S&B Ch6 p.127，考试常考）

两个 state A、B；无 discount；8 个 episode：

  • {A,0,B,0}（从 A 出发，reward 0 到 B，再 reward 0 结束）
  • {B,1} × 6
  • {B,0} × 1

Q：V(A)、V(B) 是多少？

  • V(B)：B 出现 8 次，return 为 1 的有 6 次 ⇒ V(B)=6/8=0.75（两种方法一致）
  • V(A)：两种方法不同

MC：minimize mean-squared error

  • MC 收敛到对观察到的 return 最小均方误差的解（best fit to the observed returns）：
∑k=1K∑t=1Tk(Gtk−V(stk))2
  • A 只出现一次，那次 return 是 0 ⇒ V(A)=0

TD：certainty equivalence

  • TD(0) 收敛到最大似然 Markov 模型的解——即最能拟合数据的 MDP ⟨𝒮,𝒜,𝒫,ℛ,γ⟩：
p^(s′∣s,a)=1N(s,a)∑k=1K∑t=1Tk𝟙(stk,atk,st+1k=s,a,s′)
r^(s,a)=1N(s,a)∑k=1K∑t=1Tk𝟙(stk,atk=s,a) rtk

（课件的 r^ 式子漏了因子 rtk，没有它求出来的是频率而不是平均 reward。）

  • 数据中 A 100% 以 reward 0 转到 B ⇒ $V(A) = 0 + V(B) = $ 0.75

谁对？ 如果过程真的是 Markov 的，TD 的答案（0.75）更合理：A 之后的一切都由 B 决定，而 B 的 value 是用 8 个样本估计的；MC 只用了 A 自己那 1 个样本。

Certainty-equivalence estimate：先拟合一个最佳的 Markov 模型，假设它完全正确，然后算它预测的 value。这正是 TD(0) 的 batch 解。

3.9 Markov 性

TD MC
利用 Markov property 不利用 Markov property
在 Markov 环境中通常更高效 在 non-Markov 环境中通常更有效

3.10 MC vs TD 的路径直觉（课件网格图）

  • MC：V(st)←rti+γrt+1i+γ2rt+2i+⋯——每一项都是本条路径上的 reward
  • TD：V(st)←rt+γ𝔼[rt+1′]+γ2𝔼[rt+2′′]+⋯——第一项来自本条路径，之后的是所有与本路径相交的路径的期望（通过 V(st+1) 间接用到别的 episode 的经验）

即 TD 能把不同 episode 的经验在共同经过的 state 处「拼接」起来，MC 不能。

3.11 DP vs MC vs TD

Vπ(s)=𝔼π[Gt∣st=s]=𝔼π[∑k=0∞γkrt+k ∣ st=s]=𝔼π[rt+γ∑k=0∞γkrt+k+1 ∣ st=s]=𝔼π[rt+γVπ(st+1)∣st=s]
  • MC：用 sample average return 近似第一行的期望
  • TD：两者结合——采样第三行的期望，并用当前估计 V(st+1) 代替真的 Vπ(st+1)
  • DP：期望由 model 提供（不采样），但同样用当前估计 V(st+1)
方法 更新 backup 图
MC V(st)←V(st)+α(Gt−V(st)) 一条路径走到底（到 terminal）
TD V(st)←V(st)+α(rt+γV(st+1)−V(st)) 一条路径只走一步
DP V(st)←𝔼π[rt+γV(st+1)] 所有分支，只走一步

4 · TD(λ)

4.1 n-step prediction

让 TD target 往后看 n 步：

n n-step return
1 （TD） Gt(1)=rt+γV(st+1)
2 Gt(2)=rt+γrt+1+γ2V(st+2)
⋮ ⋮
∞ （MC） Gt(∞)=rt+γrt+1+⋯+γT−trT

定义 n-step return：

Gt(n)=rt+γrt+1+⋯+γn−1rt+n−1+γnV(st+n)

n-step TD learning：

V(st)←V(st)+α(Gt(n)−V(st))

（n 越大，用的真实 reward 越多、bootstrap 越少：bias 小、variance 大。）

例：Large Random Walk（19 个 state，前 10 个 episode 的平均 RMS error 对 α 的曲线）：中间的 n（如 4、8）比 n=1（TD）和很大的 n（接近 MC）误差都小——推广到 n-step 可能比两个极端都好。

4.2 平均 n-step returns

  • 可以对不同 n 的 return 取平均，例如 12G(2)+12G(4)
  • 结合了两个不同时间步的信息
  • Q：能不能高效地结合所有时间步的信息？

4.3 λ-return

Gtλ=(1−λ)∑n=1∞λn−1Gt(n)
  • 用权重 (1−λ)λn−1 组合所有 n-step return
  • Forward-view TD(λ)：
V(st)←V(st)+α(Gtλ−V(st))

权重函数（课件图）：

  • 权重随 n 以 λ 几何衰减；总面积 = 1（(1−λ)∑n≥1λn−1=1）
  • 例如 3-step return 的权重是 (1−λ)λ2
  • episode 在 T 结束时，n≥T−t 的所有 n-step return 都等于实际 return，剩下的权重 λT−t−1 全给实际最终 return

两个极端：

  • λ=0：Gtλ=Gt(1)，就是 TD(0)
  • λ=1：所有权重都到最终 return，就是 MC

6 · 易错点

  • MC 的 target 是 Gt（实际 return），TD(0) 的 target 是 rt+γV(st+1)（估计）。
  • TD error 是 rt+γV(st+1)−V(st)，不是 Gt−V(st)。
  • MC 无偏、高方差；TD 有偏、低方差——别反过来。
  • DP bootstrap 但不 sample；MC sample 但不 bootstrap；TD 两者都有。
  • AB 例子里 MC 的 V(A)=0 不是「错的」，它是对观察数据的 MSE 最优；TD 的 0.75 是假设 Markov 性下的最大似然解。
  • λ-return 权重 (1−λ)λn−1 中是 n−1 次方；λ=0 是 TD(0) 不是 MC。
  • MC 只能用在 episodic 任务；TD 也能用在 continuing 任务。
