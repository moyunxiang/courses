1 · 复习：矩阵乘法与 A𝐞i

A∈Mm×n(K) represents T∈ℒ(Kn,Km) w.r.t. ℰ：A=(𝐚1⋯𝐚n)，𝐚i=T(𝐞i)∈Km（from ℰ）。

(A⋅B)ij=∑k=1naikbkjAm×n⋅Bn×r=( )m×r
  • Kn≃ℒ(K,Kn)：𝐯↦「n×1 matrix」（列向量也是矩阵）
  • A⋅𝐞i=𝐚i=T(𝐞i)（𝐞i 第 i 位是 1）

记号注意（课件框）：

对象 正确写法 错误写法
matrix A⋅𝐞i ✓ A(𝐞i) ✗
linear transformation T(𝐞i) ✓ T⋅𝐞i ✗

1.1 一般 basis

dim⁡V=n，dim⁡W=m，T:V→W。𝐯=c1𝐛1+⋯+cn𝐛n↦(c1,…,cn)T∈Kn，𝐛i↦𝐞i。

[T]ℬ′ℬ is an m×n matrix representing T w.r.t. ℬ（of V）and ℬ′（of W）；i-th column is the image of 𝐞i∈Kn：[T(𝐛i)]ℬ′∈Km。

（1st slide 的情况：A representing T∈ℒ(Kn,Km) 就是 A=[T]ℰℰ。）

2 · Trace

Def. A is n×n matrix ⇒ Trace of A：tr(A)=∑i=1naii (∈K)

Prop. A,B are n×n matrices：Tr(A⋅B)=Tr(B⋅A)

Pf.

∑i=1n(A⋅B)ii=∑i=1n∑k=1naikbki=∑k=1n∑i=1nbkiaik=∑k=1n(B⋅A)kk

关键：有限和可以交换求和顺序，数（K 里）的乘法可交换。∎

注意：虽然 AB≠BA，但它们的 trace 相等。（讲义：A、B 可以是 m×n 和 n×m，结论仍成立。）

3 · 矩阵乘法的列视角

Prop. A=(𝐚1 𝐚2 ⋯ 𝐚n)（m×n），𝐛=(b1,…,bn)T（n×1）：

A⋅𝐛=b1𝐚1+⋯+bn𝐚n
A⋅B=A⋅(𝐛1 𝐛2 ⋯ 𝐛r)=(A𝐛1  A𝐛2 ⋯ A𝐛r)

A𝐛 是 A 的列的 linear combination，系数是 𝐛 的分量。 这是理解 Col A 的关键。

4 · AB 对应复合

Prop. If A（m×n）rep. T∈ℒ(Kn,Km)（w.r.t. ℰ），then A⋅𝐛=T(𝐛). If B（n×r）rep. S∈ℒ(Kr,Kn)（w.r.t. ℰ），then A⋅B（m×r）represents T∘S∈ℒ(Kr,Km).

Pf. 𝐛∈Kn，𝐛=b1𝐞1+⋯+bn𝐞n：

T(𝐛)=b1T(𝐞1)+⋯+bnT(𝐞n)=b1𝐚1+⋯+bn𝐚n(T(𝐞i)=:𝐚i)=A⋅𝐛

[T∘S] 的第 i 列 = 𝐞i 的像：

(T∘S)(𝐞i)=T(S(𝐞i))=T(𝐛i)=A⋅𝐛i

（B rep. S ⇒ S(𝐞i)=𝐛i = B 的第 i 列）。所以 [T∘S] 的列就是 A𝐛1,…,A𝐛r，即 A⋅B。∎

Prop（一般 basis）. S∈ℒ(U,V)，T∈ℒ(V,W)；U,V,W 的 basis 分别为 ℬ,ℬ′,ℬ′′，𝐯∈V：

[T]ℬ′′ℬ′[𝐯]ℬ′=[T(𝐯)]ℬ′′[T∘S]ℬ′′ℬ=[T]ℬ′′ℬ′[S]ℬ′ℬ

交换图：U→SV→TW 下面对应 Kr→[S]Kn→[T]Km，整体是 [T][S]。中间的 basis ℬ′ 必须一致（像约分一样）。

6 · Null space、Column space、Row space

Def. T:Kn→Km rep. by A：

  • Ker T = null space Nul A={𝐱∈Kn:A⋅𝐱=𝟎}⊂Kn；dim⁡Nul A = nullity
  • Im T = column space Col A = span of columns of A ⊂Km；dim⁡Col A = rank （因为 Im T=Span{T(𝐞i)}，T(𝐞i)=A𝐞i=𝐚i）
  • Row A = span of rows of A（dim⁡Row A = row rank）

7 · Fundamental Theorem of Linear Algebra

Thm. (Column) Rank = Row Rank   ⟺   Rank A=Rank AT

（AT：(AT)ij:=Aji；A 的列变成 AT 的行）

Cor. If A is n×n：columns form a basis（dim n）  ⟺   rows form a basis（dim n）.

Thm（Rank–Nullity Theorem）. dim⁡V<∞，T∈ℒ(V,W)：

dim⁡Im(T)+dim⁡Ker(T)=dim⁡V
（矩阵版本：A∈Mm×n(K)，rank(A)+nullity(A)=dim⁡Kn=n）

直觉：domain 的 n 个维度，一部分被「压扁」成 0（kernel），剩下的「活下来」成为 image。

Cor. dim⁡V>dim⁡W ⇒ T cannot be injective.

（T injective   ⟺   Ker T={𝟎}   ⟺   nullity = 0 ⇒ dim⁡V=dim⁡Im(T)≤dim⁡W。）

Cor. dim⁡V<dim⁡W ⇒ T cannot be surjective.

（dim⁡Im(T)≤dim⁡V<dim⁡W。）

8 · Row operations（MATH2111 速通）

三种行变换：

  1. Interchange rows：𝐫i↔𝐫j，i≠j
  2. Add a scalar multiple of one row to another：𝐫i↦𝐫i+c𝐫j，i≠j，c∈K
  3. Rescale：𝐫i↦c𝐫i，c≠0

（Column operations similarly.）

Prop.

  • A↦A′ by row operations ⇒ Nul A=Nul A′
  • A↦A′ by column operations ⇒ Col A=Col A′

为什么？ 行变换就是对方程组 A𝐱=𝟎 做「交换方程、方程加减、方程乘非零数」，解集不变。列变换是把列做可逆的组合，张成的空间不变。

Def. Row echelon form（REF）：

  • 全零的行在最下面
  • 每个非零行的 pivot（第一个非零元）= 1，并且严格在上一行 pivot 的右边

Reduced（RREF）：再加上 每个含 pivot 的列，其他位置都是 0

★ Prop. Row operations do not change linear dependency of column vectors. A=(𝐚1⋯𝐚n)→row opsA′=(𝐚1′⋯𝐚n′)：

c1𝐚1+⋯+cn𝐚n=𝟎  ⟺  c1𝐚1′+⋯+cn𝐚n′=𝟎
（for the same ci!）

为什么？ c1𝐚1+⋯+cn𝐚n=A𝐜，所以这句话就是 Nul A=Nul A′。

Cor. RREF is unique!（不同的 RREF 会有不同的列线性关系）

这条 Prop 的用法：A 的哪些列 l.i.、某一列怎样由别的列组合，看 RREF 就知道——RREF 里一目了然（pivot 列就是标准基向量），而且关系和原矩阵一模一样。

9 · 用 RREF 证明两个定理

Thm. Rank A = Row Rank A

Pf.

  • Rank A = # l.i. columns in A ★= # l.i. columns in A′（RREF）= # pivots in RREF
  • Row Rank A = # l.i. rows in A = # 非零行 in RREF = # pivots in RREF（行变换不改变 row space；RREF 的非零行 l.i.）∎

Thm（Rank–Nullity）. dim⁡V<∞，T∈ℒ(V,W)：dim⁡Im T+dim⁡Ker T=dim⁡V

Pf（dim⁡W<∞）. 选 basis 化成矩阵 A：

  • dim⁡Im T=dim⁡Col A = # columns containing pivots in RREF
  • dim⁡Ker T=dim⁡Nul A = # columns NOT containing pivots（每个 free variable 给一个 basis 向量）
  • dim⁡V = # columns ✓

（dim⁡W=∞） Im(T) is still finite dimensional：T(V)=Span{T(𝐛i)}（𝐛i 是 V 的 basis）。把 target 缩成 T(V)，得 T′:V→T(V)，Ker T=Ker T′，Im T=Im T′，apply Thm to T′。∎

12 · 易错点

  • Col A 的 basis 取原矩阵的 pivot 列。
  • Nul A 的 basis 向量个数 = free variables 个数 = 非 pivot 列数。
  • Rank–nullity 里加起来等于 domain 的维数（列数 n），不是 target 的维数 m。
  • Tr(AB)=Tr(BA)，但一般 Tr(ABC)≠Tr(BAC)（只能循环移动）。
  • ddt 的矩阵是 (n+1)×(n+1)，最后一行全 0。
