0 · 这一讲在讲什么

  1. Sparse connectivity、receptive field、feature hierarchy、growing receptive field
  2. Shared weights / parameter sharing（平移鲁棒）
  3. Convolutional layer：多个 feature map 沿 depth 叠起来；tensor view；1×1 convolution
  4. 效率：参数共享大幅减少参数（课件 320×280 例）
  5. Nonlinearity（ReLU）、padding、pooling、stride
  6. 输出大小公式 Hout=⌊(Hin+2pad−K)/str⌋+1；网络组件；分类架构例

必会计算：输出尺寸（三个课件例：8→6、8→8、8→4）；参数量（Co×Ci×Kh×Kw + bias）；课件效率表（2 / >8×109 / 178,640）；架构例每层的尺寸（2562×3→⋯→16384→1000）。必会概念：为什么要 nonlinearity、padding、pooling；pooling 带来 spatial invariance；1×1 conv 的用途。

1 · Sparse Connectivity

  • 每个 hidden unit 只连到上一层的局部子集——它的 receptive field
  • 对比全连接：每个输出连所有输入

Multi-channel inputs：彩色图有 RGB 三个通道，核也有三个通道，跨通道求和。

Feature hierarchy：低层学边缘 → 中层学部件 → 高层学物体（例：face recognition：边 → 眼鼻 → 脸）。

Growing receptive field：越深的层，间接覆盖的输入区域越大——深层单元能「看到」整张图。

2 · Shared Weights / Parameter Sharing

  • 每个局部 receptive field 在整张图上复制；同色的权重共享（约束为相同）
  • 好处：不管特征出现在图中哪个位置都能检测到 ⇒ 对输入的平移鲁棒（robustness to shifts）

3 · Convolutional Layer

  • 多个 feature maps 看输入的同一区域（每个 filter 检测一种特征）
  • 把所有 filter 的 activation maps 沿 depth 维叠起来

3.1 Tensor view

对象 形状 课件例
Feature map（3-D tensor） C×H×W 输入 3×64×64
Filters（4-D tensor） Co×Ci×Kh×Kw 16×3×3×3
输出 Co×Ho×Wo 16×64×64

C：channels；Co / Ci：输出 / 输入通道；Kh,Kw：filter 高宽。

参数量（补充）：16×3×3×3=432 个权重 + 16 个 bias = 448。

3.2 1×1 convolution

  • 卷积时不看邻近像素（只在通道间做线性组合）
  • 用于 dimension reduction（减少通道数）

4 · 卷积的效率

课件例：输入 320×280，核 2×1（相邻两像素相减，检测边缘），输出 319×280。

实现 存储的浮点数
Convolution 2
Dense matrix 319⋅280⋅320⋅280>8×109
Sparse matrix 2⋅319⋅280=178,640

参数共享极大减少了要学的自由参数。

（核验：319×280=89,320，320×280=89,600，乘积 ≈8.0×109 ✓。）

5 · Nonlinearity

  • 卷积是线性运算 ⇒ 需要非线性；否则 2 个卷积层不比 1 个强（同 4.4 的论证）
  • 常用 ReLU：y=max⁡(z,0)

6 · Padding

不 padding：每层表示都会缩小，限制了层数。

Hout=Hin−Kh+1（例：8×8 输入，3×3 核 → 6×6）

Zero-padding：每层在边缘补 0 ⇒ 可以用任意深的卷积网络。

Hout=Hin+2padh−Kh+1（例：8×8，pad 1，3×3 → 8×8）

7 · Pooling

动机：一旦检测到特征，只有它相对于其他特征的大致位置才重要。

课件例：数字 7 的图像包含 (1) 左上方一段近似水平线段的端点、(2) 右上方一个角、(3) 下方一段近似竖直线段的端点——不同人写的 7 这些位置会变 ⇒ 需要 spatial invariance。

  • Max-pooling：每个子区域（如 2×2）输出最大值
  • 也有 average pooling

Pooling with downsampling（stride 2）：表示尺寸减半；减少下一层的计算和统计负担。

补充算例：(1320421101522234)，2×2 max-pool stride 2 → (4225)。

8 · Stride 与输出尺寸公式

Hout=⌊Hin+2padh−Khstr⌋+1

课件例：8×8 输入，3×3 filter，stride 2（pad 1）：⌊(8+2−3)/2⌋+1=⌊3.5⌋+1=4 ⇒ 4×4。

输入 K pad stride 输出
8 3 0 1 6
8 3 1 1 8
8 3 1 2 4

9 · 网络组件与架构

一个卷积层（complex layer terminology）= convolution stage（affine transform）→ detector stage（nonlinearity，如 ReLU）→ pooling stage。（simple layer terminology 把这三个各算一层。）

课件分类架构例：

层 输出尺寸
Input image 256×256×3
Convolution + ReLU 256×256×64
Pooling, stride 4 64×64×64
Convolution + ReLU 64×64×64
Pooling, stride 4 16×16×64
Reshape to vector 16×16×64=16,384
Matrix multiply 1,000
Softmax 1,000 class probabilities

典型结构：低层是交替的卷积和 max-pooling 层；最后是全连接层（传统 MLP）；输出用 classification error / cross-entropy 训练。

11 · 易错点

  • 尺寸公式里 padding 是 2×pad（两边），stride 除完要向下取整再 +1。
  • 参数量与输入的 H,W 无关，只和 Co,Ci,Kh,Kw 有关。
  • Pooling 没有可学习参数。
  • Stride 4 的 pooling 让每边缩小 4 倍（256→64）。
  • Flatten 后的长度 = H×W×C。
