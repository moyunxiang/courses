0 · 这一讲在讲什么

  1. Training error vs testing error：能测的 vs 想要的
  2. Overfitting 的形式定义
  3. Bias–variance tradeoff
  4. 验证方法：hold-out validation、k-fold cross-validation、leave-one-out

必会：两种 error 的公式；overfitting 定义（要有另一个 h′）；复杂 / 简单模型的 bias、variance 方向；k-fold 的步骤和计数（训练几次、每次用多少数据）。

1 · Training Error

设定：target function f；hypothesis / model h（例如某个神经网络）；实例分布 𝒟；从 𝒟 抽出的 training set S（大小 n）。

errorS(h)=1n∑x∈Sδ(f(x)≠h(x)),δ(⋅)={1f(x)≠h(x)0otherwise

= S 中被 h 分错的比例——我们能测量的。

问题：用几个 hidden units / layers？选 training error 最小的网络？——不对，我们想要的是 testing error 低的模型。

2 · Testing Error

error𝒟(h)=Pr⁡x∈𝒟[f(x)≠h(x)]

= 从 𝒟 随机抽一个实例被 h 分错的概率——我们想要的。

通常用 test set 估计：

errortest(h)=1∣testSet∣∑x∈testSetδ(f(x)≠h(x))
  • Test patterns 要独立抽取
  • Testing data 不能以任何方式用于学习 hypothesis

3 · 为什么不直接拟合训练集

  • Training set 只是从底层分布中抽出的一个样本
  • 不同的 training set 会得到不同的 classifier（回归同理）——完美拟合某一个样本，会把它的噪声也学进去

4 · Overfitting

h∈ℋ overfits the training data，如果存在另一个 h′∈ℋ 使得

  • h 在训练样本上的误差比 h′ 小，但
  • h 在整个实例分布上的误差比 h′ 大。

（模型复杂度 ↑：training error 一直 ↓；testing error 先 ↓ 后 ↑。）

5 · Bias–Variance Tradeoff

  • Bias：预测偏离真值的量
  • Variance：换一个训练集时模型变化的量
模型 Bias Variance 原因
太复杂（hidden units 太多） 小 大 能贴近真实函数，但对有限训练集敏感
太简单（hidden units 太少） 大 小 离真实函数远，但对训练集不敏感

6 · Hold-Out Validation

把可用的（训练）数据分成两部分：

  • Training set：学 hypothesis
  • Validation set：估计这个 hypothesis 在后续数据上的准确率

评估完后（可选）用全部数据训练最终 hypothesis。

Tradeoff：training set 越大 → hypothesis 越好；validation set 越大 → 误差估计越准。

例：留 13 做 validation，23 训练。

怎么让估计更可靠？用不同的子样本重复这个过程 → cross-validation。

7 · k-fold Cross-Validation

  1. 把 m 个样本分成 k 个不相交子集，每个大小 mk
  2. 跑 k 次学习，每次用一个子集做 validation，其余 k−1 个合并做训练
  3. 对 k 次 validation 表现取平均

性质：

  • 每个样本在 validation 中恰好用一次，在训练中用 k−1 次
  • 每次训练用了 1−1k 的数据，同时全部数据都参与了误差估计
  • 要训练 k 次；常用 k≈10
  • Leave-one-out（k=m）：每次在 m−1 个上训练、1 个上验证；适合小数据集

计数例：

  • m=100，k=5：每折验证 20、训练 80；训练 5 次
  • LOOCV，m=100：训练 100 次，每次 99 个
  • 用 k-fold 在 M 个候选模型中选：M⋅k 次训练，选平均 validation error 最低的

8 · 考点清单

考点 至少要会
errorS / error𝒟 / errortest 公式；能测 vs 想要
Test set 规则 独立；不能用于学习
Overfitting 定义中的 h′
Bias / variance 复杂 / 简单模型的方向
Hold-out 比例；两个「越大越好」的 tradeoff
k-fold 三步；每个样本验证一次；训练 k 次；LOOCV

9 · 易错点

  • 不能用 test set 调参 / 选模型——用 validation set。
  • Overfitting 是相对于另一个 hypothesis h′ 定义的。
  • 复杂模型：低 bias、高 variance（别反了）。
  • k-fold 中每个样本做 validation 恰好一次。
  • LOOCV 的 k=m，训练 m 次。
