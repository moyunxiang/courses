1 · 为什么要 unsupervised learning

1.1 三个例子

任务 输入 输出
Unsupervised image classification 一堆没标签的图片 自动分成 Parrot / Mountain / Leopard / Golden Fish 等组
Unsupervised image segmentation 图片，without labels 像素分成 Group 1、2、3、4…
Word clustering [Brown et al, 1992] 1 亿词的新闻原文 词聚成类：星期几一类、月份一类、物质（water gas coal…）一类、人名一类、亲属称谓一类…

1.2 Supervised vs unsupervised

回顾 supervised classification：训练数据 𝒟train 每行是 (ϕ(x),y)，例如

ϕ(x)1 ϕ(x)2 y
0 2 1
−2 0 1
1 −1 −1

学出 classifier f，对新点 [2,0] 预测 −1。三个 design decisions：hypothesis class、loss function、optimization algorithm（gradient descent）。

关键问题：loss function（zero-one / hinge / logistic，横轴都是 margin (𝐰⋅ϕ(x))y）里面有 y——要用 ground-truth label 衡量预测对不对。

  • Labeled data is expensive to obtain（要人工标）
  • Unlabeled data is very cheap to obtain（图片、视频、文本到处都是）

→ 所以想要一种不需要 y 的学习方法：clustering。

2 · Clustering 与 K-means

2.1 Clustering 的定义

课件例子：训练数据只有 ϕ(x)，没有 y：

ϕ(x)1 −2 0 −2 0 2 1 2 3
ϕ(x)2 1 1 3 3 −1 −2 −3 −2
输出 z 1 1 1 1 2 2 2 2

前四个点在左上角挤在一起，后四个在右下角 → 分成两类。Intuition: want to assign nearby points to same cluster.

Definition: clustering

  • Input：training points 𝒟train=[x1,…,xn]
  • Output：每个点的 cluster assignment 𝐳=[z1,…,zn]，其中 zi∈{1,…,K}

注意：cluster 的编号 1、2 本身没意义（和 supervised 的 y 不同），只表示「哪些点在同一组」。把所有 1 和 2 对调，聚类结果是一样的。

2.2 Centroids

  • 每个 cluster k=1,…,K 用一个 centroid（中心点）μk∈ℝd 代表
  • 𝝁=[μ1,…,μK]
  • Target：每个点 ϕ(xi) 要离它被分到的 centroid μzi 近

2.3 K-means objective

Losskmeans(𝐳,𝝁)=∑i=1n∥ϕ(xi)−μzi∥2
  • 对每个点，算它到自己 cluster 的 centroid 的距离平方，全部加起来。
  • Two objectives：同时要找最好的 K 个 centroid（𝝁），以及把每个点分给最近的 centroid（𝐳）。
  • 优化目标：
min⁡𝐳min⁡𝝁Losskmeans(𝐳,𝝁)

为什么不能直接用 gradient descent？

  • 𝐳 是离散的（每个 zi 只能取 1,…,K），没有梯度可言。
  • 但是：固定一个，另一个很好求。这就是 alternating minimization（交替最小化）。

2.4 Alternating minimization：两步各自怎么做

一维例子：点 0,2,10,12，K=2。

Step 1：已知 centroid，求 assignment。 设 μ1=1，μ2=11。每个点选距离平方最小的 centroid：

z1=arg⁡min⁡{(0−1)2,(0−11)2}=1z2=arg⁡min⁡{(2−1)2,(2−11)2}=1z3=arg⁡min⁡{(10−1)2,(10−11)2}=2z4=arg⁡min⁡{(12−1)2,(12−11)2}=2

→ Calculate distance between points and the centroids，取最近的。

为什么这样就是最优的 𝐳？ loss 是每个点各自一项相加，每个 zi 只影响自己那一项；让每一项都最小，总和就最小。

Step 2：已知 assignment，求 centroid。 已知 z1=z2=1，z3=z4=2：

μ1=12(0+2)=1,μ2=12(10+12)=11

→ Calculate the mean of each cluster.

为什么最优 centroid 是平均值？ 对 cluster k，要最小化 ∑i:zi=k∥ϕ(xi)−μk∥2。对 μk 求导令其为 0：

∑i:zi=k2(μk−ϕ(xi))=0⇒  μk=1∣{i:zi=k}∣∑i:zi=kϕ(xi)

也就是这个 cluster 所有点的平均。

2.5 从随机初始化开始：完整手算（考试重点）

点 0,2,10,12；Initialize μ1=0，μ2=2。

轮 Step 1：assignment Step 2：新 centroid Losskmeans（step 2 之后）
Iteration 1 0 → 1（离 0 最近）；2、10、12 → 2（离 2 更近） μ1=0，μ2=2+10+123=8 0+36+4+16=56
Iteration 2 0 → 1；2 → 1（到 0 是 4，到 8 是 36）；10、12 → 2 μ1=0+22=1，μ2=10+122=11 1+1+1+1=4
Iteration 3 assignment 和上一轮一样 centroid 不变 4

Converged. 课件原话：The assignments will remain the same in Iteration 3!

How do we determine if it is converged? —— 看 assignment 不再变化，或者 centroid 基本稳定。

解题套路：每一轮先写「每个点到每个 centroid 的距离平方」，取最小的定 zi；再对每组求平均得新 μk；直到 𝐳 不变。

补充（帮助理解，课件没单独列）：每一步都只会让 loss 变小或不变（step 1 对 𝐳 最优、step 2 对 𝝁 最优），所以一定会停下来；但停下来的可能是 local minimum，结果依赖初始化。

2.6 K-means 算法框

Algorithm: K-means

Initialize 𝝁=[μ1,…,μK] randomly.

For t=1,…,T:

  • Step 1: set assignments 𝐳 given 𝝁
    • For each point i=1,…,n:   zi←arg⁡min⁡k=1,…,K∥ϕ(xi)−μk∥2
  • Step 2: set centroids 𝝁 given 𝐳
    • For each cluster k=1,…,K:   μk←1∣{i:zi=k}∣∑i:zi=kϕ(xi)

课件图：K=3 的二维例子，平面被分成三块区域（每块里的点离该块的 centroid 最近），方块是 centroid。

最后回到开头：K-means 可以用来做 unsupervised image classification（对图片特征聚类）。

3 · Stochastic Gradient Descent

3.1 Gradient descent is slow

TrainLoss(𝐰)=1∣𝒟train∣∑(x,y)∈𝒟trainLoss(x,y,𝐰)

Algorithm: gradient descent

Initialize 𝐰=[0,…,0]

For t=1,…,T:   𝐰←𝐰−η∇𝐰TrainLoss(𝐰)

Problem：每更新一次，都要把所有训练样本的梯度算一遍再平均——数据多的时候非常贵。

3.2 SGD

Algorithm: stochastic gradient descent

Initialize 𝐰=[0,…,0]

For t=1,…,T:

  • For (x,y)∈𝒟train:   𝐰←𝐰−η∇𝐰Loss(x,y,𝐰)
  • 区别：梯度 只用一个训练样本（gradient with only one training sample），看一个样本就更新一次。
  • 一轮（一个 epoch）里，GD 更新 1 次，SGD 更新 ∣𝒟train∣ 次。
  • Problem：单个样本的梯度很 noisy（一个样本的方向不代表整体）→ unstable learning。

3.3 Mini-batch SGD

For t=1,…,T:

  • For {xi,yi}i=1B⊂𝒟train:   𝐰←𝐰−η∇𝐰Loss(x,y,𝐰)
  • 每次用 一个 batch（B 个样本） 的平均梯度。
  • A tradeoff between GD and SGD：less noisy gradients but still efficient。
方法 每次更新用多少样本 优点 缺点
GD 全部 ∣𝒟train∣ 梯度准、稳定 每步太贵
SGD 1 每步很便宜 梯度 noisy、不稳定
Mini-batch SGD B 折中：较稳定又高效 多一个超参数 batch size

4 · Generalization

4.1 Training loss 是不是好的（唯一的）目标？

目前的配方：hypothesis class f𝐰(x)=𝐰⋅ϕ(x) + 最小化 TrainLoss + SGD。问题：Is the training loss a good (only) objective to optimize?

A strawman algorithm（稻草人反例）：

Algorithm: rote learning（死记硬背）

  • Training：just store 𝒟train
  • Predictor f(x)：if (x,y)∈𝒟train, return y；else: segfault
  • 它让 training loss 完美为 0，但显然很差——没见过的输入就崩了。
  • 结论：training loss 为 0 不等于好模型。

4.2 Overfitting

  • 曲线：随 iteration 增加，loss 一直下降；Train accuracy 一直上升，Val accuracy 先升后平 / 下降。
  • 定义特征：training performance 上升，validation performance 下降。
  • 图示：overfitting 的边界弯弯曲曲、把每个训练点都绕进去；right fitting 是平滑的边界。

4.3 真正的目标

Key idea: the real learning objective Our goal is to minimize error on unseen future examples.

但我们手上没有「未来的样本」，次优选择：

Definition: test set Test set 𝒟test contains examples not used for training.

问题变成：How can we make a learning algorithm generalize well?（从 𝒟train 学的东西在 𝒟test 上也好用）

4.4 Strategy 1：Regularization

思路：𝐰∈ℝd，reduce the norm（length）∥𝐰∥——keep the weights small to avoid a complex model。

为什么权重小 ≈ 模型简单？ 权重大，输入稍微变一点，输出就剧烈变化，边界可以扭得很复杂去迁就每个训练点；权重小，函数更平滑。

Regularized objective：

min⁡𝐰  TrainLoss(𝐰)⏟data loss term+λ2∥𝐰∥2⏟regularization term
  • λ 越大，越强调「权重小」。

对应的 gradient descent：

𝐰←𝐰−η(∇𝐰TrainLoss(𝐰)⏟from data loss+λ𝐰⏟from regularization)

λ𝐰 怎么来的？

∇𝐰(λ2∥𝐰∥2)=∇𝐰(λ2∑jwj2)=λ𝐰

这里 12 就是为了求导后把 2 消掉。

直觉：整理一下，

𝐰←(1−ηλ)𝐰−η∇𝐰TrainLoss(𝐰)

每一步先把 𝐰 缩小一点（乘 1−ηλ），再按数据梯度走——所以也叫 weight decay。

课件第三页写成 L=Ldata+Lreg，Lreg=λ12∥W∥22，配了 λ=0.001,0.01,0.1 三张分类边界图：λ 越大，边界越平滑。→ Regularization helps reduce overfitting.

4.5 Strategy 2：Early stopping

Algorithm: gradient descent：Initialize 𝐰=[0,…,0]；For t=1,…,𝐓: 𝐰←𝐰−η∇𝐰TrainLoss(𝐰)

  • Idea：simply make T smaller（少迭代几轮，在 val 开始变差之前停）
  • Lesson：try to minimize the training error, but don't try too hard.

4.6 Summary

  • Not the real objective：training loss
  • Real objective：loss on unseen future examples（test loss）
  • Key idea: keep it simple —— try to minimize training error, but keep the model less complex.

5 · Best Practices

5.1 Choose your own adventure：有哪些设计选择

部分 可选项
Hypothesis class f𝐰(x)=sign(𝐰⋅ϕ(x)) Feature extractor ϕ：linear、quadratic；Architecture：number of layers、number of hidden units
Training objective 1∣𝒟train∣∑Loss(x,y,𝐰)+Reg(𝐰) Loss function：hinge、logistic；Regularization：none、L1、L2
Optimization algorithm（SGD） Number of iterations（epochs）；Step size：constant、decreasing、adaptive；Initialization：zero initialization with noisy variations、pre-training；Batch size

5.2 Hyperparameters

Definition: hyperparameters Design decisions（hypothesis class, training objective, optimization algorithm）that need to be made before running the learning algorithm.

  • 和参数 𝐰 的区别：𝐰 是算法学出来的；hyperparameter（如 λ、η、T、K、层数）是事先定好的。
  • 问题：How do we choose hyperparameters（model selection）？

5.3 Validation set

Definition: validation set A validation set is taken out of the training set and used to optimize hyperparameters.

数据划分：𝒟train ｜ 𝒟val（从 train 里切出来）｜ 𝒟test（单独）

  • For each setting of hyperparameters, train on 𝒟train, evaluate on 𝒟val
  • Select the hyperparameters（model）based on evaluation error on 𝒟val
  • The test data should never be used for hyperparameter tuning

为什么 test 不能用来调参？ 用 test 选超参数，就等于让 test 参与了「训练」，最后报告的 test error 会偏乐观，不再代表 unseen examples 上的表现。

5.4 K-Fold cross validation

  • Objective：making error of evaluation more reliable（只切一次 val，结果可能碰巧好 / 坏）
  • K-fold：把训练数据分成 K 份等大的子集；每一折（fold）用其中 K−1 份训练、剩下 1 份做 validation；轮流 K 次，每份都当一次 validation。
  • 课件图：5-fold，第 1～5 轮的 validation fold 依次是第 1～5 块。
  • If all partitions perform well, this is a good sign（计算这些 error 的 mean 和 variance）。

5.5 Model development strategy

Algorithm: Model development strategy

  • Split data into train, validation, test
  • Look at data to get intuition
  • Repeat:
    • Implement model / feature, adjust hyperparameters
    • Run learning algorithm
    • Check train and validation loss rates
    • Look at weights and prediction accuracy
  • Evaluate on test set to get final error rates

注意 test 只在最后用一次。

8 · 易错点

  • K-means 的 step 2 是平均值，不是中位数，也不是离得最近的那个数据点。
  • 手算时 step 1 用的是这一轮开始时的 centroid，不要边分配边更新 centroid。
  • 收敛条件是 assignment 不再变化，不是 loss 等于 0。
  • SGD 的「stochastic」指每次只用一个（随机的）样本估计梯度，不是指随机初始化。
  • Regularization 的梯度项是 λ𝐰（因为有 12），不是 2λ𝐰；如果题目没写 12，就是 2λ𝐰。
  • Validation set 是从 training set 里切出来的；test set 永远不用来调超参数。
  • Early stopping 是让 T 变小，不是让 η 变小。
