1 · Point Estimation 的术语

  • 用 statistic T、estimate T(𝐱)、estimator T(𝐗) 去估计未知 g(θ)；θ∈Θ（parameter space）
  • Estimand：要估的量，通常是 θ 的函数 g(θ)，例如 μ2、σμ
  • 为什么叫「点」估计：g(θ) 和 T 都是 ℝk 中的一个点
  • 只估计未知参数
  • Regular data = 有精确值的数据；irregular data = 不完整数据（例如只知道 ≥30），见 (iv) 章

2 · Likelihood 与 MLE

Motivating example（手写 10/6）：一个红球来自 Box 1（95 红 5 黑，θ=1）或 Box 2（5 红 95 黑，θ=2）。比较 P(红∣θ=1)=0.95 与 P(红∣θ=2)=0.05——选让观察到的数据最可能出现的 θ=1。

Statistical belief：我们（一次收集）得到的这组数据，是出现概率最高的那组。

Likelihood function：

L(θ)=L(θ1,…,θk∣𝐱)={∏i=1nf(xi∣θ)连续∏i=1np(xi∣θ)离散

离散时它就是 P(X1=x1,…,Xn=xn∣θ)。

L(θ) 是 θ 的函数，𝐱 固定——和联合 pdf / pmf 的角色对调。

Definition（mle）：θ^=arg⁡max⁡θ∈ΘL(θ)，即 L(θ^)=max⁡θ∈ΘL(θ)。MLE 也指 estimator / estimation。

Log likelihood ℓ(θ)=log⁡L(θ)：log 严格递增，最大值点相同；乘积变求和，求导方便。

目标永远是全局最大值！

3 · 求 MLE 的三种方法

3.1 (i) 有限参数空间：直接比较

Example 3：n=10，Binomial(1,θ)，L(θ)=θnxˉ(1−θ)n−nxˉ；只可能 θ∈{0.1,0.5}；数据 xˉ=0.4（4 个 1、6 个 0）：

L(0.1)=0.14(0.9)6=0.0000531441L(0.5)=0.54(0.5)6=0.0009765625

L(0.5) 更大 ⇒ θ^=0.5。

3.2 (ii) 求导

L 在 Θ 内部可微时，解 likelihood equations：∂∂θiL(θ)=0 或 ∂∂θiℓ(θ)=0，i=1,…,k。

注意：

  • 这只是必要条件——解是 critical points，未必是极值
  • 只找到内部的临界点；最大值在边界时导数不一定为 0 ⇒ 边界要单独检查

单参数特例（k=1）：若唯一临界点且该点 ℓ′′<0（或 L′′<0），则它一定是全局最大，不用检查边界。

Example 1：N(θ,1) 的 rs

L(θ)=∏12πe−(xi−θ)22=(2π)−n/2e−∑(xi−θ)22
0=ℓ′(θ)=ddθ[−n2log⁡(2π)]+ddθ[−∑(xi−θ)22]=∑(xi−θ)  ⇒  θ=xˉ

唯一解，且 ℓ′′(θ)=−n<0 ⇒ θ^=xˉ 是全局最大。

3.3 (iii) 直接最大化（找上界）

找 L 的全局上界，再证明只有一个点达到它。

Example 1（续）：

∑(xi−θ)2=∑(xi−xˉ+xˉ−θ)2=∑(xi−xˉ)2+n(xˉ−θ)2≥∑(xi−xˉ)2

等号 ⟺ θ=xˉ。所以 L(θ)≤L(xˉ)，等号 ⟺ θ=xˉ。（最大化 L ⟺ 最小化 ∑(xi−θ)2。）

3.4 Question：Uniform[0,θ] 的 MLE（必会）

f(x∣θ)=1θ，x∈[0,θ]，否则 0；θ∈(0,∞)。

用 indicator：I(x∈A)=1 若 x∈A，否则 0。f(x∣θ)=1θI(x∈[0,θ])。

L(θ)=∏i=1n1θI(xi∈[0,θ])=1θnI(all xi∈[0,θ])=1θnI(0≤x(1), x(n)≤θ)

（x(1)=min⁡，x(n)=max⁡。）

  • θ<x(n)：L=0
  • θ≥x(n)：L=θ−n，严格递减
θ^=X(n)=max⁡iXi

（不能用求导：ℓ′=−nθ≠0；最大值在「边界」θ=x(n)——正是方法 (ii) 警告的情况。）

补充：E(X(n))=nn+1θ ⇒ MLE 有偏（但渐近无偏）。

Remark：MLE 可能有偏；可能不存在于 Θ 中（尤其 Θ 是开集时）；可能不唯一。

3.5 Oct 08 板书：Remark 的三个例子

这三个例子分别对应 Remark 的三句话：MLE 可能不唯一、求导法的完整写法、MLE 可能落在边界。

Example 1（MLE 不唯一）：X∼U[θ−1,θ+1]，θ∈(−∞,∞)。

L(θ)=∏i=1n12I(xi∈[θ−1,θ+1])=12nI(θ−1≤all xi≤θ+1)=12nI(θ−1≤x(1)≤x(n)≤θ+1)=12nI(x(n)−1≤θ≤x(1)+1)
  • L 在区间 [x(n)−1, x(1)+1] 上恒等于 12n，区间外为 0。
  • ⇒ 区间内任意 θ 都是 MLE，MLE 不唯一。
  • 区间一定非空：所有观测都落在长度为 2 的区间里，所以 x(n)−x(1)≤2。
  • （补充）常见的取法是中点 x(1)+x(n)2。

Example 2（求导法的标准写法）：X∼Binomial(1,θ)，θ∈(0,1)；p(x∣θ)=θx(1−θ)1−x，x=0,1。

L(θ)=∏i=1nθxi(1−θ)1−xi=θ∑xi(1−θ)n−∑xiℓ(θ)=∑xiln⁡θ+(n−∑xi)ln⁡(1−θ)0=ℓ′(θ)=∑xiθ−n−∑xi1−θ ⇒ 唯一解 θ=xˉ
  • 二阶条件（板书留作「check it by yourselves」）：
ℓ′′(θ)=−∑xiθ2−n−∑xi(1−θ)2<0
  • 唯一临界点 + ℓ′′<0 ⇒ θ^=Xˉ。
  • （补充）xˉ=0 或 1（全是 0 或全是 1）时，xˉ∉(0,1)：L 在开区间上单调，MLE 不存在。这正是 Remark 说的「Θ 是开集时可能不存在」。

Example 3（参数空间受限 → 边界解）：X∼N(θ,1)，但 Θ=[0,∞)。（Θ=(−∞,∞) 时 θ^=xˉ，见 3.2 / 3.3。）

用 3.3 的分解 ∑(xi−θ)2=∑(xi−xˉ)2+n(θ−xˉ)2：

ℓ(θ)=−n2ln⁡(2π)−12∑i=1n(xi−xˉ)2−n2(θ−xˉ)2
  • ℓ 是以 xˉ 为顶点、开口向下的抛物线。
  • Case (i) xˉ≥0：顶点在 Θ 内，θ^=xˉ。
  • Case (ii) xˉ<0：在 [0,∞) 上 ℓ 递减，最大值在边界 θ=0。
θ^=max⁡{0, Xˉ}

要点：ℓ′(θ)=0 的唯一解 xˉ 不一定在 Θ 里。求导法得到的临界点要先检查是否属于参数空间，再比较边界。

4 · 数值 MLE（R）

多数情况写得出 ℓ(θ)，但 likelihood equation 没有显式解 → 数值方法。

Example：Cauchy(θ)：f(x∣θ)=π−1[1+(x−θ)2]−1

ℓ(θ)=−nlog⁡π−∑i=1nlog⁡[1+(xi−θ)2]ℓ′(θ)=∑i=1n2(xi−θ)1+(xi−θ)2=0

没有显式解。

Newton–Raphson：Taylor 0=1nℓ′(θ^)≈1nℓ′(θ)+(θ^−θ)1nℓ′′(θ) ⇒

θj+1=θj−ℓ′(θj)[ℓ′′(θj)]−1,j=0,1,2,…

R（maxLik 包）：

library(maxLik)
llik = function(par) {          # 单个观测的 log likelihood
  theta = par
  -log(pi) - log(1 + (x - theta)^2)
}
mle_cauchy = maxLik(logLik = llik, start = c(theta = 5), method = "NR")
summary(mle_cauchy)

课件结果（46 个 Cauchy(10.5) 模拟数据）：8 次迭代，estimate 10.5021，std. error 0.1941。

多参数（Normal，par 是向量）：

llik = function(par) {
  mu = par[1]; sigma = par[2]
  -0.5*log(2*pi) - log(sigma) - 0.5*(x - mu)^2/sigma^2
}
maxLik(logLik = llik, start = c(mu = 0, sigma = 1), method = "NR")
# mu 已知 = 2 时：start = c(mu = 2, sigma = 1), fixed = "mu"

课件结果（34 个 N(2,9) 数据）：μ^=2.2816、σ^=2.9050；固定 μ=2 时 σ^=2.9186。

（其他函数如 optim 也可以。）

5 · MLE 的性质

  • Invariance property：θ^i 是 θi 的 MLE ⇒ h(θ^1,…,θ^k) 是 h(θ1,…,θk) 的 MLE（h 已知）。例：σ^ 是 MLE ⇒ σ^2 是 σ2 的 MLE。
  • 大样本（regularity conditions 下）：θ^n 相合、渐近无偏、渐近有效、渐近正态：
n(θ^n−θ)→dNk(𝟎,IX−1(θ))

IX(θ)：k×k Fisher information matrix，(i,j) 元 E[(∂∂θilog⁡fX(X∣θ))(∂∂θjlog⁡fX(X∣θ))]。

6 · Fisher Information

衡量 random variable / data 中关于 θ 的信息量；有可加性等好性质。

Definition（单参数）：

IX1,…,Xn(θ)=E[(ddθlog⁡fX1,…,Xn(X1,…,Xn∣θ))2]

IXi(θ)=IXj(θ) 只说明信息量相同，不说明信息内容相同。

6.1 Regularity conditions

  1. ddθln⁡f(x1,…,xn∣θ) 对所有 𝐱、θ∈Θ 存在
  2. 对任意 statistic t，ddθ∫tf d𝐱=∫tddθf d𝐱（求导与积分可交换）
  3. 0<I(θ)<∞

条件 2 在 support 不依赖 θ 时成立（support ={x:f(x∣θ)>0}）。Uniform[0,θ] 违反——所以它的 MLE 不满足下面的渐近正态结论。

6.2 Lemma 1：score 均值为 0

EX[ddθln⁡fX(X∣θ)]=0

证明：∫f dx=1，两边求导（条件 2）：

0=∫ddθf(x∣θ) dx=∫[ddθln⁡f(x∣θ)]f(x∣θ) dx

（ddθf=f⋅ddθln⁡f。）

⇒ IX(θ)=Var(ddθln⁡fX(X∣θ))

6.3 Lemma 2：二阶导形式

若还有 d2dθ2ln⁡f 存在：

E[(ddθln⁡fX(X∣θ))2]=−E[d2dθ2ln⁡fX(X∣θ)]

证明：对 Lemma 1 的 0=∫(ddθln⁡f)f dx 再求导（乘积法则）：

0=∫[d2dθ2ln⁡f]f dx+∫[ddθln⁡f]dfdθ dx=E[ℓ′′]+∫[ddθln⁡f]2f dx

（第二项再用 dfdθ=fdln⁡fdθ。）把单个 X 换成一组随机变量，两个 Lemma 仍成立。

6.4 Lemma 3：可加性；rs 的信息

X,Y 独立且满足 regularity ⇒ IX,Y(θ)=IX(θ)+IY(θ)。

rs：IX1,…,Xn(θ)=nIX1(θ)——rs 的信息是一个观测的 n 倍。

6.5 Lemma 4：statistic 不会增加信息（不证）

IT(𝐗)(θ)≤I𝐗(θ)

Statistic 是数据压缩（n 维 → 低维），可能丢信息；没有 statistic 能比 rs 携带更多关于 θ 的信息。

6.6 补充算例

Poisson(λ)：ln⁡p=xln⁡λ−λ−ln⁡x!，d2dλ2ln⁡p=−xλ2 ⇒ I(λ)=EXλ2=1λ；MLE λ^=Xˉ，n(Xˉ−λ)→dN(0,λ)（和 CLT 一致 ✓）。

Exponential（rate β）：ln⁡f=ln⁡β−βx，d2dβ2=−1β2 ⇒ I(β)=1β2；MLE β^=1Xˉ，n(β^−β)→dN(0,β2)（和 delta method g(t)=1/t 的结果 σ2μ4=1/β21/β4=β2 一致 ✓）。

7 · MLE 渐近正态的证明（单参数）

在 regularity conditions 下：n(θ^n−θ)→dN(0,1IX(θ))。渐近方差 1nIX(θ) 正是 CRLB（下一章）。

证明：θ^n 解 ℓ′(θ)=0，ℓ(θ)=∑ln⁡f(Xi∣θ)。Taylor 展开 ℓ′(θ^n) 于 θ：

0=ℓ′(θ^n)≈ℓ′(θ)+(θ^n−θ)ℓ′′(θ)  ⇒  n(θ^n−θ)≈1nℓ′(θ)−1nℓ′′(θ)

分子：ddθln⁡f(Xi∣θ) i.i.d.，均值 0（Lemma 1），方差 IX(θ)；CLT：

1nℓ′(θ)=1n∑i=1nddθln⁡f(Xi∣θ)→dN(0,IX(θ))

分母：d2dθ2ln⁡f(Xi∣θ) i.i.d.；WLLN + Lemma 2：

−1nℓ′′(θ)=−1n∑d2dθ2ln⁡f(Xi∣θ)→p−E[d2dθ2ln⁡f(X1∣θ)]=IX(θ)

Slutsky：

n(θ^n−θ)→d1IX(θ)N(0,IX(θ))=N(0,1IX(θ))

或 nIX1/2(θ)(θ^n−θ)→dN(0,1)。

Observed Fisher information：IX(θ) 不易求（含未知 θ）→ 用 −1nℓ′′(θ^n) 代替；θ^n 相合 ⇒ −1nℓ′′(θ^n)→pIX(θ)：

−ℓ′′(θ^n) (θ^n−θ)=n−1nℓ′′(θ^n) (θ^n−θ)→dN(0,1)

（R 输出的 Std. error 就是 1/−ℓ′′(θ^)。）

8 · 大样本性质的定义

性质 定义 备注
Asymptotic unbiasedness lim⁡n→∞E(θ^n)=θ，∀θ 例：Sn2（σ2 的 MLE / MME）有限样本有偏，但渐近无偏
Consistency ∀ϵ>0，lim⁡P(∣θ^n−θ∣≤ϵ)=1，∀θ 即 θ^n→pθ
Asymptotic normality n(θ^n−θ)→dN(0,σθ2) 渐近方差 σθ2n；用于 CI、检验
  • 渐近无偏与相合一般互不蕴含
  • 渐近无偏 + Var(θ^n)→0 ⇒ 相合

⚠️ 课件 p.14 写的是 "Sn2 … is asymptotically biased"，按上下文（"can also enjoy a nice property"）应为 asymptotically unbiased：E(Sn2)=n−1nσ2→σ2。

10 · 易错点

  • 求导解出来的只是 critical point——要说明为什么是全局最大（唯一 + 二阶导负 / 上界法）。
  • Uniform[0,θ] 的 L 别忘了 indicator；MLE 是 max⁡Xi，不是 2Xˉ（那是矩估计）。
  • MLE 的渐近正态要 regularity conditions；support 依赖 θ 时不适用。
  • I𝐗(θ)=nIX1(θ)；渐近方差是 1nIX1。
  • Lemma 2 有负号：I=−E[ℓ′′]。
  • 「似然」不是概率分布（对 θ 积分不一定为 1）。
  • 求导得到的临界点可能不在 Θ 里（受限参数空间）→ 要和边界比较，如 max⁡{0,Xˉ}。
  • MLE 不唯一时要写出整个集合（如 [x(n)−1,x(1)+1]），不能只给一个点。
