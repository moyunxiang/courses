Common Mistakes

  • W=TAT−B, not Tfirst run−Tarr (that is response); gap method: first gap from Tarr.
  • ⚠️ Response convention: S26 official uses R=end of 1st run−Tarr (MLFQ: P1 runs 0–4⇒R1=4); textbook uses Tfirst run−Tarr (R1=0). Check the question / slide 5.13; state your convention if in doubt.
  • RR: new arrival and quantum expiry at the same t ⇒ new arrival enqueued first.
  • MLFQ: preempted ≠ full quantum ⇒ no demotion, back to head of own queue. ⚠️ Quantum reset vs resume after returning to head: not tested; read the question.
  • RM / EDF (S26 convention): missed job keeps running until done; RM priority by Ti, not Di.
  • Tie-breaks vary (paper had both "smaller ID first" and "larger ID first").
  • Circular buffer capacity =N−1; ordinary pipe ⇏ unrelated processes.
  • Code after successful exec never runs; fork fails ⇒ return −1 ⇒ parent takes else branch.
  • ⚠️ printf without \n before fork ⇒ stdout buffer copied ⇒ may print twice; past questions used \n or excluded it — check assumptions.
  • Microkernel slower; API ≯ syscall speed; multicore ≠ simpler scheduling.
